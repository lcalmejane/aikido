🔍 Service Locator Pattern

Centraliser la localisation des services dans un registre unique

🏗️ Architectural
📊 Intermédiaire
📍 Localisation de Services

📋 Définition

❌ Problème

Les clients doivent connaître l'emplacement et la méthode d'instanciation de chaque service. Cette connaissance dispersée rend le système difficile à maintenir et à tester.

✅ Solution

Le pattern Service Locator centralise la localisation des services dans un registre unique. Les clients demandent les services au locator sans connaître leur implémentation ou leur localisation.

🏗️ Structure UML

💡 Point clé : Le Service Locator centralise l'accès aux services et peut optimiser les performances avec un système de cache intégré.

// Interface pour les plugins
interface Plugin {
    getName(): string;
    getVersion(): string;
    execute(data: any): Promise<any>;
    isEnabled(): boolean;
}

// Implémentations de plugins
class AuthenticationPlugin implements Plugin {
    getName(): string { return 'authentication'; }
    getVersion(): string { return '1.0.0'; }
    
    async execute(data: { username: string, password: string }): Promise<any> {
        console.log(`🔐 Authentification de ${data.username}`);
        // Simulation d'authentification
        await new Promise(resolve => setTimeout(resolve, 100));
        return {
            success: data.password === 'secret',
            token: data.password === 'secret' ? 'jwt-token-123' : null
        };
    }
    
    isEnabled(): boolean { return true; }
}

class LoggingPlugin implements Plugin {
    private logs: string[] = [];
    
    getName(): string { return 'logging'; }
    getVersion(): string { return '2.1.0'; }
    
    async execute(data: { level: string, message: string }): Promise<any> {
        const timestamp = new Date().toISOString();
        const logEntry = `[${timestamp}] ${data.level.toUpperCase()}: ${data.message}`;
        this.logs.push(logEntry);
        console.log(`📝 ${logEntry}`);
        return { logged: true, totalLogs: this.logs.length };
    }
    
    isEnabled(): boolean { return true; }
    
    getLogs(): string[] { return [...this.logs]; }
}

class CachePlugin implements Plugin {
    private cache = new Map<string, { value: any, expiry: number }>();
    
    getName(): string { return 'cache'; }
    getVersion(): string { return '1.5.0'; }
    
    async execute(data: { action: 'get' | 'set' | 'delete', key: string, value?: any, ttl?: number }): Promise<any> {
        const now = Date.now();
        
        switch (data.action) {
            case 'get':
                const cached = this.cache.get(data.key);
                if (cached && cached.expiry > now) {
                    console.log(`💾 Cache HIT: ${data.key}`);
                    return { hit: true, value: cached.value };
                }
                console.log(`💾 Cache MISS: ${data.key}`);
                return { hit: false, value: null };
                
            case 'set':
                const expiry = now + (data.ttl || 300000); // 5 minutes par défaut
                this.cache.set(data.key, { value: data.value, expiry });
                console.log(`💾 Cache SET: ${data.key} (expire dans ${data.ttl || 300000}ms)`);
                return { stored: true };
                
            case 'delete':
                const deleted = this.cache.delete(data.key);
                console.log(`💾 Cache DELETE: ${data.key} (${deleted ? 'trouvé' : 'non trouvé'})`);
                return { deleted };
                
            default:
                throw new Error(`Action non supportée: ${data.action}`);
        }
    }
    
    isEnabled(): boolean { return true; }
}

// Service Locator
class ServiceLocator {
    private static instance: ServiceLocator;
    private services = new Map<string, any>();
    private factories = new Map<string, () => any>();
    private singletons = new Set<string>();
    
    private constructor() {}
    
    static getInstance(): ServiceLocator {
        if (!ServiceLocator.instance) {
            ServiceLocator.instance = new ServiceLocator();
        }
        return ServiceLocator.instance;
    }
    
    // Enregistrement d'un service
    registerService<T>(name: string, service: T): void {
        this.services.set(name, service);
        console.log(`📋 Service enregistré: ${name}`);
    }
    
    // Enregistrement d'une factory
    registerFactory<T>(name: string, factory: () => T, singleton: boolean = false): void {
        this.factories.set(name, factory);
        if (singleton) {
            this.singletons.add(name);
        }
        console.log(`🏭 Factory enregistrée: ${name} (${singleton ? 'singleton' : 'instance'})`);
    }
    
    // Récupération d'un service
    getService<T>(name: string): T {
        // Service déjà instancié
        if (this.services.has(name)) {
            return this.services.get(name) as T;
        }
        
        // Factory disponible
        if (this.factories.has(name)) {
            const factory = this.factories.get(name)!;
            const service = factory();
            
            // Si singleton, on le cache
            if (this.singletons.has(name)) {
                this.services.set(name, service);
            }
            
            return service as T;
        }
        
        throw new Error(`Service non trouvé: ${name}`);
    }
    
    // Vérification de l'existence d'un service
    hasService(name: string): boolean {
        return this.services.has(name) || this.factories.has(name);
    }
    
    // Suppression d'un service
    removeService(name: string): boolean {
        const hadService = this.services.delete(name);
        const hadFactory = this.factories.delete(name);
        this.singletons.delete(name);
        
        if (hadService || hadFactory) {
            console.log(`🗑️ Service supprimé: ${name}`);
        }
        
        return hadService || hadFactory;
    }
    
    // Liste des services disponibles
    listServices(): string[] {
        const services = Array.from(this.services.keys());
        const factories = Array.from(this.factories.keys());
        return [...new Set([...services, ...factories])];
    }
}

// Application utilisant le Service Locator
class PluginManager {
    private locator: ServiceLocator;
    
    constructor() {
        this.locator = ServiceLocator.getInstance();
        this.initializePlugins();
    }
    
    private initializePlugins(): void {
        // Enregistrement des plugins comme singletons
        this.locator.registerFactory('auth', () => new AuthenticationPlugin(), true);
        this.locator.registerFactory('logging', () => new LoggingPlugin(), true);
        this.locator.registerFactory('cache', () => new CachePlugin(), true);
    }
    
    async authenticateUser(username: string, password: string): Promise<any> {
        const authPlugin = this.locator.getService<AuthenticationPlugin>('auth');
        const loggingPlugin = this.locator.getService<LoggingPlugin>('logging');
        
        await loggingPlugin.execute({
            level: 'info',
            message: `Tentative d'authentification pour ${username}`
        });
        
        const result = await authPlugin.execute({ username, password });
        
        await loggingPlugin.execute({
            level: result.success ? 'info' : 'warning',
            message: `Authentification ${result.success ? 'réussie' : 'échouée'} pour ${username}`
        });
        
        return result;
    }
    
    async cacheData(key: string, value: any, ttl?: number): Promise<void> {
        const cachePlugin = this.locator.getService<CachePlugin>('cache');
        const loggingPlugin = this.locator.getService<LoggingPlugin>('logging');
        
        await cachePlugin.execute({ action: 'set', key, value, ttl });
        await loggingPlugin.execute({
            level: 'debug',
            message: `Données mises en cache: ${key}`
        });
    }
    
    async getCachedData(key: string): Promise<any> {
        const cachePlugin = this.locator.getService<CachePlugin>('cache');
        const result = await cachePlugin.execute({ action: 'get', key });
        
        const loggingPlugin = this.locator.getService<LoggingPlugin>('logging');
        await loggingPlugin.execute({
            level: 'debug',
            message: `Cache ${result.hit ? 'HIT' : 'MISS'} pour: ${key}`
        });
        
        return result.value;
    }
    
    getAvailablePlugins(): string[] {
        return this.locator.listServices();
    }
}

// Utilisation
async function demonstrateServiceLocator() {
    const pluginManager = new PluginManager();
    
    console.log('🔌 Plugins disponibles:', pluginManager.getAvailablePlugins());

}

// Interface pour les providers de configuration
interface ConfigProvider {
    public function getName(): string;
    public function load(): array;
    public function get(string $key, $default = null);
    public function set(string $key, $value): void;
    public function has(string $key): bool;
}

// Provider de configuration fichier
class FileConfigProvider implements ConfigProvider {
    private array $config = [];
    private string $filePath;
    
    public function __construct(string $filePath) {
        $this->filePath = $filePath;
        $this->load();
    }
    
    public function getName(): string {
        return 'file_config';
    }
    
    public function load(): array {
        if (file_exists($this->filePath)) {
            $content = file_get_contents($this->filePath);
            $this->config = json_decode($content, true) ?: [];
            echo "📁 Configuration chargée depuis: {$this->filePath}\n";
        } else {
            $this->config = [];
            echo "📁 Fichier de configuration non trouvé: {$this->filePath}\n";
        }
        return $this->config;
    }
    
    public function get(string $key, $default = null) {
        $keys = explode('.', $key);
        $value = $this->config;
        
        foreach ($keys as $k) {
            if (!isset($value[$k])) {
                return $default;
            }
            $value = $value[$k];
        }
        
        return $value;
    }
    
    public function set(string $key, $value): void {
        $keys = explode('.', $key);
        $config = &$this->config;
        
        foreach ($keys as $k) {
            if (!isset($config[$k])) {
                $config[$k] = [];
            }
            $config = &$config[$k];
        }
        
        $config = $value;
        echo "📝 Configuration mise à jour: {$key} = " . json_encode($value) . "\n";
    }
    
    public function has(string $key): bool {
        return $this->get($key) !== null;
    }
}

// Service Locator pour la configuration
class ConfigServiceLocator {
    private static ?ConfigServiceLocator $instance = null;
    private array $providers = [];
    private array $cache = [];
    
    private function __construct() {}
    
    public static function getInstance(): ConfigServiceLocator {
        if (self::$instance === null) {
            self::$instance = new ConfigServiceLocator();
        }
        return self::$instance;
    }
    
    public function registerProvider(ConfigProvider $provider): void {
        $this->providers[$provider->getName()] = $provider;
        echo "📋 Provider enregistré: {$provider->getName()}\n";
    }
    
    public function getProvider(string $name): ?ConfigProvider {
        return $this->providers[$name] ?? null;
    }
    
    public function hasProvider(string $name): bool {
        return isset($this->providers[$name]);
    }
    
    public function removeProvider(string $name): bool {
        if (isset($this->providers[$name])) {
            unset($this->providers[$name]);
            unset($this->cache[$name]);
            echo "🗑️ Provider supprimé: {$name}\n";
            return true;
        }
        return false;
    }
    
    public function getConfig(string $providerName, string $key, $default = null) {
        $cacheKey = "{$providerName}.{$key}";
        
        // Vérification du cache
        if (isset($this->cache[$cacheKey])) {
            echo "💾 Cache HIT: {$cacheKey}\n";
            return $this->cache[$cacheKey];
        }
        
        // Récupération depuis le provider
        if (!isset($this->providers[$providerName])) {
            throw new Exception("Provider non trouvé: {$providerName}");
        }
        
        $value = $this->providers[$providerName]->get($key, $default);
        
        // Mise en cache
        $this->cache[$cacheKey] = $value;
        echo "💾 Cache SET: {$cacheKey}\n";
        
        return $value;
    }
    
    public function setConfig(string $providerName, string $key, $value): void {
        if (!isset($this->providers[$providerName])) {
            throw new Exception("Provider non trouvé: {$providerName}");
        }
        
        $this->providers[$providerName]->set($key, $value);
        
        // Invalidation du cache
        $cacheKey = "{$providerName}.{$key}";
        unset($this->cache[$cacheKey]);
        echo "🗑️ Cache invalidé: {$cacheKey}\n";
    }
    
    public function listProviders(): array {
        return array_keys($this->providers);
    }
    
    public function clearCache(): void {
        $this->cache = [];
        echo "🧹 Cache vidé\n";
    }
}

// Application utilisant le Service Locator
class ConfigurationManager {
    private ConfigServiceLocator $locator;
    
    public function __construct() {
        $this->locator = ConfigServiceLocator::getInstance();
        $this->initializeProviders();
    }
    
    private function initializeProviders(): void {
        // Enregistrement des providers
        $this->locator->registerProvider(new FileConfigProvider('/etc/myapp/config.json'));
        $this->locator->registerProvider(new EnvironmentConfigProvider());
        $this->locator->registerProvider(new DatabaseConfigProvider('postgresql://localhost:5432/myapp'));
    }
    
    public function getAppName(): string {
        // Priorité: fichier > environnement > défaut
        return $this->locator->getConfig('file_config', 'app.name') 
            ?: $this->locator->getConfig('env_config', 'APP_NAME') 
            ?: 'Application';
    }
    
    public function getDatabaseConfig(): array {
        return [
            'host' => $this->locator->getConfig('env_config', 'DB_HOST', 'localhost'),
            'port' => (int)$this->locator->getConfig('env_config', 'DB_PORT', 5432),
            'name' => $this->locator->getConfig('env_config', 'DB_NAME', 'app'),
        ];
    }
    
    public function isFeatureEnabled(string $feature): bool {
        return (bool)$this->locator->getConfig('db_config', "features.{$feature}", false);
    }
    
    public function getUserLimit(): int {
        return (int)$this->locator->getConfig('db_config', 'limits.max_users', 100);
    }
    
    public function getTheme(): string {
        return $this->locator->getConfig('db_config', 'ui.theme', 'light');
    }
    
    public function updateFeature(string $feature, bool $enabled): void {
        $this->locator->setConfig('db_config', "features.{$feature}", $enabled);
    }
    
    public function getAvailableProviders(): array {
        return $this->locator->listProviders();
    }
}

// Interface pour les drivers de base de données
interface DatabaseDriver {
    String getName();
    String getVersion();
    boolean connect(String connectionString);
    void disconnect();
    boolean isConnected();
    ResultSet executeQuery(String sql);
    int executeUpdate(String sql);
}

// Classe pour simuler les résultats
class ResultSet {
    private final String[] columns;
    private final Object[][] data;
    private int currentRow = -1;
    
    public ResultSet(String[] columns, Object[][] data) {
        this.columns = columns;
        this.data = data;
    }
    
    public boolean next() {
        currentRow++;
        return currentRow < data.length;
    }
    
    public String getString(String columnName) {
        int columnIndex = getColumnIndex(columnName);
        return (String) data[currentRow][columnIndex];
    }
    
    public int getInt(String columnName) {
        int columnIndex = getColumnIndex(columnName);
        return (Integer) data[currentRow][columnIndex];
    }
    
    private int getColumnIndex(String columnName) {
        for (int i = 0; i < columns.length; i++) {
            if (columns[i].equals(columnName)) {
                return i;
            }
        }
        throw new IllegalArgumentException("Colonne non trouvée: " + columnName);
    }
}

// Driver PostgreSQL
class PostgreSQLDriver implements DatabaseDriver {
    private boolean connected = false;
    private String connectionString;
    
    @Override
    public String getName() {
        return "PostgreSQL";
    }
    
    @Override
    public String getVersion() {
        return "42.3.1";
    }
    
    @Override
    public boolean connect(String connectionString) {
        this.connectionString = connectionString;
        this.connected = true;
        System.out.println("🐘 Connexion PostgreSQL: " + connectionString);
        return true;
    }
    
    @Override
    public void disconnect() {
        this.connected = false;
        System.out.println("🐘 Déconnexion PostgreSQL");
    }
    
    @Override
    public boolean isConnected() {
        return connected;
    }
    
    @Override
    public ResultSet executeQuery(String sql) {
        if (!connected) {
            throw new IllegalStateException("Non connecté à la base de données");
        }
        
        System.out.println("🐘 Exécution requête PostgreSQL: " + sql);
        
        // Simulation de résultats
        if (sql.toLowerCase().contains("select")) {
            String[] columns = {"id", "name", "email"};
            Object[][] data = {
                {1, "Alice", "alice@example.com"},
                {2, "Bob", "bob@example.com"},
                {3, "Charlie", "charlie@example.com"}
            };
            return new ResultSet(columns, data);
        }
        
        return null;
    }
    
    @Override
    public int executeUpdate(String sql) {
        if (!connected) {
            throw new IllegalStateException("Non connecté à la base de données");
        }
        
        System.out.println("🐘 Exécution mise à jour PostgreSQL: " + sql);
        return 1; // Simulation d'une ligne affectée
    }
}

    @Override
    public ResultSet executeQuery(String sql) {

            throw new IllegalStateException("Non connecté à la base de données");

        System.out.println("📁 Exécution requête SQLite: " + sql);
        
        if (sql.toLowerCase().contains("select")) {

                {1, "config1", "value1"},
                {2, "config2", "value2"}
            };
            return new ResultSet(columns, data);
        }
        
        return null;
    }
    
    @Override
    public int executeUpdate(String sql) {
        if (!connected) {
            throw new IllegalStateException("Non connecté à la base de données");
        }
        
        System.out.println("📁 Exécution mise à jour SQLite: " + sql);
        return 1;
    }
}

// Service Locator pour les drivers
class DriverServiceLocator {
    private static DriverServiceLocator instance;
    private final Map drivers = new HashMap<>();
    private final Map> factories = new HashMap<>();
    
    private DriverServiceLocator() {}
    
    public static DriverServiceLocator getInstance() {
        if (instance == null) {
            instance = new DriverServiceLocator();
        }
        return instance;
    }
    
    public void registerDriver(String name, DatabaseDriver driver) {
        drivers.put(name, driver);
        System.out.println("📋 Driver enregistré: " + name);
    }
    
    public void registerDriverFactory(String name, Supplier factory) {
        factories.put(name, factory);
        System.out.println("🏭 Factory de driver enregistrée: " + name);
    }
    
    public DatabaseDriver getDriver(String name) {
        // Driver déjà instancié
        if (drivers.containsKey(name)) {
            return drivers.get(name);
        }
        
        // Factory disponible
        if (factories.containsKey(name)) {
            DatabaseDriver driver = factories.get(name).get();
            drivers.put(name, driver); // Cache du driver
            return driver;
        }
        
        throw new IllegalArgumentException("Driver non trouvé: " + name);
    }
    
    public boolean hasDriver(String name) {
        return drivers.containsKey(name) || factories.containsKey(name);
    }
    
    public void removeDriver(String name) {
        DatabaseDriver driver = drivers.remove(name);
        if (driver != null && driver.isConnected()) {
            driver.disconnect();
        }
        factories.remove(name);
        System.out.println("🗑️ Driver supprimé: " + name);
    }
    
    public Set listDrivers() {
        Set allDrivers = new HashSet<>(drivers.keySet());
        allDrivers.addAll(factories.keySet());
        return allDrivers;
    }
}

// Gestionnaire de base de données utilisant le Service Locator
class DatabaseManager {
    private final DriverServiceLocator locator;
    
    public DatabaseManager() {
        this.locator = DriverServiceLocator.getInstance();
        initializeDrivers();
    }
    
    private void initializeDrivers() {
        // Enregistrement des factories de drivers
        locator.registerDriverFactory("postgresql", PostgreSQLDriver::new);
        locator.registerDriverFactory("mysql", MySQLDriver::new);
        locator.registerDriverFactory("sqlite", SQLiteDriver::new);
    }
    
    public boolean connectToDatabase(String driverName, String connectionString) {
        try {
            DatabaseDriver driver = locator.getDriver(driverName);
            return driver.connect(connectionString);
        } catch (Exception e) {
            System.err.println("❌ Erreur de connexion: " + e.getMessage());
            return false;
        }
    }
    
    public void disconnectFromDatabase(String driverName) {
        try {
            DatabaseDriver driver = locator.getDriver(driverName);
            if (driver.isConnected()) {
                driver.disconnect();
            }
        } catch (Exception e) {
            System.err.println("❌ Erreur de déconnexion: " + e.getMessage());
        }
    }
    
    public void executeQuery(String driverName, String sql) {
        try {
            DatabaseDriver driver = locator.getDriver(driverName);
            ResultSet rs = driver.executeQuery(sql);
            
            if (rs != null) {
                System.out.println("📊 Résultats de la requête:");
                while (rs.next()) {
                    // Affichage des résultats (exemple)
                    try {
                        System.out.println("  ID: " + rs.getInt("id") + 
                                         ", Nom: " + rs.getString("name"));
                    } catch (Exception e) {
                        // Colonnes différentes selon le driver
                        System.out.println("  Ligne de résultat trouvée");
                    }
                }
            }
        } catch (Exception e) {
            System.err.println("❌ Erreur d'exécution: " + e.getMessage());
        }
    }
    
    public void executeUpdate(String driverName, String sql) {
        try {
            DatabaseDriver driver = locator.getDriver(driverName);
            int rowsAffected = driver.executeUpdate(sql);
            System.out.println("✅ " + rowsAffected + " ligne(s) affectée(s)");
        } catch (Exception e) {
            System.err.println("❌ Erreur de mise à jour: " + e.getMessage());
        }
    }
    
    public Set getAvailableDrivers() {
        return locator.listDrivers();
    }
    
    public String getDriverInfo(String driverName) {
        try {
            DatabaseDriver driver = locator.getDriver(driverName);
            return driver.getName() + " v" + driver.getVersion() + 
                   " (Connecté: " + driver.isConnected() + ")";
        } catch (Exception e) {
            return "Driver non disponible: " + e.getMessage();
        }
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Centralisation : Point unique de localisation des services
  • Découplage : Clients indépendants des implémentations concrètes
  • Flexibilité : Changement de services à l'exécution
  • Cache intégré : Performances optimisées avec mise en cache
  • Configuration dynamique : Enregistrement/suppression de services

❌ Inconvénients

  • Couplage au locator : Dépendance forte au service locator
  • Tests difficiles : Difficulté d'injection de mocks
  • Point de défaillance : Locator devient critique
  • Dépendances cachées : Services requis non explicites
  • Anti-pattern potentiel : Peut masquer les vraies dépendances

🎯 Cas d'usage recommandés

✅ Recommandé pour

  • Applications avec nombreux services interchangeables
  • Systèmes de plugins dynamiques
  • Applications legacy nécessitant une refactorisation progressive
  • Environnements où l'injection de dépendance est complexe
  • Services avec cycle de vie complexe

❌ Éviter pour

  • Nouvelles applications avec DI disponible
  • Applications nécessitant des tests unitaires extensifs
  • Systèmes avec dépendances simples et statiques
  • Projets privilégiant l'explicité des dépendances
  • Applications avec contraintes de performance strictes

🔄 Alternatives et variantes

💉 Dependency Injection

Inversion de contrôle avec injection explicite des dépendances

🏭 Abstract Factory

Création de familles d'objets liés sans spécifier leurs classes

📋 Registry Pattern

Registre global pour stocker et récupérer des objets

🎭 Strategy Pattern

Sélection d'algorithmes à l'exécution

🧠 Biais cognitifs associés

🎯 Biais de confirmation

🔨 Loi de l'instrument

Utiliser le Service Locator comme solution universelle

🏗️ Complexité accidentelle

Ajouter un layer d'indirection sans bénéfice réel

🎮 Exercice pratique

Scénario : Système de logging multi-destinations

Vous développez une application qui doit logger vers différentes destinations :

  • Fichiers locaux (rotation automatique)
  • Base de données (pour requêtes complexes)
  • Services cloud (AWS CloudWatch, Azure Monitor)
  • Systèmes de monitoring (Elasticsearch, Splunk)

Question : Quel est le principal avantage du Service Locator dans ce contexte ?

🤔 Pas directement.

Le Service Locator peut améliorer les performances via la mise en cache, mais ce n'est pas son avantage principal dans ce contexte de logging multi-destinations.

✅ Excellente réponse !

La configuration dynamique est effectivement l'avantage clé du Service Locator ici. Il permet :

  • Ajout/suppression de destinations à l'exécution
  • Changement de configuration sans redémarrage
  • Activation/désactivation conditionnelle des loggers
  • Basculement automatique en cas de panne d'une destination

Dans votre système de logging, vous pourriez désactiver CloudWatch en cas de problème réseau et activer le logging local, tout cela dynamiquement via le Service Locator.

❌ Incorrect.

Le Service Locator ne réduit pas la consommation mémoire. Au contraire, il maintient un registre des services qui peut consommer de la mémoire supplémentaire.

Bien que le Service Locator puisse simplifier l'accès aux services, il peut aussi masquer les dépendances et rendre le code moins explicite. La configuration dynamique est un avantage plus significatif.
