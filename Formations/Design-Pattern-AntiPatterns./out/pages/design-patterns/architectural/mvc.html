🏗️ MVC Pattern

Séparer la logique métier, la présentation et le contrôle

🎨 Design Patterns
⭐ Difficulté: Intermédiaire
⏱️ 20 min
🏗️ Architectural

🎯 Définition

Le MVC (Model-View-Controller) est un pattern architectural qui sépare une application en trois composants interconnectés : le Modèle (données et logique métier), la Vue (interface utilisateur) et le Contrôleur (logique de contrôle). Cette séparation permet de développer, tester et maintenir chaque partie indépendamment.

❌ Problème Résolu

  • Couplage fort entre interface et logique métier
  • Code difficile à tester et maintenir
  • Réutilisation limitée des composants
  • Évolution complexe de l'interface utilisateur

✅ Solution Apportée

  • Séparation claire des responsabilités
  • Testabilité améliorée de chaque composant
  • Réutilisation du modèle avec différentes vues
  • Développement parallèle des équipes
💡 Analogie : Comme un restaurant où le chef (Modèle) prépare les plats, le serveur (Contrôleur) prend les commandes et coordonne, et la salle (Vue) présente l'expérience aux clients.

🏗️ Structure UML

Model
- data: any
- observers: Observer[]
+ getData(): any
+ setData(data: any): void
+ addObserver(observer: Observer): void
+ notifyObservers(): void
View
- model: Model
- controller: Controller
+ render(): void
+ update(): void
+ handleUserInput(): void
Controller
- model: Model
- view: View
+ handleRequest(request: Request): void
+ updateModel(data: any): void
+ updateView(): void

Éléments Clés

  • Model : Gère les données et la logique métier
  • View : Responsable de l'affichage et de l'interface utilisateur
  • Controller : Coordonne les interactions entre Model et View
  • Observer Pattern : Le Model notifie les changements aux Views

// Interface Observer pour le pattern Observer
interface Observer {
    update(): void;
}

// Model - Gestion des données et logique métier
class TaskModel {
    private tasks: Task[] = [];
    private observers: Observer[] = [];

    addObserver(observer: Observer): void {
        this.observers.push(observer);
    }

    removeObserver(observer: Observer): void {
        const index = this.observers.indexOf(observer);
        if (index > -1) {
            this.observers.splice(index, 1);
        }
    }

    notifyObservers(): void {
        this.observers.forEach(observer => observer.update());
    }

    // Logique métier
    addTask(title: string, description: string): void {
        const task: Task = {
            id: Date.now(),
            title,
            description,
            completed: false,
            createdAt: new Date()
        };
        
        this.tasks.push(task);
        this.notifyObservers();
    }

    removeTask(id: number): void {
        this.tasks = this.tasks.filter(task => task.id !== id);
        this.notifyObservers();
    }

    toggleTask(id: number): void {
        const task = this.tasks.find(t => t.id === id);
        if (task) {
            task.completed = !task.completed;
            this.notifyObservers();
        }
    }

    getTasks(): Task[] {
        return [...this.tasks]; // Copie pour éviter les modifications externes
    }

    getCompletedTasks(): Task[] {
        return this.tasks.filter(task => task.completed);
    }

    getPendingTasks(): Task[] {
        return this.tasks.filter(task => !task.completed);
    }
}

// Interface Task
interface Task {
    id: number;
    title: string;
    description: string;
    completed: boolean;
    createdAt: Date;
}

// View - Interface utilisateur
class TaskView implements Observer {
    private model: TaskModel;
    private controller: TaskController;
    private container: HTMLElement;

    constructor(model: TaskModel, controller: TaskController, containerId: string) {
        this.model = model;
        this.controller = controller;
        this.container = document.getElementById(containerId)!;
        
        // S'enregistrer comme observateur du modèle
        this.model.addObserver(this);
        
        this.initializeView();
        this.bindEvents();
    }

    private initializeView(): void {
        this.container.innerHTML = `
            

                
Gestionnaire de Tâches

                
                

                    
                    
                    
                

                
                

                    0 tâches total |
                    0 en cours |
                    0 terminées
                

                
                

            

        `;
    }

    private bindEvents(): void {
        const form = document.getElementById('task-form') as HTMLFormElement;
        form.addEventListener('submit', (e) => {
            e.preventDefault();
            this.handleAddTask();
        });
    }

    private handleAddTask(): void {
        const titleInput = document.getElementById('task-title') as HTMLInputElement;
        const descriptionInput = document.getElementById('task-description') as HTMLTextAreaElement;
        
        const title = titleInput.value.trim();
        const description = descriptionInput.value.trim();
        
        if (title) {
            // Déléguer au contrôleur
            this.controller.addTask(title, description);
            
            // Réinitialiser le formulaire
            titleInput.value = '';
            descriptionInput.value = '';
        }
    }

    // Méthode Observer - appelée quand le modèle change
    update(): void {
        this.render();
    }

    private render(): void {
        const tasks = this.model.getTasks();
        const taskList = document.getElementById('task-list')!;
        
        // Mettre à jour les statistiques
        this.updateStats();
        
        // Rendre la liste des tâches
        taskList.innerHTML = tasks.map(task =>
            `

                

                    
${task.title}

                    
${task.description}

                    Créée le ${task.createdAt.toLocaleDateString()}
                

                

                    
                    
                

            
`
        ).join('');
    }

    private updateStats(): void {
        const allTasks = this.model.getTasks();
        const pendingTasks = this.model.getPendingTasks();
        const completedTasks = this.model.getCompletedTasks();
        
        document.getElementById('total-tasks')!.textContent = allTasks.length.toString();
        document.getElementById('pending-tasks')!.textContent = pendingTasks.length.toString();
        document.getElementById('completed-tasks')!.textContent = completedTasks.length.toString();
    }
}

// Controller - Logique de contrôle
class TaskController {
    private model: TaskModel;
    private view: TaskView;

    constructor(model: TaskModel) {
        this.model = model;
    }

    setView(view: TaskView): void {
        this.view = view;
    }

    // Actions déclenchées par la vue
    addTask(title: string, description: string): void {
        // Validation
        if (!title.trim()) {
            alert('Le titre est requis');
            return;
        }
        
        // Déléguer au modèle
        this.model.addTask(title, description);
    }

    removeTask(id: number): void {
        if (confirm('Êtes-vous sûr de vouloir supprimer cette tâche ?')) {
            this.model.removeTask(id);
        }
    }

    toggleTask(id: number): void {
        this.model.toggleTask(id);
    }

    // Actions pour les requêtes externes (API, etc.)
    loadTasks(tasks: Task[]): void {
        // Logique pour charger des tâches depuis une source externe
        tasks.forEach(task => {
            this.model.addTask(task.title, task.description);
        });
    }

    exportTasks(): Task[] {
        return this.model.getTasks();
    }
}

// Initialisation de l'application MVC
function initializeTaskApp(): void {
    // Créer les composants
    const model = new TaskModel();
    const controller = new TaskController(model);
    const view = new TaskView(model, controller, 'app-container');
    
    // Connecter le contrôleur à la vue
    controller.setView(view);
    
    // Exposer le contrôleur globalement pour les événements HTML
    (window as any).taskController = controller;
}

// Démarrer l'application
document.addEventListener('DOMContentLoaded', initializeTaskApp);


<?php

// Interface Observer
interface Observer {
    public function update(): void;
}

// Model - Gestion des données et logique métier
class TaskModel {
    private array $tasks = [];
    private array $observers = [];
    private int $nextId = 1;

    public function addObserver(Observer $observer): void {
        $this->observers[] = $observer;
    }

    public function removeObserver(Observer $observer): void {
        $key = array_search($observer, $this->observers, true);
        if ($key !== false) {
            unset($this->observers[$key]);
        }
    }

    public function notifyObservers(): void {
        foreach ($this->observers as $observer) {
            $observer->update();
        }
    }

    // Logique métier
    public function addTask(string $title, string $description): void {
        $task = [
            'id' => $this->nextId++,
            'title' => $title,
            'description' => $description,
            'completed' => false,
            'created_at' => new DateTime()
        ];
        
        $this->tasks[] = $task;
        $this->notifyObservers();
    }

    public function removeTask(int $id): void {
        $this->tasks = array_filter($this->tasks, function($task) use ($id) {
            return $task['id'] !== $id;
        });
        
        $this->tasks = array_values($this->tasks); // Réindexer
        $this->notifyObservers();
    }

    public function toggleTask(int $id): void {
        foreach ($this->tasks as &$task) {
            if ($task['id'] === $id) {
                $task['completed'] = !$task['completed'];
                $this->notifyObservers();
                break;
            }
        }
    }

    public function getTasks(): array {
        return $this->tasks;
    }

    public function getCompletedTasks(): array {
        return array_filter($this->tasks, function($task) {
            return $task['completed'];
        });
    }

    public function getPendingTasks(): array {
        return array_filter($this->tasks, function($task) {
            return !$task['completed'];
        });
    }
}

// View - Interface utilisateur
class TaskView implements Observer {
    private TaskModel $model;
    private TaskController $controller;

    public function __construct(TaskModel $model, TaskController $controller) {
        $this->model = $model;
        $this->controller = $controller;
        
        // S'enregistrer comme observateur
        $this->model->addObserver($this);
    }

    public function update(): void {
        $this->render();
    }

    public function render(): void {
        $tasks = $this->model->getTasks();
        $pendingCount = count($this->model->getPendingTasks());
        $completedCount = count($this->model->getCompletedTasks());
        $totalCount = count($tasks);
        
        echo "<div class='task-app'>";
        echo "<h2>Gestionnaire de Tâches</h2>";
        
        // Formulaire d'ajout
        echo "<form method='POST' action='?action=add'>";
        echo "<input type='text' name='title' placeholder='Titre de la tâche' required>";
        echo "<textarea name='description' placeholder='Description'></textarea>";
        echo "<button type='submit'>Ajouter Tâche</button>";
        echo "</form>";
        
        // Statistiques
        echo "<div class='task-stats'>";
        echo "$totalCount tâches total | $pendingCount en cours | $completedCount terminées";
        echo "</div>";
        
        // Liste des tâches
        echo "<div class='task-list'>";
        foreach ($tasks as $task) {
            $completedClass = $task['completed'] ? 'completed' : '';
            $toggleText = $task['completed'] ? '↶ Réactiver' : '✓ Terminer';
            
            echo "<div class='task-item $completedClass'>";
            echo "<div class='task-content'>";
            echo "<h4>" . htmlspecialchars($task['title']) . "</h4>";
            echo "<p>" . htmlspecialchars($task['description']) . "</p>";
            echo "<small>Créée le " . $task['created_at']->format('d/m/Y') . "</small>";
            echo "</div>";
            echo "<div class='task-actions'>";
            echo "<a href='?action=toggle&id=" . $task['id'] . "' class='toggle-btn'>$toggleText</a>";
            echo "<a href='?action=delete&id=" . $task['id'] . "' class='delete-btn' onclick='return confirm(\"Supprimer cette tâche ?\")'>🗑️ Supprimer</a>";
            echo "</div>";
            echo "</div>";
        }
        echo "</div>";
        echo "</div>";
    }

    public function renderJson(): string {
        $tasks = $this->model->getTasks();
        return json_encode([
            'tasks' => $tasks,
            'stats' => [
                'total' => count($tasks),
                'pending' => count($this->model->getPendingTasks()),
                'completed' => count($this->model->getCompletedTasks())
            ]
        ]);
    }
}

// Controller - Logique de contrôle
class TaskController {
    private TaskModel $model;
    private TaskView $view;

    public function __construct(TaskModel $model) {
        $this->model = $model;
    }

    public function setView(TaskView $view): void {
        $this->view = $view;
    }

    // Gestion des requêtes HTTP
    public function handleRequest(): void {
        $action = $_GET['action'] ?? 'index';
        
        switch ($action) {
            case 'add':
                $this->addTask();
                break;
            case 'delete':
                $this->removeTask();
                break;
            case 'toggle':
                $this->toggleTask();
                break;
            case 'api':
                $this->apiResponse();
                break;
            default:
                $this->index();
                break;
        }
    }

    private function index(): void {
        $this->view->render();
    }

    private function addTask(): void {
        if ($_SERVER['REQUEST_METHOD'] === 'POST') {
            $title = trim($_POST['title'] ?? '');
            $description = trim($_POST['description'] ?? '');
            
            if (!empty($title)) {
                $this->model->addTask($title, $description);
            }
        }
        
        // Redirection pour éviter la resoumission
        header('Location: ' . $_SERVER['PHP_SELF']);
        exit;
    }

    private function removeTask(): void {
        $id = (int)($_GET['id'] ?? 0);
        if ($id > 0) {
            $this->model->removeTask($id);
        }
        
        header('Location: ' . $_SERVER['PHP_SELF']);
        exit;
    }

    private function toggleTask(): void {
        $id = (int)($_GET['id'] ?? 0);
        if ($id > 0) {
            $this->model->toggleTask($id);
        }
        
        header('Location: ' . $_SERVER['PHP_SELF']);
        exit;
    }

    private function apiResponse(): void {
        header('Content-Type: application/json');
        echo $this->view->renderJson();
        exit;
    }
}

// Initialisation de l'application MVC
function initializeTaskApp(): void {
    // Démarrer la session pour la persistance
    session_start();
    
    // Créer les composants
    $model = new TaskModel();
    $controller = new TaskController($model);
    $view = new TaskView($model, $controller);
    
    // Connecter les composants
    $controller->setView($view);
    
    // Charger les données de session si disponibles
    if (isset($_SESSION['tasks'])) {
        foreach ($_SESSION['tasks'] as $taskData) {
            $model->addTask($taskData['title'], $taskData['description']);
        }
    }
    
    // Traiter la requête
    $controller->handleRequest();
    
    // Sauvegarder en session
    $_SESSION['tasks'] = $model->getTasks();
}

// Démarrer l'application
initializeTaskApp();

import java.util.*;
import java.time.LocalDateTime;

// Interface Observer
interface Observer {
    void update();
}

// Classe Task
class Task {
    private int id;
    private String title;
    private String description;
    private boolean completed;
    private LocalDateTime createdAt;
    
    public Task(int id, String title, String description) {
        this.id = id;
        this.title = title;
        this.description = description;
        this.completed = false;
        this.createdAt = LocalDateTime.now();
    }
    
    // Getters et setters
    public int getId() { return id; }
    public String getTitle() { return title; }
    public String getDescription() { return description; }
    public boolean isCompleted() { return completed; }
    public LocalDateTime getCreatedAt() { return createdAt; }
    
    public void setCompleted(boolean completed) { this.completed = completed; }
    
    @Override
    public String toString() {
        return String.format("Task{id=%d, title='%s', completed=%s}", 
                           id, title, completed);
    }
}

// Model - Gestion des données et logique métier
class TaskModel {
    private List<Task> tasks = new ArrayList<>();
    private List<Observer> observers = new ArrayList<>();
    private int nextId = 1;
    
    public void addObserver(Observer observer) {
        observers.add(observer);
    }
    
    public void removeObserver(Observer observer) {
        observers.remove(observer);
    }
    
    public void notifyObservers() {
        for (Observer observer : observers) {
            observer.update();
        }
    }
    
    // Logique métier
    public void addTask(String title, String description) {
        Task task = new Task(nextId++, title, description);
        tasks.add(task);
        notifyObservers();
    }
    
    public void removeTask(int id) {
        tasks.removeIf(task -> task.getId() == id);
        notifyObservers();
    }
    
    public void toggleTask(int id) {
        for (Task task : tasks) {
            if (task.getId() == id) {
                task.setCompleted(!task.isCompleted());
                notifyObservers();
                break;
            }
        }
    }
    
    public List<Task> getTasks() {
        return new ArrayList<>(tasks); // Copie défensive
    }
    
    public List<Task> getCompletedTasks() {
        return tasks.stream()
                   .filter(Task::isCompleted)
                   .collect(ArrayList::new, ArrayList::add, ArrayList::addAll);
    }
    
    public List<Task> getPendingTasks() {
        return tasks.stream()
                   .filter(task -> !task.isCompleted())
                   .collect(ArrayList::new, ArrayList::add, ArrayList::addAll);
    }
}

// View - Interface utilisateur
class TaskView implements Observer {
    private TaskModel model;
    private TaskController controller;
    
    public TaskView(TaskModel model, TaskController controller) {
        this.model = model;
        this.controller = controller;
        
        // S'enregistrer comme observateur
        this.model.addObserver(this);
    }
    
    @Override
    public void update() {
        render();
    }
    
    public void render() {
        List<Task> tasks = model.getTasks();
        List<Task> pendingTasks = model.getPendingTasks();
        List<Task> completedTasks = model.getCompletedTasks();
        
        System.out.println("=== Gestionnaire de Tâches ===");
        System.out.println("Statistiques: " + tasks.size() + " total | " +
                          pendingTasks.size() + " en cours | " +
                          completedTasks.size() + " terminées");
        System.out.println();
        
        if (tasks.isEmpty()) {
            System.out.println("Aucune tâche pour le moment.");
        } else {
            for (Task task : tasks) {
                String status = task.isCompleted() ? "[✓]" : "[ ]";
                System.out.println(status + " " + task.getId() + ". " + task.getTitle());
                if (!task.getDescription().isEmpty()) {
                    System.out.println("    " + task.getDescription());
                }
                System.out.println("    Créée le: " + task.getCreatedAt().toLocalDate());
                System.out.println();
            }
        }
    }
    
    public void showMenu() {
        System.out.println("=== Menu ===");
        System.out.println("1. Ajouter une tâche");
        System.out.println("2. Marquer comme terminée");
        System.out.println("3. Supprimer une tâche");
        System.out.println("4. Afficher les tâches");
        System.out.println("5. Quitter");
        System.out.print("Votre choix: ");
    }
}

// Controller - Logique de contrôle
class TaskController {
    private TaskModel model;
    private TaskView view;
    private Scanner scanner;
    
    public TaskController(TaskModel model) {
        this.model = model;
        this.scanner = new Scanner(System.in);
    }
    
    public void setView(TaskView view) {
        this.view = view;
    }
    
    public void run() {
        boolean running = true;
        
        while (running) {
            view.showMenu();
            
            try {
                int choice = scanner.nextInt();
                scanner.nextLine(); // Consommer la nouvelle ligne
                
                switch (choice) {
                    case 1:
                        addTask();
                        break;
                    case 2:
                        toggleTask();
                        break;
                    case 3:
                        removeTask();
                        break;
                    case 4:
                        view.render();
                        break;
                    case 5:
                        running = false;
                        System.out.println("Au revoir !");
                        break;
                    default:
                        System.out.println("Choix invalide. Veuillez réessayer.");
                }
            } catch (Exception e) {
                System.out.println("Erreur: " + e.getMessage());
                scanner.nextLine(); // Nettoyer le buffer
            }
            
            if (running) {
                System.out.println("\nAppuyez sur Entrée pour continuer...");
                scanner.nextLine();
                clearScreen();
            }
        }
    }
    
    private void addTask() {
        System.out.print("Titre de la tâche: ");
        String title = scanner.nextLine().trim();
        
        if (title.isEmpty()) {
            System.out.println("Le titre ne peut pas être vide.");
            return;
        }
        
        System.out.print("Description (optionnelle): ");
        String description = scanner.nextLine().trim();
        
        model.addTask(title, description);
        System.out.println("Tâche ajoutée avec succès !");
    }
    
    private void toggleTask() {
        List<Task> tasks = model.getTasks();
        if (tasks.isEmpty()) {
            System.out.println("Aucune tâche disponible.");
            return;
        }
        
        view.render();
        System.out.print("ID de la tâche à basculer: ");
        
        try {
            int id = scanner.nextInt();
            model.toggleTask(id);
            System.out.println("Statut de la tâche mis à jour !");
        } catch (Exception e) {
            System.out.println("ID invalide.");
        }
    }
    
    private void removeTask() {
        List<Task> tasks = model.getTasks();
        if (tasks.isEmpty()) {
            System.out.println("Aucune tâche à supprimer.");
            return;
        }
        
        view.render();
        System.out.print("ID de la tâche à supprimer: ");
        
        try {
            int id = scanner.nextInt();
            model.removeTask(id);
            System.out.println("Tâche supprimée !");
        } catch (Exception e) {
            System.out.println("ID invalide.");
        }
    }
    
    private void clearScreen() {
        // Simulation de nettoyage d'écran
        for (int i = 0; i < 50; i++) {
            System.out.println();
        }
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Séparation des responsabilités : Chaque composant a un rôle bien défini
  • Testabilité : Chaque partie peut être testée indépendamment
  • Réutilisabilité : Le modèle peut être utilisé avec différentes vues
  • Maintenabilité : Modifications isolées dans chaque couche
  • Développement parallèle : Équipes peuvent travailler simultanément

❌ Inconvénients

  • Complexité initiale : Plus de fichiers et de structure à gérer
  • Overhead : Peut être excessif pour des applications simples
  • Couplage indirect : Dépendances via les interfaces
  • Courbe d'apprentissage : Concept à maîtriser pour les débutants
  • Performance : Couches supplémentaires peuvent ralentir

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Applications web complexes : Interfaces riches avec beaucoup d'interactions
  • Applications desktop : GUI avec logique métier importante
  • Équipes multiples : Développement parallèle front/back
  • Évolution fréquente : Interface qui change souvent

❌ Quand l'éviter

  • Applications simples : CRUD basique sans logique complexe
  • Prototypes rapides : Développement exploratoire
  • Équipe réduite : Une seule personne sur le projet
  • Contraintes de performance : Applications temps réel critiques

🧩 Biais Cognitifs Associés

🏗️ Biais de Sur-Architecture

Manifestation : "Il faut absolument séparer tout en MVC, même pour une page statique !"

Risque : Complexifier inutilement des applications simples qui n'ont pas besoin de cette séparation.

🎯 Biais de Pureté Architecturale

Manifestation : Vouloir respecter MVC à 100% même quand cela nuit à la productivité.

Risque : Perdre du temps sur des détails architecturaux au détriment des fonctionnalités.

🔄 Biais de Familiarité

Manifestation : "On a toujours fait du MVC, continuons comme ça."

Risque : Ne pas considérer d'autres patterns plus adaptés au contexte actuel.

🎯 Exercice Pratique

Scenario : Application de Blog

Vous devez développer une application de blog où les utilisateurs peuvent créer, modifier et supprimer des articles. L'application doit supporter différents formats d'affichage (liste, grille, détail) et permettre la recherche et le filtrage. L'équipe comprend des développeurs front-end et back-end qui travaillent en parallèle.

Question :

Comment organiseriez-vous cette application ?

🏗️ Utiliser le pattern MVC avec séparation claire
📦 Créer une application monolithique simple
🔧 Découper en microservices dès le début

✅ Excellente réponse !

MVC est parfait pour ce cas d'usage car :

  • Séparation claire : Modèle (articles, utilisateurs), Vue (formats d'affichage), Contrôleur (actions CRUD)
  • Équipes parallèles : Front-end peut travailler sur les vues pendant que back-end développe le modèle
  • Flexibilité d'affichage : Plusieurs vues peuvent utiliser le même modèle
  • Testabilité : Logique métier isolée et facilement testable
// Modèle : Gestion des articles
class ArticleModel {
    getArticles(), createArticle(), updateArticle()...
}

// Vue : Affichage des articles
class ArticleListView, ArticleDetailView, ArticleGridView...

// Contrôleur : Actions utilisateur
class ArticleController {
    handleCreate(), handleUpdate(), handleDelete()...
}

⚠️ Pas optimal

Une approche monolithique pose des problèmes :

  • Couplage fort : Interface et logique métier mélangées
  • Collaboration difficile : Équipes front/back se marchent dessus
  • Tests complexes : Difficile de tester la logique isolément
  • Évolution limitée : Changements d'interface impactent tout

❌ Trop complexe

Les microservices sont excessifs pour ce cas :

  • Over-engineering : Complexité réseau et déploiement inutile
  • Overhead opérationnel : Monitoring, logging, découverte de services
  • Latence : Appels réseau entre services
  • Équipe insuffisante : Nécessite plus de compétences DevOps
🏗️

Pattern MVC Maîtrisé !

Vous avez appris à séparer efficacement la logique métier, la présentation et le contrôle.
