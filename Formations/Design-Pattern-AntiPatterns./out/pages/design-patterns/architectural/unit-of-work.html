📦 Unit of Work Pattern

Maintenir une liste des objets affectés par une transaction métier

🏗️ Architectural
📊 Avancé
🔄 Gestion Transactionnelle

📋 Définition

❌ Problème

Les opérations métier impliquent souvent plusieurs objets qui doivent être sauvegardés de manière cohérente. Gérer manuellement les transactions et l'ordre des opérations devient complexe et source d'erreurs.

✅ Solution

Le pattern Unit of Work maintient une liste des objets affectés par une transaction métier et coordonne l'écriture des modifications et la résolution des problèmes de concurrence.

💡 Point clé : Unit of Work coordonne toutes les modifications d'objets métier et les exécute dans l'ordre optimal lors du commit, garantissant la cohérence transactionnelle.

interface DomainObject {

    isDirty(): boolean;
}

// Classe de base pour les objets de domaine
abstract class BaseDomainObject implements DomainObject {
    protected id: string;
    protected version: number = 0;
    protected dirty: boolean = false;

    constructor(id: string) {
        this.id = id;
    }

    getId(): string {
        return this.id;
    }

    getVersion(): number {
        return this.version;
    }

    markDirty(): void {
        this.dirty = true;
    }

    isDirty(): boolean {
        return this.dirty;
    }

    protected incrementVersion(): void {
        this.version++;
        this.dirty = false;
    }
}

// Entités métier
class Order extends BaseDomainObject {
    private customerId: string;
    private items: OrderItem[] = [];
    private status: 'pending' | 'confirmed' | 'shipped' | 'delivered' = 'pending';
    private totalAmount: number = 0;

    constructor(id: string, customerId: string) {
        super(id);
        this.customerId = customerId;
    }

    addItem(productId: string, quantity: number, price: number): OrderItem {
        const item = new OrderItem(`${this.id}-${this.items.length + 1}`, this.id, productId, quantity, price);
        this.items.push(item);
        this.calculateTotal();
        this.markDirty();
        return item;
    }

    removeItem(itemId: string): boolean {
        const index = this.items.findIndex(item => item.getId() === itemId);
        if (index !== -1) {
            this.items.splice(index, 1);
            this.calculateTotal();
            this.markDirty();
            return true;
        }
        return false;
    }

    updateStatus(newStatus: typeof this.status): void {
        if (this.status !== newStatus) {
            this.status = newStatus;
            this.markDirty();
        }
    }

    private calculateTotal(): void {
        this.totalAmount = this.items.reduce((total, item) => total + item.getSubtotal(), 0);
    }

    // Getters
    getCustomerId(): string { return this.customerId; }
    getItems(): OrderItem[] { return [...this.items]; }
    getStatus(): string { return this.status; }
    getTotalAmount(): number { return this.totalAmount; }
}

class OrderItem extends BaseDomainObject {
    private orderId: string;
    private productId: string;
    private quantity: number;
    private unitPrice: number;

    constructor(id: string, orderId: string, productId: string, quantity: number, unitPrice: number) {
        super(id);
        this.orderId = orderId;
        this.productId = productId;
        this.quantity = quantity;
        this.unitPrice = unitPrice;
    }

    updateQuantity(newQuantity: number): void {
        if (this.quantity !== newQuantity) {
            this.quantity = newQuantity;
            this.markDirty();
        }
    }

    updatePrice(newPrice: number): void {
        if (this.unitPrice !== newPrice) {
            this.unitPrice = newPrice;
            this.markDirty();
        }
    }

    getSubtotal(): number {
        return this.quantity * this.unitPrice;
    }

    // Getters
    getOrderId(): string { return this.orderId; }
    getProductId(): string { return this.productId; }
    getQuantity(): number { return this.quantity; }
    getUnitPrice(): number { return this.unitPrice; }
}

class Customer extends BaseDomainObject {
    private name: string;
    private email: string;
    private address: string;

    constructor(id: string, name: string, email: string, address: string) {
        super(id);
        this.name = name;
        this.email = email;
        this.address = address;
    }

    updateInfo(name?: string, email?: string, address?: string): void {
        let changed = false;
        
        if (name && this.name !== name) {
            this.name = name;
            changed = true;
        }
        
        if (email && this.email !== email) {
            this.email = email;
            changed = true;
        }
        
        if (address && this.address !== address) {
            this.address = address;
            changed = true;
        }
        
        if (changed) {
            this.markDirty();
        }
    }

    // Getters
    getName(): string { return this.name; }
    getEmail(): string { return this.email; }
    getAddress(): string { return this.address; }
}

// Unit of Work
class UnitOfWork {
    private newObjects = new Set();
    private dirtyObjects = new Set();
    private removedObjects = new Set();
    private cleanObjects = new Set();
    private mappers = new Map>();
    private inTransaction = false;

    constructor() {
        // Enregistrement des mappers
        this.mappers.set(Order, new OrderMapper());
        this.mappers.set(OrderItem, new OrderItemMapper());
        this.mappers.set(Customer, new CustomerMapper());
    }

    registerNew(object: DomainObject): void {
        if (this.removedObjects.has(object)) {
            throw new Error(`Objet ${object.getId()} marqué pour suppression, impossible de l'ajouter`);
        }
        
        if (!this.dirtyObjects.has(object) && !this.cleanObjects.has(object)) {
            this.newObjects.add(object);
            console.log(`➕ Nouvel objet enregistré: ${object.constructor.name}(${object.getId()})`);
        }
    }

    registerDirty(object: DomainObject): void {
        if (this.removedObjects.has(object)) {
            throw new Error(`Objet ${object.getId()} marqué pour suppression, impossible de le modifier`);
        }
        
        if (!this.newObjects.has(object) && !this.dirtyObjects.has(object)) {
            this.dirtyObjects.add(object);
            console.log(`✏️ Objet modifié enregistré: ${object.constructor.name}(${object.getId()})`);
        }
    }

    registerRemoved(object: DomainObject): void {
        if (this.newObjects.has(object)) {
            this.newObjects.delete(object);
        } else {
            this.dirtyObjects.delete(object);
            this.cleanObjects.delete(object);
            this.removedObjects.add(object);
        }
        console.log(`🗑️ Objet marqué pour suppression: ${object.constructor.name}(${object.getId()})`);
    }

    registerClean(object: DomainObject): void {
        if (!this.newObjects.has(object) && !this.dirtyObjects.has(object) && !this.removedObjects.has(object)) {
            this.cleanObjects.add(object);
        }
    }

    async commit(): Promise {
        if (this.inTransaction) {
            throw new Error('Transaction déjà en cours');
        }

        this.inTransaction = true;
        console.log('\n🔄 Début de la transaction...');

        try {
            // 1. Insertions des nouveaux objets
            for (const obj of this.newObjects) {
                const mapper = this.getMapper(obj);
                await mapper.insert(obj);
            }

            // 2. Mises à jour des objets modifiés
            for (const obj of this.dirtyObjects) {
                const mapper = this.getMapper(obj);
                await mapper.update(obj);
            }

            // 3. Suppressions des objets supprimés
            for (const obj of this.removedObjects) {
                const mapper = this.getMapper(obj);
                await mapper.delete(obj);
            }

            // Nettoyage des listes
            this.newObjects.clear();
            this.dirtyObjects.clear();
            this.removedObjects.clear();

            console.log('✅ Transaction commitée avec succès\n');
        } catch (error) {
            console.error('❌ Erreur lors du commit, rollback automatique:', error);
            await this.rollback();
            throw error;
        } finally {
            this.inTransaction = false;
        }
    }

    async rollback(): Promise {
        console.log('🔙 Rollback de la transaction...');
        
        // Nettoyage des listes
        this.newObjects.clear();
        this.dirtyObjects.clear();
        this.removedObjects.clear();
        
        this.inTransaction = false;
        console.log('↩️ Rollback terminé\n');
    }

    isInTransaction(): boolean {
        return this.inTransaction;
    }

    private getMapper(object: DomainObject): DataMapper {
        const mapper = this.mappers.get(object.constructor);
        if (!mapper) {
            throw new Error(`Aucun mapper trouvé pour ${object.constructor.name}`);
        }
        return mapper;
    }

    // Méthodes utilitaires pour le debug
    getStats(): { new: number, dirty: number, removed: number, clean: number } {
        return {
            new: this.newObjects.size,
            dirty: this.dirtyObjects.size,
            removed: this.removedObjects.size,
            clean: this.cleanObjects.size
        };
    }
}

// Service métier utilisant Unit of Work
class OrderService {
    private unitOfWork: UnitOfWork;

    constructor(unitOfWork: UnitOfWork) {
        this.unitOfWork = unitOfWork;
    }

    async createCompleteOrder(customerId: string, customerName: string, customerEmail: string, customerAddress: string): Promise {
        // Création du client
        const customer = new Customer(customerId, customerName, customerEmail, customerAddress);
        this.unitOfWork.registerNew(customer);

        // Création de la commande
        const order = new Order(`order-${Date.now()}`, customerId);
        this.unitOfWork.registerNew(order);

        // Ajout d'articles
        const item1 = order.addItem('product-1', 2, 29.99);
        const item2 = order.addItem('product-2', 1, 49.99);
        
        this.unitOfWork.registerNew(item1);
        this.unitOfWork.registerNew(item2);

        return order;
    }

    async updateOrderStatus(order: Order, newStatus: 'pending' | 'confirmed' | 'shipped' | 'delivered'): Promise {
        order.updateStatus(newStatus);
        this.unitOfWork.registerDirty(order);
    }

    async addItemToOrder(order: Order, productId: string, quantity: number, price: number): Promise {
        const item = order.addItem(productId, quantity, price);
        this.unitOfWork.registerNew(item);
        this.unitOfWork.registerDirty(order); // La commande est modifiée (total recalculé)
        return item;
    }

    async removeItemFromOrder(order: Order, itemId: string): Promise {
        const removed = order.removeItem(itemId);
        if (removed) {
            this.unitOfWork.registerDirty(order); // La commande est modifiée
            // Note: l'item supprimé devrait être marqué pour suppression séparément
        }
        return removed;
    }

    async cancelOrder(order: Order): Promise {
        // Suppression des items
        for (const item of order.getItems()) {
            this.unitOfWork.registerRemoved(item);
        }
        
        // Suppression de la commande
        this.unitOfWork.registerRemoved(order);
    }
}

// Entités métier
class Article extends BaseDomainObject {
    private string $title;
    private string $content;
    private string $authorId;
    private string $status; // draft, published, archived
    private array $tags = [];
    private ?DateTime $publishedAt = null;

    public function __construct(string $id, string $title, string $content, string $authorId) {
        parent::__construct($id);
        $this->title = $title;
        $this->content = $content;
        $this->authorId = $authorId;
        $this->status = 'draft';
    }

    public function updateTitle(string $newTitle): void {
        if ($this->title !== $newTitle) {
            $this->title = $newTitle;
            $this->markDirty();
        }
    }

    public function updateContent(string $newContent): void {
        if ($this->content !== $newContent) {
            $this->content = $newContent;
            $this->markDirty();
        }
    }

    public function publish(): void {
        if ($this->status !== 'published') {
            $this->status = 'published';
            $this->publishedAt = new DateTime();
            $this->markDirty();
        }
    }

    public function archive(): void {
        if ($this->status !== 'archived') {
            $this->status = 'archived';
            $this->markDirty();
        }
    }

    public function addTag(string $tag): void {
        if (!in_array($tag, $this->tags)) {
            $this->tags[] = $tag;
            $this->markDirty();
        }
    }

    public function removeTag(string $tag): bool {
        $index = array_search($tag, $this->tags);
        if ($index !== false) {
            array_splice($this->tags, $index, 1);
            $this->markDirty();
            return true;
        }
        return false;
    }

    // Getters
    public function getTitle(): string { return $this->title; }
    public function getContent(): string { return $this->content; }
    public function getAuthorId(): string { return $this->authorId; }
    public function getStatus(): string { return $this->status; }
    public function getTags(): array { return $this->tags; }
    public function getPublishedAt(): ?DateTime { return $this->publishedAt; }
}

class Comment extends BaseDomainObject {
    private string $articleId;
    private string $authorName;
    private string $authorEmail;
    private string $content;
    private bool $approved = false;

            $this->approved = true;
            $this->markDirty();

    }

    public function updateContent(string $newContent): void {
        if ($this->content !== $newContent) {
            $this->content = $newContent;
            $this->markDirty();
        }
    }

    public function getCreatedAt(): DateTime { return $this->createdAt; }
}

class Author extends BaseDomainObject {
    private string $name;
    private string $email;
    private string $bio;
    private array $socialLinks = [];

    public function __construct(string $id, string $name, string $email, string $bio = '') {
        parent::__construct($id);
        $this->name = $name;
        $this->email = $email;
        $this->bio = $bio;
    }

    public function updateProfile(string $name = null, string $email = null, string $bio = null): void {
        $changed = false;

        if ($name !== null && $this->name !== $name) {
            $this->name = $name;
            $changed = true;
        }

        if ($email !== null && $this->email !== $email) {
            $this->email = $email;
            $changed = true;
        }

        if ($bio !== null && $this->bio !== $bio) {
            $this->bio = $bio;
            $changed = true;
        }

        if ($changed) {
            $this->markDirty();
        }
    }

    public function addSocialLink(string $platform, string $url): void {
        if (!isset($this->socialLinks[$platform]) || $this->socialLinks[$platform] !== $url) {
            $this->socialLinks[$platform] = $url;
            $this->markDirty();
        }
    }

    public function removeSocialLink(string $platform): bool {
        if (isset($this->socialLinks[$platform])) {
            unset($this->socialLinks[$platform]);
            $this->markDirty();
            return true;
        }
        return false;
    }

    // Getters
    public function getName(): string { return $this->name; }
    public function getEmail(): string { return $this->email; }
    public function getBio(): string { return $this->bio; }
    public function getSocialLinks(): array { return $this->socialLinks; }
}

class UnitOfWork {
    private array $newObjects = [];
    private array $dirtyObjects = [];
    private array $removedObjects = [];
    private array $cleanObjects = [];
    private array $mappers = [];
    private bool $inTransaction = false;

    public function __construct() {
        // Enregistrement des mappers
        $this->mappers[Article::class] = new ArticleMapper();
        $this->mappers[Comment::class] = new CommentMapper();
        $this->mappers[Author::class] = new AuthorMapper();
    }

    public function registerNew(DomainObject $object): void {
        $id = $object->getId();
        
        if (isset($this->removedObjects[$id])) {
            throw new InvalidArgumentException("Objet {$id} marqué pour suppression, impossible de l'ajouter");
        }
        
        if (!isset($this->dirtyObjects[$id]) && !isset($this->cleanObjects[$id])) {
            $this->newObjects[$id] = $object;
            echo "➕ Nouvel objet enregistré: " . get_class($object) . "({$id})\n";
        }
    }

    public function registerDirty(DomainObject $object): void {
        $id = $object->getId();
        
        if (isset($this->removedObjects[$id])) {
            throw new InvalidArgumentException("Objet {$id} marqué pour suppression, impossible de le modifier");
        }
        
        if (!isset($this->newObjects[$id]) && !isset($this->dirtyObjects[$id])) {
            $this->dirtyObjects[$id] = $object;
            echo "✏️ Objet modifié enregistré: " . get_class($object) . "({$id})\n";
        }
    }

    public function registerRemoved(DomainObject $object): void {
        $id = $object->getId();
        
        if (isset($this->newObjects[$id])) {
            unset($this->newObjects[$id]);
        } else {
            unset($this->dirtyObjects[$id]);
            unset($this->cleanObjects[$id]);
            $this->removedObjects[$id] = $object;
        }
        
        echo "🗑️ Objet marqué pour suppression: " . get_class($object) . "({$id})\n";
    }

    public function registerClean(DomainObject $object): void {
        $id = $object->getId();
        
        if (!isset($this->newObjects[$id]) && !isset($this->dirtyObjects[$id]) && !isset($this->removedObjects[$id])) {
            $this->cleanObjects[$id] = $object;
        }
    }

    public function commit(): void {
        if ($this->inTransaction) {
            throw new RuntimeException('Transaction déjà en cours');
        }

        $this->inTransaction = true;
        echo "\n🔄 Début de la transaction...\n";

        try {
            // 1. Insertions des nouveaux objets
            foreach ($this->newObjects as $obj) {
                $mapper = $this->getMapper($obj);
                $mapper->insert($obj);
            }

            // 2. Mises à jour des objets modifiés
            foreach ($this->dirtyObjects as $obj) {
                $mapper = $this->getMapper($obj);
                $mapper->update($obj);
            }

            // 3. Suppressions des objets supprimés
            foreach ($this->removedObjects as $obj) {
                $mapper = $this->getMapper($obj);
                $mapper->delete($obj);
            }

            // Nettoyage des listes
            $this->newObjects = [];
            $this->dirtyObjects = [];
            $this->removedObjects = [];

            echo "✅ Transaction commitée avec succès\n\n";
        } catch (Exception $e) {
            echo "❌ Erreur lors du commit, rollback automatique: {$e->getMessage()}\n";
            $this->rollback();
            throw $e;
        } finally {
            $this->inTransaction = false;
        }
    }

    public function rollback(): void {
        echo "🔙 Rollback de la transaction...\n";
        
        // Nettoyage des listes
        $this->newObjects = [];
        $this->dirtyObjects = [];
        $this->removedObjects = [];
        
        $this->inTransaction = false;
        echo "↩️ Rollback terminé\n\n";
    }

    public function isInTransaction(): bool {
        return $this->inTransaction;
    }

    private function getMapper(DomainObject $object): DataMapper {
        $className = get_class($object);
        
        if (!isset($this->mappers[$className])) {
            throw new RuntimeException("Aucun mapper trouvé pour {$className}");
        }
        
        return $this->mappers[$className];
    }

    // Méthodes utilitaires pour le debug
    public function getStats(): array {
        return [
            'new' => count($this->newObjects),
            'dirty' => count($this->dirtyObjects),
            'removed' => count($this->removedObjects),
            'clean' => count($this->cleanObjects)
        ];
    }
}

// Interface pour les objets de domaine
interface DomainObject {
    String getId();
    int getVersion();
    void markDirty();
    boolean isDirty();
}

// Classe de base pour les objets de domaine
abstract class BaseDomainObject implements DomainObject {
    protected String id;
    protected int version = 0;
    protected boolean dirty = false;

    public BaseDomainObject(String id) {
        this.id = id;
    }

    @Override
    public String getId() {
        return id;
    }

    @Override
    public int getVersion() {
        return version;
    }

    @Override
    public void markDirty() {
        this.dirty = true;
    }

    @Override
    public boolean isDirty() {
        return dirty;
    }

    protected void incrementVersion() {
        this.version++;
        this.dirty = false;
    }
}

// Entités métier
class Project extends BaseDomainObject {
    private String name;
    private String description;
    private String managerId;
    private ProjectStatus status;
    private LocalDateTime startDate;
    private LocalDateTime endDate;
    private List<Task> tasks = new ArrayList<>();

    public enum ProjectStatus {
        PLANNING, ACTIVE, ON_HOLD, COMPLETED, CANCELLED
    }

    public Project(String id, String name, String description, String managerId) {
        super(id);
        this.name = name;
        this.description = description;
        this.managerId = managerId;
        this.status = ProjectStatus.PLANNING;
        this.startDate = LocalDateTime.now();
    }

    public void updateName(String newName) {
        if (!Objects.equals(this.name, newName)) {
            this.name = newName;
            markDirty();
        }
    }

    public void updateDescription(String newDescription) {
        if (!Objects.equals(this.description, newDescription)) {
            this.description = newDescription;
            markDirty();
        }
    }

    public void updateStatus(ProjectStatus newStatus) {
        if (this.status != newStatus) {
            this.status = newStatus;
            if (newStatus == ProjectStatus.COMPLETED) {
                this.endDate = LocalDateTime.now();
            }
            markDirty();
        }
    }

    public Task addTask(String taskId, String title, String description, String assigneeId) {
        Task task = new Task(taskId, this.id, title, description, assigneeId);
        this.tasks.add(task);
        markDirty();
        return task;
    }

    public boolean removeTask(String taskId) {
        boolean removed = tasks.removeIf(task -> task.getId().equals(taskId));
        if (removed) {
            markDirty();
        }
        return removed;
    }

    // Getters
    public String getName() { return name; }
    public String getDescription() { return description; }
    public String getManagerId() { return managerId; }
    public ProjectStatus getStatus() { return status; }
    public LocalDateTime getStartDate() { return startDate; }
    public LocalDateTime getEndDate() { return endDate; }
    public List<Task> getTasks() { return new ArrayList<>(tasks); }
}

// Unit of Work
class UnitOfWork {
    private final Map<String, DomainObject> newObjects = new ConcurrentHashMap<>();
    private final Map<String, DomainObject> dirtyObjects = new ConcurrentHashMap<>();
    private final Map<String, DomainObject> removedObjects = new ConcurrentHashMap<>();
    private final Map<String, DomainObject> cleanObjects = new ConcurrentHashMap<>();
    private final Map<Class<?>, DataMapper<?>> mappers = new HashMap<>();
    private boolean inTransaction = false;

    public UnitOfWork() {
        // Enregistrement des mappers
        mappers.put(Project.class, new ProjectMapper());
        mappers.put(Task.class, new TaskMapper());
        mappers.put(TeamMember.class, new TeamMemberMapper());
    }

    public void registerNew(DomainObject object) {
        String id = object.getId();
        
        if (removedObjects.containsKey(id)) {
            throw new IllegalArgumentException("Objet " + id + " marqué pour suppression, impossible de l'ajouter");
        }
        
        if (!dirtyObjects.containsKey(id) && !cleanObjects.containsKey(id)) {
            newObjects.put(id, object);
            System.out.println("➕ Nouvel objet enregistré: " + object.getClass().getSimpleName() + "(" + id + ")");
        }
    }

    public void registerDirty(DomainObject object) {
        String id = object.getId();
        
        if (removedObjects.containsKey(id)) {
            throw new IllegalArgumentException("Objet " + id + " marqué pour suppression, impossible de le modifier");
        }
        
        if (!newObjects.containsKey(id) && !dirtyObjects.containsKey(id)) {
            dirtyObjects.put(id, object);
            System.out.println("✏️ Objet modifié enregistré: " + object.getClass().getSimpleName() + "(" + id + ")");
        }
    }

    public void registerRemoved(DomainObject object) {
        String id = object.getId();
        
        if (newObjects.containsKey(id)) {
            newObjects.remove(id);
        } else {
            dirtyObjects.remove(id);
            cleanObjects.remove(id);
            removedObjects.put(id, object);
        }
        
        System.out.println("🗑️ Objet marqué pour suppression: " + object.getClass().getSimpleName() + "(" + id + ")");
    }

    public void registerClean(DomainObject object) {
        String id = object.getId();
        
        if (!newObjects.containsKey(id) && !dirtyObjects.containsKey(id) && !removedObjects.containsKey(id)) {
            cleanObjects.put(id, object);
        }
    }

    public void commit() throws Exception {
        if (inTransaction) {
            throw new RuntimeException("Transaction déjà en cours");
        }

        inTransaction = true;
        System.out.println("\n🔄 Début de la transaction...");

        try {
            // 1. Insertions des nouveaux objets
            for (DomainObject obj : newObjects.values()) {
                DataMapper<DomainObject> mapper = getMapper(obj);
                mapper.insert(obj);
            }

            // 2. Mises à jour des objets modifiés
            for (DomainObject obj : dirtyObjects.values()) {
                DataMapper<DomainObject> mapper = getMapper(obj);
                mapper.update(obj);
            }

            // 3. Suppressions des objets supprimés
            for (DomainObject obj : removedObjects.values()) {
                DataMapper<DomainObject> mapper = getMapper(obj);
                mapper.delete(obj);
            }

            // Nettoyage des listes
            newObjects.clear();
            dirtyObjects.clear();
            removedObjects.clear();

            System.out.println("✅ Transaction commitée avec succès\n");
        } catch (Exception e) {
            System.err.println("❌ Erreur lors du commit, rollback automatique: " + e.getMessage());
            rollback();
            throw e;
        } finally {
            inTransaction = false;
        }
    }

    public void rollback() {
        System.out.println("🔙 Rollback de la transaction...");
        
        // Nettoyage des listes
        newObjects.clear();
        dirtyObjects.clear();
        removedObjects.clear();
        
        inTransaction = false;
        System.out.println("↩️ Rollback terminé\n");
    }

    public boolean isInTransaction() {
        return inTransaction;
    }

    @SuppressWarnings("unchecked")
    private DataMapper<DomainObject> getMapper(DomainObject object) {
        DataMapper<?> mapper = mappers.get(object.getClass());
        if (mapper == null) {
            throw new RuntimeException("Aucun mapper trouvé pour " + object.getClass().getSimpleName());
        }
        return (DataMapper<DomainObject>) mapper;
    }

    // Méthodes utilitaires pour le debug
    public Map<String, Integer> getStats() {
        Map<String, Integer> stats = new HashMap<>();
        stats.put("new", newObjects.size());
        stats.put("dirty", dirtyObjects.size());
        stats.put("removed", removedObjects.size());
        stats.put("clean", cleanObjects.size());
        return stats;
    }
}

                "Conception de l'architecture", 
                "Définir l'architecture technique du système", 
                "member-1");
            
            Task task2 = projectService.addTaskToProject(project, 
                "Développement du frontend", 
                "Créer l'interface utilisateur", 
                "member-2");
            
            Task task3 = projectService.addTaskToProject(project, 
                "Design des maquettes", 
                "Concevoir les maquettes UI/UX", 
                "member-3");

            task1.updatePriority(5); // Haute priorité
            task2.updatePriority(4);
            task3.updatePriority(3);

            System.out.println("📊 Stats UoW: " + unitOfWork.getStats());

            // Mise à jour des statuts
            System.out.println("\n🔄 Mise à jour des statuts...");
            projectService.updateProjectStatus(project, Project.ProjectStatus.ACTIVE);
            projectService.updateTaskStatus(task1, Task.TaskStatus.IN_PROGRESS);
            projectService.updateTaskStatus(task3, Task.TaskStatus.DONE);

            // Ajout de compétences
            System.out.println("\n🎯 Ajout de compétences...");
            projectService.addSkillToMember(teamMembers.get(1), "Node.js");

            System.out.println("📊 Stats UoW: " + unitOfWork.getStats());

            // Commit de toutes les modifications
            unitOfWork.commit();

            System.out.println("📊 Stats après commit: " + unitOfWork.getStats());

        } catch (Exception e) {
            System.err.println("Erreur: " + e.getMessage());
            e.printStackTrace();
        }
    }

⚖️ Avantages et Inconvénients

✅ Avantages

  • Cohérence transactionnelle : Garantit l'atomicité des opérations
  • Optimisation des performances : Regroupement des opérations de base de données
  • Gestion centralisée : Point unique de contrôle des modifications
  • Ordre des opérations : Résolution automatique des dépendances
  • Rollback automatique : Annulation en cas d'erreur

❌ Inconvénients

  • Complexité accrue : Architecture plus complexe à maintenir
  • Consommation mémoire : Stockage des objets en mémoire
  • Couplage fort : Dépendance aux mappers et à l'UoW
  • Gestion des conflits : Complexité de la concurrence
  • Courbe d'apprentissage : Pattern avancé difficile à maîtriser

🎯 Cas d'usage recommandés

✅ Recommandé pour

  • Applications avec transactions métier complexes
  • Systèmes nécessitant une forte cohérence des données
  • Opérations impliquant plusieurs entités liées
  • Applications avec besoins de rollback sophistiqués
  • Systèmes avec optimisations de performance critiques

❌ Éviter pour

  • Applications simples avec peu de relations
  • Systèmes avec contraintes mémoire strictes
  • Applications nécessitant des transactions longues
  • Projets avec équipes junior
  • Systèmes distribués avec microservices
