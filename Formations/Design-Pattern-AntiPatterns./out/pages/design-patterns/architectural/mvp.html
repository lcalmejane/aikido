🎭 MVP Pattern

Séparer la logique de présentation avec un Presenter

🏗️ Architectural
⭐ Difficulté: Intermédiaire
⏱️ 25 min
🎯 Séparation des responsabilités

🎯 Définition

Le MVP (Model-View-Presenter) est un pattern architectural qui sépare la logique de présentation de la logique métier en introduisant un Presenter qui fait le lien entre la Vue et le Modèle.

❌ Problème Résolu

  • Vue trop couplée à la logique métier
  • Difficultés pour tester la logique de présentation
  • Code de présentation mélangé avec l'interface
  • Réutilisation limitée des composants

✅ Solution Apportée

  • Séparation claire des responsabilités
  • Vue passive et testable
  • Presenter contient toute la logique de présentation
  • Meilleure testabilité et maintenabilité
💡 Différence avec MVC : Dans MVP, la Vue ne communique jamais directement avec le Modèle. Tout passe par le Presenter qui orchestre les interactions.

🏗️ Structure UML

Model
+ getData(): Data
+ saveData(data: Data): void
+ notifyObservers(): void
View (Interface)
+ displayData(data: Data): void
+ showError(message: string): void
+ getUserInput(): UserInput
Presenter
- model: Model
- view: View
+ handleUserAction(): void
+ updateView(): void
- processData(): void

Éléments Clés

  • Model : Contient les données et la logique métier
  • View : Interface passive qui affiche les données
  • Presenter : Orchestre les interactions entre Model et View
  • Communication unidirectionnelle : View → Presenter → Model

💡 Point clé : Le Presenter agit comme un médiateur entre la Vue et le Modèle, centralisant toute la logique de présentation.

// Model - Gestion des données
interface Contact {
    id: number;
    name: string;
    email: string;
    phone: string;
}

class ContactModel {
    private contacts: Contact[] = [];
    private observers: ContactObserver[] = [];
    
    addObserver(observer: ContactObserver): void {
        this.observers.push(observer);
    }
    
    removeObserver(observer: ContactObserver): void {
        const index = this.observers.indexOf(observer);
        if (index > -1) {
            this.observers.splice(index, 1);
        }
    }
    
    private notifyObservers(): void {
        this.observers.forEach(observer => observer.onContactsChanged(this.contacts));
    }
    
    getAllContacts(): Contact[] {
        return [...this.contacts];
    }
    
    addContact(contact: Omit): void {
        const newContact: Contact = {
            id: Date.now(),
            ...contact
        };
        this.contacts.push(newContact);
        this.notifyObservers();
    }
    
    updateContact(id: number, updates: Partial): void {
        const index = this.contacts.findIndex(c => c.id === id);
        if (index !== -1) {
            this.contacts[index] = { ...this.contacts[index], ...updates };
            this.notifyObservers();
        }
    }
    
    deleteContact(id: number): void {
        this.contacts = this.contacts.filter(c => c.id !== id);
        this.notifyObservers();
    }
    
    searchContacts(query: string): Contact[] {
        return this.contacts.filter(contact =>
            contact.name.toLowerCase().includes(query.toLowerCase()) ||
            contact.email.toLowerCase().includes(query.toLowerCase())
        );
    }
}

// View Interface
interface ContactView {
    displayContacts(contacts: Contact[]): void;
    displayContact(contact: Contact): void;
    showError(message: string): void;
    showSuccess(message: string): void;
    clearForm(): void;
    getFormData(): Omit;
    setPresenter(presenter: ContactPresenter): void;
}

// Observer Interface
interface ContactObserver {
    onContactsChanged(contacts: Contact[]): void;
}

// Presenter
class ContactPresenter implements ContactObserver {
    private model: ContactModel;
    private view: ContactView;
    
    constructor(model: ContactModel, view: ContactView) {
        this.model = model;
        this.view = view;
        this.view.setPresenter(this);
        this.model.addObserver(this);
        this.loadContacts();
    }
    
    // Méthodes appelées par la View
    onAddContact(): void {
        try {
            const formData = this.view.getFormData();
            
            if (!this.validateContactData(formData)) {
                this.view.showError('Veuillez remplir tous les champs obligatoires');
                return;
            }
            
            this.model.addContact(formData);
            this.view.clearForm();
            this.view.showSuccess('Contact ajouté avec succès');
        } catch (error) {
            this.view.showError('Erreur lors de l\'ajout du contact');
        }
    }
    
    onDeleteContact(id: number): void {
        try {
            this.model.deleteContact(id);
            this.view.showSuccess('Contact supprimé avec succès');
        } catch (error) {
            this.view.showError('Erreur lors de la suppression');
        }
    }
    
    onSearchContacts(query: string): void {
        try {
            const results = this.model.searchContacts(query);
            this.view.displayContacts(results);
        } catch (error) {
            this.view.showError('Erreur lors de la recherche');
        }
    }
    
    // Observer callback
    onContactsChanged(contacts: Contact[]): void {
        this.view.displayContacts(contacts);
    }
    
    private loadContacts(): void {
        const contacts = this.model.getAllContacts();
        this.view.displayContacts(contacts);
    }
    
    private validateContactData(data: Omit): boolean {
        return !!(data.name && data.email && data.phone);
    }
}

// Model - Gestion des données
class Contact {
    public int $id;
    public string $name;
    public string $email;
    public string $phone;
    
    public function __construct(int $id, string $name, string $email, string $phone) {
        $this->id = $id;
        $this->name = $name;
        $this->email = $email;
        $this->phone = $phone;
    }
    
    public function toArray(): array {
        return [
            'id' => $this->id,
            'name' => $this->name,
            'email' => $this->email,
            'phone' => $this->phone
        ];
    }
}

interface ContactObserver {
    public function onContactsChanged(array $contacts): void;
}

class ContactModel {
    private array $contacts = [];
    private array $observers = [];
    private int $nextId = 1;
    
    public function addObserver(ContactObserver $observer): void {
        $this->observers[] = $observer;
    }
    
    public function removeObserver(ContactObserver $observer): void {
        $key = array_search($observer, $this->observers, true);
        if ($key !== false) {
            unset($this->observers[$key]);
        }
    }
    
    private function notifyObservers(): void {
        foreach ($this->observers as $observer) {
            $observer->onContactsChanged($this->contacts);
        }
    }
    
    public function getAllContacts(): array {
        return $this->contacts;
    }
    
    public function addContact(string $name, string $email, string $phone): Contact {
        $contact = new Contact($this->nextId++, $name, $email, $phone);
        $this->contacts[] = $contact;
        $this->notifyObservers();
        return $contact;
    }
    
    public function updateContact(int $id, array $updates): bool {
        foreach ($this->contacts as $contact) {
            if ($contact->id === $id) {
                if (isset($updates['name'])) $contact->name = $updates['name'];
                if (isset($updates['email'])) $contact->email = $updates['email'];
                if (isset($updates['phone'])) $contact->phone = $updates['phone'];
                $this->notifyObservers();
                return true;
            }
        }
        return false;
    }
    
    public function deleteContact(int $id): bool {
        foreach ($this->contacts as $key => $contact) {
            if ($contact->id === $id) {
                unset($this->contacts[$key]);
                $this->contacts = array_values($this->contacts);
                $this->notifyObservers();
                return true;
            }
        }
        return false;
    }
    
    public function searchContacts(string $query): array {
        $query = strtolower($query);
        return array_filter($this->contacts, function($contact) use ($query) {
            return strpos(strtolower($contact->name), $query) !== false ||
                   strpos(strtolower($contact->email), $query) !== false;
        });
    }
}

// Presenter
class ContactPresenter implements ContactObserver {
    private ContactModel $model;
    private ContactView $view;
    
    public function __construct(ContactModel $model, ContactView $view) {
        $this->model = $model;
        $this->view = $view;
        $this->view->setPresenter($this);
        $this->model->addObserver($this);
        $this->loadContacts();
    }
    
    public function onAddContact(): void {
        try {
            $formData = $this->view->getFormData();
            
            if (!$this->validateContactData($formData)) {
                $this->view->showError('Veuillez remplir tous les champs obligatoires');
                return;
            }
            
            $this->model->addContact(
                $formData['name'],
                $formData['email'],
                $formData['phone']
            );
            
            $this->view->clearForm();
            $this->view->showSuccess('Contact ajouté avec succès');
        } catch (Exception $e) {
            $this->view->showError('Erreur lors de l\'ajout du contact: ' . $e->getMessage());
        }
    }
    
    public function onDeleteContact(int $id): void {
        try {
            if ($this->model->deleteContact($id)) {
                $this->view->showSuccess('Contact supprimé avec succès');
            } else {
                $this->view->showError('Contact non trouvé');
            }
        } catch (Exception $e) {
            $this->view->showError('Erreur lors de la suppression: ' . $e->getMessage());
        }
    }
    
    public function onSearchContacts(string $query): void {
        try {
            $results = $this->model->searchContacts($query);
            $this->view->displayContacts($results);
        } catch (Exception $e) {
            $this->view->showError('Erreur lors de la recherche: ' . $e->getMessage());
        }
    }
    
    public function onContactsChanged(array $contacts): void {
        $this->view->displayContacts($contacts);
    }
    
    private function loadContacts(): void {
        $contacts = $this->model->getAllContacts();
        $this->view->displayContacts($contacts);
    }
    
    private function validateContactData(array $data): bool {
        return !empty($data['name']) && 
               !empty($data['email']) && 
               !empty($data['phone']) &&
               filter_var($data['email'], FILTER_VALIDATE_EMAIL);
    }
}

import java.util.*;
import java.util.stream.Collectors;

// Model - Entité Contact
class Contact {
    private int id;
    private String name;
    private String email;
    private String phone;
    
    public Contact(int id, String name, String email, String phone) {
        this.id = id;
        this.name = name;
        this.email = email;
        this.phone = phone;
    }
    
    // Getters et Setters
    public int getId() { return id; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }
    public String getPhone() { return phone; }
    public void setPhone(String phone) { this.phone = phone; }
    
    @Override
    public String toString() {
        return String.format("Contact{id=%d, name='%s', email='%s', phone='%s'}", 
                           id, name, email, phone);
    }
}

// Observer Interface
interface ContactObserver {
    void onContactsChanged(List contacts);
}

// Model - Gestion des données
class ContactModel {
    private List contacts = new ArrayList<>();
    private List observers = new ArrayList<>();
    private int nextId = 1;
    
    public void addObserver(ContactObserver observer) {
        observers.add(observer);
    }
    
    public void removeObserver(ContactObserver observer) {
        observers.remove(observer);
    }
    
    private void notifyObservers() {
        for (ContactObserver observer : observers) {
            observer.onContactsChanged(new ArrayList<>(contacts));
        }
    }
    
    public List getAllContacts() {
        return new ArrayList<>(contacts);
    }
    
    public Contact addContact(String name, String email, String phone) {
        Contact contact = new Contact(nextId++, name, email, phone);
        contacts.add(contact);
        notifyObservers();
        return contact;
    }
    
    public boolean updateContact(int id, String name, String email, String phone) {
        for (Contact contact : contacts) {
            if (contact.getId() == id) {
                if (name != null) contact.setName(name);
                if (email != null) contact.setEmail(email);
                if (phone != null) contact.setPhone(phone);
                notifyObservers();
                return true;
            }
        }
        return false;
    }
    
    public boolean deleteContact(int id) {
        boolean removed = contacts.removeIf(contact -> contact.getId() == id);
        if (removed) {
            notifyObservers();
        }
        return removed;
    }
    
    public List searchContacts(String query) {
        String lowerQuery = query.toLowerCase();
        return contacts.stream()
                .filter(contact -> 
                    contact.getName().toLowerCase().contains(lowerQuery) ||
                    contact.getEmail().toLowerCase().contains(lowerQuery))
                .collect(Collectors.toList());
    }
}

// Classe pour les données du formulaire
class ContactFormData {
    private String name;
    private String email;
    private String phone;
    
    public ContactFormData(String name, String email, String phone) {
        this.name = name;
        this.email = email;
        this.phone = phone;
    }
    
    public String getName() { return name; }
    public String getEmail() { return email; }
    public String getPhone() { return phone; }
    
    public boolean isValid() {
        return name != null && !name.trim().isEmpty() &&
               email != null && !email.trim().isEmpty() &&
               phone != null && !phone.trim().isEmpty();
    }
}

// Presenter
class ContactPresenter implements ContactObserver {
    private ContactModel model;
    private ContactView view;
    
    public ContactPresenter(ContactModel model, ContactView view) {
        this.model = model;
        this.view = view;
        this.view.setPresenter(this);
        this.model.addObserver(this);
        loadContacts();
    }
    
    public void onAddContact() {
        try {
            ContactFormData formData = view.getFormData();
            
            if (!formData.isValid()) {
                view.showError("Veuillez remplir tous les champs obligatoires");
                return;
            }
            
            model.addContact(formData.getName(), formData.getEmail(), formData.getPhone());
            view.clearForm();
            view.showSuccess("Contact ajouté avec succès");
        } catch (Exception e) {
            view.showError("Erreur lors de l'ajout du contact: " + e.getMessage());
        }
    }
    
    public void onDeleteContact(int id) {
        try {
            if (model.deleteContact(id)) {
                view.showSuccess("Contact supprimé avec succès");
            } else {
                view.showError("Contact non trouvé");
            }
        } catch (Exception e) {
            view.showError("Erreur lors de la suppression: " + e.getMessage());
        }
    }
    
    public void onSearchContacts(String query) {
        try {
            List results = model.searchContacts(query);
            view.displayContacts(results);
        } catch (Exception e) {
            view.showError("Erreur lors de la recherche: " + e.getMessage());
        }
    }
    
    @Override
    public void onContactsChanged(List contacts) {
        view.displayContacts(contacts);
    }
    
    private void loadContacts() {
        List contacts = model.getAllContacts();
        view.displayContacts(contacts);
    }
}

class ConsoleContactView implements ContactView {
    private ContactPresenter presenter;
    private Scanner scanner = new Scanner(System.in);
    
    @Override
    public void setPresenter(ContactPresenter presenter) {
        this.presenter = presenter;
    }
    
    @Override
    public void displayContacts(List contacts) {
        System.out.println("\n=== Liste des Contacts ===");
        if (contacts.isEmpty()) {
            System.out.println("Aucun contact trouvé.");
        } else {
            for (Contact contact : contacts) {
                System.out.println(contact);
            }
        }
    }
    
    @Override
    public void displayContact(Contact contact) {
        System.out.println("\n=== Détail du Contact ===");
        System.out.println(contact);
    }
    
    @Override
    public void showError(String message) {
        System.err.println("❌ ERREUR: " + message);
    }
    
    @Override
    public void showSuccess(String message) {
        System.out.println("✅ SUCCÈS: " + message);
    }
    
    @Override
    public void clearForm() {
        // Pas de formulaire à vider en mode console
    }
    
    @Override
    public ContactFormData getFormData() {
        System.out.print("Nom: ");
        String name = scanner.nextLine();
        System.out.print("Email: ");
        String email = scanner.nextLine();
        System.out.print("Téléphone: ");
        String phone = scanner.nextLine();
        
        return new ContactFormData(name, email, phone);
    }
    
    public void showMenu() {
        System.out.println("\n=== Gestionnaire de Contacts MVP ===");
        System.out.println("1. Ajouter un contact");
        System.out.println("2. Afficher tous les contacts");
        System.out.println("3. Rechercher des contacts");
        System.out.println("4. Supprimer un contact");
        System.out.println("0. Quitter");
        System.out.print("Votre choix: ");
    }
    
    public void handleUserInput() {
        while (true) {
            showMenu();
            String choice = scanner.nextLine();
            
            switch (choice) {
                case "1":
                    presenter.onAddContact();
                    break;
                case "2":
                    presenter.onContactsChanged(new ArrayList<>());
                    break;
                case "3":
                    System.out.print("Terme de recherche: ");
                    String query = scanner.nextLine();
                    presenter.onSearchContacts(query);
                    break;
                case "4":
                    System.out.print("ID du contact à supprimer: ");
                    try {
                        int id = Integer.parseInt(scanner.nextLine());
                        presenter.onDeleteContact(id);
                    } catch (NumberFormatException e) {
                        showError("ID invalide");
                    }
                    break;
                case "0":
                    System.out.println("Au revoir !");
                    return;
                default:
                    showError("Choix invalide");
            }
        }
    }
}

        model.addContact("Bob Johnson", "bob@example.com", "555-123-4567");
        
        // Démarrage de l'interface utilisateur
        view.handleUserInput();
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Séparation claire : Vue passive, logique dans le Presenter
  • Testabilité excellente : Presenter facilement testable
  • Réutilisabilité : Même Presenter pour différentes vues
  • Maintenance facilitée : Responsabilités bien définies
  • Évolutivité : Ajout facile de nouvelles fonctionnalités

❌ Inconvénients

  • Complexité accrue : Plus de classes et d'interfaces
  • Couplage Presenter-Vue : Interface spécifique requise
  • Overhead : Peut être excessif pour des vues simples
  • Courbe d'apprentissage : Concept plus complexe que MVC
  • Duplication potentielle : Logique similaire entre Presenters

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Applications complexes : Logique de présentation importante
  • Tests unitaires critiques : Besoin de tester la logique UI
  • Équipes séparées : Développeurs UI et logique métier
  • Vues multiples : Même logique, interfaces différentes
  • Applications d'entreprise : Maintenance long terme

❌ Quand l'éviter

  • Applications simples : Peu de logique de présentation
  • Prototypes rapides : Développement agile requis
  • Équipe réduite : Overhead de structure trop important
  • Vues statiques : Peu d'interactions utilisateur
  • Contraintes de performance : Latence critique

🔨 Marteau de Maslow

Manifestation : "MVP sépare bien les responsabilités, utilisons-le partout."

Risque : Sur-architecture d'applications simples qui n'en ont pas besoin.

⚓ Biais d'Ancrage

Manifestation : S'accrocher au premier pattern architectural appris.

Risque : Ne pas considérer d'autres patterns plus adaptés au contexte.

🎯 Biais de Complexité

Manifestation : "Plus c'est complexe, plus c'est professionnel."

Risque : Ajouter des couches d'abstraction inutiles qui compliquent la maintenance.
