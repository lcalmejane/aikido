🎪 MVVM Pattern

Data binding automatique entre Vue et ViewModel

🏗️ Architectural
⭐ Difficulté: Avancé
⏱️ 30 min
🔗 Data Binding

🎯 Définition

Le MVVM (Model-View-ViewModel) est un pattern architectural qui utilise le data binding pour synchroniser automatiquement la Vue avec un ViewModel, éliminant le besoin de code de synchronisation manuel.

❌ Problème Résolu

  • Synchronisation manuelle Vue-Données
  • Code répétitif de mise à jour d'interface
  • Couplage fort entre Vue et logique
  • Gestion complexe des états d'interface

✅ Solution Apportée

  • Data binding bidirectionnel automatique
  • ViewModel observable et réactif
  • Séparation complète Vue-Logique
  • Testabilité maximale du ViewModel
💡 Spécificité MVVM : Le data binding élimine le besoin de code de synchronisation explicite. La Vue se met à jour automatiquement quand le ViewModel change.

🏗️ Structure UML

Model
+ getData(): Data
+ saveData(data: Data): void
+ validateData(data: Data): boolean
View
- dataBinding: DataBinding
+ bindToViewModel(vm: ViewModel): void
+ render(): void
ViewModel
- model: Model
- observableProperties: Observable[]
+ getProperty(name: string): Observable
+ setProperty(name: string, value: any): void
+ executeCommand(cmd: string): void
- notifyPropertyChanged(): void

Éléments Clés

  • Model : Données et logique métier pure
  • View : Interface utilisateur avec data binding
  • ViewModel : Propriétés observables et commandes
  • Data Binding : Synchronisation automatique bidirectionnelle

// Model - Entité Produit
interface Product {
    id: number;
    name: string;
    price: number;
    category: string;
    inStock: boolean;
}

class ProductModel {
    private products: Product[] = [];
    private observers: ProductObserver[] = [];
    
    addObserver(observer: ProductObserver): void {
        this.observers.push(observer);
    }
    
    private notifyObservers(): void {
        this.observers.forEach(observer => observer.onProductsChanged(this.products));
    }
    
    getAllProducts(): Product[] {
        return [...this.products];
    }
    
    addProduct(product: Omit): Product {
        const newProduct: Product = {
            id: Date.now(),
            ...product
        };
        this.products.push(newProduct);
        this.notifyObservers();
        return newProduct;
    }
    
    updateProduct(id: number, updates: Partial): boolean {
        const index = this.products.findIndex(p => p.id === id);
        if (index !== -1) {
            this.products[index] = { ...this.products[index], ...updates };
            this.notifyObservers();
            return true;
        }
        return false;
    }
    
    deleteProduct(id: number): boolean {
        const initialLength = this.products.length;
        this.products = this.products.filter(p => p.id !== id);
        if (this.products.length < initialLength) {
            this.notifyObservers();
            return true;
        }
        return false;
    }
    
    searchProducts(query: string): Product[] {
        return this.products.filter(product =>
            product.name.toLowerCase().includes(query.toLowerCase()) ||
            product.category.toLowerCase().includes(query.toLowerCase())
        );
    }
    
    getProductsByCategory(category: string): Product[] {
        return this.products.filter(p => p.category === category);
    }
}

interface ProductObserver {
    onProductsChanged(products: Product[]): void;
}

// ViewModel avec propriétés observables
class ProductViewModel implements ProductObserver {
    private model: ProductModel;
    
    // Propriétés observables (Vue.js reactive)
    public products: Product[] = [];
    public filteredProducts: Product[] = [];
    public searchQuery: string = '';
    public selectedCategory: string = 'all';
    public newProduct: Omit = {
        name: '',
        price: 0,
        category: '',
        inStock: true
    };
    public isLoading: boolean = false;
    public errorMessage: string = '';
    public successMessage: string = '';
    
    // Propriétés calculées
    public get categories(): string[] {
        const cats = [...new Set(this.products.map(p => p.category))];
        return ['all', ...cats];
    }
    
    public get totalProducts(): number {
        return this.filteredProducts.length;
    }
    
    public get totalValue(): number {
        return this.filteredProducts.reduce((sum, p) => sum + p.price, 0);
    }
    
    public get inStockCount(): number {
        return this.filteredProducts.filter(p => p.inStock).length;
    }
    
    constructor(model: ProductModel) {
        this.model = model;
        this.model.addObserver(this);
        this.loadProducts();
    }
    
    // Commandes (actions)
    public addProductCommand(): void {
        if (!this.validateNewProduct()) {
            this.errorMessage = 'Veuillez remplir tous les champs obligatoires';
            return;
        }
        
        this.isLoading = true;
        this.errorMessage = '';
        
        try {
            this.model.addProduct(this.newProduct);
            this.resetNewProduct();
            this.successMessage = 'Produit ajouté avec succès';
            setTimeout(() => this.successMessage = '', 3000);
        } catch (error) {
            this.errorMessage = 'Erreur lors de l\'ajout du produit';
        } finally {
            this.isLoading = false;
        }
    }
    
    public deleteProductCommand(id: number): void {
        if (confirm('Êtes-vous sûr de vouloir supprimer ce produit ?')) {
            this.isLoading = true;
            try {
                if (this.model.deleteProduct(id)) {
                    this.successMessage = 'Produit supprimé avec succès';
                    setTimeout(() => this.successMessage = '', 3000);
                } else {
                    this.errorMessage = 'Produit non trouvé';
                }
            } catch (error) {
                this.errorMessage = 'Erreur lors de la suppression';
            } finally {
                this.isLoading = false;
            }
        }
    }
    
    public toggleStockCommand(id: number): void {
        const product = this.products.find(p => p.id === id);
        if (product) {
            this.model.updateProduct(id, { inStock: !product.inStock });
        }
    }
    
    public searchCommand(): void {
        this.applyFilters();
    }
    
    public filterByCategoryCommand(): void {
        this.applyFilters();
    }
    
    public clearFiltersCommand(): void {
        this.searchQuery = '';
        this.selectedCategory = 'all';
        this.applyFilters();
    }
    
    // Observer callback
    public onProductsChanged(products: Product[]): void {
        this.products = products;
        this.applyFilters();
    }
    
    private loadProducts(): void {
        this.isLoading = true;
        try {
            const products = this.model.getAllProducts();
            this.onProductsChanged(products);
        } catch (error) {
            this.errorMessage = 'Erreur lors du chargement des produits';
        } finally {
            this.isLoading = false;
        }
    }
    
    private applyFilters(): void {
        let filtered = this.products;
        
        // Filtre par recherche
        if (this.searchQuery.trim()) {
            filtered = this.model.searchProducts(this.searchQuery);
        }
        
        // Filtre par catégorie
        if (this.selectedCategory !== 'all') {
            filtered = filtered.filter(p => p.category === this.selectedCategory);
        }
        
        this.filteredProducts = filtered;
    }
    
    private validateNewProduct(): boolean {
        return !!(this.newProduct.name.trim() && 
                 this.newProduct.category.trim() && 
                 this.newProduct.price > 0);
    }
    
    private resetNewProduct(): void {
        this.newProduct = {
            name: '',
            price: 0,
            category: '',
            inStock: true
        };
    }
}

<?php

// Model - Entité Produit
class Product {
    public int $id;
    public string $name;
    public float $price;
    public string $category;
    public bool $inStock;
    
    public function __construct(int $id, string $name, float $price, string $category, bool $inStock = true) {
        $this->id = $id;
        $this->name = $name;
        $this->price = $price;
        $this->category = $category;
        $this->inStock = $inStock;
    }
    
    public function toArray(): array {
        return [
            'id' => $this->id,
            'name' => $this->name,
            'price' => $this->price,
            'category' => $this->category,
            'inStock' => $this->inStock
        ];
    }
}

interface ProductObserver {
    public function onProductsChanged(array $products): void;
}

class ProductModel {
    private array $products = [];
    private array $observers = [];
    private int $nextId = 1;
    
    public function addObserver(ProductObserver $observer): void {
        $this->observers[] = $observer;
    }
    
    private function notifyObservers(): void {
        foreach ($this->observers as $observer) {
            $observer->onProductsChanged($this->products);
        }
    }
    
    public function getAllProducts(): array {
        return $this->products;
    }
    
    public function addProduct(string $name, float $price, string $category, bool $inStock = true): Product {
        $product = new Product($this->nextId++, $name, $price, $category, $inStock);
        $this->products[] = $product;
        $this->notifyObservers();
        return $product;
    }
    
    public function updateProduct(int $id, array $updates): bool {
        foreach ($this->products as $product) {
            if ($product->id === $id) {
                if (isset($updates['name'])) $product->name = $updates['name'];
                if (isset($updates['price'])) $product->price = $updates['price'];
                if (isset($updates['category'])) $product->category = $updates['category'];
                if (isset($updates['inStock'])) $product->inStock = $updates['inStock'];
                $this->notifyObservers();
                return true;
            }
        }
        return false;
    }
    
    public function deleteProduct(int $id): bool {
        foreach ($this->products as $key => $product) {
            if ($product->id === $id) {
                unset($this->products[$key]);
                $this->products = array_values($this->products);
                $this->notifyObservers();
                return true;
            }
        }
        return false;
    }
    
    public function searchProducts(string $query): array {
        $query = strtolower($query);
        return array_filter($this->products, function($product) use ($query) {
            return strpos(strtolower($product->name), $query) !== false ||
                   strpos(strtolower($product->category), $query) !== false;
        });
    }
    
    public function getProductsByCategory(string $category): array {
        return array_filter($this->products, function($product) use ($category) {
            return $product->category === $category;
        });
    }
}

class ProductViewModel implements ProductObserver {

    private array $filteredProducts = [];

    public function __construct(ProductModel $model) {
        $this->model = $model;
        $this->model->addObserver($this);
        $this->loadProducts();
    }
    
    // Simulation du data binding avec callbacks
    public function onPropertyChange(string $property, callable $callback): void {
        if (!isset($this->propertyChangeCallbacks[$property])) {
            $this->propertyChangeCallbacks[$property] = [];
        }
        $this->propertyChangeCallbacks[$property][] = $callback;
    }
    
    private function notifyPropertyChange(string $property): void {
        if (isset($this->propertyChangeCallbacks[$property])) {
            foreach ($this->propertyChangeCallbacks[$property] as $callback) {
                $callback($this->$property);
            }
        }
    }
    
    // Getters et Setters avec notification
    public function getProducts(): array {
        return $this->products;
    }
    
    public function getFilteredProducts(): array {
        return $this->filteredProducts;
    }
    
    public function setSearchQuery(string $query): void {
        $this->searchQuery = $query;
        $this->notifyPropertyChange('searchQuery');
        $this->applyFilters();
    }
    
    public function getSearchQuery(): string {
        return $this->searchQuery;
    }
    
    public function setSelectedCategory(string $category): void {
        $this->selectedCategory = $category;
        $this->notifyPropertyChange('selectedCategory');
        $this->applyFilters();
    }
    
    public function getSelectedCategory(): string {
        return $this->selectedCategory;
    }
    
    public function getNewProduct(): array {
        return $this->newProduct;
    }
    
    public function setNewProductProperty(string $key, $value): void {
        $this->newProduct[$key] = $value;
        $this->notifyPropertyChange('newProduct');
    }
    
    public function getErrorMessage(): string {
        return $this->errorMessage;
    }
    
    public function getSuccessMessage(): string {
        return $this->successMessage;
    }
    
    public function isLoading(): bool {
        return $this->isLoading;
    }

    public function getCategories(): array {
        $categories = array_unique(array_map(fn($p) => $p->category, $this->products));
        return array_merge(['all'], array_values($categories));
    }

        return count($this->filteredProducts);
    }
    
    public function getTotalValue(): float {
        return array_sum(array_map(fn($p) => $p->price, $this->filteredProducts));
    }
    
    public function getInStockCount(): int {
        return count(array_filter($this->filteredProducts, fn($p) => $p->inStock));
    }
    
    // Commandes
    public function addProductCommand(): void {
        if (!$this->validateNewProduct()) {
            $this->errorMessage = 'Veuillez remplir tous les champs obligatoires';
            $this->notifyPropertyChange('errorMessage');
            return;

        $this->isLoading = true;
        $this->errorMessage = '';
        $this->notifyPropertyChange('isLoading');
        $this->notifyPropertyChange('errorMessage');

            $this->model->addProduct(
                $this->newProduct['name'],
                $this->newProduct['price'],
                $this->newProduct['category'],
                $this->newProduct['inStock']
            );
            
            $this->resetNewProduct();
            $this->successMessage = 'Produit ajouté avec succès';
            $this->notifyPropertyChange('successMessage');
            
            // Simuler l'effacement du message après 3 secondes
            // En réalité, cela serait géré par le framework de binding
        } catch (Exception $e) {
            $this->errorMessage = 'Erreur lors de l\'ajout du produit: ' . $e->getMessage();
            $this->notifyPropertyChange('errorMessage');
        } finally {
            $this->isLoading = false;
            $this->notifyPropertyChange('isLoading');
        }
    }
    
    public function deleteProductCommand(int $id): void {
        $this->isLoading = true;
        $this->notifyPropertyChange('isLoading');
        
        try {
            if ($this->model->deleteProduct($id)) {
                $this->successMessage = 'Produit supprimé avec succès';
                $this->notifyPropertyChange('successMessage');
            } else {
                $this->errorMessage = 'Produit non trouvé';
                $this->notifyPropertyChange('errorMessage');
            }
        } catch (Exception $e) {
            $this->errorMessage = 'Erreur lors de la suppression: ' . $e->getMessage();
            $this->notifyPropertyChange('errorMessage');
        } finally {
            $this->isLoading = false;
            $this->notifyPropertyChange('isLoading');
        }
    }
    
    public function toggleStockCommand(int $id): void {
        $product = array_filter($this->products,

fn($p) => $p->id === $id);
        if (!empty($product)) {
            $product = array_values($product)[0];
            $this->model->updateProduct($id, ['inStock' => !$product->inStock]);
        }
    }
    
    public function clearFiltersCommand(): void {
        $this->searchQuery = '';
        $this->selectedCategory = 'all';
        $this->notifyPropertyChange('searchQuery');
        $this->notifyPropertyChange('selectedCategory');
        $this->applyFilters();
    }
    
    // Observer callback
    public function onProductsChanged(array $products): void {
        $this->products = $products;
        $this->notifyPropertyChange('products');
        $this->applyFilters();
    }
    
    private function loadProducts(): void {
        $this->isLoading = true;
        $this->notifyPropertyChange('isLoading');
        
        try {
            $products = $this->model->getAllProducts();
            $this->onProductsChanged($products);
        } catch (Exception $e) {
            $this->errorMessage = 'Erreur lors du chargement des produits: ' . $e->getMessage();
            $this->notifyPropertyChange('errorMessage');
        } finally {
            $this->isLoading = false;
            $this->notifyPropertyChange('isLoading');
        }
    }
    
    private function applyFilters(): void {
        $filtered = $this->products;
        
        // Filtre par recherche
        if (!empty(trim($this->searchQuery))) {
            $filtered = $this->model->searchProducts($this->searchQuery);
        }
        
        // Filtre par catégorie
        if ($this->selectedCategory !== 'all') {
            $filtered = array_filter($filtered, fn($p) => $p->category === $this->selectedCategory);
        }
        
        $this->filteredProducts = array_values($filtered);
        $this->notifyPropertyChange('filteredProducts');
    }
    
    private function validateNewProduct(): bool {
        return !empty(trim($this->newProduct['name'])) && 
               !empty(trim($this->newProduct['category'])) && 
               $this->newProduct['price'] > 0;
    }
    
    private function resetNewProduct(): void {
        $this->newProduct = [
            'name' => '',
            'price' => 0,
            'category' => '',
            'inStock' => true
        ];
        $this->notifyPropertyChange('newProduct');
    }
}

class Product {
    private int id;

    public Product(int id, String name, double price, String category, boolean inStock) {
        this.id = id;
        this.name = name;
        this.price = price;
        this.category = category;
        this.inStock = inStock;

    // Getters et Setters
    public int getId() { return id; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public double getPrice() { return price; }
    public void setPrice(double price) { this.price = price; }

    public void setCategory(String category) { this.category = category; }
    public boolean isInStock() { return inStock; }
    public void setInStock(boolean inStock) { this.inStock = inStock; }
    
    @Override
    public String toString() {
        return String.format("Product{id=%d, name='%s', price=%.2f, category='%s', inStock=%s}", 
                           id, name, price, category, inStock);
    }
}

interface ProductObserver {
    void onProductsChanged(List products);
}

// Model
class ProductModel {
    private List products = new ArrayList<>();
    private List observers = new ArrayList<>();
    private int nextId = 1;
    
    public void addObserver(ProductObserver observer) {
        observers.add(observer);
    }
    
    public void removeObserver(ProductObserver observer) {
        observers.remove(observer);
    }
    
    private void notifyObservers() {
        for (ProductObserver observer : observers) {
            observer.onProductsChanged(new ArrayList<>(products));
        }
    }
    
    public List getAllProducts() {
        return new ArrayList<>(products);
    }
    
    public Product addProduct(String name, double price, String category, boolean inStock) {
        Product product = new Product(nextId++, name, price, category, inStock);
        products.add(product);
        notifyObservers();
        return product;
    }
    
    public boolean updateProduct(int id, String name, Double price, String category, Boolean inStock) {
        for (Product product : products) {
            if (product.getId() == id) {
                if (name != null) product.setName(name);
                if (price != null) product.setPrice(price);
                if (category != null) product.setCategory(category);
                if (inStock != null) product.setInStock(inStock);
                notifyObservers();
                return true;
            }
        }
        return false;
    }
    
    public boolean deleteProduct(int id) {
        boolean removed = products.removeIf(product -> product.getId() == id);
        if (removed) {
            notifyObservers();
        }
        return removed;
    }
    
    public List searchProducts(String query) {
        String lowerQuery = query.toLowerCase();
        return products.stream()
                .filter(product -> 
                    product.getName().toLowerCase().contains(lowerQuery) ||
                    product.getCategory().toLowerCase().contains(lowerQuery))
                .collect(Collectors.toList());
    }
    
    public List getProductsByCategory(String category) {
        return products.stream()
                .filter(product -> product.getCategory().equals(category))
                .collect(Collectors.toList());
    }
}

// ViewModel avec PropertyChangeSupport pour simuler le data binding
class ProductViewModel implements ProductObserver {
    private ProductModel model;
    private PropertyChangeSupport propertyChangeSupport;
    
    // Propriétés observables
    private List products = new ArrayList<>();
    private List filteredProducts = new ArrayList<>();
    private String searchQuery = "";
    private String selectedCategory = "all";
    private String newProductName = "";
    private double newProductPrice = 0.0;
    private String newProductCategory = "";
    private boolean newProductInStock = true;
    private boolean isLoading = false;
    private String errorMessage = "";
    private String successMessage = "";
    
    public ProductViewModel(ProductModel model) {
        this.model = model;
        this.propertyChangeSupport = new PropertyChangeSupport(this);
        this.model.addObserver(this);
        loadProducts();
    }
    
    // Méthodes pour le data binding
    public void addPropertyChangeListener(PropertyChangeListener listener) {
        propertyChangeSupport.addPropertyChangeListener(listener);
    }
    
    public void removePropertyChangeListener(PropertyChangeListener listener) {
        propertyChangeSupport.removePropertyChangeListener(listener);
    }
    
    // Getters et Setters avec notification de changement
    public List getProducts() {
        return new ArrayList<>(products);
    }
    
    private void setProducts(List products) {
        List oldValue = this.products;
        this.products = new ArrayList<>(products);
        propertyChangeSupport.firePropertyChange("products", oldValue, this.products);
    }
    
    public List getFilteredProducts() {
        return new ArrayList<>(filteredProducts);
    }
    
    private void setFilteredProducts(List filteredProducts) {
        List oldValue = this.filteredProducts;
        this.filteredProducts = new ArrayList<>(filteredProducts);
        propertyChangeSupport.firePropertyChange("filteredProducts", oldValue, this.filteredProducts);
    }
    
    public String getSearchQuery() {
        return searchQuery;
    }
    
    public void setSearchQuery(String searchQuery) {
        String oldValue = this.searchQuery;
        this.searchQuery = searchQuery;
        propertyChangeSupport.firePropertyChange("searchQuery", oldValue, searchQuery);
        applyFilters();
    }
    
    public String getSelectedCategory() {
        return selectedCategory;
    }
    
    public void setSelectedCategory(String selectedCategory) {
        String oldValue = this.selectedCategory;
        this.selectedCategory = selectedCategory;
        propertyChangeSupport.firePropertyChange("selectedCategory", oldValue, selectedCategory);
        applyFilters();
    }
    
    public String getNewProductName() {
        return newProductName;
    }
    
    public void setNewProductName(String newProductName) {
        String oldValue = this.newProductName;
        this.newProductName = newProductName;
        propertyChangeSupport.firePropertyChange("newProductName", oldValue, newProductName);
    }
    
    public double getNewProductPrice() {
        return newProductPrice;
    }
    
    public void setNewProductPrice(double newProductPrice) {
        double oldValue = this.newProductPrice;
        this.newProductPrice = newProductPrice;
        propertyChangeSupport.firePropertyChange("newProductPrice", oldValue, newProductPrice);
    }
    
    public String getNewProductCategory() {
        return newProductCategory;
    }
    
    public void setNewProductCategory(String newProductCategory) {
        String oldValue = this.newProductCategory;
        this.newProductCategory = newProductCategory;
        propertyChangeSupport.firePropertyChange("newProductCategory", oldValue, newProductCategory);
    }
    
    public boolean isNewProductInStock() {
        return newProductInStock;
    }
    
    public void setNewProductInStock(boolean newProductInStock) {
        boolean oldValue = this.newProductInStock;
        this.newProductInStock = newProductInStock;
        propertyChangeSupport.firePropertyChange("newProductInStock", oldValue, newProductInStock);
    }
    
    public boolean isLoading() {
        return isLoading;
    }
    
    private void setLoading(boolean loading) {
        boolean oldValue = this.isLoading;
        this.isLoading = loading;
        propertyChangeSupport.firePropertyChange("isLoading", oldValue, loading);
    }
    
    public String getErrorMessage() {
        return errorMessage;
    }
    
    private void setErrorMessage(String errorMessage) {
        String oldValue = this.errorMessage;
        this.errorMessage = errorMessage;
        propertyChangeSupport.firePropertyChange("errorMessage", oldValue, errorMessage);
    }
    
    public String getSuccessMessage() {
        return successMessage;
    }
    
    private void setSuccessMessage(String successMessage) {
        String oldValue = this.successMessage;
        this.successMessage = successMessage;
        propertyChangeSupport.firePropertyChange("successMessage", oldValue, successMessage);
    }
    
    // Propriétés calculées
    public List getCategories() {
        Set categories = products.stream()
                .map(Product::getCategory)
                .collect(Collectors.toSet());
        List result = new ArrayList<>();
        result.add("all");
        result.addAll(categories);
        return result;
    }
    
    public int getTotalProducts() {
        return filteredProducts.size();
    }
    
    public double getTotalValue() {
        return filteredProducts.stream()
                .mapToDouble(Product::getPrice)
                .sum();
    }
    
    public int getInStockCount() {
        return (int) filteredProducts.stream()
                .filter(Product::isInStock)
                .count();
    }
    
    // Commandes
    public void addProductCommand() {
        if (!validateNewProduct()) {
            setErrorMessage("Veuillez remplir tous les champs obligatoires");
            return;
        }
        
        setLoading(true);
        setErrorMessage("");
        
        try {
            model.addProduct(newProductName, newProductPrice, newProductCategory, newProductInStock);
            resetNewProduct();
            setSuccessMessage("Produit ajouté avec succès");
            
            // Simuler l'effacement du message après 3 secondes
            Timer timer = new Timer();
            timer.schedule(new TimerTask() {
                @Override
                public void run() {
                    setSuccessMessage("");
                }
            }, 3000);
            
        } catch (Exception e) {
            setErrorMessage("Erreur lors de l'ajout du produit: " + e.getMessage());
        } finally {
            setLoading(false);
        }
    }
    
    public void deleteProductCommand(int id) {
        setLoading(true);
        try {
            if (model.deleteProduct(id)) {
                setSuccessMessage("Produit supprimé avec succès");
                Timer timer = new Timer();
                timer.schedule(new TimerTask() {
                    @Override
                    public void run() {
                        setSuccessMessage("");
                    }
                }, 3000);
            } else {
                setErrorMessage("Produit non trouvé");
            }
        } catch (Exception e) {
            setErrorMessage("Erreur lors de la suppression: " + e.getMessage());
        } finally {
            setLoading(false);
        }
    }
    
    public void toggleStockCommand(int id) {
        Optional product = products.stream()
                .filter(p -> p.getId() == id)
                .findFirst();
        
        if (product.isPresent()) {
            model.updateProduct(id, null, null, null, !product.get().isInStock());
        }
    }
    
    public void clearFiltersCommand() {
        setSearchQuery("");
        setSelectedCategory("all");
    }
    
    // Observer callback
    @Override
    public void onProductsChanged(List products) {
        setProducts(products);
        applyFilters();
    }
    
    private void loadProducts() {
        setLoading(true);
        try {
            List products = model.getAllProducts();
            onProductsChanged(products);
        } catch (Exception e) {
            setErrorMessage("Erreur lors du chargement des produits: " + e.getMessage());
        } finally {
            setLoading(false);
        }
    }
    
    private void applyFilters() {
        List filtered = new ArrayList<>(products);
        
        // Filtre par recherche
        if (!searchQuery.trim().isEmpty()) {
            filtered = model.searchProducts(searchQuery);
        }
        
        // Filtre par catégorie
        if (!"all".equals(selectedCategory)) {
            filtered = filtered.stream()
                    .filter(product -> product.getCategory().equals(selectedCategory))
                    .collect(Collectors.toList());
        }
        
        setFilteredProducts(filtered);
    }
    
    private boolean validateNewProduct() {
        return !newProductName.trim().isEmpty() && 
               !newProductCategory.trim().isEmpty() && 
               newProductPrice > 0;
    }
    
    private void resetNewProduct() {
        setNewProductName("");
        setNewProductPrice(0.0);
        setNewProductCategory("");
        setNewProductInStock(true);
    }
}

class ProductSwingView extends javax.swing.JFrame {
    private ProductViewModel viewModel;
    private javax.swing.JTable productsTable;

    public ProductSwingView(ProductViewModel viewModel) {

    }
    
    private void initComponents() {
        setTitle("Gestionnaire de Produits MVVM");
        setDefaultCloseOperation(javax.swing.JFrame.EXIT_ON_CLOSE);
        setLayout(new java.awt.BorderLayout());

        javax.swing.JPanel controlPanel = new javax.swing.JPanel(new java.awt.GridLayout(0, 1));

        filterPanel.add(new javax.swing.JLabel("Recherche:"));
        filterPanel.add(searchField);

        filterPanel.add(categoryCombo);
        controlPanel.add(filterPanel);
        
        // Formulaire d'ajout
        javax.swing.JPanel formPanel = new javax.swing.JPanel();
        nameField = new javax.swing.JTextField(10);
        priceField = new javax.swing.JTextField(10);
        categoryField = new javax.swing.JTextField(10);
        stockCheckBox = new javax.swing.JCheckBox("En stock", true);
        javax.swing.JButton addButton = new javax.swing.JButton("Ajouter");
        
        formPanel.add(new javax.swing.JLabel("Nom:"));
        formPanel.add(nameField);
        formPanel.add(new javax.swing.JLabel("Prix:"));
        formPanel.add(priceField);
        formPanel.add(new javax.swing.JLabel("Catégorie:"));
        formPanel.add(categoryField);
        formPanel.add(stockCheckBox);
        formPanel.add(addButton);
        controlPanel.add(formPanel);
        
        // Status
        statusLabel = new javax.swing.JLabel(" ");
        controlPanel.add(statusLabel);
        
        add(controlPanel, java.awt.BorderLayout.SOUTH);
        
        // Event listeners
        addButton.addActionListener(e -> viewModel.addProductCommand());
        searchField.addActionListener(e -> viewModel.setSearchQuery(searchField.getText()));
        categoryCombo.addActionListener(e -> {
            String selected = (String) categoryCombo.getSelectedItem();
            if (selected != null) {
                viewModel.setSelectedCategory(selected);
            }
        });
        
        pack();
    }
    
    private void setupDataBinding() {
        // Binding bidirectionnel simulé avec PropertyChangeListener
        viewModel.addPropertyChangeListener(evt -> {
            switch (evt.getPropertyName()) {
                case "filteredProducts":
                    updateProductsTable();
                    break;
                case "errorMessage":
                    updateStatusLabel();
                    break;
                case "successMessage":
                    updateStatusLabel();
                    break;
                case "isLoading":
                    updateLoadingState();
                    break;
            }
        });
        
        // Binding des champs de formulaire vers le ViewModel
        nameField.addActionListener(e -> viewModel.setNewProductName(nameField.getText()));
        priceField.addActionListener(e -> {
            try {
                viewModel.setNewProductPrice(Double.parseDouble(priceField.getText()));
            } catch (NumberFormatException ex) {
                // Ignorer les valeurs invalides
            }
        });
        categoryField.addActionListener(e -> viewModel.setNewProductCategory(categoryField.getText()));
        stockCheckBox.addActionListener(e -> viewModel.setNewProductInStock(stockCheckBox.isSelected()));
        
        // Initialisation
        updateProductsTable();
        updateCategoryCombo();
    }
    
    private void updateProductsTable() {
        tableModel.setRowCount(0);
        for (Product product : viewModel.getFilteredProducts()) {
            Object[] row = {
                product.getId(),
                product.getName(),
                String.format("%.2f€", product.getPrice()),
                product.getCategory(),
                product.isInStock() ? "Oui" : "Non"
            };
            tableModel.addRow(row);
        }
    }
    
    private void updateCategoryCombo() {
        categoryCombo.removeAllItems();
        for (String category : viewModel.getCategories()) {
            categoryCombo.addItem(category);
        }
    }
    
    private void updateStatusLabel() {
        String error = viewModel.getErrorMessage();
        String success = viewModel.getSuccessMessage();
        
        if (!error.isEmpty()) {
            statusLabel.setText("Erreur: " + error);
            statusLabel.setForeground(java.awt.Color.RED);
        } else if (!success.isEmpty()) {
            statusLabel.setText(success);
            statusLabel.setForeground(java.awt.Color.GREEN);
        } else {
            statusLabel.setText(" ");
        }
    }
    
    private void updateLoadingState() {
        boolean loading = viewModel.isLoading();
        nameField.setEnabled(!loading);
        priceField.setEnabled(!loading);
        categoryField.setEnabled(!loading);
        stockCheckBox.setEnabled(!loading);
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Data binding automatique : Synchronisation transparente Vue-ViewModel
  • Testabilité maximale : ViewModel complètement indépendant de l'UI
  • Séparation parfaite : Aucun couplage entre Vue et
  • Séparation parfaite : Aucun couplage entre Vue et logique métier
  • Réactivité native : Mise à jour automatique de l'interface
  • Réutilisabilité : ViewModel indépendant de la technologie d'affichage

❌ Inconvénients

  • Complexité initiale : Mise en place du système de binding
  • Courbe d'apprentissage : Concepts de programmation réactive
  • Performance : Overhead du système d'observation
  • Debugging complexe : Flux de données automatisés difficiles à tracer

🎯 Cas d'usage recommandés

✅ Recommandé pour

  • Applications avec interfaces complexes et dynamiques
  • Formulaires avec validation en temps réel
  • Dashboards avec données changeantes
  • Applications nécessitant une synchronisation bidirectionnelle
  • Projets utilisant des frameworks supportant le data binding

❌ Éviter pour

  • Applications simples avec peu d'interactions
  • Projets sans framework de data binding
  • Équipes non familières avec la programmation réactive
  • Applications avec contraintes de performance strictes
  • Prototypes rapides ou applications temporaires
