🔨 Builder Pattern

Construire des objets complexes étape par étape

🎨 Design Patterns
⭐ Difficulté: Moyen
⏱️ 20 min
🏭 Création

🎯 Définition

Le Builder est un pattern de création qui permet de construire des objets complexes étape par étape. Il sépare la construction d'un objet complexe de sa représentation.

❌ Problème Résolu

  • Éviter les constructeurs avec trop de paramètres
  • Créer des objets avec des configurations optionnelles
  • Construire des objets complexes de manière lisible
  • Valider la cohérence lors de la construction

✅ Solution Apportée

  • Construction étape par étape
  • Interface fluide et lisible
  • Validation centralisée
  • Réutilisabilité du processus
⚠️ Attention : Le Builder peut être sur-utilisé pour des objets simples où un constructeur classique suffirait.

🏗️ Structure UML

Builder
+ buildPartA(): Builder
+ buildPartB(): Builder
+ getResult(): Product
ConcreteBuilder
+ buildPartA(): Builder
+ buildPartB(): Builder
+ getResult(): Product
Director
+ construct(): void
Product
+ operation(): void

Éléments Clés

  • Builder : Interface définissant les étapes de construction
  • ConcreteBuilder : Implémente les étapes et assemble le produit
  • Director : Orchestre la construction selon un ordre spécifique
  • Product : Objet complexe résultant de la construction

💡 Point clé : Le Director orchestre la construction, mais c'est le Builder qui connaît les détails de l'assemblage.

💻 Implémentations

Exemple : Constructeur de Requêtes SQL


// Product - La requête SQL complexe
class SQLQuery {
    constructor(
        public readonly select: string[],
        public readonly from: string,
        public readonly joins: string[],
        public readonly where: string[],
        public readonly orderBy: string[],
        public readonly limit?: number
    ) {}
    
    public toString(): string {
        let sql = `SELECT ${this.select.join(', ')} FROM ${this.from}`;
        
        if (this.joins.length > 0) {
            sql += ' ' + this.joins.join(' ');
        }
        
        if (this.where.length > 0) {
            sql += ' WHERE ' + this.where.join(' AND ');
        }
        
        if (this.orderBy.length > 0) {
            sql += ' ORDER BY ' + this.orderBy.join(', ');
        }
        
        if (this.limit) {
            sql += ` LIMIT ${this.limit}`;
        }
        
        return sql;
    }
}

// Builder interface
interface QueryBuilder {
    select(fields: string[]): QueryBuilder;
    from(table: string): QueryBuilder;
    join(table: string, condition: string): QueryBuilder;
    where(condition: string): QueryBuilder;
    orderBy(field: string, direction?: 'ASC' | 'DESC'): QueryBuilder;
    limit(count: number): QueryBuilder;
    build(): SQLQuery;
}

// Concrete Builder
class MySQLQueryBuilder implements QueryBuilder {
    private selectFields: string[] = [];
    private fromTable: string = '';
    private joinClauses: string[] = [];
    private whereClauses: string[] = [];
    private orderByClauses: string[] = [];
    private limitCount?: number;
    
    select(fields: string[]): QueryBuilder {
        this.selectFields = [...fields];
        return this;
    }
    
    from(table: string): QueryBuilder {
        this.fromTable = table;
        return this;
    }
    
    join(table: string, condition: string): QueryBuilder {
        this.joinClauses.push(`JOIN ${table} ON ${condition}`);
        return this;
    }
    
    where(condition: string): QueryBuilder {
        this.whereClauses.push(condition);
        return this;
    }
    
    orderBy(field: string, direction: 'ASC' | 'DESC' = 'ASC'): QueryBuilder {
        this.orderByClauses.push(`${field} ${direction}`);
        return this;
    }
    
    limit(count: number): QueryBuilder {
        this.limitCount = count;
        return this;
    }
    
    build(): SQLQuery {
        if (!this.fromTable) {
            throw new Error('FROM clause is required');
        }
        if (this.selectFields.length === 0) {
            throw new Error('SELECT fields are required');
        }
        
        return new SQLQuery(
            this.selectFields,
            this.fromTable,
            this.joinClauses,
            this.whereClauses,
            this.orderByClauses,
            this.limitCount
        );
    }
}

// Director (optionnel)
class QueryDirector {
    constructor(private builder: QueryBuilder) {}
    
    buildUserPostsQuery(userId: number): SQLQuery {
        return this.builder
            .select(['p.title', 'p.content', 'u.name as author'])
            .from('posts p')
            .join('users u', 'p.user_id = u.id')
            .where(`u.id = ${userId}`)
            .where('p.published = 1')
            .orderBy('p.created_at', 'DESC')
            .limit(10)
            .build();
    }
}

    .where('active = 1')
    .orderBy('name')
    .build();

// Product - Email complexe
class Email {
    private string $to;
    private string $subject;
    private string $body;
    private array $attachments = [];
    private array $headers = [];
    private string $priority = 'normal';
    
    public function __construct(
        string $to,
        string $subject,
        string $body,
        array $attachments = [],
        array $headers = [],
        string $priority = 'normal'
    ) {
        $this->to = $to;
        $this->subject = $subject;
        $this->body = $body;
        $this->attachments = $attachments;
        $this->headers = $headers;
        $this->priority = $priority;
    }
    
    public function send(): bool {
        echo "📧 Envoi email à: {$this->to}\n";
        echo "📋 Sujet: {$this->subject}\n";
        echo "📄 Corps: " . substr($this->body, 0, 50) . "...\n";
        echo "📎 Pièces jointes: " . count($this->attachments) . "\n";
        echo "⚡ Priorité: {$this->priority}\n";
        return true;
    }
}

// Builder interface
interface EmailBuilder {
    public function to(string $email): EmailBuilder;
    public function subject(string $subject): EmailBuilder;
    public function body(string $body): EmailBuilder;
    public function attach(string $filePath): EmailBuilder;
    public function priority(string $level): EmailBuilder;
    public function build(): Email;
}

// Concrete Builder
class HTMLEmailBuilder implements EmailBuilder {
    private string $to = '';
    private string $subject = '';
    private string $body = '';
    private array $attachments = [];
    private array $headers = [];
    private string $priority = 'normal';
    
    public function to(string $email): EmailBuilder {
        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            throw new InvalidArgumentException("Email invalide: {$email}");
        }
        $this->to = $email;
        return $this;
    }
    
    public function subject(string $subject): EmailBuilder {
        $this->subject = htmlspecialchars($subject);
        return $this;
    }
    
    public function body(string $body): EmailBuilder {
        $this->body = $body;
        $this->headers['Content-Type'] = 'text/html; charset=UTF-8';
        return $this;
    }
    
    public function attach(string $filePath): EmailBuilder {
        if (!file_exists($filePath)) {
            throw new InvalidArgumentException("Fichier introuvable: {$filePath}");
        }
        
        $this->attachments[] = [
            'path' => $filePath,
            'name' => basename($filePath),
            'size' => filesize($filePath)
        ];
        return $this;
    }
    
    public function priority(string $level): EmailBuilder {
        $validPriorities = ['low', 'normal', 'high', 'urgent'];
        if (!in_array($level, $validPriorities)) {
            throw new InvalidArgumentException("Priorité invalide: {$level}");
        }
        $this->priority = $level;
        return $this;
    }
    
    public function build(): Email {
        if (empty($this->to)) {
            throw new RuntimeException('Destinataire requis');
        }
        if (empty($this->subject)) {
            throw new RuntimeException('Sujet requis');
        }
        
        return new Email(
            $this->to,
            $this->subject,
            $this->body,
            $this->attachments,
            $this->headers,
            $this->priority
        );
    }
}

// Utilisation
$builder = new HTMLEmailBuilder();

$email = $builder
    ->to('user@example.com')
    ->subject('Test Builder Pattern')
    ->body('<p>Ceci est un test du pattern Builder.</p>')
    ->priority('high')
    ->build();

$email->send();

// Product - Configuration de serveur
public class ServerConfig {
    private final String host;
    private final int port;
    private final String protocol;
    private final int maxConnections;
    private final boolean sslEnabled;
    private final Map<String, String> properties;
    
    public ServerConfig(String host, int port, String protocol, 
                       int maxConnections, boolean sslEnabled,
                       Map<String, String> properties) {
        this.host = host;
        this.port = port;
        this.protocol = protocol;
        this.maxConnections = maxConnections;
        this.sslEnabled = sslEnabled;
        this.properties = new HashMap<>(properties);
    }
    
    public void start() {
        System.out.println("🚀 Démarrage serveur:");
        System.out.println("📡 " + protocol + "://" + host + ":" + port);
        System.out.println("🔗 Max connexions: " + maxConnections);
        System.out.println("🔒 SSL: " + (sslEnabled ? "Activé" : "Désactivé"));
    }
    
    // Getters
    public String getHost() { return host; }
    public int getPort() { return port; }
    public String getProtocol() { return protocol; }
}

// Builder interface
public interface ServerConfigBuilder {
    ServerConfigBuilder host(String host);
    ServerConfigBuilder port(int port);
    ServerConfigBuilder protocol(String protocol);
    ServerConfigBuilder maxConnections(int max);
    ServerConfigBuilder enableSsl();
    ServerConfigBuilder property(String key, String value);
    ServerConfig build();
}

// Concrete Builder
public class HttpServerConfigBuilder implements ServerConfigBuilder {
    private String host = "localhost";
    private int port = 8080;
    private String protocol = "HTTP";
    private int maxConnections = 100;
    private boolean sslEnabled = false;
    private Map<String, String> properties = new HashMap<>();
    
    @Override
    public ServerConfigBuilder host(String host) {
        this.host = host;
        return this;
    }
    
    @Override
    public ServerConfigBuilder port(int port) {
        if (port < 1 || port > 65535) {
            throw new IllegalArgumentException("Port invalide");
        }
        this.port = port;
        return this;
    }
    
    @Override
    public ServerConfigBuilder protocol(String protocol) {
        this.protocol = protocol.toUpperCase();
        return this;
    }
    
    @Override
    public ServerConfigBuilder maxConnections(int max) {
        this.maxConnections = max;
        return this;
    }
    
    @Override
    public ServerConfigBuilder enableSsl() {
        this.sslEnabled = true;
        this.protocol = "HTTPS";
        if (this.port == 8080) {
            this.port = 8443;
        }
        return this;
    }
    
    @Override
    public ServerConfigBuilder property(String key, String value) {
        this.properties.put(key, value);
        return this;
    }
    
    @Override
    public ServerConfig build() {
        return new ServerConfig(
            host, port, protocol, maxConnections, 
            sslEnabled, properties
        );
    }
}

// Utilisation
ServerConfigBuilder builder = new HttpServerConfigBuilder();

ServerConfig server = builder
    .host("example.com")
    .port(443)
    .enableSsl()
    .maxConnections(1000)
    .property("compression", "gzip")
    .build();

server.start();

⚖️ Avantages et Inconvénients

✅ Avantages

  • Lisibilité : Code fluide et expressif
  • Flexibilité : Paramètres optionnels faciles
  • Validation : Contrôle à chaque étape
  • Immutabilité : Objets finaux non modifiables
  • Réutilisabilité : Builders configurables

❌ Inconvénients

  • Complexité : Plus de code à maintenir
  • Performance : Objets intermédiaires créés
  • Mémoire : Builder garde l'état temporaire
  • Sur-ingénierie : Overkill pour objets simples
  • Duplication : Logique répétée entre builders

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Configuration complexe : Serveurs, API clients
  • Requêtes : SQL builders, filtres de recherche
  • Documents : PDF, emails HTML, rapports
  • Objets de jeu : Personnages, véhicules
  • Tests : Test data builders, mocks

❌ Quand l'éviter

  • Objets simples : Moins de 3-4 paramètres
  • Objets immutables : Quand tous les champs sont requis
  • Performance critique : Quand chaque allocation compte
  • API temporaire : Prototypes ou code jetable
  • Équipe inexpérimentée : Risque de sur-complexification

🔄 Alternatives et Patterns Liés

🏭 Factory Method

Pour créer des objets sans exposer la logique de création

EmailFactory.createWelcomeEmail(user)

🧬 Prototype

Pour cloner des objets existants avec modifications

baseConfig.clone().setPort(8080)

📋 Fluent Interface

Interface fluide sans pattern Builder complet

new Query().select("*").from("users")

🧩 Biais Cognitifs Associés

🔨 Marteau de Maslow

Manifestation : "Le Builder rend le code élégant, utilisons-le partout."

Risque : Sur-utilisation du pattern même pour des objets simples.

🎯 Biais de Perfectionnisme

Manifestation : Créer des builders avec trop de méthodes de configuration.

Risque : API surchargée et difficile à utiliser.

✅ Biais de Confirmation

Manifestation : Ignorer les alternatives plus simples (constructeurs, factory).

Risque : Solution inadaptée au problème réel.

⚠️ Anti-Patterns à Éviter

🏗️ God Builder

Un Builder qui construit trop de types d'objets différents.

// ❌ Mauvais : Builder qui fait tout class UniversalBuilder { // Construit emails, configs, requêtes, etc. }

🔧 Over-Engineering

Utiliser le Builder pour des objets simples avec peu de paramètres.

// ❌ Overkill pour un objet simple class PersonBuilder { name(String name) { ... } age(int age) { ... } // Seulement 2 champs ! }
