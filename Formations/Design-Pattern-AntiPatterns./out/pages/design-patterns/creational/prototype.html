🧬 Prototype Pattern

Créer des objets par clonage d'instances existantes

🎨 Design Patterns
⭐ Difficulté: Moyen
⏱️ 18 min
🏭 Création

🎯 Définition

Le Prototype est un pattern de création qui permet de créer de nouveaux objets en clonant des instances existantes plutôt qu'en les construisant depuis zéro. Il est particulièrement utile lorsque la création d'un objet est coûteuse.

❌ Problème Résolu

  • Éviter la création coûteuse d'objets complexes
  • Créer des objets sans connaître leur classe exacte
  • Réduire le nombre de sous-classes
  • Configurer des objets à l'exécution

✅ Solution Apportée

  • Clonage d'instances existantes
  • Performance améliorée
  • Flexibilité de création
  • Registre de prototypes
⚠️ Attention : Le clonage profond peut être complexe avec des objets contenant des références circulaires ou des ressources externes.

🏗️ Structure UML

Éléments Clés

  • Prototype : Interface définissant la méthode de clonage
  • ConcretePrototype : Implémente le clonage de lui-même
  • Client : Crée des objets en clonant des prototypes
  • Registry : Optionnel, stocke les prototypes disponibles

💡 Point clé : Chaque prototype sait comment se cloner, permettant la création d'objets sans connaître leur classe concrète.

💻 Implémentations

Exemple : Système de Documents


// Interface Prototype
interface Prototype {
    clone(): Prototype;
}

// Prototype concret
class Document implements Prototype {
    private title: string;
    private content: string;
    private metadata: Map<string, any>;

    constructor(title: string, content: string) {
        this.title = title;
        this.content = content;
        this.metadata = new Map();
    }

    // Méthode de clonage
    clone(): Document {
        const cloned = new Document(this.title, this.content);
        // Clonage profond des métadonnées
        cloned.metadata = new Map(this.metadata);
        return cloned;
    }

    setTitle(title: string): void {
        this.title = title;
    }

    setContent(content: string): void {
        this.content = content;
    }

    addMetadata(key: string, value: any): void {
        this.metadata.set(key, value);
    }

    getInfo(): string {
        return `Document: ${this.title} - ${this.content.substring(0, 50)}...`;
    }
}

// Registre de prototypes
class PrototypeRegistry {
    private prototypes: Map<string, Prototype> = new Map();

    register(name: string, prototype: Prototype): void {
        this.prototypes.set(name, prototype);
    }

    create(name: string): Prototype | null {
        const prototype = this.prototypes.get(name);
        return prototype ? prototype.clone() : null;
    }

    getAvailableTypes(): string[] {
        return Array.from(this.prototypes.keys());
    }
}

// Utilisation
const registry = new PrototypeRegistry();

// Création d'un prototype de base
const baseDocument = new Document("Template", "Contenu de base");
baseDocument.addMetadata("author", "AI-KIDO");
baseDocument.addMetadata("version", "1.0");

// Enregistrement du prototype
registry.register("document-template", baseDocument);

// Création d'instances par clonage
const doc1 = registry.create("document-template") as Document;
doc1.setTitle("Document 1");
doc1.setContent("Contenu spécifique du document 1");

const doc2 = registry.create("document-template") as Document;
doc2.setTitle("Document 2");
doc2.setContent("Contenu spécifique du document 2");

console.log(doc1.getInfo());
console.log(doc2.getInfo());

// Vérification que les objets sont différents
console.log(doc1 === doc2); // false
console.log(doc1 === baseDocument); // false


<?php

// Interface Prototype
interface Prototype
{
    public function clone(): Prototype;
}

// Prototype concret
class GameCharacter implements Prototype
{
    private string $name;
    private int $level;
    private array $equipment;
    private array $skills;

    public function __construct(string $name, int $level = 1)
    {
        $this->name = $name;
        $this->level = $level;
        $this->equipment = [];
        $this->skills = [];
    }

    // Méthode de clonage
    public function clone(): GameCharacter
    {
        $cloned = new GameCharacter($this->name, $this->level);
        // Clonage profond des équipements et compétences
        $cloned->equipment = $this->equipment;
        $cloned->skills = $this->skills;
        return $cloned;
    }

    public function setName(string $name): void
    {
        $this->name = $name;
    }

    public function setLevel(int $level): void
    {
        $this->level = $level;
    }

    public function addEquipment(string $item): void
    {
        $this->equipment[] = $item;
    }

    public function addSkill(string $skill): void
    {
        $this->skills[] = $skill;
    }

    public function getInfo(): string
    {
        return "Personnage: {$this->name} (Niveau {$this->level}) - " .
               count($this->equipment) . " équipements, " .
               count($this->skills) . " compétences";
    }
}

// Registre de prototypes
class CharacterRegistry
{
    private array $prototypes = [];

    public function register(string $type, Prototype $prototype): void
    {
        $this->prototypes[$type] = $prototype;
    }

    public function create(string $type): ?Prototype
    {
        return isset($this->prototypes[$type]) 
            ? $this->prototypes[$type]->clone() 
            : null;
    }
}

// Utilisation
$registry = new CharacterRegistry();

// Création de prototypes de base
$warrior = new GameCharacter("Guerrier Template", 10);
$warrior->addEquipment("Épée");
$warrior->addEquipment("Bouclier");
$warrior->addSkill("Combat");
$warrior->addSkill("Défense");

$mage = new GameCharacter("Mage Template", 8);
$mage->addEquipment("Bâton magique");
$mage->addEquipment("Robe");
$mage->addSkill("Magie");
$mage->addSkill("Guérison");

// Enregistrement des prototypes
$registry->register("warrior", $warrior);
$registry->register("mage", $mage);

// Création de personnages par clonage
$player1 = $registry->create("warrior");
$player1->setName("Aragorn");
$player1->setLevel(15);

$player2 = $registry->create("mage");
$player2->setName("Gandalf");
$player2->addSkill("Téléportation");

echo $player1->getInfo() . "\n";
echo $player2->getInfo() . "\n";

import java.util.*;

// Interface Prototype
interface Prototype {
    Prototype clone();
}

// Prototype concret
class NetworkConnection implements Prototype {
    private String host;
    private int port;
    private String protocol;
    private Map<String, String> headers;
    private boolean isConnected;

    public NetworkConnection(String host, int port, String protocol) {
        this.host = host;
        this.port = port;
        this.protocol = protocol;
        this.headers = new HashMap<>();
        this.isConnected = false;
    }

    // Méthode de clonage
    @Override
    public NetworkConnection clone() {
        NetworkConnection cloned = new NetworkConnection(this.host, this.port, this.protocol);
        // Clonage profond des headers
        cloned.headers = new HashMap<>(this.headers);
        cloned.isConnected = false; // Nouvelle connexion non établie
        return cloned;
    }

    public void setHost(String host) {
        this.host = host;
    }

    public void setPort(int port) {
        this.port = port;
    }

    public void addHeader(String key, String value) {
        this.headers.put(key, value);
    }

    public void connect() {
        this.isConnected = true;
        System.out.println("Connexion établie vers " + protocol + "://" + host + ":" + port);
    }

    public void disconnect() {
        this.isConnected = false;
        System.out.println("Connexion fermée");
    }

    public String getInfo() {
        return String.format("Connexion %s://%s:%d (%s) - %d headers",
            protocol, host, port, 
            isConnected ? "connectée" : "déconnectée",
            headers.size());
    }

    // Getters
    public String getHost() { return host; }
    public int getPort() { return port; }
    public String getProtocol() { return protocol; }
    public boolean isConnected() { return isConnected; }
}

// Registre de prototypes
class ConnectionRegistry {
    private Map<String, Prototype> prototypes = new HashMap<>();

    public void register(String name, Prototype prototype) {
        prototypes.put(name, prototype);
    }

    public Prototype create(String name) {
        Prototype prototype = prototypes.get(name);
        return prototype != null ? prototype.clone() : null;
    }

    public Set<String> getAvailableTypes() {
        return prototypes.keySet();
    }
}

// Utilisation
public class PrototypeExample {
    public static void main(String[] args) {
        ConnectionRegistry registry = new ConnectionRegistry();

        // Création de prototypes de base
        NetworkConnection httpTemplate = new NetworkConnection("api.example.com", 80, "HTTP");
        httpTemplate.addHeader("User-Agent", "MyApp/1.0");
        httpTemplate.addHeader("Accept", "application/json");

        NetworkConnection httpsTemplate = new NetworkConnection("secure.example.com", 443, "HTTPS");
        httpsTemplate.addHeader("User-Agent", "MyApp/1.0");
        httpsTemplate.addHeader("Accept", "application/json");
        httpsTemplate.addHeader("Authorization", "Bearer token");

        // Enregistrement des prototypes
        registry.register("http-api", httpTemplate);
        registry.register("https-api", httpsTemplate);

        // Création de connexions par clonage
        NetworkConnection conn1 = (NetworkConnection) registry.create("http-api");
        conn1.setHost("api1.example.com");
        conn1.connect();

        NetworkConnection conn2 = (NetworkConnection) registry.create("https-api");
        conn2.setHost("api2.example.com");
        conn2.setPort(8443);
        conn2.connect();

        System.out.println(conn1.getInfo());
        System.out.println(conn2.getInfo());

        // Vérification que les objets sont différents
        System.out.println("Objets différents: " + (conn1 != conn2));
        System.out.println("Objets différents du template: " + (conn1 != httpTemplate));
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Performance : Évite la création coûteuse d'objets
  • Flexibilité : Création sans connaître la classe exacte
  • Configuration : Objets pré-configurés réutilisables
  • Réduction de classes : Moins de sous-classes nécessaires
  • Runtime : Ajout/suppression de prototypes à l'exécution

❌ Inconvénients

  • Clonage complexe : Difficile avec références circulaires
  • Clonage profond : Peut être coûteux en mémoire
  • Dépendances cachées : Objets partagés non évidents
  • Maintenance : Gestion du registre de prototypes
  • Debugging : Plus difficile de tracer l'origine des objets

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Objets coûteux : Création nécessitant beaucoup de ressources
  • Configuration complexe : Objets avec beaucoup de paramètres
  • Templates : Modèles pré-configurés à personnaliser
  • Objets similaires : Variations d'un même type d'objet
  • Runtime creation : Types d'objets déterminés à l'exécution

❌ Quand l'éviter

  • Objets simples : Création rapide et peu coûteuse
  • Objets immutables : Pas de bénéfice du clonage
  • Références externes : Objets avec beaucoup de dépendances
  • Singletons : Quand une seule instance est requise
  • Objets avec état critique : Risque de corruption par clonage

🔄 Alternatives et Patterns Liés

🏭 Factory Method

Créer des objets via des méthodes de factory

DocumentFactory.createReport(type)

🔨 Builder Pattern

Construire des objets complexes étape par étape

new DocumentBuilder().title("...").build()

📋 Object Pool

Réutiliser des objets existants plutôt que les cloner

ConnectionPool.acquire()

🧩 Biais Cognitifs Associés

🔄 Biais de Disponibilité

Manifestation : "J'ai un prototype qui marche, utilisons-le partout."

Risque : Réutilisation excessive sans évaluer si c'est approprié.

⚡ Biais de l'Effort Justifié

Manifestation : Surestimer la valeur du pattern car il nécessite un effort de mise en place.

Risque : Utiliser le pattern même quand la création directe serait plus simple.

✅ Biais de Confirmation

Manifestation : Chercher uniquement les cas où le clonage est bénéfique.

Risque : Ignorer les situations où d'autres patterns seraient plus appropriés.

⚠️ Anti-Patterns à Éviter

🔗 Shallow Clone Trap

Utiliser un clonage superficiel quand un clonage profond est nécessaire.

// ❌ Clonage superficiel problématique clone.references = this.references; // Références partagées !

🏭 Prototype Factory Confusion

Confondre le pattern Prototype avec une simple Factory.

// ❌ Ce n'est pas du Prototype, c'est une Factory createDocument(type) { return new Document(type); }
