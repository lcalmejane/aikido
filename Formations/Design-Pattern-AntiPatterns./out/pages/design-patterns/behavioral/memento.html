💾 Memento Pattern

Capturer et restaurer l'état interne d'un objet

🎨 Design Patterns
⭐ Difficulté: Moyen
⏱️ 20 min
🎭 Comportemental

🎯 Définition

Le Memento est un pattern comportemental qui permet de capturer et d'externaliser l'état interne d'un objet sans violer l'encapsulation, de sorte que l'objet puisse être restauré à cet état ultérieurement.

❌ Problème Résolu

  • Besoin de sauvegarder l'état d'un objet
  • Violation de l'encapsulation pour accéder à l'état
  • Couplage fort entre l'objet et son mécanisme de sauvegarde
  • Impossibilité d'annuler des opérations (undo/redo)

✅ Solution Apportée

  • Sauvegarde de l'état sans violer l'encapsulation
  • Séparation des responsabilités de sauvegarde
  • Support des fonctionnalités undo/redo
  • Historique des états précédents
💡 Analogie : Comme une sauvegarde de jeu vidéo qui capture l'état complet du jeu pour pouvoir y revenir plus tard.

🏗️ Structure UML

Originator
- state: State
+ createMemento(): Memento
+ restoreMemento(m: Memento): void
+ setState(state: State): void
+ getState(): State
Memento
- state: State
- timestamp: Date
+ getState(): State
+ getTimestamp(): Date
Caretaker
- mementos: List<Memento>
- originator: Originator
+ backup(): void
+ undo(): void
+ showHistory(): void

Éléments Clés

  • Originator : L'objet dont on veut sauvegarder l'état
  • Memento : Stocke l'état de l'Originator à un moment donné
  • Caretaker : Gère les mementos sans accéder à leur contenu

🔄 Flux d'Exécution

💡 Point clé : Le Caretaker ne peut pas accéder au contenu du Memento, préservant ainsi l'encapsulation.

💻 Implémentations

Exemple : Éditeur de Texte avec Undo/Redo


// Interface du Memento
interface TextMemento {
    getContent(): string;
    getCursorPosition(): number;
    getTimestamp(): Date;
}

// Memento concret
class ConcreteTextMemento implements TextMemento {
    private content: string;
    private cursorPosition: number;
    private timestamp: Date;
    
    constructor(content: string, cursorPosition: number) {
        this.content = content;
        this.cursorPosition = cursorPosition;
        this.timestamp = new Date();
    }
    
    getContent(): string {
        return this.content;
    }
    
    getCursorPosition(): number {
        return this.cursorPosition;
    }
    
    getTimestamp(): Date {
        return this.timestamp;
    }
}

// Originator - Éditeur de texte
class TextEditor {
    private content: string = '';
    private cursorPosition: number = 0;
    
    write(text: string): void {
        const before = this.content.substring(0, this.cursorPosition);
        const after = this.content.substring(this.cursorPosition);
        this.content = before + text + after;
        this.cursorPosition += text.length;
        console.log(`Écrit: "${text}" - Contenu: "${this.content}"`);
    }
    
    delete(length: number): void {
        const before = this.content.substring(0, Math.max(0, this.cursorPosition - length));
        const after = this.content.substring(this.cursorPosition);
        this.content = before + after;
        this.cursorPosition = Math.max(0, this.cursorPosition - length);
        console.log(`Supprimé ${length} caractères - Contenu: "${this.content}"`);
    }
    
    setCursorPosition(position: number): void {
        this.cursorPosition = Math.max(0, Math.min(position, this.content.length));
        console.log(`Curseur déplacé à la position ${this.cursorPosition}`);
    }
    
    // Création d'un memento
    createMemento(): TextMemento {
        console.log(`Sauvegarde créée - Contenu: "${this.content}"`);
        return new ConcreteTextMemento(this.content, this.cursorPosition);
    }
    
    // Restauration depuis un memento
    restoreMemento(memento: TextMemento): void {
        this.content = memento.getContent();
        this.cursorPosition = memento.getCursorPosition();
        console.log(`État restauré - Contenu: "${this.content}", Curseur: ${this.cursorPosition}`);
    }
    
    getContent(): string {
        return this.content;
    }
    
    getCursorPosition(): number {
        return this.cursorPosition;
    }
    
    display(): void {
        const before = this.content.substring(0, this.cursorPosition);
        const after = this.content.substring(this.cursorPosition);
        console.log(`Affichage: "${before}|${after}"`);
    }
}

// Caretaker - Gestionnaire d'historique
class EditorHistory {
    private mementos: TextMemento[] = [];
    private currentIndex: number = -1;
    private editor: TextEditor;
    
    constructor(editor: TextEditor) {
        this.editor = editor;
    }
    
    backup(): void {
        // Supprimer les mementos après l'index actuel (pour les nouvelles actions après undo)
        this.mementos = this.mementos.slice(0, this.currentIndex + 1);
        
        // Ajouter le nouveau memento
        const memento = this.editor.createMemento();
        this.mementos.push(memento);
        this.currentIndex = this.mementos.length - 1;
        
        console.log(`Sauvegarde effectuée. Historique: ${this.mementos.length} états`);
    }
    
    undo(): boolean {
        if (this.currentIndex > 0) {
            this.currentIndex--;
            const memento = this.mementos[this.currentIndex];
            this.editor.restoreMemento(memento);
            console.log(`Undo effectué. Index: ${this.currentIndex}`);
            return true;
        }
        console.log('Aucun état précédent disponible');
        return false;
    }
    
    redo(): boolean {
        if (this.currentIndex < this.mementos.length - 1) {
            this.currentIndex++;
            const memento = this.mementos[this.currentIndex];
            this.editor.restoreMemento(memento);
            console.log(`Redo effectué. Index: ${this.currentIndex}`);
            return true;
        }
        console.log('Aucun état suivant disponible');
        return false;
    }
    
    showHistory(): void {
        console.log('\n=== Historique des États ===');
        this.mementos.forEach((memento, index) => {
            const marker = index === this.currentIndex ? ' <-- ACTUEL' : '';
            const timestamp = memento.getTimestamp().toLocaleTimeString();
            console.log(`${index}: "${memento.getContent()}" (${timestamp})${marker}`);
        });
        console.log('===========================\n');
    }
    
    canUndo(): boolean {
        return this.currentIndex > 0;
    }
    
    canRedo(): boolean {
        return this.currentIndex < this.mementos.length - 1;
    }
}

// Utilisation
const editor = new TextEditor();
const history = new EditorHistory(editor);

// État initial
history.backup();

// Séquence d'édition
editor.write('Hello');
history.backup();

editor.write(' World');
history.backup();

editor.write('!');
history.backup();

editor.display(); // "Hello World!|"

// Tests undo/redo
console.log('\n--- Tests Undo/Redo ---');
history.showHistory();

history.undo(); // Retour à "Hello World"
editor.display();

history.undo(); // Retour à "Hello"
editor.display();

history.redo(); // Avance à "Hello World"
editor.display();

// Nouvelle modification après undo
editor.write(' Universe');
history.backup();

history.showHistory(); // L'historique après "Hello World" est supprimé

// Interface du Memento
interface GameMemento {
    public function getLevel(): int;
    public function getScore(): int;
    public function getHealth(): int;
    public function getInventory(): array;
    public function getTimestamp(): DateTime;
}

// Memento concret
class ConcreteGameMemento implements GameMemento {
    private $level;
    private $score;
    private $health;
    private $inventory;
    private $timestamp;
    
    public function __construct(int $level, int $score, int $health, array $inventory) {
        $this->level = $level;
        $this->score = $score;
        $this->health = $health;
        $this->inventory = $inventory;
        $this->timestamp = new DateTime();
    }
    
    public function getLevel(): int {
        return $this->level;
    }
    
    public function getScore(): int {
        return $this->score;
    }
    
    public function getHealth(): int {
        return $this->health;
    }
    
    public function getInventory(): array {
        return $this->inventory;
    }
    
    public function getTimestamp(): DateTime {
        return $this->timestamp;
    }
}

// Originator - État du jeu
class GameState {
    private $level = 1;
    private $score = 0;
    private $health = 100;
    private $inventory = [];
    
    public function levelUp(): void {
        $this->level++;
        $this->health = 100; // Restaurer la santé
        echo "Niveau supérieur ! Niveau: {$this->level}\n";
    }
    
    public function addScore(int $points): void {
        $this->score += $points;
        echo "Score ajouté: +{$points} (Total: {$this->score})\n";
    }
    
    public function takeDamage(int $damage): void {
        $this->health = max(0, $this->health - $damage);
        echo "Dégâts subis: -{$damage} (Santé: {$this->health})\n";
        
        if ($this->health === 0) {
            echo "Game Over !\n";
        }
    }
    
    public function addItem(string $item): void {
        $this->inventory[] = $item;
        echo "Objet ajouté: {$item}\n";
    }
    
    public function useItem(string $item): bool {
        $index = array_search($item, $this->inventory);
        if ($index !== false) {
            unset($this->inventory[$index]);
            $this->inventory = array_values($this->inventory); // Réindexer
            echo "Objet utilisé: {$item}\n";
            
            // Effets des objets
            switch ($item) {
                case 'Potion de Santé':
                    $this->health = min(100, $this->health + 50);
                    echo "Santé restaurée: {$this->health}\n";
                    break;
                case 'Boost de Score':
                    $this->addScore(1000);
                    break;
            }
            return true;
        }
        echo "Objet non trouvé: {$item}\n";
        return false;
    }
    
    // Création d'un memento
    public function createMemento(): GameMemento {
        echo "Sauvegarde du jeu créée\n";
        return new ConcreteGameMemento(
            $this->level,
            $this->score,
            $this->health,
            $this->inventory
        );
    }
    
    // Restauration depuis un memento
    public function restoreMemento(GameMemento $memento): void {
        $this->level = $memento->getLevel();
        $this->score = $memento->getScore();
        $this->health = $memento->getHealth();
        $this->inventory = $memento->getInventory();
        echo "Jeu restauré depuis la sauvegarde\n";
    }
    
    public function displayStatus(): void {
        echo "\n=== État du Jeu ===\n";
        echo "Niveau: {$this->level}\n";
        echo "Score: {$this->score}\n";
        echo "Santé: {$this->health}\n";
        echo "Inventaire: " . (empty($this->inventory) ? 'Vide' : implode(', ', $this->inventory)) . "\n";
        echo "==================\n\n";
    }
    
    // Getters
    public function getLevel(): int { return $this->level; }
    public function getScore(): int { return $this->score; }
    public function getHealth(): int { return $this->health; }
    public function getInventory(): array { return $this->inventory; }
}

// Caretaker - Gestionnaire de sauvegardes
class SaveGameManager {
    private $saves = [];
    private $gameState;
    private $maxSaves;
    
    public function __construct(GameState $gameState, int $maxSaves = 5) {
        $this->gameState = $gameState;
        $this->maxSaves = $maxSaves;
    }
    
    public function saveGame(string $saveName = null): void {
        $memento = $this->gameState->createMemento();
        $saveName = $saveName ?: 'Save_' . (count($this->saves) + 1);
        
        // Limiter le nombre de sauvegardes
        if (count($this->saves) >= $this->maxSaves) {
            $oldestSave = array_key_first($this->saves);
            unset($this->saves[$oldestSave]);
            echo "Ancienne sauvegarde supprimée: {$oldestSave}\n";
        }
        
        $this->saves[$saveName] = $memento;
        echo "Jeu sauvegardé: {$saveName}\n";
    }
    
    public function loadGame(string $saveName): bool {
        if (isset($this->saves[$saveName])) {
            $this->gameState->restoreMemento($this->saves[$saveName]);
            echo "Jeu chargé: {$saveName}\n";
            return true;
        }
        echo "Sauvegarde non trouvée: {$saveName}\n";
        return false;
    }
    
    public function deleteSave(string $saveName): bool {
        if (isset($this->saves[$saveName])) {
            unset($this->saves[$saveName]);
            echo "Sauvegarde supprimée: {$saveName}\n";
            return true;
        }
        echo "Sauvegarde non trouvée: {$saveName}\n";
        return false;
    }
    
    public function listSaves(): void {
        echo "\n=== Sauvegardes Disponibles ===\n";
        if (empty($this->saves)) {
            echo "Aucune sauvegarde disponible\n";
        } else {
            foreach ($this->saves as $name => $memento) {
                $timestamp = $memento->getTimestamp()->format('Y-m-d H:i:s');
                echo "- {$name} (Niveau {$memento->getLevel()}, Score {$memento->getScore()}) - {$timestamp}\n";
            }
        }
        echo "==============================\n\n";
    }
}

// Interface du Memento
interface CalculatorMemento {
    double getValue();
    String getOperation();
    Date getTimestamp();
}

// Memento concret
class ConcreteCalculatorMemento implements CalculatorMemento {
    private final double value;
    private final String operation;
    private final Date timestamp;
    
    public ConcreteCalculatorMemento(double value, String operation) {
        this.value = value;
        this.operation = operation;
        this.timestamp = new Date();
    }
    
    @Override
    public double getValue() {
        return value;
    }
    
    @Override
    public String getOperation() {
        return operation;
    }
    
    @Override
    public Date getTimestamp() {
        return timestamp;
    }
}

// Originator - Calculatrice
class Calculator {
    private double currentValue = 0.0;
    private String lastOperation = "Initialisation";
    
    public void add(double value) {
        this.currentValue += value;
        this.lastOperation = "+" + value;
        System.out.println("Addition: " + value + " = " + this.currentValue);
    }
    
    public void subtract(double value) {
        this.currentValue -= value;
        this.lastOperation = "-" + value;
        System.out.println("Soustraction: " + value + " = " + this.currentValue);
    }
    
    public void multiply(double value) {
        this.currentValue *= value;
        this.lastOperation = "*" + value;
        System.out.println("Multiplication: " + value + " = " + this.currentValue);
    }
    
    public void divide(double value) {
        if (value != 0) {
            this.currentValue /= value;
            this.lastOperation = "/" + value;
            System.out.println("Division: " + value + " = " + this.currentValue);
        } else {
            System.out.println("Erreur: Division par zéro");
        }
    }
    
    public void clear() {
        this.currentValue = 0.0;
        this.lastOperation = "Clear";
        System.out.println("Calculatrice remise à zéro");
    }
    
    // Création d'un memento
    public CalculatorMemento createMemento() {
        System.out.println("État sauvegardé: " + this.currentValue);
        return new ConcreteCalculatorMemento(this.currentValue, this.lastOperation);
    }
    
    // Restauration depuis un memento
    public void restoreMemento(CalculatorMemento memento) {
        this.currentValue = memento.getValue();
        this.lastOperation = "Restauré (" + memento.getOperation() + ")";
        System.out.println("État restauré: " + this.currentValue);
    }
    
    public double getCurrentValue() {
        return currentValue;
    }
    
    public String getLastOperation() {
        return lastOperation;
    }
    
    public void displayResult() {
        System.out.println("Résultat actuel: " + this.currentValue + " (Dernière op: " + this.lastOperation + ")");
    }
}

// Caretaker - Gestionnaire d'historique de calculs
class CalculatorHistory {
    private List<CalculatorMemento> history = new ArrayList<>();
    private int currentIndex = -1;
    private Calculator calculator;
    private final int maxHistorySize;
    
    public CalculatorHistory(Calculator calculator, int maxHistorySize) {
        this.calculator = calculator;
        this.maxHistorySize = maxHistorySize;
    }
    
    public void saveState() {
        // Supprimer les états après l'index actuel (pour les nouvelles opérations après undo)
        if (currentIndex < history.size() - 1) {
            history = history.subList(0, currentIndex + 1);
        }
        
        // Limiter la taille de l'historique
        if (history.size() >= maxHistorySize) {
            history.remove(0);
            currentIndex--;
        }
        
        CalculatorMemento memento = calculator.createMemento();
        history.add(memento);
        currentIndex = history.size() - 1;
        
        System.out.println("État sauvegardé. Historique: " + history.size() + " états");
    }
    
    public boolean undo() {
        if (currentIndex > 0) {
            currentIndex--;
            CalculatorMemento memento = history.get(currentIndex);
            calculator.restoreMemento(memento);
            System.out.println("Undo effectué. Index: " + currentIndex);
            return true;
        }
        System.out.println("Aucun état précédent disponible");
        return false;
    }
    
    public boolean redo() {
        if (currentIndex < history.size() - 1) {
            currentIndex++;
            CalculatorMemento memento = history.get(currentIndex);
            calculator.restoreMemento(memento);
            System.out.println("Redo effectué. Index: " + currentIndex);
            return true;
        }
        System.out.println("Aucun état suivant disponible");
        return false;
    }
    
    public void showHistory() {
        System.out.println("\n=== Historique des Calculs ===");
        for (int i = 0; i < history.size(); i++) {
 memento = history.get(i);
            String marker = (i == currentIndex) ? " <-- ACTUEL" : "";
            SimpleDateFormat sdf = new SimpleDateFormat("HH:mm:ss");
            String timestamp = sdf.format(memento.getTimestamp());
            System.out.println(i + ": " + memento.getValue() + " (" + memento.getOperation() + ") - " + timestamp + marker);
        }
        System.out.println("=============================\n");
    }
    
    public boolean canUndo() {
        return currentIndex > 0;
    }
    
    public boolean canRedo() {
        return currentIndex < history.size() - 1;
    }
    
    public void clearHistory() {
        history.clear();
        currentIndex = -1;
        System.out.println("Historique effacé");
    }
}

// Utilisation
public class MementoPatternDemo {
    public static void main(String[] args) {
        Calculator calc = new Calculator();
        CalculatorHistory history = new CalculatorHistory(calc, 10);
        
        // État initial
        history.saveState();
        calc.displayResult();
        
        // Séquence de calculs
        calc.add(10);
        history.saveState();
        
        calc.multiply(2);
        history.saveState();
        
        calc.subtract(5);
        history.saveState();
        
        calc.divide(3);
        history.saveState();
        
        calc.displayResult();
        
        // Tests undo/redo
        System.out.println("\n--- Tests Undo/Redo ---");
        history.showHistory();
        
        history.undo(); // Retour à 15
        calc.displayResult();
        
        history.undo(); // Retour à 20
        calc.displayResult();
        
        history.redo(); // Avance à 15
        calc.displayResult();
        
        // Nouvelle opération après undo
        calc.add(100);
        history.saveState();
        
        history.showHistory(); // L'historique après 15 est supprimé
        
        System.out.println("\nDémonstration terminée !");
    }
}

🎯 Cas d'Usage Pratiques

📝

Éditeurs de Texte

Implémentation des fonctionnalités undo/redo dans les éditeurs de code et de texte.

Exemple : Visual Studio Code, Word, Google Docs
🎮

Jeux Vidéo

Système de sauvegarde et de chargement d'états de jeu, points de contrôle.

Exemple : Sauvegardes automatiques, états de partie
🗃️

Bases de Données

Transactions et rollback, snapshots de données pour la récupération.

Exemple : PostgreSQL MVCC, MongoDB snapshots
🎨

Applications Graphiques

Historique des modifications dans les logiciels de design et de retouche photo.

Exemple : Photoshop, Figma, Canva
⚙️

Configuration Système

Sauvegarde et restauration de configurations, points de restauration système.

Exemple : Windows System Restore, Git commits
📊

Applications Financières

Audit trail et historique des transactions, annulation d'opérations.

Exemple : Systèmes bancaires, logiciels comptables
🎯 Conseil : Utilisez Memento quand vous avez besoin de sauvegarder l'état d'un objet sans exposer ses détails internes, particulièrement pour les fonctionnalités undo/redo.

🧠 Biais Cognitifs Associés

Le pattern Memento peut être influencé par plusieurs biais cognitifs lors de sa conception et utilisation :

🔄 Biais de Récence

Tendance à accorder plus d'importance aux états récents. Peut conduire à limiter l'historique ou à privilégier les sauvegardes récentes au détriment des plus anciennes.

💾 Biais de Perte d'Aversion

Peur excessive de perdre des données peut mener à conserver trop d'états en mémoire, causant des problèmes de performance et de consommation mémoire.

🎯 Biais de Confirmation

Supposer que tous les états sont importants à sauvegarder sans analyser réellement les besoins utilisateur pour les fonctionnalités undo/redo.

⚡ Biais d'Optimisme

Sous-estimer la complexité de la sérialisation d'objets complexes ou l'impact mémoire de la conservation de nombreux états.

⚠️ Anti-Patterns à Éviter

🗂️ Memento Obèse (Fat Memento)

Problème : Sauvegarder trop d'informations dans le memento, incluant des données non essentielles à la restauration.

Solution : Ne sauvegarder que l'état minimal nécessaire pour restaurer l'objet correctement.

🔓 Memento Exposé (Exposed Memento)

Problème : Permettre au Caretaker ou à d'autres objets d'accéder directement au contenu du memento.

Solution : Utiliser des interfaces appropriées pour limiter l'accès aux données du memento.

♾️ Historique Infini (Infinite History)

Problème : Conserver un historique illimité sans mécanisme de nettoyage, causant des fuites mémoire.

Solution : Implémenter une limite sur le nombre de mementos conservés et un système de nettoyage automatique.

🐌 Sérialisation Lourde (Heavy Serialization)

Problème : Utiliser des mécanismes de sérialisation complexes pour des objets simples.

Solution : Adapter la stratégie de sauvegarde à la complexité réelle de l'objet.

🎯 Exercice Pratique

Vous développez un éditeur de diagrammes. Quelle approche Memento choisiriez-vous pour implémenter l'undo/redo ?

📋 Sauvegarde Complète

Sauvegarder l'état complet du diagramme à chaque modification

📝 Sauvegarde Incrémentale

Sauvegarder uniquement les modifications (commandes) effectuées

🔄 Approche Hybride

Combiner snapshots complets et modifications incrémentales

⏰ Sauvegarde Paresseuse

Sauvegarder seulement quand l'utilisateur demande explicitement

⚠️ Attention ! Cette approche peut être très coûteuse en mémoire pour des diagrammes complexes. Chaque sauvegarde duplique tout le contenu.

Mieux : Considérez l'approche hybride pour optimiser l'utilisation mémoire tout en gardant des performances acceptables.
🤔 Intéressant ! Cette approche est efficace en mémoire mais complexe à implémenter. Il faut gérer l'inversion des commandes pour l'undo.

Note : Cela s'apparente plus au pattern Command qu'au pattern Memento pur.
✅ Excellent choix ! L'approche hybride combine le meilleur des deux mondes : snapshots complets périodiques + modifications incrémentales.

Avantages : Équilibre optimal entre performance, mémoire et complexité d'implémentation.
❌ Problématique ! Cette approche ne permet pas un vrai système undo/redo fluide. L'utilisateur s'attend à pouvoir annuler chaque action immédiatement.

Risque : Perte de données si l'utilisateur oublie de sauvegarder avant une action destructrice.
