⚡ Command Pattern

Encapsuler une requête comme un objet

🎨 Design Patterns
⭐ Difficulté: Moyen
⏱️ 20 min
🎭 Comportemental

🎯 Définition

Le Command est un pattern comportemental qui transforme une requête en un objet autonome contenant toutes les informations sur la requête. Cette transformation permet de paramétrer les méthodes avec différentes requêtes, de mettre en file d'attente ou d'enregistrer les requêtes, et de supporter les opérations d'annulation.

❌ Problème Résolu

  • Couplage fort entre l'invocateur et le récepteur
  • Impossibilité d'annuler ou de rejouer des opérations
  • Difficulté à paramétrer des objets avec des requêtes
  • Gestion complexe des files d'attente d'opérations

✅ Solution Apportée

  • Découplage entre invocateur et récepteur
  • Support des opérations undo/redo
  • Paramétrage flexible avec des commandes
  • Files d'attente et logging des opérations
⚠️ Attention : Le pattern Command peut introduire de la complexité supplémentaire pour des opérations simples. Évaluez le besoin réel avant de l'implémenter.

Éléments Clés

  • Command : Interface déclarant une méthode pour exécuter une commande
  • ConcreteCommand : Implémente Command et définit la liaison entre Receiver et action
  • Invoker : Demande à la commande d'exécuter la requête
  • Receiver : Sait comment effectuer les opérations associées à une requête

💡 Point clé : L'Invoker ne connaît pas le Receiver, il ne fait qu'appeler execute() sur la Command.

💻 Implémentations

Exemple : Éditeur de Texte avec Undo/Redo


// Interface Command
interface Command {
    execute(): void;
    undo(): void;
    getDescription(): string;
}

// Receiver - L'éditeur de texte
class TextEditor {
    private content: string = "";
    private cursorPosition: number = 0;
    
    insertText(text: string, position: number): void {
        this.content = this.content.slice(0, position) + text + this.content.slice(position);
        this.cursorPosition = position + text.length;
        console.log(`📝 Texte inséré: "${text}" à la position ${position}`);
    }
    
    deleteText(startPos: number, length: number): string {
        const deletedText = this.content.slice(startPos, startPos + length);
        this.content = this.content.slice(0, startPos) + this.content.slice(startPos + length);
        this.cursorPosition = startPos;
        console.log(`🗑️ Texte supprimé: "${deletedText}"`);
        return deletedText;
    }
    
    getContent(): string {
        return this.content;
    }
}

// Commande concrète pour insérer du texte
class InsertTextCommand implements Command {
    private editor: TextEditor;
    private text: string;
    private position: number;
    
    constructor(editor: TextEditor, text: string, position: number) {
        this.editor = editor;
        this.text = text;
        this.position = position;
    }
    
    execute(): void {
        this.editor.insertText(this.text, this.position);
    }
    
    undo(): void {
        this.editor.deleteText(this.position, this.text.length);
    }
    
    getDescription(): string {
        return `Insérer "${this.text}" à la position ${this.position}`;
    }
}

// Commande concrète pour supprimer du texte
class DeleteTextCommand implements Command {
    private editor: TextEditor;
    private startPosition: number;
    private length: number;
    private deletedText: string = "";
    
    constructor(editor: TextEditor, startPosition: number, length: number) {
        this.editor = editor;
        this.startPosition = startPosition;
        this.length = length;
    }
    
    execute(): void {
        this.deletedText = this.editor.deleteText(this.startPosition, this.length);
    }
    
    undo(): void {
        if (this.deletedText) {
            this.editor.insertText(this.deletedText, this.startPosition);
        }
    }
    
    getDescription(): string {
        return `Supprimer ${this.length} caractères à la position ${this.startPosition}`;
    }
}

// Invoker - Gestionnaire de commandes avec historique
class CommandManager {
    private history: Command[] = [];
    private currentPosition: number = -1;
    
    executeCommand(command: Command): void {
        console.log(`⚡ Exécution: ${command.getDescription()}`);
        
        // Supprimer les commandes après la position actuelle
        this.history = this.history.slice(0, this.currentPosition + 1);
        
        // Exécuter la commande
        command.execute();
        
        // Ajouter à l'historique
        this.history.push(command);
        this.currentPosition++;
    }
    
    undo(): boolean {
        if (this.currentPosition >= 0) {
            const command = this.history[this.currentPosition];
            console.log(`↩️ Annulation: ${command.getDescription()}`);
            command.undo();
            this.currentPosition--;
            return true;
        }
        console.log("❌ Aucune commande à annuler");
        return false;
    }
    
    redo(): boolean {
        if (this.currentPosition < this.history.length - 1) {
            this.currentPosition++;
            const command = this.history[this.currentPosition];
            console.log(`↪️ Rétablissement: ${command.getDescription()}`);
            command.execute();
            return true;
        }
        console.log("❌ Aucune commande à rétablir");
        return false;
    }
}

// Utilisation
const editor = new TextEditor();
const commandManager = new CommandManager();

commandManager.executeCommand(new InsertTextCommand(editor, "Hello", 0));
commandManager.executeCommand(new InsertTextCommand(editor, " World", 5));
commandManager.undo();
commandManager.redo();


<?php

// Interface Command
interface Command {
    public function execute(): void;
    public function undo(): void;
    public function getDescription(): string;
}

// Receiver - Système de fichiers
class FileSystem {
    private array $files = [];
    
    public function createFile(string $path, string $content = ""): void {
        $this->files[$path] = $content;
        echo "📄 Fichier créé: {$path}\n";
    }
    
    public function deleteFile(string $path): ?string {
        if (isset($this->files[$path])) {
            $content = $this->files[$path];
            unset($this->files[$path]);
            echo "🗑️ Fichier supprimé: {$path}\n";
            return $content;
        }
        return null;
    }
    
    public function listFiles(): array {
        return array_keys($this->files);
    }
}

// Commande pour créer un fichier
class CreateFileCommand implements Command {
    private FileSystem $fileSystem;
    private string $path;
    private string $content;
    
    public function __construct(FileSystem $fileSystem, string $path, string $content = "") {
        $this->fileSystem = $fileSystem;
        $this->path = $path;
        $this->content = $content;
    }
    
    public function execute(): void {
        $this->fileSystem->createFile($this->path, $this->content);
    }
    
    public function undo(): void {
        $this->fileSystem->deleteFile($this->path);
    }
    
    public function getDescription(): string {
        return "Créer fichier: {$this->path}";
    }
}

// Commande pour supprimer un fichier
class DeleteFileCommand implements Command {
    private FileSystem $fileSystem;
    private string $path;
    private ?string $backupContent = null;
    
    public function __construct(FileSystem $fileSystem, string $path) {
        $this->fileSystem = $fileSystem;
        $this->path = $path;
    }
    
    public function execute(): void {
        $this->backupContent = $this->fileSystem->deleteFile($this->path);
    }
    
    public function undo(): void {
        if ($this->backupContent !== null) {
            $this->fileSystem->createFile($this->path, $this->backupContent);
        }
    }
    
    public function getDescription(): string {
        return "Supprimer fichier: {$this->path}";
    }
}

// Invoker - Gestionnaire de commandes
class CommandInvoker {
    private array $history = [];
    private int $currentPosition = -1;
    
    public function executeCommand(Command $command): void {
        echo "⚡ Exécution: " . $command->getDescription() . "\n";
        
        // Supprimer les commandes après la position actuelle
        $this->history = array_slice($this->history, 0, $this->currentPosition + 1);
        
        // Exécuter la commande
        $command->execute();
        
        // Ajouter à l'historique
        $this->history[] = $command;
        $this->currentPosition++;
    }
    
    public function undo(): bool {
        if ($this->currentPosition >= 0) {
            $command = $this->history[$this->currentPosition];
            echo "↩️ Annulation: " . $command->getDescription() . "\n";
            $command->undo();
            $this->currentPosition--;
            return true;
        }
        echo "❌ Aucune commande à annuler\n";
        return false;
    }
}

// Utilisation
$fileSystem = new FileSystem();
$invoker = new CommandInvoker();

$invoker->executeCommand(new CreateFileCommand($fileSystem, "/home/user/document.txt", "Contenu"));
$invoker->executeCommand(new DeleteFileCommand($fileSystem, "/home/user/document.txt"));
$invoker->undo();

import java.util.*;

// Interface Command
interface Command {
    void execute();
    void undo();
    String getDescription();
}

// Receiver - Système de base de données
class DatabaseManager {
    private Map<String, String> records = new HashMap<>();
    
    public void insertRecord(String id, String data) {
        records.put(id, data);
        System.out.println("📝 Enregistrement inséré: " + id + " = " + data);
    }
    
    public String deleteRecord(String id) {
        String data = records.remove(id);
        if (data != null) {
            System.out.println("🗑️ Enregistrement supprimé: " + id);
        }
        return data;
    }
    
    public Set<String> getAllIds() {
        return records.keySet();
    }
}

// Commande pour insérer un enregistrement
class InsertRecordCommand implements Command {
    private DatabaseManager database;
    private String id;
    private String data;
    
    public InsertRecordCommand(DatabaseManager database, String id, String data) {
        this.database = database;
        this.id = id;
        this.data = data;
    }
    
    @Override
    public void execute() {
        database.insertRecord(id, data);
    }
    
    @Override
    public void undo() {
        database.deleteRecord(id);
    }
    
    @Override
    public String getDescription() {
        return "Insérer enregistrement: " + id + " = " + data;
    }
}

// Commande pour supprimer un enregistrement
class DeleteRecordCommand implements Command {
    private DatabaseManager database;
    private String id;
    private String backupData;
    
    public DeleteRecordCommand(DatabaseManager database, String id) {
        this.database = database;
        this.id = id;
    }
    
    @Override
    public void execute() {
        backupData = database.deleteRecord(id);
    }
    
    @Override
    public void undo() {
        if (backupData != null) {
            database.insertRecord(id, backupData);
        }
    }
    
    @Override
    public String getDescription() {
        return "Supprimer enregistrement: " + id;
    }
}

// Invoker - Gestionnaire de commandes
class CommandManager {
    private List<Command> history = new ArrayList<>();
    private int currentPosition = -1;
    
    public void executeCommand(Command command) {
        System.out.println("⚡ Exécution: " + command.getDescription());
        
        // Supprimer les commandes après la position actuelle
        if (currentPosition < history.size() - 1) {
            history.subList(currentPosition + 1, history.size()).clear();
        }
        
        // Exécuter la commande
        command.execute();
        
        // Ajouter à l'historique
        history.add(command);
        currentPosition++;
    }
    
    public boolean undo() {
        if (currentPosition >= 0) {
            Command command = history.get(currentPosition);
            System.out.println("↩️ Annulation: " + command.getDescription());
            command.undo();
            currentPosition--;
            return true;
        }
        System.out.println("❌ Aucune commande à annuler");
        return false;
    }
}

// Utilisation
public class CommandPatternDemo {
    public static void main(String[] args) {
        DatabaseManager database = new DatabaseManager();
        CommandManager commandManager = new CommandManager();
        
        commandManager.executeCommand(new InsertRecordCommand(database, "user1", "John Doe"));
        commandManager.executeCommand(new DeleteRecordCommand(database, "user1"));
        commandManager.undo();
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Découplage : Sépare l'invocateur du récepteur
  • Undo/Redo : Support natif des opérations d'annulation
  • Logging : Enregistrement automatique des opérations
  • Queuing : Mise en file d'attente et traitement différé
  • Macro commandes : Composition de commandes complexes
  • Extensibilité : Ajout facile de nouvelles commandes

❌ Inconvénients

  • Complexité : Augmente le nombre de classes
  • Mémoire : Stockage de l'historique des commandes
  • Over-engineering : Peut être excessif pour des opérations simples
  • État partagé : Gestion complexe des dépendances entre commandes
  • Performance : Overhead pour des opérations fréquentes

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Éditeurs de texte : Opérations d'édition avec undo/redo
  • Interfaces utilisateur : Boutons, menus, raccourcis clavier
  • Bases de données : Transactions, rollback, batch operations
  • Systèmes de workflow : Étapes de processus, validation
  • Jeux vidéo : Actions du joueur, système de replay
  • Systèmes de queue : Traitement asynchrone, retry logic

❌ Quand l'éviter

  • Opérations simples : Quand un appel direct suffit
  • Performance critique : Overhead non acceptable
  • Mémoire limitée : Historique trop coûteux
  • Actions irréversibles : Quand undo n'a pas de sens
  • Systèmes temps réel : Latence inacceptable

🧩 Biais Cognitifs Associés

🔨 Marteau de Maslow

Manifestation : Utiliser Command pour toutes les actions, même les plus simples.

Risque : Over-engineering et complexité inutile pour des besoins basiques.

📈 Biais de Complexité

Manifestation : Préférer une solution complexe car elle semble plus professionnelle.

Risque : Code difficile à maintenir pour des besoins simples.

✅ Biais de Confirmation

Manifestation : Ignorer les inconvénients du pattern (mémoire, performance).

Risque : Implémentation inadaptée au contexte réel.

⚠️ Anti-Patterns à Éviter

❌ Command Anémique

Command qui ne fait que déléguer sans logique métier.

// ❌ Mauvais : Command inutile class PrintCommand implements Command { execute() { printer.print(text); } }

❌ God Command

Command qui fait trop de choses différentes.

// ❌ Mauvais : Command trop complexe class ProcessOrderCommand { execute() { // Validation, calcul, paiement, email, facture... } }
