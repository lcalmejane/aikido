👁️ Observer Pattern

Définir une dépendance un-à-plusieurs entre objets

🎨 Design Patterns
⭐ Difficulté: Moyen
⏱️ 20 min
🎭 Comportemental

🎯 Définition

Le Observer est un pattern comportemental qui définit une dépendance un-à-plusieurs entre objets, de sorte que lorsqu'un objet change d'état, tous ses dépendants sont notifiés et mis à jour automatiquement.

❌ Problème Résolu

  • Couplage fort entre objets interdépendants
  • Notification manuelle des changements d'état
  • Difficulté à maintenir la cohérence des données
  • Code dupliqué pour la gestion des notifications

✅ Solution Apportée

  • Couplage faible via interface Observer
  • Notification automatique des changements
  • Ajout/suppression dynamique d'observateurs
  • Séparation des préoccupations claire
💡 Principe clé : Le pattern Observer implémente le principe "Don't call us, we'll call you" - les observateurs sont notifiés automatiquement.

Éléments Clés

  • Observer : Interface définissant la méthode de notification
  • Subject : Interface pour gérer les observateurs
  • ConcreteSubject : Implémentation maintenant l'état et notifiant les observateurs
  • ConcreteObserver : Implémentation réagissant aux notifications

// Interface Observer
interface Observer {
    update(data: any): void;
}

// Interface Subject
interface Subject {
    attach(observer: Observer): void;
    detach(observer: Observer): void;
    notify(): void;
}

// ConcreteSubject : Newsletter
class Newsletter implements Subject {
    private observers: Observer[] = [];
    private articles: string[] = [];
    
    public attach(observer: Observer): void {
        const isExist = this.observers.includes(observer);
        if (isExist) {
            console.log('Observer déjà abonné');
            return;
        }
        
        this.observers.push(observer);
        console.log('Observer abonné à la newsletter');
    }
    
    public detach(observer: Observer): void {
        const observerIndex = this.observers.indexOf(observer);
        if (observerIndex === -1) {
            console.log('Observer non trouvé');
            return;
        }
        
        this.observers.splice(observerIndex, 1);
        console.log('Observer désabonné de la newsletter');
    }
    
    public notify(): void {
        console.log('Notification de tous les abonnés...');
        for (const observer of this.observers) {
            observer.update({
                type: 'new_article',
                articles: [...this.articles],
                timestamp: new Date()
            });
        }
    }
    
    public addArticle(article: string): void {
        this.articles.push(article);
        console.log(`Nouvel article ajouté: ${article}`);
        this.notify(); // Notification automatique
    }
    
    public getArticles(): string[] {
        return [...this.articles];
    }
}

// ConcreteObserver : Abonné Email
class EmailSubscriber implements Observer {
    private name: string;
    private email: string;
    
    constructor(name: string, email: string) {
        this.name = name;
        this.email = email;
    }
    
    public update(data: any): void {
        console.log(`📧 Email envoyé à ${this.name} (${this.email})`);
        console.log(`Nouveaux articles: ${data.articles.join(', ')}`);
        this.sendEmail(data);
    }
    
    private sendEmail(data: any): void {
        // Simulation d'envoi d'email
        console.log(`Envoi email à ${this.email} avec ${data.articles.length} articles`);
    }
}

// ConcreteObserver : Notification Push
class PushNotificationSubscriber implements Observer {
    private deviceId: string;
    private preferences: string[];
    
    constructor(deviceId: string, preferences: string[] = []) {
        this.deviceId = deviceId;
        this.preferences = preferences;
    }
    
    public update(data: any): void {
        console.log(`📱 Push notification vers ${this.deviceId}`);
        this.sendPushNotification(data);
    }
    
    private sendPushNotification(data: any): void {
        const message = `${data.articles.length} nouveaux articles disponibles!`;
        console.log(`Push: ${message} vers ${this.deviceId}`);
    }
}

// ConcreteObserver : Analytics
class AnalyticsObserver implements Observer {
    private analyticsId: string;
    
    constructor(analyticsId: string) {
        this.analyticsId = analyticsId;
    }
    
    public update(data: any): void {
        console.log(`📊 Analytics: Nouvel article publié`);
        this.trackEvent(data);
    }
    
    private trackEvent(data: any): void {
        console.log(`Tracking: article_published, count: ${data.articles.length}`);
    }
}

<?php

// Interface Observer
interface Observer {
    public function update(array $data): void;
}

// Interface Subject
interface Subject {
    public function attach(Observer $observer): void;
    public function detach(Observer $observer): void;
    public function notify(): void;
}

// ConcreteSubject : Système de Stock
class StockPrice implements Subject {
    private array $observers = [];
    private string $symbol;
    private float $price;
    
    public function __construct(string $symbol, float $initialPrice) {
        $this->symbol = $symbol;
        $this->price = $initialPrice;
    }
    
    public function attach(Observer $observer): void {
        if (in_array($observer, $this->observers, true)) {
            echo "Observer déjà attaché\n";
            return;
        }
        
        $this->observers[] = $observer;
        echo "Observer attaché pour {$this->symbol}\n";
    }
    
    public function detach(Observer $observer): void {
        $key = array_search($observer, $this->observers, true);
        if ($key === false) {
            echo "Observer non trouvé\n";
            return;
        }
        
        unset($this->observers[$key]);
        echo "Observer détaché pour {$this->symbol}\n";
    }
    
    public function notify(): void {
        echo "Notification des observateurs pour {$this->symbol}...\n";
        foreach ($this->observers as $observer) {
            $observer->update([
                'symbol' => $this->symbol,
                'price' => $this->price,
                'timestamp' => time()
            ]);
        }
    }
    
    public function setPrice(float $newPrice): void {
        $oldPrice = $this->price;
        $this->price = $newPrice;
        
        echo "Prix de {$this->symbol} changé: {$oldPrice} → {$newPrice}\n";
        $this->notify(); // Notification automatique
    }
    
    public function getPrice(): float {
        return $this->price;
    }
    
    public function getSymbol(): string {
        return $this->symbol;
    }
}

// ConcreteObserver : Investisseur
class Investor implements Observer {
    private string $name;
    private array $portfolio = [];
    
    public function __construct(string $name) {
        $this->name = $name;
    }
    
    public function update(array $data): void {
        $symbol = $data['symbol'];
        $price = $data['price'];
        
        echo "📈 {$this->name} notifié: {$symbol} = {$price}€\n";
        
        // Logique de trading automatique
        if ($price < 50) {
            $this->buyStock($symbol, $price);
        } elseif ($price > 100) {
            $this->sellStock($symbol, $price);
        }
    }
    
    private function buyStock(string $symbol, float $price): void {
        echo "💰 {$this->name} achète {$symbol} à {$price}€\n";
        $this->portfolio[$symbol] = ($this->portfolio[$symbol] ?? 0) + 10;
    }
    
    private function sellStock(string $symbol, float $price): void {
        if (($this->portfolio[$symbol] ?? 0) > 0) {
            echo "💸 {$this->name} vend {$symbol} à {$price}€\n";
            $this->portfolio[$symbol] -= 5;
        }
    }
    
    public function getPortfolio(): array {
        return $this->portfolio;
    }
}

// ConcreteObserver : Système d'Alerte
class AlertSystem implements Observer {
    private array $thresholds = [];
    
    public function setThreshold(string $symbol, float $minPrice, float $maxPrice): void {
        $this->thresholds[$symbol] = [
            'min' => $minPrice,
            'max' => $maxPrice
        ];
    }
    
    public function update(array $data): void {
        $symbol = $data['symbol'];
        $price = $data['price'];
        
        if (!isset($this->thresholds[$symbol])) {
            return;
        }
        
        $threshold = $this->thresholds[$symbol];
        
        if ($price <= $threshold['min']) {
            $this->sendAlert($symbol, $price, 'LOW');
        } elseif ($price >= $threshold['max']) {
            $this->sendAlert($symbol, $price, 'HIGH');
        }
    }
    
    private function sendAlert(string $symbol, float $price, string $type): void {
        echo "🚨 ALERTE {$type}: {$symbol} à {$price}€\n";
        // Envoi SMS, email, etc.
    }
}

// ConcreteObserver : Logger
class PriceLogger implements Observer {
    private string $logFile;
    
    public function __construct(string $logFile = 'price_log.txt') {
        $this->logFile = $logFile;
    }
    
    public function update(array $data): void {
        $logEntry = sprintf(
            "[%s] %s: %.2f€\n",
            date('Y-m-d H:i:s', $data['timestamp']),
            $data['symbol'],
            $data['price']
        );
        
        file_put_contents($this->logFile, $logEntry, FILE_APPEND | LOCK_EX);
        echo "📝 Prix loggé: {$data['symbol']} = {$data['price']}€\n";
    }
}

import java.util.*;
import java.util.concurrent.CopyOnWriteArrayList;

// Interface Observer
interface Observer {
    void update(Map<String, Object> data);
}

// Interface Subject
interface Subject {
    void attach(Observer observer);
    void detach(Observer observer);
    void notifyObservers();
}

// ConcreteSubject : Système de Chat
class ChatRoom implements Subject {
    private final List<Observer> observers = new CopyOnWriteArrayList<>();
    private final String roomName;
    private final List<String> messages = new ArrayList<>();
    
    public ChatRoom(String roomName) {
        this.roomName = roomName;
    }
    
    @Override
    public void attach(Observer observer) {
        if (observers.contains(observer)) {
            System.out.println("Observer déjà dans le chat " + roomName);
            return;
        }
        
        observers.add(observer);
        System.out.println("Utilisateur rejoint le chat " + roomName);
    }
    
    @Override
    public void detach(Observer observer) {
        if (observers.remove(observer)) {
            System.out.println("Utilisateur quitte le chat " + roomName);
        } else {
            System.out.println("Observer non trouvé dans " + roomName);
        }
    }
    
    @Override
    public void notifyObservers() {
        System.out.println("Notification de " + observers.size() + " utilisateurs...");
        
        Map<String, Object> data = new HashMap<>();
        data.put("roomName", roomName);
        data.put("messages", new ArrayList<>(messages));
        data.put("timestamp", System.currentTimeMillis());
        data.put("lastMessage", messages.isEmpty() ? null : messages.get(messages.size() - 1));
        
        for (Observer observer : observers) {
            observer.update(data);
        }
    }
    
    public void sendMessage(String username, String message) {
        String formattedMessage = String.format("[%s] %s: %s", 
            new Date(), username, message);
        messages.add(formattedMessage);
        
        System.out.println("Message envoyé dans " + roomName + ": " + message);
        notifyObservers(); // Notification automatique
    }
    
    public List<String> getMessages() {
        return new ArrayList<>(messages);
    }
    
    public String getRoomName() {
        return roomName;
    }
}

// ConcreteObserver : Utilisateur du Chat
class ChatUser implements Observer {
    private final String username;
    private final List<String> receivedMessages = new ArrayList<>();
    private boolean isOnline = true;
    
    public ChatUser(String username) {
        this.username = username;
    }
    
    @Override
    public void update(Map<String, Object> data) {
        if (!isOnline) {
            return; // Utilisateur hors ligne
        }
        
        String roomName = (String) data.get("roomName");
        String lastMessage = (String) data.get("lastMessage");
        
        if (lastMessage != null && !lastMessage.contains(username + ":")) {
            System.out.println("💬 " + username + " reçoit: " + lastMessage);
            receivedMessages.add(lastMessage);
            
            // Simulation de réponse automatique
            if (lastMessage.toLowerCase().contains("hello")) {
                simulateResponse(roomName);
            }
        }
    }
    
    private void simulateResponse(String roomName) {
        // Simulation d'une réponse (dans un vrai système, ce serait déclenché par l'utilisateur)
        System.out.println("🤖 " + username + " prépare une réponse...");
    }
    
    public void setOnline(boolean online) {
        this.isOnline = online;
        System.out.println(username + " est maintenant " + (online ? "en ligne" : "hors ligne"));
    }
    
    public List<String> getReceivedMessages() {
        return new ArrayList<>(receivedMessages);
    }
    
    public String getUsername() {
        return username;
    }
}

// ConcreteObserver : Bot de Modération
class ModerationBot implements Observer {
    private final List<String> bannedWords = Arrays.asList("spam", "inappropriate", "banned");
    private final Map<String, Integer> warningCounts = new HashMap<>();
    
    @Override
    public void update(Map<String, Object> data) {
        String lastMessage = (String) data.get("lastMessage");
        String roomName = (String) data.get("roomName");
        
        if (lastMessage == null) return;
        
        // Extraction du nom d'utilisateur du message
        String username = extractUsername(lastMessage);
        if (username == null) return;
        
        // Vérification du contenu
        if (containsBannedWords(lastMessage)) {
            handleViolation(username, roomName, lastMessage);
        }
    }
    
    private String extractUsername(String message) {
        // Format: [timestamp] username: message
        int start = message.indexOf("] ") + 2;
        int end = message.indexOf(":");
        if (start > 1 && end > start) {
            return message.substring(start, end);
        }
        return null;
    }
    
    private boolean containsBannedWords(String message) {
        String lowerMessage = message.toLowerCase();
        return bannedWords.stream().anyMatch(lowerMessage::contains);
    }
    
    private void handleViolation(String username, String roomName, String message) {
        int warnings = warningCounts.getOrDefault(username, 0) + 1;
        warningCounts.put(username, warnings);
        
        System.out.println("🚨 Modération: Contenu inapproprié détecté de " + username);
        System.out.println("   Avertissement #" + warnings + " dans " + roomName);
        
        if (warnings >= 3) {
            System.out.println("🔨 " + username + " banni du chat pour violations répétées");
        }
    }
}

// ConcreteObserver : Logger de Chat
class ChatLogger implements Observer {
    private final String logFileName;
    
    public ChatLogger(String logFileName) {
        this.logFileName = logFileName;
    }
    
    @Override
    public void update(Map<String, Object> data) {
        String roomName = (String) data.get("roomName");
        String lastMessage = (String) data.get("lastMessage");
        Long timestamp = (Long) data.get("timestamp");
        
        if (lastMessage != null) {
            String logEntry = String.format("[%s] %s: %s%n", 
                new Date(timestamp), roomName, lastMessage);
            
            // Dans un vrai système, on écrirait dans un fichier
            System.out.println("📝 Log: " + logEntry.trim());
        }
    }
}

// Utilisation
public class ChatApplication {
    public static void main(String[] args) {
        // Création du chat room
        ChatRoom generalChat = new ChatRoom("General");
        
        // Création des observateurs
        ChatUser alice = new ChatUser("Alice");
        ChatUser bob = new ChatUser("Bob");
        ChatUser charlie = new ChatUser("Charlie");
        ModerationBot moderator = new ModerationBot();
        ChatLogger logger = new ChatLogger("chat.log");
        
        // Abonnement au chat
        generalChat.attach(alice);
        generalChat.attach(bob);
        generalChat.attach(charlie);
        generalChat.attach(moderator);
        generalChat.attach(logger);
        
        // Simulation de conversation
        generalChat.sendMessage("Alice", "Hello everyone!");
        generalChat.sendMessage("Bob", "Hi Alice, how are you?");
        generalChat.sendMessage("Charlie", "Good morning!");
        
        // Charlie se déconnecte
        charlie.setOnline(false);
        generalChat.sendMessage("Alice", "Charlie, are you there?");
        
        // Message inapproprié pour tester la modération
        generalChat.sendMessage("Bob", "This is spam content");
        
        // Charlie se reconnecte et quitte le chat
        charlie.setOnline(true);
        generalChat.detach(charlie);
        generalChat.sendMessage("Alice", "Goodbye everyone!");
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Couplage faible : Subject et Observer sont faiblement couplés
  • Communication dynamique : Ajout/suppression d'observateurs à l'exécution
  • Principe Ouvert/Fermé : Nouveaux observateurs sans modifier le Subject
  • Broadcast automatique : Notification simultanée de tous les observateurs
  • Séparation des préoccupations : Logique métier séparée de la notification

❌ Inconvénients

  • Ordre de notification : Pas de garantie sur l'ordre d'exécution
  • Performance : Notifications en cascade peuvent être coûteuses
  • Fuites mémoire : Observateurs non détachés restent en mémoire
  • Debugging difficile : Flux d'exécution complexe à suivre
  • Effets de bord : Modifications inattendues lors des notifications

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Interface utilisateur : Mise à jour de vues lors de changements de modèle
  • Système d'événements : Notifications d'événements métier
  • Monitoring : Surveillance de métriques et alertes
  • Cache invalidation : Invalidation automatique lors de modifications
  • Logging distribué : Enregistrement d'événements dans plusieurs systèmes

❌ Quand l'éviter

  • Relations simples : Communication directe plus appropriée
  • Performance critique : Overhead des notifications trop important
  • Ordre strict requis : Quand l'ordre de traitement est crucial
  • Transactions : Risque de corruption lors de rollback
  • Systèmes synchrones : Quand la synchronisation est requise

🧩 Biais Cognitifs Associés

🔨 Marteau de Maslow

Manifestation : "Observer résout tous les problèmes de communication, utilisons-le partout."

Risque : Sur-utilisation du pattern même pour des communications simples.

🎯 Biais de Disponibilité

Manifestation : Utiliser Observer car c'est le pattern de notification le plus connu.

Risque : Ignorer des alternatives plus simples comme les callbacks directs.

⚓ Biais d'Ancrage

Manifestation : "J'ai toujours utilisé Observer pour les notifications."

Risque : Ne pas considérer les patterns plus modernes comme les Event Bus.

⚠️ Anti-Patterns à Éviter

🌊 Observer Cascade

Chaînes d'observateurs déclenchant d'autres observateurs créant des cascades incontrôlables.

// ❌ Mauvais : Cascade d'observateurs observer1.update() → triggers observer2.update() → triggers observer3.update()...

💾 Memory Leak Observer

Observateurs non détachés qui restent en mémoire après leur utilisation.

// ❌ Oubli de détachement component.destroy(); // Observer toujours attaché au Subject !
