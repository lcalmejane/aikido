🔄 Iterator Pattern

Parcourir séquentiellement les éléments d'une collection

🎨 Design Patterns
⭐ Difficulté: Facile
⏱️ 15 min
🎭 Comportemental

🎯 Définition

L'Iterator est un pattern comportemental qui permet de parcourir séquentiellement les éléments d'une collection sans exposer sa représentation interne (liste, pile, arbre, etc.).

❌ Problème Résolu

  • Exposition de la structure interne des collections
  • Code client dépendant du type de collection
  • Difficulté de parcourir différents types de structures
  • Logique de parcours mélangée avec la logique métier

✅ Solution Apportée

  • Interface uniforme pour parcourir les collections
  • Encapsulation de la logique de parcours
  • Support de multiples parcours simultanés
  • Séparation des responsabilités
💡 Analogie : Comme une télécommande qui permet de naviguer dans les chaînes TV sans connaître le fonctionnement interne du téléviseur.

🏗️ Structure UML

+ hasNext(): boolean

+ reset(): void
ConcreteIterator<T>

Éléments Clés

  • Iterator : Interface définissant les méthodes de parcours
  • ConcreteIterator : Implémentation concrète du parcours
  • Iterable : Interface pour les collections parcourables
  • ConcreteCollection : Collection concrète qui crée ses iterators

💡 Point clé : L'iterator maintient son propre état de parcours, permettant plusieurs parcours simultanés de la même collection.

// Iterator séquentiel (ordre normal)
class SequentialIterator<T> implements Iterator<T> {
    private position: number = 0;
    
    constructor(private items: T[]) {}
    
    hasNext(): boolean {
        return this.position < this.items.length;
    }
    
    next(): T | null {
        if (this.hasNext()) {
            return this.items[this.position++];
        }
        return null;
    }
    
    reset(): void {
        this.position = 0;
    }
    
    current(): T | null {
        if (this.position > 0 && this.position <= this.items.length) {
            return this.items[this.position - 1];
        }
        return null;
    }
}

// Iterator aléatoire (shuffle)
class RandomIterator<T> implements Iterator<T> {
    private shuffledIndices: number[];
    private position: number = 0;
    
    constructor(private items: T[]) {
        this.shuffledIndices = this.createShuffledIndices();
    }
    
    private createShuffledIndices(): number[] {
        const indices = Array.from({length: this.items.length}, (_, i) => i);
        // Algorithme de Fisher-Yates
        for (let i = indices.length - 1; i > 0; i--) {
            const j = Math.floor(Math.random() * (i + 1));
            [indices[i], indices[j]] = [indices[j], indices[i]];
        }
        return indices;
    }
    
    hasNext(): boolean {
        return this.position < this.shuffledIndices.length;
    }
    
    next(): T | null {
        if (this.hasNext()) {
            const index = this.shuffledIndices[this.position++];
            return this.items[index];
        }
        return null;
    }
    
    reset(): void {
        this.position = 0;
        this.shuffledIndices = this.createShuffledIndices(); // Nouveau mélange
    }
    
    current(): T | null {
        if (this.position > 0 && this.position <= this.shuffledIndices.length) {
            const index = this.shuffledIndices[this.position - 1];
            return this.items[index];
        }
        return null;
    }
}

// Iterator inversé (ordre décroissant)
class ReverseIterator<T> implements Iterator<T> {
    private position: number;
    
    constructor(private items: T[]) {
        this.position = items.length - 1;
    }
    
    hasNext(): boolean {
        return this.position >= 0;
    }
    
    next(): T | null {
        if (this.hasNext()) {
            return this.items[this.position--];
        }
        return null;
    }
    
    reset(): void {
        this.position = this.items.length - 1;
    }
    
    current(): T | null {
        if (this.position >= -1 && this.position < this.items.length - 1) {
            return this.items[this.position + 1];
        }
        return null;
    }
}

// Collection Playlist
class Playlist implements Iterable<Song> {
    private songs: Song[] = [];
    
    addSong(song: Song): void {
        this.songs.push(song);
        console.log(`Ajouté: ${song.toString()}`);
    }
    
    removeSong(title: string): boolean {
        const index = this.songs.findIndex(song => song.title === title);
        if (index !== -1) {
            const removed = this.songs.splice(index, 1)[0];
            console.log(`Supprimé: ${removed.toString()}`);
            return true;
        }
        return false;
    }
    
    createIterator(mode: string = 'sequential'): Iterator<Song> {
        switch (mode.toLowerCase()) {
            case 'random':
            case 'shuffle':
                return new RandomIterator(this.songs);
            case 'reverse':
                return new ReverseIterator(this.songs);
            case 'rock':
            case 'pop':
            case 'jazz':
            case 'classical':
                return new GenreFilterIterator(this.songs, mode.toLowerCase());
            default:
                return new SequentialIterator(this.songs);
        }
    }
    
    getSongCount(): number {
        return this.songs.length;
    }
    
    getTotalDuration(): number {
        return this.songs.reduce((total, song) => total + song.duration, 0);
    }
    
    getGenres(): string[] {
        const genres = new Set(this.songs.map(song => song.genre));
        return Array.from(genres).sort();
    }
}

class MusicPlayer {
    private currentPlaylist: Playlist | null = null;
    private currentIterator: Iterator<Song> | null = null;
    private currentMode: string = 'sequential';
    
    loadPlaylist(playlist: Playlist): void {
        this.currentPlaylist = playlist;
        this.currentIterator = playlist.createIterator(this.currentMode);
        console.log(`Playlist chargée: ${playlist.getSongCount()} chansons`);
    }
    
    setPlayMode(mode: string): void {
        if (this.currentPlaylist) {
            this.currentMode = mode;
            this.currentIterator = this.currentPlaylist.createIterator(mode);
            console.log(`Mode de lecture changé: ${mode}`);
        }
    }
    
    playNext(): Song | null {
        if (this.currentIterator && this.currentIterator.hasNext()) {
            const song = this.currentIterator.next();
            if (song) {
                console.log(`🎵 Lecture: ${song.toString()}`);
                return song;
            }
        }
        console.log('Fin de la playlist');
        return null;
    }
    
    playAll(): void {
        console.log(`\n=== Lecture complète (mode: ${this.currentMode}) ===`);
        let songCount = 0;
        while (this.currentIterator && this.currentIterator.hasNext()) {
            const song = this.currentIterator.next();
            if (song) {
                songCount++;
                console.log(`${songCount}. ${song.toString()}`);
            }
        }
        console.log(`=== Fin de lecture (${songCount} chansons) ===\n`);
    }
    
    restart(): void {
        if (this.currentIterator) {
            this.currentIterator.reset();
            console.log('Playlist redémarrée');
        }
    }
    
    showPlaylistInfo(): void {
        if (this.currentPlaylist) {
            const totalDuration = this.currentPlaylist.getTotalDuration();
            const minutes = Math.floor(totalDuration / 60);
            const genres = this.currentPlaylist.getGenres();
            
            console.log(`\n--- Informations Playlist ---`);
            console.log(`Chansons: ${this.currentPlaylist.getSongCount()}`);
            console.log(`Durée totale: ${minutes} minutes`);
            console.log(`Genres: ${genres.join(', ')}`);
            console.log(`Mode actuel: ${this.currentMode}`);
            console.log('-----------------------------\n');
        }
    }
}

// Iterator standard (ordre d'ajout)
class ForwardIterator implements Iterator {
    private int $position = 0;
    
    public function __construct(private array $items) {}
    
    public function hasNext(): bool {
        return $this->position < count($this->items);
    }
    
    public function next() {
        if ($this->hasNext()) {
            return $this->items[$this->position++];
        }
        return null;
    }
    
    public function reset(): void {
        $this->position = 0;
    }
    
    public function current() {
        if ($this->position > 0 && $this->position <= count($this->items)) {
            return $this->items[$this->position - 1];
        }
        return null;
    }
}

// Iterator inversé
class BackwardIterator implements Iterator {
    private int $position;
    
    public function __construct(private array $items) {
        $this->position = count($items) - 1;
    }
    
    public function hasNext(): bool {
        return $this->position >= 0;
    }
    
    public function next() {
        if ($this->hasNext()) {
            return $this->items[$this->position--];
        }
        return null;
    }
    
    public function reset(): void {
        $this->position = count($this->items) - 1;
    }
    
    public function current() {
        if ($this->position >= -1 && $this->position < count($this->items) - 1) {
            return $this->items[$this->position + 1];
        }
        return null;
    }
}

// Iterator trié par prix
class PriceSortedIterator implements Iterator {
    private array $sortedItems;
    private int $position = 0;
    
    public function __construct(array $items, bool $ascending = true) {
        $this->sortedItems = $items;
        usort($this->sortedItems, function($a, $b) use ($ascending) {
            $result = $a->price <=> $b->price;
            return $ascending ? $result : -$result;
        });
    }
    
    public function hasNext(): bool {
        return $this->position < count($this->sortedItems);
    }
    
    public function next() {
        if ($this->hasNext()) {
            return $this->sortedItems[$this->position++];
        }
        return null;
    }
    
    public function reset(): void {
        $this->position = 0;
    }
    
    public function current() {
        if ($this->position > 0 && $this->position <= count($this->sortedItems)) {
            return $this->sortedItems[$this->position - 1];
        }
        return null;
    }
}

// Collection de produits
class ProductCatalog implements IterableCollection {
    private array $products = [];
    
    public function addProduct(Product $product): void {
        $this->products[] = $product;
        echo "Produit ajouté: {$product}\n";
    }
    
    public function removeProduct(string $id): bool {
        foreach ($this->products as $index => $product) {
            if ($product->id === $id) {
                unset($this->products[$index]);
                $this->products = array_values($this->products); // Réindexer
                echo "Produit supprimé: {$product}\n";
                return true;
            }
        }
        return false;
    }
    
    public function createIterator(string $type = 'forward'): Iterator {
        return match($type) {
            'backward' => new BackwardIterator($this->products),
            'price_asc' => new PriceSortedIterator($this->products, true),
            'price_desc' => new PriceSortedIterator($this->products, false),
            'electronics' => new CategoryFilterIterator($this->products, 'Electronics'),
            'books' => new CategoryFilterIterator($this->products, 'Books'),
            'clothing' => new CategoryFilterIterator($this->products, 'Clothing'),
            'in_stock' => new InStockIterator($this->products),
            default => new ForwardIterator($this->products)
        };
    }
    
    public function getProductCount(): int {
        return count($this->products);
    }
    
    public function getTotalValue(): float {
        return array_sum(array_map(fn($p) => $p->price * $p->stock, $this->products));
    }
    
    public function getCategories(): array {
        $categories = array_unique(array_map(fn($p) => $p->category, $this->products));
        sort($categories);
        return $categories;
    }
}

// Iterator standard
class StandardIterator<T> implements Iterator<T> {
    private List<T> items;
    private int position = 0;
    
    public StandardIterator(List<T> items) {
        this.items = new ArrayList<>(items);
    }
    
    @Override
    public boolean hasNext() {
        return position < items.size();
    }
    
    @Override
    public T next() {
        if (hasNext()) {
            return items.get(position++);
        }
        return null;
    }
    
    @Override
    public void reset() {
        position = 0;
    }
    
    @Override
    public T current() {
        if (position > 0 && position <= items.size()) {
            return items.get(position - 1);
        }
        return null;
    }
}

// Iterator trié par salaire
class SalaryIterator implements Iterator<Employee> {
    private List<Employee> sortedEmployees;
    private int position = 0;
    
    public SalaryIterator(List<Employee> employees, boolean ascending) {
        this.sortedEmployees = new ArrayList<>(employees);
        this.sortedEmployees.sort((e1, e2) -> {
            int result = Double.compare(e1.getSalary(), e2.getSalary());
            return ascending ? result : -result;
        });
    }
    
    @Override
    public boolean hasNext() {
        return position < sortedEmployees.size();
    }
    
    @Override
    public Employee next() {
        if (hasNext()) {
            return sortedEmployees.get(position++);
        }
        return null;
    }
    
    @Override
    public void reset() {
        position = 0;
    }
    
    @Override
    public Employee current() {
        if (position > 0 && position <= sortedEmployees.size()) {
            return sortedEmployees.get(position - 1);
        }
        return null;
    }
}

class EmployeeDirectory implements IterableCollection<Employee> {
    private List<Employee> employees = new ArrayList<>();
    
    public void addEmployee(Employee employee) {
        employees.add(employee);
        System.out.println("Employé ajouté: " + employee);
    }
    
    public boolean removeEmployee(String id) {
        Employee toRemove = employees.stream()
            .filter(emp -> emp.getId().equals(id))
            .findFirst()
            .orElse(null);
            
        if (toRemove != null) {
            employees.remove(toRemove);
            System.out.println("Employé supprimé: " + toRemove);
            return true;
        }
        return false;
    }
    
    @Override
    public Iterator<Employee> createIterator(String type) {
        switch (type.toLowerCase()) {
            case "salary_asc":
                return new SalaryIterator(employees, true);
            case "salary_desc":
                return new SalaryIterator(employees, false);
            case "it":
            case "hr":
            case "finance":
            case "marketing":
                return new DepartmentIterator(employees, type);
            case "senior":
                return new SeniorIterator(employees);
            default:
                return new StandardIterator<>(employees);
        }
    }
    
    public int getEmployeeCount() {
        return employees.size();
    }
    
    public double getAverageSalary() {
        return employees.stream()
            .mapToDouble(Employee::getSalary)
            .average()
            .orElse(0.0);
    }
    
    public Set<String> getDepartments() {
        return employees.stream()
            .map(Employee::getDepartment)
            .collect(TreeSet::new, TreeSet::add, TreeSet::addAll);
    }
}

// Système RH
class HRSystem {
    private EmployeeDirectory directory;
    
    public void loadDirectory(EmployeeDirectory directory) {
        this.directory = directory;
        System.out.println("Annuaire chargé: " + directory.getEmployeeCount() + " employés");
    }
    
    public void listEmployees(String iteratorType) {
        if (directory == null) {
            System.out.println("Aucun annuaire chargé");
            return;
        }
        
        Iterator<Employee> iterator = directory.createIterator(iteratorType);
        int count = 0;
        
        System.out.println("\n=== Liste des employés (mode: " + iteratorType + ") ===");
        while (iterator.hasNext()) {
            Employee employee = iterator.next();
            if (employee != null) {
                count++;
                System.out.println(count + ". " + employee);
            }
        }
        System.out.println("=== Total: " + count + " employés ===\n");
    }
    
    public void showDirectoryStats() {
        if (directory == null) {
            System.out.println("Aucun annuaire chargé");
            return;
        }
        
        System.out.println("\n--- Statistiques RH ---");
        System.out.println("Employés: " + directory.getEmployeeCount());
        System.out.println("Salaire moyen: " + String.format("%.0f€", directory.getAverageSalary()));
        System.out.println("Départements: " + String.join(", ", directory.getDepartments()));
        System.out.println("----------------------\n");
    }
}

🧠 Biais Cognitifs Associés

Le pattern Iterator peut être influencé par plusieurs biais cognitifs lors de sa conception :

📈 Biais de Linéarité

Tendance à penser que tous les parcours doivent être linéaires et séquentiels, sans considérer des approches plus sophistiquées comme les parcours en arbre ou les accès aléatoires optimisés.

🔄 Biais de Simplicité

Supposer qu'un seul type d'iterator suffit pour tous les cas d'usage, sans anticiper les besoins de filtrage, tri ou parcours spécialisés.

💾 Biais de Performance

Sous-estimer l'impact mémoire des iterators qui créent des copies ou des vues filtrées des données, particulièrement sur de gros volumes.

🔒 Biais d'Encapsulation

Croire que l'iterator doit toujours masquer complètement la structure interne, même quand un accès direct serait plus efficace pour certains cas d'usage.

⚠️ Anti-Patterns à Éviter

🔄 Iterator Stateful Partagé

Problème : Partager le même iterator entre plusieurs clients, causant des interférences dans le parcours.

Solution : Créer un nouvel iterator pour chaque parcours ou implémenter un système de clonage.

💥 Iterator Fragile

Problème : Iterator qui devient invalide dès qu'on modifie la collection sous-jacente.

Solution : Implémenter des mécanismes de détection de modification ou des iterators fail-safe.

🐌 Iterator Lourd

Problème : Iterator qui charge toutes les données en mémoire même pour un parcours partiel.

Solution : Implémenter un lazy loading ou un iterator avec pagination pour les gros volumes.

🔧 Iterator Monolithique

Problème : Un seul iterator qui gère tous les types de parcours avec de nombreux paramètres.

Solution : Créer des iterators spécialisés pour chaque type de parcours (filtrage, tri, etc.).
