🔄 State Pattern

Permettre à un objet de modifier son comportement selon son état interne

🎨 Design Patterns
⭐ Difficulté: Moyen
⏱️ 25 min
🎭 Comportemental

🎯 Définition

Le State est un pattern comportemental qui permet à un objet de modifier son comportement lorsque son état interne change. L'objet apparaîtra comme s'il avait changé de classe. Ce pattern encapsule les états dans des classes séparées et délègue le travail à l'instance de l'état actuel.

❌ Problème Résolu

  • Conditions complexes avec de nombreux if/else ou switch
  • Comportements différents selon l'état de l'objet
  • Code difficile à maintenir avec l'ajout de nouveaux états
  • Logique d'état dispersée dans plusieurs méthodes

✅ Solution Apportée

  • Encapsulation de chaque état dans une classe dédiée
  • Élimination des conditions complexes
  • Facilité d'ajout de nouveaux états
  • Centralisation de la logique par état
⚠️ Attention : Le pattern State peut être excessif si l'objet n'a que quelques états simples ou si les états changent rarement.

🏗️ Structure UML

Context
- state: State
+ setState(state): void
+ request(): void
<<interface>>
State
+ handle(context): void
ConcreteStateA
+ handle(context): void
ConcreteStateB
+ handle(context): void

Éléments Clés

  • Context : Maintient une référence vers l'état actuel et délègue les requêtes
  • State : Interface définissant les méthodes que tous les états concrets doivent implémenter
  • ConcreteState : Implémente le comportement spécifique à un état particulier
  • Transition : Les états peuvent déclencher des changements d'état dans le contexte

🔄 Flux d'Exécution

stateDiagram-v2 [*] --> StateA StateA --> StateB : event1 StateB --> StateC : event2 StateC --> StateA : event3 StateB --> StateA : event4 note right of StateA : Comportement A note right of StateB : Comportement B note right of StateC : Comportement C

💡 Point clé : Chaque état encapsule son comportement et peut déclencher des transitions vers d'autres états.

// Interface State
interface AudioState {
    play(player: AudioPlayer): void;
    pause(player: AudioPlayer): void;
    stop(player: AudioPlayer): void;
    next(player: AudioPlayer): void;
    getStateName(): string;
}

// Context - Lecteur Audio
class AudioPlayer {
    private state: AudioState;
    private currentTrack: string = "";
    private volume: number = 50;
    private playlist: string[] = [];
    private currentIndex: number = 0;
    
    constructor() {
        this.state = new StoppedState();
        this.playlist = ["Track 1", "Track 2", "Track 3"];
    }
    
    setState(state: AudioState): void {
        console.log(`🔄 Changement d'état: ${this.state.getStateName()} → ${state.getStateName()}`);
        this.state = state;
    }
    
    play(): void {
        this.state.play(this);
    }
    
    pause(): void {
        this.state.pause(this);
    }
    
    stop(): void {
        this.state.stop(this);
    }
    
    next(): void {
        this.state.next(this);
    }
    
    // Méthodes utilitaires
    startPlayback(): void {
        this.currentTrack = this.playlist[this.currentIndex];
        console.log(`▶️ Lecture: ${this.currentTrack} (Volume: ${this.volume}%)`);
    }
    
    pausePlayback(): void {
        console.log(`⏸️ Pause: ${this.currentTrack}`);
    }
    
    stopPlayback(): void {
        console.log(`⏹️ Arrêt: ${this.currentTrack}`);
        this.currentTrack = "";
    }
    
    nextTrack(): void {
        this.currentIndex = (this.currentIndex + 1) % this.playlist.length;
        this.currentTrack = this.playlist[this.currentIndex];
        console.log(`⏭️ Piste suivante: ${this.currentTrack}`);
    }
    
    getCurrentState(): string {
        return this.state.getStateName();
    }
    
    getCurrentTrack(): string {
        return this.currentTrack;
    }
    
    setVolume(volume: number): void {
        this.volume = Math.max(0, Math.min(100, volume));
        console.log(`🔊 Volume: ${this.volume}%`);
    }
}

// État Arrêté

    play(player: AudioPlayer): void {
        player.startPlayback();
        player.setState(new PlayingState());
    }
    
    pause(player: AudioPlayer): void {
        console.log("❌ Impossible de mettre en pause : lecteur arrêté");
    }
    
    stop(player: AudioPlayer): void {
        console.log("ℹ️ Lecteur déjà arrêté");
    }
    
    next(player: AudioPlayer): void {
        player.nextTrack();
        // Reste en état arrêté
    }
    
    getStateName(): string {
        return "Arrêté";
    }
}

// État de Chargement
class LoadingState implements AudioState {
    private loadingTimer: NodeJS.Timeout | null = null;
    
    play(player: AudioPlayer): void {
        console.log("⏳ Chargement en cours, veuillez patienter...");
    }
    
    pause(player: AudioPlayer): void {
        console.log("❌ Impossible de mettre en pause pendant le chargement");
    }
    
    stop(player: AudioPlayer): void {
        if (this.loadingTimer) {
            clearTimeout(this.loadingTimer);
        }
        player.setState(new StoppedState());
        console.log("🛑 Chargement annulé");
    }
    
    next(player: AudioPlayer): void {
        console.log("❌ Impossible de changer de piste pendant le chargement");
    }
    
    startLoading(player: AudioPlayer): void {
        console.log("📡 Chargement de la piste...");
        this.loadingTimer = setTimeout(() => {
            console.log("✅ Chargement terminé");
            player.startPlayback();
            player.setState(new PlayingState());
        }, 2000);
    }
    
    getStateName(): string {
        return "Chargement";
    }
}

    player.setState(loadingState);
    loadingState.startLoading(player);
    
    // Simulation d'attente
    setTimeout(() => {
        console.log(`État après chargement: ${player.getCurrentState()}`);
        player.setVolume(75);
        player.pause();
    }, 2500);

// Interface State
interface OrderState {
    public function payOrder(OrderContext $context): void;
    public function shipOrder(OrderContext $context): void;
    public function deliverOrder(OrderContext $context): void;
    public function cancelOrder(OrderContext $context): void;
    public function getStateName(): string;
}

// Context - Commande
class OrderContext {
    private OrderState $state;
    private string $orderId;
    private float $amount;
    private array $items;
    
    public function __construct(string $orderId, float $amount, array $items) {
        $this->orderId = $orderId;
        $this->amount = $amount;
        $this->items = $items;
        $this->state = new PendingState();
        echo "📦 Commande créée: {$this->orderId} ({$this->amount}€)\n";
    }
    
    public function setState(OrderState $state): void {
        $oldState = $this->state->getStateName();
        $newState = $state->getStateName();
        echo "🔄 Changement d'état: {$oldState} → {$newState}\n";
        $this->state = $state;
    }
    
    public function payOrder(): void {
        $this->state->payOrder($this);
    }
    
    public function shipOrder(): void {
        $this->state->shipOrder($this);
    }
    
    public function deliverOrder(): void {
        $this->state->deliverOrder($this);
    }
    
    public function cancelOrder(): void {
        $this->state->cancelOrder($this);
    }
    
    // Méthodes utilitaires
    public function processPayment(): void {
        echo "💳 Traitement du paiement de {$this->amount}€\n";
        // Simulation du traitement
        sleep(1);
        echo "✅ Paiement confirmé\n";
    }
    
    public function prepareShipment(): void {
        echo "📋 Préparation de l'expédition\n";
        foreach ($this->items as $item) {
            echo "  - Emballage: {$item}\n";
        }
        echo "📦 Colis prêt pour expédition\n";
    }
    
    public function trackDelivery(): void {
        echo "🚚 Suivi de livraison activé pour {$this->orderId}\n";
    }
    
    public function refundPayment(): void {
        echo "💰 Remboursement de {$this->amount}€ en cours\n";
    }
    
    public function getOrderId(): string {
        return $this->orderId;
    }
    
    public function getAmount(): float {
        return $this->amount;
    }
    
    public function getCurrentState(): string {
        return $this->state->getStateName();
    }
}

        return "En attente";
    }
}

// Gestionnaire de commandes
class OrderManager {
    private array $orders = [];
    
    public function createOrder(string $orderId, float $amount, array $items): OrderContext {
        $order = new OrderContext($orderId, $amount, $items);
        $this->orders[$orderId] = $order;
        return $order;
    }
    
    public function getOrder(string $orderId): ?OrderContext {
        return $this->orders[$orderId] ?? null;
    }
    
    public function processOrderWorkflow(string $orderId): void {
        $order = $this->getOrder($orderId);
        if (!$order) {
            echo "❌ Commande non trouvée: {$orderId}\n";
            return;
        }
        
        echo "\n--- Traitement automatique de la commande ---\n";
        
        // Workflow automatique
        $order->payOrder();
        sleep(1);
        
        $order->shipOrder();
        sleep(1);
        
        $order->deliverOrder();
        
        echo "✅ Workflow terminé - État final: {$order->getCurrentState()}\n";
    }
    
    public function getOrdersSummary(): array {
        $summary = [];
        foreach ($this->orders as $orderId => $order) {
            $summary[$orderId] = [
                'id' => $orderId,
                'amount' => $order->getAmount(),
                'state' => $order->getCurrentState()
            ];
        }
        return $summary;
    }
}

    }
}

import java.util.*;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.TimeUnit;

// Interface State
interface ConnectionState {
    void connect(NetworkConnection context);
    void disconnect(NetworkConnection context);
    void sendData(NetworkConnection context, String data);
    void receiveData(NetworkConnection context);
    String getStateName();
}

// Context - Connexion Réseau
class NetworkConnection {
    private ConnectionState state;
    private String serverAddress;
    private int connectionId;
    private List<String> messageQueue;
    private boolean isSecure;
    
    public NetworkConnection(String serverAddress) {
        this.serverAddress = serverAddress;
        this.connectionId = new Random().nextInt(10000);
        this.messageQueue = new ArrayList<>();
        this.isSecure = false;
        this.state = new DisconnectedState();
        System.out.println("🌐 Connexion créée: " + serverAddress + " (ID: " + connectionId + ")");
    }
    
    public void setState(ConnectionState state) {
        String oldState = this.state.getStateName();
        String newState = state.getStateName();
        System.out.println("🔄 Changement d'état: " + oldState + " → " + newState);
        this.state = state;
    }
    
    public void connect() {
        this.state.connect(this);
    }
    
    public void disconnect() {
        this.state.disconnect(this);
    }
    
    public void sendData(String data) {
        this.state.sendData(this, data);
    }
    
    public void receiveData() {
        this.state.receiveData(this);
    }
    
    // Méthodes utilitaires
    public void establishConnection() {
        System.out.println("🔌 Établissement de la connexion à " + serverAddress);
        // Simulation de la connexion
        try {
            Thread.sleep(1000);
            System.out.println("✅ Connexion établie (ID: " + connectionId + ")");
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
    
    public void closeConnection() {
        System.out.println("🔌 Fermeture de la connexion");
        messageQueue.clear();
        isSecure = false;
    }
    
    public void enableSecurity() {
        System.out.println("🔒 Activation du chiffrement SSL/TLS");
        isSecure = true;
    }
    
    public void queueMessage(String data) {
        messageQueue.add(data);
        System.out.println("📤 Message mis en file: " + data);
    }
    
    public void transmitData(String data) {
        if (isSecure) {
            System.out.println("🔐 Envoi sécurisé: " + data);
        } else {
            System.out.println("📡 Envoi: " + data);
        }
    }
    
    public void processIncomingData() {
        String[] sampleData = {"Données reçues", "Réponse serveur", "Notification"};
        String data = sampleData[new Random().nextInt(sampleData.length)];
        System.out.println("📥 Réception: " + data);
    }
    
    public String getCurrentState() {
        return this.state.getStateName();
    }
    
    public String getServerAddress() {
        return serverAddress;
    }
    
    public int getConnectionId() {
        return connectionId;
    }
    
    public boolean isSecure() {
        return isSecure;
    }
    
    public int getQueueSize() {
        return messageQueue.size();
    }
}

// État Déconnecté
class DisconnectedState implements ConnectionState {
    @Override
    public void connect(NetworkConnection context) {
        context.establishConnection();
        context.setState(new ConnectingState());
    }
    
    @Override
    public void disconnect(NetworkConnection context) {
        System.out.println("ℹ️ Déjà déconnecté");
    }
    
    @Override
    public void sendData(NetworkConnection context, String data) {
        System.out.println("❌ Impossible d'envoyer : connexion fermée");
        context.queueMessage(data);
    }
    
    @Override
    public void receiveData(NetworkConnection context) {
        System.out.println("❌ Impossible de recevoir : connexion fermée");
    }
    
    @Override
    public String getStateName() {
        return "Déconnecté";
    }
}

// État En Connexion
class ConnectingState implements ConnectionState {
    @Override
    public void connect(NetworkConnection context) {
        System.out.println("⏳ Connexion en cours...");
    }
    
    @Override
    public void disconnect(NetworkConnection context) {
        System.out.println("🛑 Annulation de la connexion");
        context.setState(new DisconnectedState());
    }
    
    @Override
    public void sendData(NetworkConnection context, String data) {
        System.out.println("⏳ Connexion en cours, mise en file: " + data);
        context.queueMessage(data);
    }
    
    @Override
    public void receiveData(NetworkConnection context) {
        System.out.println("⏳ Connexion en cours...");
    }
    
    @Override
    public String getStateName() {
        return "En connexion";
    }
    
    public void completeConnection(NetworkConnection context) {
        System.out.println("🔐 Négociation de sécurité...");
        context.enableSecurity();
        context.setState(new ConnectedState());
    }
}

// État Connecté
class ConnectedState implements ConnectionState {
    @Override
    public void connect(NetworkConnection context) {
        System.out.println("ℹ️ Déjà connecté");
    }
    
    @Override
    public void disconnect(NetworkConnection context) {
        context.closeConnection();
        context.setState(new DisconnectedState());
    }
    
    @Override
    public void sendData(NetworkConnection context, String data) {
        context.transmitData(data);
    }
    
    @Override
    public void receiveData(NetworkConnection context) {
        context.processIncomingData();
    }
    
    @Override
    public String getStateName() {
        return "Connecté";
    }
}

    public void receiveData(NetworkConnection context) {

class ConnectionManager {

    public ConnectionManager() {
        this.connections = new HashMap<>();
    }
    
    public NetworkConnection createConnection(String serverAddress) {
        NetworkConnection connection = new NetworkConnection(serverAddress);
        connections.put(serverAddress, connection);
        return connection;
    }
    
    public NetworkConnection getConnection(String serverAddress) {
        return connections.get(serverAddress);
    }
    
    public void demonstrateConnectionLifecycle(String serverAddress) {
        System.out.println("\n--- Cycle de vie de connexion ---");
        
        NetworkConnection conn = createConnection(serverAddress);
        System.out.println("État initial: " + conn.getCurrentState());
        
        // Connexion
        conn.connect();
        
        // Simulation de la finalisation de connexion
        if (conn.getCurrentState().equals("En connexion")) {
            try {
                Thread.sleep(1500);
                ConnectingState connectingState = new ConnectingState();
                connectingState.completeConnection(conn);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
        
        System.out.println("État après connexion: " + conn.getCurrentState());
        
        // Envoi de données
        conn.sendData("Hello Server!");
        conn.receiveData();
        
        // Simulation d'erreur
        System.out.println("\n--- Simulation d'erreur ---");
        conn.setState(new ErrorState("Timeout réseau"));
        conn.sendData("Message d'urgence");
        
        // Reconnexion
        conn.connect();
        
        // Déconnexion propre
        System.out.println("\n--- Déconnexion ---");
        conn.disconnect();
        System.out.println("État final: " + conn.getCurrentState());
    }
    
    public void getConnectionsSummary() {
        System.out.println("\n--- Résumé des connexions ---");
        connections.forEach((address, conn) -> {
            System.out.println("🌐 " + address + " (ID: " + conn.getConnectionId() +
                             ") - État: " + conn.getCurrentState() +
                             " - Sécurisé: " + (conn.isSecure() ? "✅" : "❌") +
                             " - File: " + conn.getQueueSize() + " messages");
        });
    }
}

                new ConnectingState().completeConnection(conn1);
            }
            if (conn2.getCurrentState().equals("En connexion")) {

🧩 Biais Cognitifs Associés

🔄 Biais de Confirmation

Tendance à implémenter des états complexes même quand une simple condition suffirait, confirmant notre expertise technique.

🎯 Biais de Disponibilité

Utiliser le State pattern parce qu'on se souvient d'un cas où il était parfait, sans évaluer si c'est approprié ici.

⚓ Biais d'Ancrage

S'ancrer sur la première implémentation d'état et avoir du mal à la refactorer quand les besoins évoluent.

🔨 Loi de l'Instrument

"Quand on a un marteau, tout ressemble à un clou" - voir des machines à états partout après avoir appris le pattern.

⚠️ Anti-Patterns à Éviter

🕸️ God State

Créer un état qui gère trop de responsabilités ou connaît trop d'autres états. Chaque état doit avoir une responsabilité claire et limitée.

🔄 Circular Dependencies

États qui se référencent mutuellement de manière complexe. Préférer une gestion centralisée des transitions dans le contexte.

🎭 State Explosion

Créer trop d'états pour des variations mineures. Utiliser des paramètres d'état plutôt que de multiplier les classes d'état.

🔒 Tight Coupling

États fortement couplés au contexte ou entre eux. Maintenir une interface claire et minimale entre états et contexte.
