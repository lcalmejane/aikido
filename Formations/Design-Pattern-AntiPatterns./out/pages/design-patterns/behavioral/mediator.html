🤝 Mediator Pattern

Définir comment des objets interagissent entre eux

🎨 Design Patterns
⭐ Difficulté: Moyen
⏱️ 25 min
🎭 Comportemental

🎯 Définition

Le Mediator est un pattern comportemental qui définit comment un ensemble d'objets interagissent entre eux. Au lieu de communiquer directement, les objets communiquent via un médiateur central qui encapsule la logique d'interaction.

❌ Problème Résolu

  • Couplage fort entre objets qui communiquent
  • Logique d'interaction dispersée dans plusieurs classes
  • Difficultés à maintenir et faire évoluer les interactions
  • Réutilisation limitée des composants

✅ Solution Apportée

  • Couplage faible entre les composants
  • Logique d'interaction centralisée
  • Composants réutilisables indépendamment
  • Facilite l'ajout de nouvelles interactions
💡 Analogie : Comme un contrôleur aérien qui coordonne les avions au lieu de les laisser communiquer directement entre eux.

Éléments Clés

  • Mediator : Interface définissant le contrat de communication
  • ConcreteMediator : Implémente la logique d'interaction entre composants
  • BaseComponent : Classe de base des composants avec référence au médiateur
  • Components : Objets qui communiquent via le médiateur

💡 Point clé : Les composants ne se connaissent pas directement, toute communication passe par le médiateur central.

Exemple : Interface de Chat


// Interface du Mediator
interface ChatMediator {
    sendMessage(message: string, user: User): void;
    addUser(user: User): void;
    removeUser(user: User): void;
}

// Mediator concret
class ChatRoom implements ChatMediator {
    private users: Set<User> = new Set();
    private messageHistory: Array<{user: string, message: string, timestamp: Date}> = [];
    
    addUser(user: User): void {
        this.users.add(user);
        user.setMediator(this);
        this.notifyAll(`${user.getName()} a rejoint le chat`, null);
        console.log(`${user.getName()} ajouté au chat`);
    }
    
    removeUser(user: User): void {
        this.users.delete(user);
        this.notifyAll(`${user.getName()} a quitté le chat`, null);
        console.log(`${user.getName()} retiré du chat`);
    }
    
    sendMessage(message: string, sender: User): void {
        // Enregistrer le message
        this.messageHistory.push({
            user: sender.getName(),
            message: message,
            timestamp: new Date()
        });
        
        // Diffuser à tous les autres utilisateurs
        this.users.forEach(user => {
            if (user !== sender) {
                user.receive(message, sender.getName());
            }
        });
        
        // Vérifier les mots interdits
        if (this.containsBadWords(message)) {
            sender.receive("⚠️ Message modéré pour contenu inapproprié", "Système");
        }
    }
    
    private notifyAll(message: string, sender: User | null): void {
        this.users.forEach(user => {
            if (user !== sender) {
                user.receive(message, "Système");
            }
        });
    }
    
    private containsBadWords(message: string): boolean {
        const badWords = ["spam", "hack", "virus"];
        return badWords.some(word => message.toLowerCase().includes(word));
    }
    
    getHistory(): Array<{user: string, message: string, timestamp: Date}> {
        return [...this.messageHistory];
    }
}

// Classe de base pour les utilisateurs
abstract class User {
    protected mediator: ChatMediator | null = null;
    protected name: string;
    
    constructor(name: string) {
        this.name = name;
    }
    
    setMediator(mediator: ChatMediator): void {
        this.mediator = mediator;
    }
    
    getName(): string {
        return this.name;
    }
    
    send(message: string): void {
        if (this.mediator) {
            console.log(`${this.name} envoie: ${message}`);
            this.mediator.sendMessage(message, this);
        }
    }
    
    abstract receive(message: string, from: string): void;
}

// Utilisateurs concrets
class RegularUser extends User {
    receive(message: string, from: string): void {
        console.log(`${this.name} reçoit de ${from}: ${message}`);
    }
}

class AdminUser extends User {
    private mutedUsers: Set<string> = new Set();
    
    receive(message: string, from: string): void {
        if (!this.mutedUsers.has(from)) {
            console.log(`[ADMIN] ${this.name} reçoit de ${from}: ${message}`);
        }
    }
    
    muteUser(username: string): void {
        this.mutedUsers.add(username);
        console.log(`[ADMIN] ${username} a été mis en sourdine`);
    }
    
    unmuteUser(username: string): void {
        this.mutedUsers.delete(username);
        console.log(`[ADMIN] ${username} n'est plus en sourdine`);
    }
}

// Utilisation
const chatRoom = new ChatRoom();

const alice = new RegularUser("Alice");
const bob = new RegularUser("Bob");
const admin = new AdminUser("Admin");

chatRoom.addUser(alice);
chatRoom.addUser(bob);
chatRoom.addUser(admin);

alice.send("Salut tout le monde !");
bob.send("Hello Alice !");
admin.send("Bienvenue dans le chat !");

// Interface du Mediator
interface FormMediator {
    public function notify(FormComponent $sender, string $event): void;
}

// Mediator concret pour un formulaire
class RegistrationFormMediator implements FormMediator {
    private $usernameField;
    private $emailField;
    private $passwordField;
    private $confirmPasswordField;
    private $submitButton;
    private $errors = [];
    
    public function __construct(
        UsernameField $username,
        EmailField $email,
        PasswordField $password,
        ConfirmPasswordField $confirmPassword,
        SubmitButton $submit
    ) {
        $this->usernameField = $username;
        $this->emailField = $email;
        $this->passwordField = $password;
        $this->confirmPasswordField = $confirmPassword;
        $this->submitButton = $submit;
        
        // Configurer les médiateurs
        $username->setMediator($this);
        $email->setMediator($this);
        $password->setMediator($this);
        $confirmPassword->setMediator($this);
        $submit->setMediator($this);
    }
    
    public function notify(FormComponent $sender, string $event): void {
        switch (get_class($sender)) {
            case 'UsernameField':
                $this->handleUsernameEvent($event);
                break;
            case 'EmailField':
                $this->handleEmailEvent($event);
                break;
            case 'PasswordField':
                $this->handlePasswordEvent($event);
                break;
            case 'ConfirmPasswordField':
                $this->handleConfirmPasswordEvent($event);
                break;
            case 'SubmitButton':
                $this->handleSubmitEvent($event);
                break;
        }
        
        $this->updateFormState();
    }
    
    private function handleUsernameEvent(string $event): void {
        if ($event === 'change') {
            $username = $this->usernameField->getValue();
            if (strlen($username) < 3) {
                $this->errors['username'] = 'Le nom d\'utilisateur doit contenir au moins 3 caractères';
            } else {
                unset($this->errors['username']);
            }
        }
    }
    
    private function handleEmailEvent(string $event): void {
        if ($event === 'change') {
            $email = $this->emailField->getValue();
            if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
                $this->errors['email'] = 'Format d\'email invalide';
            } else {
                unset($this->errors['email']);
            }
        }
    }
    
    private function handlePasswordEvent(string $event): void {
        if ($event === 'change') {
            $password = $this->passwordField->getValue();
            if (strlen($password) < 8) {
                $this->errors['password'] = 'Le mot de passe doit contenir au moins 8 caractères';
            } else {
                unset($this->errors['password']);
            }
            
            // Vérifier la confirmation si elle existe
            if ($this->confirmPasswordField->getValue()) {
                $this->validatePasswordConfirmation();
            }
        }
    }
    
    private function handleConfirmPasswordEvent(string $event): void {
        if ($event === 'change') {
            $this->validatePasswordConfirmation();
        }
    }
    
    private function validatePasswordConfirmation(): void {
        $password = $this->passwordField->getValue();
        $confirmPassword = $this->confirmPasswordField->getValue();
        
        if ($password !== $confirmPassword) {
            $this->errors['confirmPassword'] = 'Les mots de passe ne correspondent pas';
        } else {
            unset($this->errors['confirmPassword']);
        }
    }
    
    private function handleSubmitEvent(string $event): void {
        if ($event === 'click') {
            if (empty($this->errors)) {
                echo "Formulaire soumis avec succès !\n";
                $this->processRegistration();
            } else {
                echo "Erreurs dans le formulaire :\n";
                foreach ($this->errors as $field => $error) {
                    echo "- $field: $error\n";
                }
            }
        }
    }
    
    private function updateFormState(): void {
        // Activer/désactiver le bouton submit
        $isValid = empty($this->errors) && 
                   $this->usernameField->getValue() &&
                   $this->emailField->getValue() &&
                   $this->passwordField->getValue() &&
                   $this->confirmPasswordField->getValue();
        
        $this->submitButton->setEnabled($isValid);
        
        // Mettre à jour les styles des champs
        foreach (['username', 'email', 'password', 'confirmPassword'] as $field) {
            $component = $this->{$field . 'Field'};
            $hasError = isset($this->errors[$field]);
            $component->setError($hasError);
        }
    }
    
    private function processRegistration(): void {
        $userData = [
            'username' => $this->usernameField->getValue(),
            'email' => $this->emailField->getValue(),
            'password' => password_hash($this->passwordField->getValue(), PASSWORD_DEFAULT)
        ];
        
        // Simulation de l'enregistrement
        echo "Utilisateur enregistré: " . json_encode($userData) . "\n";
    }
}

// Classe de base pour les composants
abstract class FormComponent {
    protected $mediator;
    protected $value = '';
    protected $hasError = false;
    
    public function setMediator(FormMediator $mediator): void {
        $this->mediator = $mediator;
    }
    
    public function getValue(): string {
        return $this->value;
    }
    
    public function setValue(string $value): void {
        $this->value = $value;
        if ($this->mediator) {
            $this->mediator->notify($this, 'change');
        }
    }
    
    public function setError(bool $hasError): void {
        $this->hasError = $hasError;
        echo get_class($this) . " error state: " . ($hasError ? "true" : "false") . "\n";
    }
}

// Composants concrets
class UsernameField extends FormComponent {}
class EmailField extends FormComponent {}
class PasswordField extends FormComponent {}
class ConfirmPasswordField extends FormComponent {}

class SubmitButton extends FormComponent {
    private $enabled = false;
    
    public function setEnabled(bool $enabled): void {
        $this->enabled = $enabled;
        echo "Bouton submit " . ($enabled ? "activé" : "désactivé") . "\n";
    }
    
    public function click(): void {
        if ($this->mediator) {
            $this->mediator->notify($this, 'click');
        }
    }
}

// Interface du Mediator
interface AirTrafficMediator {
    void requestTakeoff(Aircraft aircraft);
    void requestLanding(Aircraft aircraft);
    void notifyPositionChange(Aircraft aircraft, String position);
}

// Mediator concret
class AirTrafficControlTower implements AirTrafficMediator {
    private List<Aircraft> aircrafts = new ArrayList<>();
    private Queue<Aircraft> takeoffQueue = new LinkedList<>();
    private Queue<Aircraft> landingQueue = new LinkedList<>();
    private boolean runwayBusy = false;
    
    public void registerAircraft(Aircraft aircraft) {
        aircrafts.add(aircraft);
        aircraft.setMediator(this);
        System.out.println("Aéronef " + aircraft.getCallSign() + " enregistré");
    }
    
    @Override
    public void requestTakeoff(Aircraft aircraft) {
        System.out.println("Tour de contrôle: Demande de décollage de " + aircraft.getCallSign());
        
        if (!runwayBusy && landingQueue.isEmpty()) {
            grantTakeoff(aircraft);
        } else {
            takeoffQueue.offer(aircraft);
            aircraft.receiveMessage("En attente de décollage. Position dans la queue: " + takeoffQueue.size());
        }
    }
    
    @Override
    public void requestLanding(Aircraft aircraft) {
        System.out.println("Tour de contrôle: Demande d'atterrissage de " + aircraft.getCallSign());
        
        // Les atterrissages ont la priorité
        if (!runwayBusy) {
            grantLanding(aircraft);
        } else {
            landingQueue.offer(aircraft);
            aircraft.receiveMessage("En attente d'atterrissage. Position dans la queue: " + landingQueue.size());
        }
    }
    
    @Override
    public void notifyPositionChange(Aircraft aircraft, String position) {
        System.out.println("Tour de contrôle: " + aircraft.getCallSign() + " signale position: " + position);
        
        // Vérifier les conflits potentiels
        checkForConflicts(aircraft, position);
        
        // Si l'aéronef a terminé d'utiliser la piste
        if (position.equals("Cleared runway")) {
            runwayBusy = false;
            processNextRequest();
        }
    }
    
    private void grantTakeoff(Aircraft aircraft) {
        runwayBusy = true;
        aircraft.receiveMessage("Décollage autorisé. Piste libre.");
        
        // Notifier les autres aéronefs
        notifyOthers(aircraft, aircraft.getCallSign() + " autorisé au décollage");
    }
    
    private void grantLanding(Aircraft aircraft) {
        runwayBusy = true;
        aircraft.receiveMessage("Atterrissage autorisé. Piste libre.");
        
        // Notifier les autres aéronefs
        notifyOthers(aircraft, aircraft.getCallSign() + " autorisé à l'atterrissage");
    }
    
    private void processNextRequest() {
        // Priorité aux atterrissages
        if (!landingQueue.isEmpty()) {
            Aircraft nextLanding = landingQueue.poll();
            grantLanding(nextLanding);
        } else if (!takeoffQueue.isEmpty()) {
            Aircraft nextTakeoff = takeoffQueue.poll();
            grantTakeoff(nextTakeoff);
        }
    }
    
    private void checkForConflicts(Aircraft aircraft, String position) {
        for (Aircraft other : aircrafts) {
            if (other != aircraft && isConflictRisk(aircraft, other, position)) {
                aircraft.receiveMessage("ATTENTION: Conflit potentiel avec " + other.getCallSign());
                other.receiveMessage("ATTENTION: Conflit potentiel avec " + aircraft.getCallSign());
            }
        }
    }
    
    private boolean isConflictRisk(Aircraft aircraft1, Aircraft aircraft2, String position) {
        // Logique simplifiée de détection de conflit
        return position.contains("Runway") && aircraft2.getCurrentPosition().contains("Runway");
    }
    
    private void notifyOthers(Aircraft sender, String message) {
        for (Aircraft aircraft : aircrafts) {
            if (aircraft != sender) {
                aircraft.receiveMessage("Tour de contrôle: " + message);
            }
        }
    }
}

// Classe de base pour les aéronefs
abstract class Aircraft {
    protected AirTrafficMediator mediator;
    protected String callSign;
    protected String currentPosition;
    
    public Aircraft(String callSign) {
        this.callSign = callSign;
        this.currentPosition = "Gate";
    }
    
    public void setMediator(AirTrafficMediator mediator) {
        this.mediator = mediator;
    }
    
    public String getCallSign() {
        return callSign;
    }
    
    public String getCurrentPosition() {
        return currentPosition;
    }
    
    public void requestTakeoff() {
        if (mediator != null) {
            mediator.requestTakeoff(this);
        }
    }
    
    public void requestLanding() {
        if (mediator != null) {
            mediator.requestLanding(this);
        }
    }
    
    public void updatePosition(String newPosition) {
        this.currentPosition = newPosition;
        if (mediator != null) {
            mediator.notifyPositionChange(this, newPosition);
        }
    }
    
    public abstract void receiveMessage(String message);
}

// Aéronefs concrets
class CommercialAircraft extends Aircraft {
    private int passengerCount;
    
    public CommercialAircraft(String callSign, int passengerCount) {
        super(callSign);
        this.passengerCount = passengerCount;
    }
    
    @Override
    public void receiveMessage(String message) {
        System.out.println("[COMMERCIAL " + callSign + "] " + message);
    }
}

class PrivateJet extends Aircraft {
    private String owner;
    
    public PrivateJet(String callSign, String owner) {
        super(callSign);
        this.owner = owner;
    }
    
    @Override
    public void receiveMessage(String message) {
        System.out.println("[PRIVATE " + callSign + "] " + message);
    }
}

public class Main {
    public static void main(String[] args) {
        AirTrafficControlTower tower = new AirTrafficControlTower();
        
        CommercialAircraft flight123 = new CommercialAircraft("AF123", 180);
        PrivateJet jet456 = new PrivateJet("PJ456", "John Doe");

⚖️ Avantages et Inconvénients

✅ Avantages

  • Couplage faible : Les composants ne se connaissent pas directement
  • Centralisation : Logique d'interaction regroupée en un endroit
  • Réutilisabilité : Composants indépendants et réutilisables
  • Extensibilité : Facile d'ajouter de nouveaux composants
  • Maintenabilité : Modifications centralisées dans le médiateur

❌ Inconvénients

  • Complexité du médiateur : Peut devenir très complexe avec beaucoup de composants
  • Point de défaillance unique : Le médiateur devient critique
  • Performance : Peut créer un goulot d'étranglement
  • Dieu objet : Risque de créer un objet qui fait tout

🎯 Cas d'Usage Typiques

💬

Interfaces Utilisateur

Coordination entre composants d'interface (formulaires, dialogues, widgets)

Exemple : Formulaire de commande où les champs interagissent
🎮

Systèmes de Jeu

Coordination entre joueurs, objets et événements de jeu

Exemple : Chat de jeu, système de combat, interactions
🏢

Workflow d'Entreprise

Orchestration de processus métier complexes

Exemple : Processus d'approbation, validation de documents
🚦

Systèmes de Contrôle

Coordination de systèmes distribués ou d'IoT

Exemple : Contrôle de trafic, domotique, systèmes industriels

🧠 Biais Cognitifs Associés

Le pattern Mediator peut être influencé par plusieurs biais cognitifs qui affectent la conception et l'utilisation des médiateurs :

🎯 Biais de Centralisation

Tendance à tout centraliser dans le médiateur, créant un "dieu objet" qui viole le principe de responsabilité unique.

🔗 Biais de Couplage

Croire que le médiateur élimine complètement le couplage alors qu'il le déplace vers une dépendance centrale.

⚡ Biais de Performance

Sous-estimer l'impact performance du passage par un médiateur central pour toutes les communications.

🎭 Biais de Complexité

Penser que le médiateur simplifie toujours le système alors qu'il peut déplacer la complexité sans la réduire.

⚠️ Anti-Patterns à Éviter

🏛️ God Mediator

Créer un médiateur qui gère trop de responsabilités et devient un point central de complexité ingérable.

🔄 Circular Dependencies

Créer des dépendances circulaires entre médiateurs ou entre composants et médiateurs.

🎪 Chatty Mediator

Faire transiter trop de messages triviaux par le médiateur, créant un goulot d'étranglement.

🎯 Exercice Pratique

Vous développez un système de chat pour une application. Quelle approche utilise correctement le pattern Mediator ?

A Communication Directe
Chaque utilisateur maintient une liste des autres utilisateurs et leur envoie directement les messages.
B Médiateur Central
Un ChatRoom médiateur gère tous les utilisateurs et redistribue les messages selon les règles métier.
C Pattern Observer
Chaque utilisateur observe tous les autres utilisateurs pour recevoir leurs messages.
D Singleton Global
Un singleton global stocke tous les messages et les utilisateurs viennent les consulter périodiquement.
❌
Incorrect. La communication directe crée un couplage fort entre tous les utilisateurs et rend difficile l'ajout de règles métier.
✅
Correct ! Le ChatRoom médiateur centralise la logique de communication, permet d'ajouter des règles (modération, historique) et découple les utilisateurs entre eux.
❌
Incorrect. Observer crée encore un couplage entre utilisateurs et ne permet pas de centraliser la logique métier du chat.
❌
Incorrect. Un singleton de stockage n'est pas un médiateur et ne gère pas les interactions entre utilisateurs.
