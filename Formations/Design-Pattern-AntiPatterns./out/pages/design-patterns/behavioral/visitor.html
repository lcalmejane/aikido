🎭 Visitor Pattern

Séparer les algorithmes des structures de données sur lesquelles ils opèrent

🎨 Design Patterns
⭐ Difficulté: Avancé
⏱️ 20 min
⚡ Comportemental

📖 Définition

Le pattern Visitor permet de séparer les algorithmes des structures de données sur lesquelles ils opèrent. Il définit une nouvelle opération sans changer les classes des éléments sur lesquels il opère.

🎯 Points Clés

  • Séparation des préoccupations : Algorithmes séparés des structures
  • Double dispatch : Mécanisme de sélection de méthode
  • Extensibilité : Ajout facile de nouvelles opérations
  • Principe ouvert/fermé : Ouvert à l'extension, fermé à la modification

// Interface Visitor pour système de fichiers
interface FileSystemVisitor {
    visitFile(file: File): void;
    visitDirectory(directory: Directory): void;
    visitSymlink(symlink: Symlink): void;
}

// Interface Element
interface FileSystemElement {
    accept(visitor: FileSystemVisitor): void;
    getName(): string;
    getPath(): string;
}

// Élément concret : Fichier
class File implements FileSystemElement {
    constructor(
        private name: string,
        private path: string,
        private size: number,
        private extension: string,
        private content: string = ''
    ) {}

    accept(visitor: FileSystemVisitor): void {
        visitor.visitFile(this);
    }

    getName(): string {
        return this.name;
    }

    getPath(): string {
        return this.path;
    }

    getSize(): number {
        return this.size;
    }

    getExtension(): string {
        return this.extension;
    }

    getContent(): string {
        return this.content;
    }

    setContent(content: string): void {
        this.content = content;
        this.size = content.length;
    }
}

// Élément concret : Répertoire
class Directory implements FileSystemElement {
    private children: FileSystemElement[] = [];

    constructor(
        private name: string,
        private path: string
    ) {}

    accept(visitor: FileSystemVisitor): void {
        visitor.visitDirectory(this);
    }

    getName(): string {
        return this.name;
    }

    getPath(): string {
        return this.path;
    }

    addChild(element: FileSystemElement): void {
        this.children.push(element);
    }

    removeChild(element: FileSystemElement): void {
        const index = this.children.indexOf(element);
        if (index > -1) {
            this.children.splice(index, 1);
        }
    }

    getChildren(): FileSystemElement[] {
        return [...this.children];
    }

    getSize(): number {
        return this.children.length;
    }
}

// Visiteur concret : Affichage arborescent
class TreeDisplayVisitor implements FileSystemVisitor {
    private output: string[] = [];
    private indentLevel: number = 0;

    visitFile(file: File): void {
        const indent = '  '.repeat(this.indentLevel);
        const sizeStr = this.formatSize(file.getSize());
        this.output.push(`${indent}📄 ${file.getName()} (${sizeStr})`);
    }

    visitDirectory(directory: Directory): void {
        const indent = '  '.repeat(this.indentLevel);
        const itemCount = directory.getSize();
        this.output.push(`${indent}📁 ${directory.getName()}/ (${itemCount} éléments)`);
        
        this.indentLevel++;
        for (const child of directory.getChildren()) {
            child.accept(this);
        }
        this.indentLevel--;
    }

    visitSymlink(symlink: Symlink): void {
        const indent = '  '.repeat(this.indentLevel);
        this.output.push(`${indent}🔗 ${symlink.getName()} -> ${symlink.getTarget()}`);
    }

    getOutput(): string {
        return this.output.join('\n');
    }

    reset(): void {
        this.output = [];
        this.indentLevel = 0;
    }

    private formatSize(bytes: number): string {
        if (bytes < 1024) return `${bytes}B`;
        if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)}KB`;
        return `${(bytes / (1024 * 1024)).toFixed(1)}MB`;
    }
}

// Visiteur concret : Recherche
class SearchVisitor implements FileSystemVisitor {
    private results: FileSystemElement[] = [];

    constructor(
        private searchTerm: string,
        private caseSensitive: boolean = false
    ) {}

    visitFile(file: File): void {
        if (this.matches(file.getName()) || this.matches(file.getContent())) {
            this.results.push(file);
        }
    }

    visitDirectory(directory: Directory): void {
        if (this.matches(directory.getName())) {
            this.results.push(directory);
        }
        
        // Continuer la recherche dans les enfants
        for (const child of directory.getChildren()) {
            child.accept(this);
        }
    }

    visitSymlink(symlink: Symlink): void {
        if (this.matches(symlink.getName()) || this.matches(symlink.getTarget())) {
            this.results.push(symlink);
        }
    }

    getResults(): FileSystemElement[] {
        return [...this.results];
    }

    reset(): void {
        this.results = [];
    }

    private matches(text: string): boolean {
        const searchText = this.caseSensitive ? text : text.toLowerCase();
        const term = this.caseSensitive ? this.searchTerm : this.searchTerm.toLowerCase();
        return searchText.includes(term);
    }
}

// Visiteur concret : Statistiques
class StatisticsVisitor implements FileSystemVisitor {
    private stats = {
        files: 0,
        directories: 0,
        symlinks: 0,
        totalSize: 0,
        extensions: new Map(),
        largestFile: null as File | null,
        deepestLevel: 0
    };
    private currentLevel: number = 0;

    visitFile(file: File): void {
        this.stats.files++;
        this.stats.totalSize += file.getSize();
        
        // Suivre l'extension
        const ext = file.getExtension();
        this.stats.extensions.set(ext, (this.stats.extensions.get(ext) || 0) + 1);
        
        // Suivre le plus gros fichier
        if (!this.stats.largestFile || file.getSize() > this.stats.largestFile.getSize()) {
            this.stats.largestFile = file;
        }
        
        // Suivre la profondeur
        this.stats.deepestLevel = Math.max(this.stats.deepestLevel, this.currentLevel);
    }

    visitDirectory(directory: Directory): void {
        this.stats.directories++;
        this.stats.deepestLevel = Math.max(this.stats.deepestLevel, this.currentLevel);
        
        this.currentLevel++;
        for (const child of directory.getChildren()) {
            child.accept(this);
        }
        this.currentLevel--;
    }

    visitSymlink(symlink: Symlink): void {
        this.stats.symlinks++;
        this.stats.deepestLevel = Math.max(this.stats.deepestLevel, this.currentLevel);
    }

    getStatistics() {
        return {
            ...this.stats,
            extensions: Object.fromEntries(this.stats.extensions)
        };
    }

    reset(): void {
        this.stats = {
            files: 0,
            directories: 0,
            symlinks: 0,
            totalSize: 0,
            extensions: new Map(),
            largestFile: null,
            deepestLevel: 0
        };
        this.currentLevel = 0;
    }
}

// Visiteur concret : Archivage
class ArchiveVisitor implements FileSystemVisitor {
    private archive: { path: string; content: string; size: number }[] = [];
    private currentPath: string = '';

    visitFile(file: File): void {
        this.archive.push({
            path: this.getFullPath(file),
            content: file.getContent(),
            size: file.getSize()
        });
    }

    visitDirectory(directory: Directory): void {
        const previousPath = this.currentPath;
        this.currentPath = this.getFullPath(directory);
        
        // Ajouter une entrée pour le répertoire
        this.archive.push({
            path: this.currentPath + '/',
            content: '',
            size: 0
        });
        
        // Traiter les enfants
        for (const child of directory.getChildren()) {
            child.accept(this);
        }
        
        this.currentPath = previousPath;
    }

    visitSymlink(symlink: Symlink): void {
        this.archive.push({
            path: this.getFullPath(symlink),
            content: `SYMLINK:${symlink.getTarget()}`,
            size: 0
        });
    }

    getArchive() {
        return [...this.archive];
    }

    exportAsJson(): string {
        return JSON.stringify(this.archive, null, 2);
    }

    reset(): void {
        this.archive = [];
        this.currentPath = '';
    }

    private getFullPath(element: FileSystemElement): string {
        return this.currentPath ? `${this.currentPath}/${element.getName()}` : element.getName();
    }
}

}

// Exemple d'utilisation avec expressions mathématiques
interface MathVisitor {
    visitNumber(number: NumberNode): number;
    visitBinaryOperation(operation: BinaryOperationNode): number;
    visitUnaryOperation(operation: UnaryOperationNode): number;
    visitVariable(variable: VariableNode): number;
}

interface MathExpression {
    accept(visitor: MathVisitor): number;
}

class NumberNode implements MathExpression {
    constructor(private value: number) {}

    accept(visitor: MathVisitor): number {
        return visitor.visitNumber(this);
    }

    getValue(): number {
        return this.value;
    }
}

class BinaryOperationNode implements MathExpression {
    constructor(
        private left: MathExpression,
        private operator: '+' | '-' | '*' | '/' | '^',
        private right: MathExpression
    ) {}

    accept(visitor: MathVisitor): number {
        return visitor.visitBinaryOperation(this);
    }

    getLeft(): MathExpression {
        return this.left;
    }

    getOperator(): string {
        return this.operator;
    }

    getRight(): MathExpression {
        return this.right;
    }
}

class UnaryOperationNode implements MathExpression {
    constructor(
        private operator: '-' | '+' | 'sin' | 'cos' | 'sqrt',
        private operand: MathExpression
    ) {}

    accept(visitor: MathVisitor): number {
        return visitor.visitUnaryOperation(this);
    }

    getOperator(): string {
        return this.operator;
    }

    getOperand(): MathExpression {
        return this.operand;
    }
}

class VariableNode implements MathExpression {
    constructor(private name: string) {}

    accept(visitor: MathVisitor): number {
        return visitor.visitVariable(this);
    }

    getName(): string {
        return this.name;
    }
}

// Visiteur pour évaluation d'expressions
class EvaluationVisitor implements MathVisitor {
    constructor(private variables: Map = new Map()) {}

    visitNumber(number: NumberNode): number {
        return number.getValue();
    }

    visitBinaryOperation(operation: BinaryOperationNode): number {
        const left = operation.getLeft().accept(this);
        const right = operation.getRight().accept(this);

        switch (operation.getOperator()) {
            case '+': return left + right;
            case '-': return left - right;
            case '*': return left * right;
            case '/': 
                if (right === 0) throw new Error('Division par zéro');
                return left / right;
            case '^': return Math.pow(left, right);
            default: throw new Error(`Opérateur inconnu: ${operation.getOperator()}`);
        }
    }

    visitUnaryOperation(operation: UnaryOperationNode): number {
        const operand = operation.getOperand().accept(this);

        switch (operation.getOperator()) {
            case '-': return -operand;
            case '+': return operand;
            case 'sin': return Math.sin(operand);
            case 'cos': return Math.cos(operand);
            case 'sqrt': 
                if (operand < 0) throw new Error('Racine carrée d\'un nombre négatif');
                return Math.sqrt(operand);
            default: throw new Error(`Opérateur unaire inconnu: ${operation.getOperator()}`);
        }
    }

    visitVariable(variable: VariableNode): number {
        const value = this.variables.get(variable.getName());
        if (value === undefined) {
            throw new Error(`Variable non définie: ${variable.getName()}`);
        }
        return value;
    }

    setVariable(name: string, value: number): void {
        this.variables.set(name, value);
    }
}

// Visiteur pour génération de code
class CodeGenerationVisitor implements MathVisitor {
    visitNumber(number: NumberNode): number {
        console.log(`LOAD ${number.getValue()}`);
        return number.getValue();
    }

    visitBinaryOperation(operation: BinaryOperationNode): number {
        const left = operation.getLeft().accept(this);
        const right = operation.getRight().accept(this);
        
        console.log(`${operation.getOperator().toUpperCase()} ${left} ${right}`);
        return 0; // Valeur fictive pour la génération de code
    }

    visitUnaryOperation(operation: UnaryOperationNode): number {
        const operand = operation.getOperand().accept(this);
        console.log(`${operation.getOperator().toUpperCase()} ${operand}`);
        return 0;
    }

    visitVariable(variable: VariableNode): number {
        console.log(`LOAD_VAR ${variable.getName()}`);
        return 0;
    }
}

    console.log(`Taille totale: ${stats.totalSize} octets`);
    console.log(`Extensions: ${JSON.stringify(stats.extensions)}`);
    console.log(`Profondeur max: ${stats.deepestLevel}`);
    
    // Test expressions mathématiques
    console.log('\n--- Expressions mathématiques ---');
    // Expression: (2 + 3) * 4 - sqrt(16)
    const expr = new BinaryOperationNode(
        new BinaryOperationNode(
            new BinaryOperationNode(
                new NumberNode(2),
                '+',
                new NumberNode(3)
            ),
            '*',
            new NumberNode(4)
        ),
        '-',
        new UnaryOperationNode('sqrt', new NumberNode(16))

    const evaluator = new EvaluationVisitor();
    const result = expr.accept(evaluator);
    console.log(`Résultat: ${result}`); // (2 + 3) * 4 - sqrt(16) = 20 - 4 = 16
    
    console.log('\n--- Génération de code ---');
    const codeGen = new CodeGenerationVisitor();
    expr.accept(codeGen);
}

<?php

// Interface Visitor pour documents
interface DocumentVisitor {
    public function visitParagraph(Paragraph $paragraph): void;
    public function visitHeading(Heading $heading): void;
    public function visitImage(Image $image): void;
    public function visitTable(Table $table): void;
}

// Interface Element
interface DocumentElement {
    public function accept(DocumentVisitor $visitor): void;
    public function getContent(): string;
}

// Élément concret : Paragraphe
class Paragraph implements DocumentElement {
    private string $text;
    private array $styles;
    
    public function __construct(string $text, array $styles = []) {
        $this->text = $text;
        $this->styles = $styles;
    }
    
    public function accept(DocumentVisitor $visitor): void {
        $visitor->visitParagraph($this);
    }
    
    public function getContent(): string {
        return $this->text;
    }
    
    public function getText(): string {
        return $this->text;
    }
    
    public function getStyles(): array {
        return $this->styles;
    }
    
    public function hasStyle(string $style): bool {
        return in_array($style, $this->styles);
    }
}

// Élément concret : Titre
class Heading implements DocumentElement {
    private string $text;
    private int $level;
    
    public function __construct(string $text, int $level = 1) {
        $this->text = $text;
        $this->level = max(1, min(6, $level)); // Limiter entre 1 et 6
    }
    
    public function accept(DocumentVisitor $visitor): void {
        $visitor->visitHeading($this);
    }
    
    public function getContent(): string {
        return $this->text;
    }
    
    public function getText(): string {
        return $this->text;
    }
    
    public function getLevel(): int {
        return $this->level;
    }
}

// Élément concret : Image
class Image implements DocumentElement {
    private string $src;
    private string $alt;
    private array $attributes;
    
    public function __construct(string $src, string $alt, array $attributes = []) {
        $this->src = $src;
        $this->alt = $alt;

// Visiteur concret : Export HTML
class HtmlExportVisitor implements DocumentVisitor {
    private string $output = '';
    private array $cssClasses;
    
    public function __construct(array $cssClasses = []) {
        $this->cssClasses = $cssClasses;
    }
    
    public function visitParagraph(Paragraph $paragraph): void {
        $classes = [];
        foreach ($paragraph->getStyles() as $style) {
            if (isset($this->cssClasses[$style])) {
                $classes[] = $this->cssClasses[$style];
            }
        }
        
        $classAttr = !empty($classes) ? ' class="' . implode(' ', $classes) . '"' : '';
        $this->output .= "<p{$classAttr}>" . htmlspecialchars($paragraph->getText()) . "</p>\n";
    }
    
    public function visitHeading(Heading $heading): void {
        $level = $heading->getLevel();
        $this->output .= "<h{$level}>" . htmlspecialchars($heading->getText()) . "</h{$level}>\n";
    }
    
    public function visitImage(Image $image): void {
        $src = htmlspecialchars($image->getSrc());
        $alt = htmlspecialchars($image->getAlt());
        
        $attributes = '';
        foreach ($image->getAttributes() as $name => $value) {
            $attributes .= ' ' . htmlspecialchars($name) . '="' . htmlspecialchars($value) . '"';
        }
        
        $this->output .= "<img src=\"{$src}\" alt=\"{$alt}\"{$attributes}>\n";
    }
    
    public function visitTable(Table $table): void {
        $this->output .= "<table>\n";
        
        // En-têtes
        if (!empty($table->getHeaders())) {
            $this->output .= "  <thead>\n    <tr>\n";
            foreach ($table->getHeaders() as $header) {
                $this->output .= "      <th>" . htmlspecialchars($header) . "</th>\n";
            }
            $this->output .= "    </tr>\n  </thead>\n";
        }
        
        // Lignes
        $this->output .= "  <tbody>\n";
        foreach ($table->getRows() as $row) {
            $this->output .= "    <tr>\n";
            foreach ($row as $cell) {
                $this->output .= "      <td>" . htmlspecialchars($cell) . "</td>\n";
            }
            $this->output .= "    </tr>\n";
        }
        $this->output .= "  </tbody>\n</table>\n";
    }
    
    public function getOutput(): string {
        return $this->output;
    }
    
    public function reset(): void {
        $this->output = '';
    }
}

// Visiteur concret : Export Markdown
class MarkdownExportVisitor implements DocumentVisitor {
    private string $output = '';
    
    public function visitParagraph(Paragraph $paragraph): void {
        $text = $paragraph->getText();
        
        // Appliquer les styles Markdown
        if ($paragraph->hasStyle('bold')) {
            $text = "**{$text}**";
        }
        if ($paragraph->hasStyle('italic')) {
            $text = "*{$text}*";
        }
        if ($paragraph->hasStyle('code')) {
            $text = "`{$text}`";
        }
        
        $this->output .= $text . "\n\n";
    }
    
    public function visitHeading(Heading $heading): void {
        $level = $heading->getLevel();
        $prefix = str_repeat('#', $level);
        $this->output .= "{$prefix} " . $heading->getText() . "\n\n";
    }
    
    public function visitImage(Image $image): void {
        $alt = $image->getAlt();
        $src = $image->getSrc();
        $this->output .= "![{$alt}]({$src})\n\n";
    }
    
    public function visitTable(Table $table): void {
        $headers = $table->getHeaders();
        $rows = $table->getRows();
        
        if (!empty($headers)) {
            // En-têtes
            $this->output .= '| ' . implode(' | ', $headers) . " |\n";
            $this->output .= '|' . str_repeat(' --- |', count($headers)) . "\n";
        }
        
        // Lignes
        foreach ($rows as $row) {
            $this->output .= '| ' . implode(' | ', $row) . " |\n";
        }
        $this->output .= "\n";
    }
    
    public function getOutput(): string {
        return $this->output;
    }
    
    public function reset(): void {
        $this->output = '';
    }
}

function demonstrateDocumentVisitor(): void {

    // Création d'un document
    $document = new Document("Guide d'utilisation");

class Document {

        $this->title = $title;
    }
    
    public function addElement(DocumentElement $element): void {
        $this->elements[] = $element;
    }
    
    public function getElements(): array {
        return $this->elements;
    }
    
    public function accept(DocumentVisitor $visitor): void {
        foreach ($this->elements as $element) {
            $element->accept($visitor);
        }
    }
    
    public function getTitle(): string {
        return $this->title;
    }
}

import java.util.*;
import java.util.stream.Collectors;

// Interface Visitor pour éléments géométriques
interface ShapeVisitor {
    double visitCircle(Circle circle);
    double visitRectangle(Rectangle rectangle);
    double visitTriangle(Triangle triangle);
    double visitComposite(CompositeShape composite);
}

// Interface Element
interface Shape {
    double accept(ShapeVisitor visitor);
    String getName();
}

// Forme concrète : Cercle
class Circle implements Shape {
    private String name;
    private double radius;
    
    public Circle(String name, double radius) {
        this.name = name;
        this.radius = radius;
    }
    
    @Override
    public double accept(ShapeVisitor visitor) {
        return visitor.visitCircle(this);
    }
    
    @Override
    public String getName() {
        return name;
    }
    
    public double getRadius() {
        return radius;
    }
}

// Forme concrète : Rectangle
class Rectangle implements Shape {
    private String name;
    private double width;
    private double height;
    
    public Rectangle(String name, double width, double height) {
        this.name = name;
        this.width = width;
        this.height = height;
    }
    
    @Override
    public double accept(ShapeVisitor visitor) {
        return visitor.visitRectangle(this);
    }
    
    @Override
    public String getName() {
        return name;
    }
    
    public double getWidth() {
        return width;
    }
    
    public double getHeight() {
        return height;
    }
}

// Forme concrète : Triangle
class Triangle implements Shape {
    private String name;
    private double base;
    private double height;
    private double sideA;
    private double sideB;
    
    public Triangle(String name, double base, double height, double sideA, double sideB) {

    public double getBase() {

        return sideB;

// Forme composite
class CompositeShape implements Shape {
    private String name;
    private List<Shape> shapes;
    
    public CompositeShape(String name) {
        this.name = name;
        this.shapes = new ArrayList<>();
    }
    
    public void addShape(Shape shape) {
        shapes.add(shape);
    }
    
    public void removeShape(Shape shape) {
        shapes.remove(shape);
    }
    
    public List<Shape> getShapes() {
        return new ArrayList<>(shapes);
    }
    
    @Override
    public double accept(ShapeVisitor visitor) {
        return visitor.visitComposite(this);
    }
    
    @Override
    public String getName() {
        return name;
    }
}

// Visiteur concret : Calcul d'aire
class AreaCalculatorVisitor implements ShapeVisitor {
    @Override
    public double visitCircle(Circle circle) {
        double area = Math.PI * Math.pow(circle.getRadius(), 2);
        System.out.println("Aire du cercle " + circle.getName() + 
                          " (r=" + circle.getRadius() + "): " + 
                          String.format("%.2f", area));
        return area;
    }
    
    @Override
    public double visitRectangle(Rectangle rectangle) {
        double area = rectangle.getWidth() * rectangle.getHeight();
        System.out.println("Aire du rectangle " + rectangle.getName() + 
                          " (" + rectangle.getWidth() + "x" + rectangle.getHeight() + "): " + 
                          String.format("%.2f", area));
        return area;
    }
    
    @Override
    public double visitTriangle(Triangle triangle) {
        double area = 0.5 * triangle.getBase() * triangle.getHeight();
        System.out.println("Aire du triangle " + triangle.getName() + 
                          " (b=" + triangle.getBase() + ", h=" + triangle.getHeight() + "): " + 
                          String.format("%.2f", area));
        return area;
    }
    
    @Override
    public double visitComposite(CompositeShape composite) {
        System.out.println("Calcul de l'aire composite " + composite.getName() + ":");
        double totalArea = 0;
        for (Shape shape : composite.getShapes()) {
            totalArea += shape.accept(this);
        }
        System.out.println("Aire totale de " + composite.getName() + ": " + 
                          String.format("%.2f", totalArea));
        return totalArea;
    }
}

class PerimeterCalculatorVisitor implements ShapeVisitor {
    @Override
    public double visitCircle(Circle circle) {

    @Override
    public double visitRectangle(Rectangle rectangle) {

        System.out.println("Périmètre du triangle " + triangle.getName() + ": " + 
                          String.format("%.2f", perimeter));
        return perimeter;
    }
    
    @Override
    public double visitComposite(CompositeShape composite) {
        System.out.println("Calcul du périmètre composite " + composite.getName() + ":");
        double totalPerimeter = 0;
        for (Shape shape : composite.getShapes()) {
            totalPerimeter += shape.accept(this);
        }
        System.out.println("Périmètre total de " + composite.getName() + ": " + 
                          String.format("%.2f", totalPerimeter));
        return totalPerimeter;
    }
}

// Visiteur concret : Export SVG
class SvgExportVisitor implements ShapeVisitor {
    private StringBuilder svg;
    private double currentX = 0;
    private double currentY = 0;
    private final double spacing = 100;
    
    public SvgExportVisitor() {
        this.svg = new StringBuilder();
        svg.append("<svg xmlns=\"http://www.w3.org/2000/svg\" viewBox=\"0 0 800 600\">\n");
    }
    
    @Override
    public double visitCircle(Circle circle) {
        double radius = circle.getRadius();
        svg.append(String.format("  <circle cx=\"%.1f\" cy=\"%.1f\" r=\"%.1f\" " +
                                "fill=\"lightblue\" stroke=\"blue\" stroke-width=\"2\"/>\n",
                                currentX + radius, currentY + radius, radius));
        svg.append(String.format("  <text x=\"%.1f\" y=\"%.1f\" text-anchor=\"middle\">%s</text>\n",
                                currentX + radius, currentY + radius, circle.getName()));
        
        currentX += spacing;
        if (currentX > 700) {
            currentX = 0;
            currentY += spacing;
        }
        
        return Math.PI * radius * radius;
    }
    
    @Override
    public double visitRectangle(Rectangle rectangle) {
        double width = rectangle.getWidth();
        double height = rectangle.getHeight();
        
        svg.append(String.format("  <rect x=\"%.1f\" y=\"%.1f\" width=\"%.1f\" height=\"%.1f\" " +
                                "fill=\"lightgreen\" stroke=\"green\" stroke-width=\"2\"/>\n",
                                currentX, currentY, width, height));
        svg.append(String.format("  <text x=\"%.1f\" y=\"%.1f\" text-anchor=\"middle\">%s</text>\n",
                                currentX + width/2, currentY + height/2, rectangle.getName()));
        
        currentX += spacing;
        if (currentX > 700) {
            currentX = 0;
            currentY += spacing;
        }
        
        return width * height;
    }
    
    @Override
    public double visitTriangle(Triangle triangle) {
        double base = triangle.getBase();
        double height = triangle.getHeight();
        
        String points = String.format("%.1f,%.1f %.1f,%.1f %.1f,%.1f",
                                     currentX, currentY + height,
                                     currentX + base/2, currentY,
                                     currentX + base, currentY + height);
        
        svg.append(String.format("  <polygon points=\"%s\" " +
                                "fill=\"lightyellow\" stroke=\"orange\" stroke-width=\"2\"/>\n",
                                points));
        svg.append(String.format("  <text x=\"%.1f\" y=\"%.1f\" text-anchor=\"middle\">%s</text>\n",
                                currentX + base/2, currentY + height/2, triangle.getName()));
        
        currentX += spacing;
        if (currentX > 700) {
            currentX = 0;
            currentY += spacing;
        }
        
        return 0.5 * base * height;
    }
    
    @Override
    public double visitComposite(CompositeShape composite) {
        svg.append(String.format("  <g id=\"%s\">\n", composite.getName()));
        double totalArea = 0;
        
        for (Shape shape : composite.getShapes()) {
            totalArea += shape.accept(this);
        }
        
        svg.append("  </g>\n");
        return totalArea;
    }
    
    public String getSvg() {
        return svg.toString() + "</svg>";
    }
    
    public void reset() {
        svg = new StringBuilder();
        svg.append("<svg xmlns=\"http://www.w3.org/2000/svg\" viewBox=\"0 0 800 600\">\n");
        currentX = 0;
        currentY = 0;
    }
}

// Visiteur concret : Validation
class ValidationVisitor implements ShapeVisitor {
    private List<String> errors = new ArrayList<>();
    private List<String> warnings = new ArrayList<>();
    
    @Override
    public double visitCircle(Circle circle) {
        if (circle.getRadius() <= 0) {
            errors.add("Cercle " + circle.getName() + ": rayon invalide (" + circle.getRadius() + ")");
        } else if (circle.getRadius() > 1000) {
            warnings.add("Cercle " + circle.getName() + ": rayon très grand (" + circle.getRadius() + ")");
        }
        
        if (circle.getName() == null || circle.getName().trim().isEmpty()) {
            warnings.add("Cercle sans nom");
        }
        
        return circle.getRadius();
    }
    
    @Override
    public double visitRectangle(Rectangle rectangle) {
        if (rectangle.getWidth() <= 0) {
            errors.add("Rectangle " + rectangle.getName() + ": largeur invalide (" + rectangle.getWidth() + ")");
        }
        
        if (rectangle.getHeight() <= 0) {
            errors.add("Rectangle " + rectangle.getName() + ": hauteur invalide (" + rectangle.getHeight() + ")");
        }
        
        if (rectangle.getWidth() > 1000 || rectangle.getHeight() > 1000) {
            warnings.add("Rectangle " + rectangle.getName() + ": dimensions très grandes");
        }
        
        if (rectangle.getName() == null || rectangle.getName().trim().isEmpty()) {
            warnings.add("Rectangle sans nom");
        }
        
        return rectangle.getWidth() * rectangle.getHeight();
    }
    
    @Override
    public double visitTriangle(Triangle triangle) {
        if (triangle.getBase() <= 0) {
            errors.add("Triangle " + triangle.getName() + ": base invalide (" + triangle.getBase() + ")");
        }
        
        if (triangle.getHeight() <= 0) {
            errors.add("Triangle " + triangle.getName() + ": hauteur invalide (" + triangle.getHeight() + ")");
        }
        
        // Vérification de l'inégalité triangulaire
        double a = triangle.getSideA();
        double b = triangle.getSideB();
        double c = triangle.getBase();
        
        if (a + b <= c || a + c <= b || b + c <= a) {
            errors.add("Triangle " + triangle.getName() + ": inégalité triangulaire non respectée");
        }
        
        if (triangle.getName() == null || triangle.getName().trim().isEmpty()) {
            warnings.add("Triangle sans nom");
        }
        
        return 0.5 * triangle.getBase() * triangle.getHeight();
    }
    
    @Override
    public double visitComposite(CompositeShape composite) {
        if (composite.getShapes().isEmpty()) {
            warnings.add("Forme composite " + composite.getName() + " vide");
        }
        
        double totalArea = 0;
        for (Shape shape : composite.getShapes()) {
            totalArea += shape.accept(this);
        }
        
        return totalArea;
    }
    
    public List<String> getErrors() {
        return new ArrayList<>(errors);
    }
    
    public List<String> getWarnings() {
        return new ArrayList<>(warnings);
    }
    
    public boolean hasErrors() {
        return !errors.isEmpty();
    }
    
    public boolean hasWarnings() {
        return !warnings.isEmpty();
    }
    
    public void reset() {
        errors.clear();
        warnings.clear();
    }
}

🎯 Cas d'Usage Typiques

🌳 Structures Arborescentes

Parcours et traitement d'arbres syntaxiques, DOM, systèmes de fichiers

Exemple : Compilateur avec visiteurs pour analyse sémantique, génération de code, optimisation

📊 Export Multi-Format

Génération de différents formats de sortie à partir d'une même structure

Exemple : Document exporté en HTML, PDF, Markdown, LaTeX

🔍 Analyse et Validation

Vérification de règles métier, collecte de statistiques, audit

Exemple : Validation de modèles UML, analyse de performance de code

🎨 Rendu Graphique

Affichage d'éléments graphiques dans différents contextes

Exemple : Formes géométriques rendues en SVG, Canvas, ou impression

🧠 Biais Cognitifs Associés

🔨 Biais du Marteau

Tendance à utiliser Visitor pour tous les problèmes de parcours, même quand une simple méthode virtuelle suffirait. Le pattern ajoute de la complexité qui n'est pas toujours justifiée.

📈 Biais de Complexité

Surestimation de la valeur du double dispatch et de la séparation des algorithmes, conduisant à une architecture over-engineered pour des besoins simples.

🎯 Biais de Focalisation

Concentration excessive sur l'extensibilité des opérations au détriment de l'extensibilité des types d'éléments, créant un déséquilibre architectural.

⚖️ Biais d'Ancrage

Attachement rigide au pattern même quand les besoins évoluent vers des solutions plus simples comme les expressions lambda ou les streams.

⚠️ Anti-Patterns Associés

🕸️ Visitor Hell

Multiplication excessive de visiteurs pour des opérations triviales, créant une hiérarchie complexe difficile à maintenir. Chaque nouvelle opération nécessite un nouveau visiteur complet.

🔄 Circular Dependencies

Dépendances circulaires entre visiteurs et éléments, particulièrement problématique quand les visiteurs ont besoin d'accéder à d'autres visiteurs ou à des services externes.

💥 Brittle Visitor

Interface Visitor fragile qui se brise à chaque ajout de nouveau type d'élément, nécessitant la modification de tous les visiteurs existants.

🎭 God Visitor

Visiteur monolithique qui tente de gérer trop d'opérations différentes, violant le principe de responsabilité unique et devenant difficile à tester.

🎮 Exercice Interactif

Implémentation d'un Système de Validation

Vous devez implémenter un visiteur pour valider des formulaires avec différents types de champs. Quelle approche respecte le mieux le pattern Visitor ?

✅ Visiteur de Validation Spécialisé

interface FormFieldVisitor {
    visitTextField(field: TextField): ValidationResult;
    visitEmailField(field: EmailField): ValidationResult;
    visitPasswordField(field: PasswordField): ValidationResult;
}

class ValidationVisitor implements FormFieldVisitor {
    visitTextField(field: TextField): ValidationResult {
        return field.getValue().length >= field.getMinLength() 
            ? ValidationResult.valid() 
            : ValidationResult.error("Texte trop court");
    }
    
    visitEmailField(field: EmailField): ValidationResult {
        const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
        return emailRegex.test(field.getValue())
            ? ValidationResult.valid()
            : ValidationResult.error("Email invalide");
    }
}

Correct ! Chaque type de champ a sa méthode de visite spécifique, permettant une validation adaptée.

❌ Méthode Générique

class GenericValidator {
    validate(field: FormField): ValidationResult {
        if (field.getType() === "email") {
            // validation email
        } else if (field.getType() === "password") {
            // validation password
        }
        // ...
    }
}

Incorrect. Cette approche utilise des conditions au lieu du double dispatch du pattern Visitor.

❌ Héritage Simple

abstract class FormField {
    abstract validate(): ValidationResult;
}

class EmailField extends FormField {
    validate(): ValidationResult {
        // validation intégrée
    }
}

Incorrect. Cette approche mélange la logique de validation avec la structure des champs, violant la séparation des préoccupations.

🎯 Excellente Analyse !

Vous avez identifié la bonne implémentation du pattern Visitor. Cette approche :

  • Sépare les préoccupations : validation séparée de la structure
  • Utilise le double dispatch : type de champ + type de visiteur
  • Facilite l'extension : nouveaux visiteurs sans modifier les champs
  • Respecte le principe ouvert/fermé : ouvert à l'extension, fermé à la modification

🤔 Approche Procédurale

Cette solution utilise des conditions explicites au lieu du mécanisme de double dispatch du pattern Visitor. Problèmes :

  • Violation du principe ouvert/fermé
  • Code difficile à maintenir avec de nombreux types
  • Pas de séparation claire des responsabilités
  • Risque d'oubli lors de l'ajout de nouveaux types

📚 Héritage Classique

Bien que fonctionnelle, cette approche ne suit pas le pattern Visitor. Limitations :

  • Mélange structure et comportement
  • Difficile d'ajouter de nouveaux types de validation
  • Chaque champ doit connaître toutes ses validations
  • Code dupliqué pour des validations similaires
