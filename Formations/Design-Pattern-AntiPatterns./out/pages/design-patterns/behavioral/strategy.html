🎯 Strategy Pattern

Définir une famille d'algorithmes interchangeables

🎨 Design Patterns
⭐ Difficulté: Facile
⏱️ 15 min
🎭 Comportemental

🎯 Définition

Le Strategy est un pattern comportemental qui définit une famille d'algorithmes, les encapsule et les rend interchangeables. Strategy permet à l'algorithme de varier indépendamment des clients qui l'utilisent.

❌ Problème Résolu

  • Conditions multiples (if/else, switch) pour choisir un algorithme
  • Code dupliqué pour des variantes d'algorithmes
  • Difficulté à ajouter de nouveaux algorithmes
  • Violation du principe Ouvert/Fermé

✅ Solution Apportée

  • Encapsulation des algorithmes dans des classes séparées
  • Interchangeabilité à l'exécution
  • Facilité d'ajout de nouvelles stratégies
  • Respect du principe de responsabilité unique
💡 Principe clé : "Favoriser la composition plutôt que l'héritage" - les stratégies sont composées plutôt qu'héritées.

🏗️ Structure UML

<<interface>>
Strategy
+ execute(data: any): any
ConcreteStrategyA
+ execute(data: any): any
ConcreteStrategyB
+ execute(data: any): any
Context
- strategy: Strategy
+ setStrategy(strategy: Strategy): void
+ executeStrategy(data: any): any

Éléments Clés

  • Strategy : Interface commune pour toutes les stratégies concrètes
  • ConcreteStrategy : Implémentations spécifiques des algorithmes
  • Context : Maintient une référence vers une stratégie et délègue le travail
  • Client : Crée et configure les stratégies appropriées

🔄 Flux d'Exécution

💡 Point clé : Le Context délègue le travail à la stratégie courante, permettant de changer d'algorithme dynamiquement sans modifier le code client.

// Interface Strategy
interface PaymentStrategy {
    pay(amount: number): PaymentResult;
    validate(): boolean;
}

// Résultat de paiement
interface PaymentResult {
    success: boolean;
    transactionId?: string;
    message: string;
    fees?: number;
}

// ConcreteStrategy : Paiement par Carte de Crédit
class CreditCardPayment implements PaymentStrategy {
    private cardNumber: string;
    private expiryDate: string;
    private cvv: string;
    
    constructor(cardNumber: string, expiryDate: string, cvv: string) {
        this.cardNumber = cardNumber;
        this.expiryDate = expiryDate;
        this.cvv = cvv;
    }
    
    validate(): boolean {
        // Validation basique de la carte
        return this.cardNumber.length === 16 && 
               this.cvv.length === 3 && 
               this.expiryDate.length === 5;
    }
    
    pay(amount: number): PaymentResult {
        if (!this.validate()) {
            return {
                success: false,
                message: "Informations de carte invalides"
            };
        }
        
        // Simulation du traitement de paiement
        const fees = amount * 0.029; // 2.9% de frais
        const transactionId = `CC_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
        
        console.log(`Traitement paiement carte: ${amount}€ + ${fees.toFixed(2)}€ de frais`);
        
        return {
            success: true,
            transactionId,
            message: `Paiement de ${amount}€ effectué par carte`,
            fees
        };
    }
}

// Interface Strategy
interface SortingStrategy {
    public function sort(array $data): array;
    public function getName(): string;
    public function getComplexity(): string;
}

// ConcreteStrategy : Tri à Bulles
class BubbleSortStrategy implements SortingStrategy {
    public function sort(array $data): array {
        $n = count($data);
        $comparisons = 0;
        
        for ($i = 0; $i < $n - 1; $i++) {
            for ($j = 0; $j < $n - $i - 1; $j++) {
                $comparisons++;
                if ($data[$j] > $data[$j + 1]) {
                    // Échange
                    $temp = $data[$j];
                    $data[$j] = $data[$j + 1];
                    $data[$j + 1] = $temp;
                }
            }
        }
        
        echo "Tri à bulles: {$comparisons} comparaisons\n";
        return $data;
    }
    
    public function getName(): string {
        return "Bubble Sort";
    }
    
    public function getComplexity(): string {
        return "O(n²)";
    }
}

// ConcreteStrategy : Tri Rapide
class QuickSortStrategy implements SortingStrategy {
    private int $comparisons = 0;
    
    public function sort(array $data): array {
        $this->comparisons = 0;
        $result = $this->quickSort($data, 0, count($data) - 1);
        echo "Tri rapide: {$this->comparisons} comparaisons\n";
        return $result;
    }
    
    private function quickSort(array $arr, int $low, int $high): array {
        if ($low < $high) {
            $pi = $this->partition($arr, $low, $high);
            $arr = $this->quickSort($arr, $low, $pi - 1);
            $arr = $this->quickSort($arr, $pi + 1, $high);
        }
        return $arr;
    }
    
    private function partition(array &$arr, int $low, int $high): int {
        $pivot = $arr[$high];
        $i = $low - 1;
        
        for ($j = $low; $j <= $high - 1; $j++) {
            $this->comparisons++;
            if ($arr[$j] < $pivot) {
                $i++;
                $temp = $arr[$i];
                $arr[$i] = $arr[$j];
                $arr[$j] = $temp;
            }
        }
        
        $temp = $arr[$i + 1];
        $arr[$i + 1] = $arr[$high];
        $arr[$high] = $temp;
        
        return $i + 1;
    }
    
    public function getName(): string {
        return "Quick Sort";
    }
    
    public function getComplexity(): string {
        return "O(n log n) moyen, O(n²) pire cas";
    }
}

// ConcreteStrategy : Tri par Fusion
class MergeSortStrategy implements SortingStrategy {
    private int $comparisons = 0;
    
    public function sort(array $data): array {
        $this->comparisons = 0;
        $result = $this->mergeSort($data);
        echo "Tri par fusion: {$this->comparisons} comparaisons\n";
        return $result;
    }
    
    private function mergeSort(array $arr): array {
        if (count($arr) <= 1) {
            return $arr;
        }
        
        $mid = intval(count($arr) / 2);
        $left = array_slice($arr, 0, $mid);
        $right = array_slice($arr, $mid);
        
        return $this->merge($this->mergeSort($left), $this->mergeSort($right));
    }
    
    private function merge(array $left, array $right): array {
        $result = [];
        $i = $j = 0;
        
        while ($i < count($left) && $j < count($right)) {
            $this->comparisons++;
            if ($left[$i] <= $right[$j]) {
                $result[] = $left[$i];
                $i++;
            } else {
                $result[] = $right[$j];
                $j++;
            }
        }
        
        while ($i < count($left)) {
            $result[] = $left[$i];
            $i++;
        }
        
        while ($j < count($right)) {
            $result[] = $right[$j];
            $j++;
        }
        
        return $result;
    }
    
    public function getName(): string {
        return "Merge Sort";
    }
    
    public function getComplexity(): string {
        return "O(n log n)";
    }
}

    }
    
    public function getName(): string {
        return "PHP Native Sort";
    }
    
    public function getComplexity(): string {

    }
}

class DataSorter {
    private SortingStrategy $strategy;
    
    public function __construct(SortingStrategy $strategy) {
        $this->strategy = $strategy;
    }
    
    public function setStrategy(SortingStrategy $strategy): void {
        $this->strategy = $strategy;
        echo "Stratégie changée vers: " . $strategy->getName() . "\n";
    }
    
    public function sortData(array $data): array {
        echo "Tri de " . count($data) . " éléments avec " . $this->strategy->getName() . "\n";
        echo "Complexité: " . $this->strategy->getComplexity() . "\n";
        
        $startTime = microtime(true);
        $sortedData = $this->strategy->sort($data);
        $endTime = microtime(true);
        
        $executionTime = ($endTime - $startTime) * 1000;
        echo "Temps d'exécution: " . number_format($executionTime, 2) . " ms\n\n";
        
        return $sortedData;
    }
    
    public function getCurrentStrategy(): string {
        return $this->strategy->getName();
    }
}

import java.util.*;
import java.util.function.Function;

// Interface Strategy
interface CompressionStrategy {
    byte[] compress(String data);
    String decompress(byte[] compressedData);
    String getName();
    double getCompressionRatio(String originalData, byte[] compressedData);
}

// ConcreteStrategy : Compression ZIP
class ZipCompressionStrategy implements CompressionStrategy {
    @Override
    public byte[] compress(String data) {
        // Simulation de compression ZIP
        System.out.println("Compression ZIP en cours...");
        
        // Simulation simple : on retire les espaces et caractères répétés
        String compressed = data.replaceAll("\\s+", " ")
                               .replaceAll("(.)\\1+", "$1");
        
        return compressed.getBytes();
    }
    
    @Override
    public String decompress(byte[] compressedData) {
        System.out.println("Décompression ZIP en cours...");
        return new String(compressedData);
    }
    
    @Override
    public String getName() {
        return "ZIP Compression";
    }
    
    @Override
    public double getCompressionRatio(String originalData, byte[] compressedData) {
        return (double) compressedData.length / originalData.length();
    }
}

// ConcreteStrategy : Compression GZIP
class GzipCompressionStrategy implements CompressionStrategy {
    @Override
    public byte[] compress(String data) {
        System.out.println("Compression GZIP en cours...");
        
        // Simulation GZIP : compression plus agressive
        String compressed = data.toLowerCase()
                               .replaceAll("[aeiou]", "")
                               .replaceAll("\\s+", "");
        
        return compressed.getBytes();
    }
    
    @Override
    public String decompress(byte[] compressedData) {
        System.out.println("Décompression GZIP en cours...");
        return new String(compressedData) + " [GZIP décompressé]";
    }
    
    @Override
    public String getName() {
        return "GZIP Compression";
    }
    
    @Override
    public double getCompressionRatio(String originalData, byte[] compressedData) {
        return (double) compressedData.length / originalData.length();
    }
}

// ConcreteStrategy : Compression LZ4 (rapide)
class Lz4CompressionStrategy implements CompressionStrategy {
    @Override
    public byte[] compress(String data) {
        System.out.println("Compression LZ4 (rapide) en cours...");
        
        // Simulation LZ4 : compression rapide mais moins efficace
        String compressed = data.replaceAll("\\s+", "_");
        
        return compressed.getBytes();
    }
    
    @Override
    public String decompress(byte[] compressedData) {
        System.out.println("Décompression LZ4 en cours...");
        return new String(compressedData).replace("_", " ");
    }
    
    @Override
    public String getName() {
        return "LZ4 Compression";
    }
    
    @Override
    public double getCompressionRatio(String originalData, byte[] compressedData) {
        return (double) compressedData.length / originalData.length();
    }
}

// ConcreteStrategy : Pas de compression
class NoCompressionStrategy implements CompressionStrategy {
    @Override
    public byte[] compress(String data) {
        System.out.println("Aucune compression appliquée");
        return data.getBytes();
    }
    
    @Override
    public String decompress(byte[] compressedData) {
        System.out.println("Aucune décompression nécessaire");
        return new String(compressedData);
    }
    
    @Override
    public String getName() {
        return "No Compression";
    }
    
    @Override
    public double getCompressionRatio(String originalData, byte[] compressedData) {
        return 1.0; // Aucune compression
    }
}

// Context : Gestionnaire de Fichiers
class FileManager {
    private CompressionStrategy compressionStrategy;
    private Map storage = new HashMap<>();
    
    public FileManager(CompressionStrategy strategy) {
        this.compressionStrategy = strategy;
    }
    
    public void setCompressionStrategy(CompressionStrategy strategy) {
        this.compressionStrategy = strategy;
        System.out.println("Stratégie de compression changée vers: " + strategy.getName());
    }
    
    public void saveFile(String filename, String content) {
        System.out.println("\n=== Sauvegarde de " + filename + " ===");
        System.out.println("Taille originale: " + content.length() + " caractères");
        
        long startTime = System.nanoTime();
        byte[] compressedData = compressionStrategy.compress(content);
        long endTime = System.nanoTime();
        
        double compressionTime = (endTime - startTime) / 1_000_000.0; // en ms
        double ratio = compressionStrategy.getCompressionRatio(content, compressedData);
        
        storage.put(filename, compressedData);
        
        System.out.println("Taille compressée: " + compressedData.length + " octets");
        System.out.println("Ratio de compression: " + String.format("%.2f", ratio));
        System.out.println("Temps de compression: " + String.format("%.2f", compressionTime) + " ms");
        System.out.println("Économie d'espace: " + String.format("%.1f", (1 - ratio) * 100) + "%");
    }
    
    public String loadFile(String filename) {
        System.out.println("\n=== Chargement de " + filename + " ===");
        
        byte[] compressedData = storage.get(filename);
        if (compressedData == null) {
            System.out.println("Fichier non trouvé: " + filename);
            return null;
        }
        
        long startTime = System.nanoTime();
        String decompressedContent = compressionStrategy.decompress(compressedData);
        long endTime = System.nanoTime();
        
        double decompressionTime = (endTime - startTime) / 1_000_000.0;
        System.out.println("Temps de décompression: " + String.format("%.2f", decompressionTime) + " ms");
        
        return decompressedContent;
    }
    
    public void showStorageInfo() {
        System.out.println("\n=== Informations de stockage ===");
        System.out.println("Stratégie actuelle: " + compressionStrategy.getName());
        System.out.println("Fichiers stockés: " + storage.size());
        
        int totalSize = storage.values().stream()
                              .mapToInt(data -> data.length)
                              .sum();
        System.out.println("Taille totale: " + totalSize + " octets");
    }
    
    public String getCurrentStrategy() {
        return compressionStrategy.getName();
    }
}

// Factory pour les stratégies de compression
class CompressionStrategyFactory {
    public static CompressionStrategy createZipStrategy() {
        return new ZipCompressionStrategy();
    }
    
    public static CompressionStrategy createGzipStrategy() {
        return new GzipCompressionStrategy();
    }
    
    public static CompressionStrategy createLz4Strategy() {
        return new Lz4CompressionStrategy();
    }
    
    public static CompressionStrategy createNoCompressionStrategy() {
        return new NoCompressionStrategy();
    }
    
    public static CompressionStrategy getBestStrategyForContent(String content) {
        if (content.length() < 100) {
            return createNoCompressionStrategy(); // Pas de compression pour petits fichiers
        } else if (content.contains("    ") || content.contains("\n\n")) {
            return createGzipStrategy(); // Bon pour texte avec répétitions
        } else if (content.length() > 10000) {
            return createLz4Strategy(); // Rapide pour gros fichiers
        } else {
            return createZipStrategy(); // Équilibré pour taille moyenne
        }
    }
}

            System.out.println(String.join("", Collections.nCopies(60, "-")));
        }
        
        // Test de sélection automatique
        System.out.println("\n=== Sélection automatique de stratégie ===");
        
        String[] testContents = {smallText, mediumText, largeText};
        String[] filenames = {"small.txt", "medium.txt", "large.txt"};
        
        for (int i = 0; i < testContents.length; i++) {
            CompressionStrategy bestStrategy = CompressionStrategyFactory.getBestStrategyForContent(testContents[i]);
            fileManager.setCompressionStrategy(bestStrategy);
            fileManager.saveFile(filenames[i], testContents[i]);
        }
        
        fileManager.showStorageInfo();
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Flexibilité : Changement d'algorithme à l'exécution
  • Extensibilité : Ajout facile de nouvelles stratégies
  • Principe Ouvert/Fermé : Ouvert à l'extension, fermé à la modification
  • Élimination des conditionnelles : Remplace les if/else complexes
  • Testabilité : Chaque stratégie peut être testée indépendamment

❌ Inconvénients

  • Complexité accrue : Plus de classes à maintenir
  • Connaissance des stratégies : Le client doit connaître les différences
  • Overhead : Peut être excessif pour des algorithmes simples
  • Communication : Interface commune peut limiter les paramètres
  • Nombre d'objets : Augmentation du nombre d'instances

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Algorithmes multiples : Plusieurs façons de résoudre un problème
  • Conditions complexes : Remplacer de longs if/else ou switch
  • Calculs variables : Tarification, taxation, remises
  • Formats multiples : Export PDF, Excel, CSV
  • Validation : Différentes règles selon le contexte

❌ Quand l'éviter

  • Algorithme unique : Une seule façon de faire
  • Logique simple : Conditions triviales
  • Pas de variation : Comportement fixe requis
  • Performance critique : Overhead inacceptable
  • Couplage nécessaire : Stratégies interdépendantes

🧩 Biais Cognitifs Associés

🔨 Marteau de Maslow

Manifestation : "Strategy résout tous les problèmes de choix d'algorithme."

Risque : Sur-ingénierie avec Strategy même pour des cas simples.

⚓ Biais d'Ancrage

Manifestation : "J'ai toujours utilisé des if/else, pourquoi changer ?"

Risque : Résistance à adopter Strategy même quand c'est approprié.

🎯 Biais de Disponibilité

Manifestation : Choisir Strategy car c'est le pattern le plus connu.

Risque : Ignorer des alternatives plus simples comme les fonctions lambda.

⚠️ Anti-Patterns à Éviter

🏗️ Strategy Explosion

Créer trop de stratégies pour des variations mineures.

// ❌ Mauvais : Une stratégie par petite variation class RedButtonStrategy, BlueButtonStrategy, GreenButtonStrategy...

🔗 Leaky Strategy

Stratégies qui dépendent trop du contexte ou d'autres stratégies.

// ❌ Stratégie qui connaît trop le contexte strategy.execute(context.getAllInternalState());
