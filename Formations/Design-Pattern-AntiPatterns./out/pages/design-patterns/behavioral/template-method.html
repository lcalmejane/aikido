📋 Template Method Pattern

Définir le squelette d'un algorithme en laissant les sous-classes redéfinir certaines étapes

🎨 Design Patterns
⭐ Difficulté: Facile
⏱️ 20 min
🎭 Comportemental

🎯 Définition

Le Template Method est un pattern comportemental qui définit le squelette d'un algorithme dans la classe mère, mais laisse les sous-classes redéfinir certaines étapes de l'algorithme sans changer sa structure globale. Il utilise l'héritage pour permettre la réutilisation de code tout en offrant de la flexibilité.

❌ Problème Résolu

  • Duplication de code dans des algorithmes similaires
  • Variations d'un même processus métier
  • Besoin de contrôler l'ordre d'exécution des étapes
  • Code répétitif avec de petites variations

✅ Solution Apportée

  • Structure d'algorithme réutilisable
  • Points d'extension bien définis
  • Contrôle de l'ordre d'exécution
  • Réduction de la duplication de code
⚠️ Attention : Le Template Method peut créer une hiérarchie rigide et complexe. Préférer la composition quand l'héritage devient problématique.

🏗️ Structure UML

AbstractClass
+ templateMethod(): void
+ step1(): void
+ step2(): void
+ step3(): void
+ hook(): void
ConcreteClassA
+ step2(): void
+ hook(): void
ConcreteClassB
+ step2(): void

Éléments Clés

  • AbstractClass : Définit la méthode template et les étapes de base
  • templateMethod() : Méthode finale qui orchestre l'algorithme
  • Méthodes abstraites : Étapes que les sous-classes doivent implémenter
  • Hooks : Points d'extension optionnels pour les sous-classes

🔄 Flux d'Exécution

graph TD A[Client appelle templateMethod] --> B[step1 - implémentation par défaut] B --> C[step2 - implémentation spécifique] C --> D[step3 - implémentation par défaut] D --> E[hook - extension optionnelle] E --> F[Fin de l'algorithme] G[ConcreteClassA] --> H[Redéfinit step2 et hook] I[ConcreteClassB] --> J[Redéfinit seulement step2] style A fill:#e1f5fe style C fill:#ffebee style E fill:#f3e5f5 style F fill:#e8f5e8

💡 Point clé : L'ordre des étapes est fixé par la classe abstraite, mais le contenu de certaines étapes peut être personnalisé.

💻 Implémentations

Exemple : Processus de Traitement de Données


// Classe abstraite définissant le template
abstract class DataProcessor {
    // Méthode template - définit l'algorithme
    public processData(data: any[]): any[] {
        console.log("🚀 Début du traitement des données");
        
        // Étape 1 : Validation (implémentation par défaut)
        const validatedData = this.validateData(data);
        
        // Étape 2 : Transformation (spécifique à chaque sous-classe)
        const transformedData = this.transformData(validatedData);
        
        // Étape 3 : Filtrage (implémentation par défaut)
        const filteredData = this.filterData(transformedData);
        
        // Hook optionnel pour post-traitement
        const finalData = this.postProcess(filteredData);
        
        // Étape 4 : Sauvegarde (implémentation par défaut)
        this.saveData(finalData);
        
        console.log("✅ Traitement terminé");
        return finalData;
    }
    
    // Étape avec implémentation par défaut
    protected validateData(data: any[]): any[] {
        console.log("🔍 Validation des données");
        return data.filter(item => item !== null && item !== undefined);
    }
    
    // Étape abstraite - doit être implémentée par les sous-classes
    protected abstract transformData(data: any[]): any[];
    
    // Étape avec implémentation par défaut
    protected filterData(data: any[]): any[] {
        console.log("🔧 Filtrage des données");
        return data;
    }
    
    // Hook - peut être redéfini par les sous-classes
    protected postProcess(data: any[]): any[] {
        // Implémentation par défaut : ne fait rien
        return data;
    }
    
    // Étape avec implémentation par défaut
    protected saveData(data: any[]): void {
        console.log(`💾 Sauvegarde de ${data.length} éléments`);
    }
}

// Processeur pour données utilisateur
class UserDataProcessor extends DataProcessor {
    protected transformData(data: any[]): any[] {
        console.log("👤 Transformation des données utilisateur");
        return data.map(user => ({
            id: user.id,
            name: user.name?.toUpperCase() || 'UNKNOWN',
            email: user.email?.toLowerCase() || '',
            createdAt: new Date().toISOString()
        }));
    }
    
    protected postProcess(data: any[]): any[] {
        console.log("🔄 Post-traitement : ajout de métadonnées");
        return data.map(user => ({
            ...user,
            processed: true,
            processedAt: new Date().toISOString()
        }));
    }
    
    protected filterData(data: any[]): any[] {
        console.log("🔧 Filtrage : suppression des emails invalides");
        return data.filter(user => user.email && user.email.includes('@'));
    }
}

// Processeur pour données de commande
class OrderDataProcessor extends DataProcessor {
    protected transformData(data: any[]): any[] {
        console.log("🛒 Transformation des données de commande");
        return data.map(order => ({
            orderId: order.id,
            customerId: order.customer_id,
            total: parseFloat(order.total) || 0,
            status: order.status || 'pending',
            items: order.items || [],
            processedAt: new Date().toISOString()
        }));
    }
    
    protected validateData(data: any[]): any[] {
        console.log("🔍 Validation spécifique aux commandes");
        return super.validateData(data).filter(order => 
            order.id && order.customer_id && order.total >= 0
        );
    }
}

// Processeur simple sans personnalisation
class SimpleDataProcessor extends DataProcessor {

        console.log("⚡ Transformation simple : ajout d'un timestamp");
        return data.map(item => ({
            ...item,
            timestamp: Date.now()
        }));
    }
}

abstract class ImageProcessor {
    public processImage(imagePath: string): string {
        console.log(`🖼️ Traitement de l'image: ${imagePath}`);
        
        // Étapes du pipeline
        const loadedImage = this.loadImage(imagePath);
        const processedImage = this.applyFilters(loadedImage);
        const optimizedImage = this.optimize(processedImage);
        const outputPath = this.saveImage(optimizedImage);
        
        // Hook pour post-traitement
        this.onProcessingComplete(outputPath);
        
        return outputPath;
    }
    
    protected loadImage(path: string): string {
        console.log("📂 Chargement de l'image");
        return `loaded_${path}`;
    }
    
    protected abstract applyFilters(image: string): string;
    
    protected optimize(image: string): string {
        console.log("⚡ Optimisation de l'image");
        return `optimized_${image}`;
    }
    
    protected saveImage(image: string): string {
        const outputPath = `output_${Date.now()}.jpg`;
        console.log(`💾 Sauvegarde: ${outputPath}`);
        return outputPath;
    }
    
    protected onProcessingComplete(outputPath: string): void {
        // Hook vide par défaut
    }
}

// Classe abstraite pour le traitement de rapports
abstract class ReportGenerator {
    // Méthode template
    public function generateReport(array $data): string {
        echo "📊 Génération du rapport\n";
        
        // Étapes du processus
        $this->prepareData($data);
        $header = $this->createHeader();
        $content = $this->createContent($data);
        $footer = $this->createFooter();
        
        $report = $this->assembleReport($header, $content, $footer);
        
        // Hook pour post-traitement
        $finalReport = $this->postProcess($report);
        
        $this->saveReport($finalReport);
        
        echo "✅ Rapport généré avec succès\n";
        return $finalReport;
    }
    
    // Étape avec implémentation par défaut
    protected function prepareData(array &$data): void {
        echo "🔄 Préparation des données\n";
        // Tri par défaut
        sort($data);
    }
    
    // Étape abstraite - doit être implémentée
    abstract protected function createContent(array $data): string;
    
    // Étapes avec implémentation par défaut
    protected function createHeader(): string {
        $date = date('Y-m-d H:i:s');
        return "=== RAPPORT GÉNÉRÉ LE {$date} ===\n\n";
    }
    
    protected function createFooter(): string {
        return "\n=== FIN DU RAPPORT ===\n";
    }
    
    protected function assembleReport(string $header, string $content, string $footer): string {
        return $header . $content . $footer;
    }
    
    // Hook - peut être redéfini
    protected function postProcess(string $report): string {
        return $report;
    }
    
    protected function saveReport(string $report): void {
        $filename = "rapport_" . date('Y-m-d_H-i-s') . ".txt";
        echo "💾 Sauvegarde du rapport: {$filename}\n";
        // file_put_contents($filename, $report);
    }
}

// Générateur de rapport de ventes
class SalesReportGenerator extends ReportGenerator {
    protected function createContent(array $data): string {
        echo "💰 Création du contenu de vente\n";
        
        $content = "RAPPORT DE VENTES\n";
        $content .= str_repeat("-", 50) . "\n\n";
        
        $total = 0;
        foreach ($data as $sale) {
            $content .= sprintf(
                "Produit: %-20s | Quantité: %3d | Prix: %8.2f€\n",
                $sale['product'],
                $sale['quantity'],
                $sale['price']
            );
            $total += $sale['quantity'] * $sale['price'];
        }
        
        $content .= str_repeat("-", 50) . "\n";
        $content .= sprintf("TOTAL: %.2f€\n", $total);
        
        return $content;
    }
    
    protected function prepareData(array &$data): void {
        echo "🔄 Préparation spécifique aux ventes\n";
        // Tri par prix décroissant
        usort($data, function($a, $b) {
            return ($b['price'] * $b['quantity']) <=> ($a['price'] * $a['quantity']);
        });
    }
    
    protected function postProcess(string $report): string {
        echo "📈 Post-traitement : ajout de statistiques\n";
        $stats = "\n--- STATISTIQUES ---\n";
        $stats .= "Rapport généré automatiquement\n";
        $stats .= "Nombre de lignes: " . substr_count($report, "\n") . "\n";
        
        return $report . $stats;
    }
}

abstract class OrderProcessor {
    public function processOrder(array $orderData): bool {
        echo "🛒 Traitement de la commande #{$orderData['id']}\n";
        
        try {
            // Pipeline de traitement
            $this->validateOrder($orderData);
            $this->calculateTotals($orderData);
            $this->processPayment($orderData);
            $this->updateInventory($orderData);
            $this->sendConfirmation($orderData);
            
            // Hook pour traitement spécifique
            $this->onOrderProcessed($orderData);
            
            echo "✅ Commande traitée avec succès\n";
            return true;
            
        } catch (Exception $e) {
            echo "❌ Erreur: " . $e->getMessage() . "\n";
            $this->handleError($orderData, $e);
            return false;
        }
    }
    
    protected function validateOrder(array $orderData): void {
        echo "🔍 Validation de la commande\n";
        if (empty($orderData['items'])) {
            throw new Exception("Commande vide");
        }
    }
    
    protected function calculateTotals(array &$orderData): void {
        echo "🧮 Calcul des totaux\n";
        $total = 0;
        foreach ($orderData['items'] as $item) {
            $total += $item['price'] * $item['quantity'];
        }
        $orderData['total'] = $total;
    }
    
    // Méthode abstraite - traitement spécifique au type de commande
    abstract protected function processPayment(array $orderData): void;
    
    protected function updateInventory(array $orderData): void {
        echo "📦 Mise à jour de l'inventaire\n";
        // Logique de mise à jour
    }
    
    protected function sendConfirmation(array $orderData): void {
        echo "📧 Envoi de confirmation\n";
    }
    
    // Hook pour traitement spécifique
    protected function onOrderProcessed(array $orderData): void {
        // Implémentation par défaut vide
    }
    
    protected function handleError(array $orderData, Exception $e): void {
        echo "🚨 Gestion d'erreur pour commande #{$orderData['id']}\n";
    }
}

import java.util.*;
import java.text.SimpleDateFormat;

// Classe abstraite pour algorithme de tri
abstract class SortAlgorithm {
    // Méthode template
    public final void sort(int[] array) {
        System.out.println("🔄 Début du tri avec " + getAlgorithmName());
        
        long startTime = System.currentTimeMillis();
        
        // Étapes du processus de tri
        preprocessArray(array);
        performSort(array);
        postprocessArray(array);
        
        long endTime = System.currentTimeMillis();
        
        System.out.println("✅ Tri terminé en " + (endTime - startTime) + "ms");
        onSortCompleted(array, endTime - startTime);
    }
    
    // Étape avec implémentation par défaut
    protected void preprocessArray(int[] array) {
        System.out.println("🔍 Préparation du tableau (taille: " + array.length + ")");
        // Validation par défaut
        if (array.length == 0) {
            throw new IllegalArgumentException("Tableau vide");
        }
    }
    
    // Méthode abstraite - algorithme spécifique
    protected abstract void performSort(int[] array);
    
    // Nom de l'algorithme
    protected abstract String getAlgorithmName();
    
    // Étape avec implémentation par défaut
    protected void postprocessArray(int[] array) {
        System.out.println("🔍 Vérification du tri");
        for (int i = 1; i < array.length; i++) {
            if (array[i] < array[i-1]) {
                throw new RuntimeException("Erreur de tri détectée");
            }
        }
    }
    
    // Hook pour actions post-tri
    protected void onSortCompleted(int[] array, long duration) {
        // Implémentation par défaut vide
    }
    
    // Méthode utilitaire
    protected void swap(int[] array, int i, int j) {
        int temp = array[i];
        array[i] = array[j];
        array[j] = temp;
    }
}

// Implémentation Bubble Sort
class BubbleSort extends SortAlgorithm {
    @Override
    protected void performSort(int[] array) {
        System.out.println("🫧 Exécution du tri à bulles");
        
        for (int i = 0; i < array.length - 1; i++) {
            boolean swapped = false;
            for (int j = 0; j < array.length - 1 - i; j++) {
                if (array[j] > array[j + 1]) {
                    swap(array, j, j + 1);
                    swapped = true;
                }
            }
            if (!swapped) break; // Optimisation
        }
    }
    
    @Override
    protected String getAlgorithmName() {
        return "Bubble Sort";
    }
    
    @Override
    protected void onSortCompleted(int[] array, long duration) {
        System.out.println("📊 Bubble Sort - Complexité: O(n²)");
    }
}

// Implémentation Quick Sort
class QuickSort extends SortAlgorithm {
    @Override
    protected void performSort(int[] array) {
        System.out.println("⚡ Exécution du tri rapide");
        quickSortRecursive(array, 0, array.length - 1);
    }
    
    private void quickSortRecursive(int[] array, int low, int high) {
        if (low < high) {
            int pivotIndex = partition(array, low, high);
            quickSortRecursive(array, low, pivotIndex - 1);
            quickSortRecursive(array, pivotIndex + 1, high);
        }
    }
    
    private int partition(int[] array, int low, int high) {
        int pivot = array[high];
        int i = low - 1;
        
        for (int j = low; j < high; j++) {
            if (array[j] <= pivot) {
                i++;
                swap(array, i, j);
            }
        }
        swap(array, i + 1, high);
        return i + 1;
    }
    
    @Override
    protected String getAlgorithmName() {
        return "Quick Sort";
    }
    
    @Override
    protected void preprocessArray(int[] array) {
        super.preprocessArray(array);
        System.out.println("🎯 Optimisation pour Quick Sort");
    }
    
    @Override
    protected void onSortCompleted(int[] array, long duration) {
        System.out.println("📊 Quick Sort - Complexité moyenne: O(n log n)");
    }
}

// Implémentation Selection Sort avec logging
class SelectionSort extends SortAlgorithm {
    private int comparisons = 0;
    
    @Override
    protected void performSort(int[] array) {
        System.out.println("🎯 Exécution du tri par sélection");
        comparisons = 0;
        
        for (int i = 0; i < array.length - 1; i++) {
            int minIndex = i;
            for (int j = i + 1; j < array.length; j++) {
                comparisons++;
                if (array[j] < array[minIndex]) {
                    minIndex = j;
                }
            }
            if (minIndex != i) {
                swap(array, i, minIndex);
            }
        }
    }
    
    @Override
    protected String getAlgorithmName() {
        return "Selection Sort";
    }
    
    @Override
    protected void onSortCompleted(int[] array, long duration) {
        System.out.println("📊 Selection Sort - Comparaisons: " + comparisons);
        System.out.println("📊 Complexité: O(n²)");
    }
}

        System.out.println("=== Démonstration Template Method - Algorithmes de Tri ===\n");
        
        // Données de test
        int[] data1 = {64, 34, 25, 12, 22, 11, 90};
        int[] data2 = Arrays.copyOf(data1, data1.length);
        int[] data3 = Arrays.copyOf(data1, data1.length);
        
        System.out.println("Données initiales: " + Arrays.toString(data1));
        System.out.println();
        
        // Test des différents algorithmes
        SortAlgorithm bubbleSort = new BubbleSort();
        bubbleSort.sort(data1);
        System.out.println("Résultat Bubble: " + Arrays.toString(data1));
        System.out.println();
        
        SortAlgorithm quickSort = new QuickSort();
        quickSort.sort(data2);
        System.out.println("Résultat Quick: " + Arrays.toString(data2));
        System.out.println();
        
        SortAlgorithm selectionSort = new SelectionSort();
        selectionSort.sort(data3);
        System.out.println("Résultat Selection: " + Arrays.toString(data3));
        
        // Test de performance
        System.out.println("\n=== Test de Performance ===");
        performanceTest();
    }
    
    private static void performanceTest() {
        int[] sizes = {100, 1000, 5000};
        SortAlgorithm[] algorithms = {
            new BubbleSort(),
            new QuickSort(),
            new SelectionSort()
        };
        
        for (int size : sizes) {
            System.out.println("\nTaille du tableau: " + size);
            int[] originalData = generateRandomArray(size);
            
            for (SortAlgorithm algorithm : algorithms) {
                int[] testData = Arrays.copyOf(originalData, originalData.length);
                
                long startTime = System.currentTimeMillis();
                algorithm.sort(testData);
                long duration = System.currentTimeMillis() - startTime;
                
                System.out.printf("%-15s: %3dms\n",
                    algorithm.getAlgorithmName(), duration);
            }
        }
    }
    
    private static int[] generateRandomArray(int size) {
        Random random = new Random();
        int[] array = new int[size];
        for (int i = 0; i < size; i++) {
            array[i] = random.nextInt(1000);
        }
        return array;
    }
}

// Exemple avancé : Pipeline de traitement de fichiers
abstract class FileProcessor {
    public final boolean processFile(String filePath) {
        System.out.println("📁 Traitement du fichier: " + filePath);
        
        try {
            // Pipeline de traitement
            validateFile(filePath);
            String content = readFile(filePath);
            String processedContent = processContent(content);
            String outputPath = generateOutputPath(filePath);
            writeFile(outputPath, processedContent);
            
            // Hook pour post-traitement
            onFileProcessed(filePath, outputPath);
            
            System.out.println("✅ Fichier traité avec succès");
            return true;
            
        } catch (Exception e) {
            System.err.println("❌ Erreur: " + e.getMessage());
            handleError(filePath, e);
            return false;
        }
    }
    
    protected void validateFile(String filePath) {
        System.out.println("🔍 Validation du fichier");
        if (filePath == null || filePath.isEmpty()) {
            throw new IllegalArgumentException("Chemin de fichier invalide");
        }
    }
    
    protected String readFile(String filePath) {
        System.out.println("📖 Lecture du fichier");
        // Simulation de lecture
        return "Contenu du fichier: " + filePath;
    }
    
    // Méthode abstraite pour traitement spécifique
    protected abstract String processContent(String content);
    
    protected String generateOutputPath(String inputPath) {
        return "processed_" + inputPath;
    }
    
    protected void writeFile(String outputPath, String content) {
        System.out.println("💾 Écriture vers: " + outputPath);
        // Simulation d'écriture
    }
    
    protected void onFileProcessed(String inputPath, String outputPath) {
        // Hook par défaut vide
    }
    
    protected void handleError(String filePath, Exception e) {
        System.err.println("🚨 Gestion d'erreur pour: " + filePath);
    }
}

// Processeur de logs
class LogProcessor extends FileProcessor {
    @Override
    protected String processContent(String content) {
        System.out.println("📊 Traitement des logs");
        
        // Simulation du traitement des logs
        String[] lines = content.split("\n");
        StringBuilder processed = new StringBuilder();
        
        processed.append("=== LOG TRAITÉ ===\n");
        processed.append("Timestamp: ").append(new Date()).append("\n");
        processed.append("Lignes traitées: ").append(lines.length).append("\n");
        processed.append("Contenu original:\n").append(content);
        
        return processed.toString();
    }
    
    @Override
    protected void onFileProcessed(String inputPath, String outputPath) {
        System.out.println("📈 Log traité - Statistiques générées");
    }
}

// Processeur de configuration
class ConfigProcessor extends FileProcessor {
    @Override
    protected String processContent(String content) {
        System.out.println("⚙️ Traitement de configuration");
        
        // Simulation du traitement de config
        return "# Configuration traitée\n" +
               "processed.timestamp=" + System.currentTimeMillis() + "\n" +
               "original.content=" + content.replace("\n", "\\n");
    }
    
    @Override
    protected void validateFile(String filePath) {
        super.validateFile(filePath);
        if (!filePath.endsWith(".conf") && !filePath.endsWith(".config")) {
            throw new IllegalArgumentException("Format de fichier non supporté");
        }
    }
    
    @Override
    protected String generateOutputPath(String inputPath) {
        return inputPath.replace(".conf", "_processed.conf")
                       .replace(".config", "_processed.config");
    }
}

🧩 Biais Cognitifs Associés

🔄 Biais de Confirmation

Tendance à forcer l'utilisation du Template Method même quand la composition serait plus appropriée, confirmant notre préférence pour l'héritage.

⚓ Biais d'Ancrage

S'ancrer sur la première structure d'algorithme conçue et avoir du mal à la refactorer quand les besoins évoluent.

🎯 Biais de Disponibilité

Utiliser le Template Method parce qu'on se souvient d'un cas où il était parfait, sans évaluer les alternatives modernes.

🏗️ Biais de Planification

Sous-estimer la complexité de maintenir une hiérarchie d'héritage avec de nombreuses sous-classes.

⚠️ Anti-Patterns à Éviter

🏗️ Deep Inheritance Hierarchy

Créer une hiérarchie d'héritage trop profonde avec de nombreux niveaux de Template Methods. Préférer la composition pour plus de flexibilité.

🔒 Rigid Template

Template trop rigide qui ne permet pas assez de personnalisation. Ajouter des hooks et des points d'extension appropriés.

🎭 God Template

Template Method qui gère trop d'étapes différentes. Diviser en plusieurs templates plus spécialisés.

🔄 Circular Dependencies

Sous-classes qui dépendent les unes des autres ou qui modifient l'état de la classe parente de manière imprévisible.
