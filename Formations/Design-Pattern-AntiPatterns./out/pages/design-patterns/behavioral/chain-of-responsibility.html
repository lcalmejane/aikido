⛓️ Chain of Responsibility Pattern

Faire passer une requête le long d'une chaîne de gestionnaires

🎨 Design Patterns
⭐ Difficulté: Moyen
⏱️ 20 min
🎭 Comportemental

🎯 Définition

Le Chain of Responsibility est un pattern comportemental qui permet de faire passer une requête le long d'une chaîne de gestionnaires potentiels jusqu'à ce que l'un d'eux traite la requête.

❌ Problème Résolu

  • Couplage fort entre expéditeur et récepteur
  • Logique de traitement complexe avec multiples conditions
  • Difficulté d'ajouter de nouveaux gestionnaires
  • Code difficile à maintenir avec de nombreux if/else

✅ Solution Apportée

  • Découplage entre expéditeur et récepteurs
  • Chaîne de traitement flexible et extensible
  • Ajout facile de nouveaux gestionnaires
  • Responsabilité unique pour chaque gestionnaire
💡 Analogie : Comme un système de support client où une demande passe du niveau 1 au niveau 2, puis au niveau 3 jusqu'à trouver la personne compétente pour la traiter.

🏗️ Structure UML

Handler
+ nextHandler: Handler
+ setNext(handler: Handler): Handler
+ handle(request: Request): Response
ConcreteHandler1
+ handle(request: Request): Response
ConcreteHandler2
+ handle(request: Request): Response
Client
+ makeRequest(): void

Éléments Clés

  • Handler : Interface ou classe abstraite définissant la méthode de traitement
  • ConcreteHandler : Implémentations concrètes qui traitent les requêtes
  • Client : Envoie les requêtes au premier maillon de la chaîne

🔄 Flux d'Exécution

💡 Point clé : Chaque gestionnaire décide s'il peut traiter la requête ou s'il doit la passer au suivant.

💻 Implémentations

Exemple : Système de Support Client


// Types pour les requêtes
enum RequestType {
    BASIC = 'BASIC',
    TECHNICAL = 'TECHNICAL',
    BILLING = 'BILLING',
    ESCALATION = 'ESCALATION'
}

interface SupportRequest {
    id: string;
    type: RequestType;
    description: string;
    priority: number;
    customerLevel: 'BRONZE' | 'SILVER' | 'GOLD' | 'PLATINUM';
}

interface SupportResponse {
    handled: boolean;
    handlerName: string;
    response: string;
    escalated?: boolean;
}

// Handler abstrait
abstract class SupportHandler {
    protected nextHandler: SupportHandler | null = null;
    
    setNext(handler: SupportHandler): SupportHandler {
        this.nextHandler = handler;
        return handler;
    }
    
    handle(request: SupportRequest): SupportResponse {
        if (this.canHandle(request)) {
            return this.processRequest(request);
        }
        
        if (this.nextHandler) {
            console.log(`${this.getHandlerName()} passe la requête au niveau suivant`);
            return this.nextHandler.handle(request);
        }
        
        return {
            handled: false,
            handlerName: 'Aucun',
            response: 'Aucun gestionnaire disponible pour traiter cette requête'
        };
    }
    
    protected abstract canHandle(request: SupportRequest): boolean;
    protected abstract processRequest(request: SupportRequest): SupportResponse;
    protected abstract getHandlerName(): string;
}

// Handler Niveau 1 - Support de base
class Level1Support extends SupportHandler {
    protected canHandle(request: SupportRequest): boolean {
        return request.type === RequestType.BASIC && request.priority <= 2;
    }
    
    protected processRequest(request: SupportRequest): SupportResponse {
        console.log(`Niveau 1 traite la requête ${request.id}`);
        return {
            handled: true,
            handlerName: 'Support Niveau 1',
            response: `Problème résolu par consultation de la FAQ. Requête: ${request.description}`
        };
    }
    
    protected getHandlerName(): string {
        return 'Support Niveau 1';
    }
}

// Handler Niveau 2 - Support technique
class Level2Support extends SupportHandler {
    protected canHandle(request: SupportRequest): boolean {
        return (request.type === RequestType.TECHNICAL || request.type === RequestType.BASIC) 
               && request.priority <= 4;
    }
    
    protected processRequest(request: SupportRequest): SupportResponse {
        console.log(`Niveau 2 traite la requête ${request.id}`);
        return {
            handled: true,
            handlerName: 'Support Technique Niveau 2',
            response: `Problème technique résolu par diagnostic approfondi. Solution personnalisée fournie.`
        };
    }
    
    protected getHandlerName(): string {
        return 'Support Technique Niveau 2';
    }
}

// Handler Niveau 3 - Support facturation
class BillingSupport extends SupportHandler {
    protected canHandle(request: SupportRequest): boolean {
        return request.type === RequestType.BILLING;
    }
    
    protected processRequest(request: SupportRequest): SupportResponse {
        console.log(`Support Facturation traite la requête ${request.id}`);
        return {
            handled: true,
            handlerName: 'Support Facturation',
            response: `Problème de facturation résolu. Ajustement effectué sur le compte.`
        };
    }
    
    protected getHandlerName(): string {
        return 'Support Facturation';
    }
}

// Handler Niveau 4 - Manager/Escalation
class ManagerSupport extends SupportHandler {
    protected canHandle(request: SupportRequest): boolean {
        return request.priority >= 5 || 
               request.type === RequestType.ESCALATION ||
               request.customerLevel === 'PLATINUM';
    }
    
    protected processRequest(request: SupportRequest): SupportResponse {
        console.log(`Manager traite la requête ${request.id} (escalation)`);
        return {
            handled: true,
            handlerName: 'Manager Support',
            response: `Requête traitée personnellement par le manager. Solution prioritaire mise en place.`,
            escalated: true
        };
    }
    
    protected getHandlerName(): string {
        return 'Manager Support';
    }
}

// Client - Système de tickets
class SupportTicketSystem {
    private handlerChain: SupportHandler;
    
    constructor() {
        // Construction de la chaîne
        const level1 = new Level1Support();
        const level2 = new Level2Support();
        const billing = new BillingSupport();
        const manager = new ManagerSupport();
        
        // Chaînage des handlers
        level1.setNext(level2).setNext(billing).setNext(manager);
        
        this.handlerChain = level1;
    }
    
    processTicket(request: SupportRequest): SupportResponse {
        console.log(`\n=== Traitement du ticket ${request.id} ===`);
        console.log(`Type: ${request.type}, Priorité: ${request.priority}, Client: ${request.customerLevel}`);
        console.log(`Description: ${request.description}`);
        
        const response = this.handlerChain.handle(request);
        
        console.log(`\n--- Résultat ---`);
        console.log(`Traité par: ${response.handlerName}`);
        console.log(`Réponse: ${response.response}`);
        if (response.escalated) {
            console.log(`⚠️ Requête escaladée`);
        }
        
        return response;
    }
}

<?php

// Énumération des types de dépenses
class ExpenseType {
    const MEAL = 'MEAL';
    const TRANSPORT = 'TRANSPORT';
    const ACCOMMODATION = 'ACCOMMODATION';
    const EQUIPMENT = 'EQUIPMENT';
    const TRAINING = 'TRAINING';
}

// Classe pour les demandes de remboursement
class ExpenseRequest {
    public $id;
    public $type;
    public $amount;
    public $description;
    public $employeeLevel;
    public $receipts;
    
    public function __construct($id, $type, $amount, $description, $employeeLevel, $receipts = true) {
        $this->id = $id;
        $this->type = $type;
        $this->amount = $amount;
        $this->description = $description;
        $this->employeeLevel = $employeeLevel;
        $this->receipts = $receipts;
    }
}

// Classe pour les réponses d'approbation
class ApprovalResponse {
    public $approved;
    public $approverName;
    public $comments;
    public $conditions;
    
    public function __construct($approved, $approverName, $comments, $conditions = null) {
        $this->approved = $approved;
        $this->approverName = $approverName;
        $this->comments = $comments;
        $this->conditions = $conditions;
    }
}

// Handler abstrait pour l'approbation
abstract class ApprovalHandler {
    protected $nextHandler = null;
    
    public function setNext(ApprovalHandler $handler): ApprovalHandler {
        $this->nextHandler = $handler;
        return $handler;
    }
    
    public function handle(ExpenseRequest $request): ApprovalResponse {
        if ($this->canApprove($request)) {
            return $this->processApproval($request);
        }
        
        if ($this->nextHandler !== null) {
            echo $this->getApproverName() . " transfère la demande au niveau supérieur\n";
            return $this->nextHandler->handle($request);
        }
        
        return new ApprovalResponse(
            false,
            'Aucun approbateur',
            'Aucun approbateur disponible pour cette demande'
        );
    }
    
    protected abstract function canApprove(ExpenseRequest $request): bool;
    protected abstract function processApproval(ExpenseRequest $request): ApprovalResponse;
    protected abstract function getApproverName(): string;
}

// Superviseur - Petites dépenses
class SupervisorApprover extends ApprovalHandler {
    protected function canApprove(ExpenseRequest $request): bool {
        return $request->amount <= 100 && 
               in_array($request->type, [ExpenseType::MEAL, ExpenseType::TRANSPORT]) &&
               $request->receipts;
    }
    
    protected function processApproval(ExpenseRequest $request): ApprovalResponse {
        echo "Superviseur approuve la demande {$request->id}\n";
        return new ApprovalResponse(
            true,
            'Superviseur',
            'Dépense courante approuvée automatiquement'
        );
    }
    
    protected function getApproverName(): string {
        return 'Superviseur';
    }
}

// Manager - Dépenses moyennes
class ManagerApprover extends ApprovalHandler {
    protected function canApprove(ExpenseRequest $request): bool {
        return $request->amount <= 500 && $request->receipts;
    }
    
    protected function processApproval(ExpenseRequest $request): ApprovalResponse {
        echo "Manager approuve la demande {$request->id}\n";
        
        $conditions = null;
        if ($request->amount > 200) {
            $conditions = 'Justification détaillée requise pour les futures dépenses similaires';
        }
        
        return new ApprovalResponse(
            true,
            'Manager',
            'Dépense approuvée après vérification des justificatifs',
            $conditions
        );
    }
    
    protected function getApproverName(): string {
        return 'Manager';
    }
}

// Directeur - Grosses dépenses
class DirectorApprover extends ApprovalHandler {
    protected function canApprove(ExpenseRequest $request): bool {
        return $request->amount <= 2000 && 
               $request->receipts &&
               in_array($request->employeeLevel, ['SENIOR', 'LEAD', 'MANAGER']);
    }
    
    protected function processApproval(ExpenseRequest $request): ApprovalResponse {
        echo "Directeur approuve la demande {$request->id}\n";
        
        $conditions = 'Approbation conditionnelle - Suivi budgétaire renforcé';
        if ($request->type === ExpenseType::TRAINING) {
            $conditions .= ' - Rapport de formation obligatoire';
        }
        
        return new ApprovalResponse(
            true,
            'Directeur',
            'Dépense exceptionnelle approuvée',
            $conditions
        );
    }
    
    protected function getApproverName(): string {
        return 'Directeur';
    }
}

// PDG - Dépenses exceptionnelles
class CEOApprover extends ApprovalHandler {
    protected function canApprove(ExpenseRequest $request): bool {
        return $request->amount <= 10000; // Limite absolue
    }
    
    protected function processApproval(ExpenseRequest $request): ApprovalResponse {
        echo "PDG approuve personnellement la demande {$request->id}\n";
        
        return new ApprovalResponse(
            true,
            'PDG',
            'Dépense stratégique approuvée au plus haut niveau',
            'Suivi mensuel obligatoire et justification trimestrielle'
        );
    }
    
    protected function getApproverName(): string {
        return 'PDG';
    }
}

// Système de gestion des dépenses
class ExpenseApprovalSystem {
    private $approvalChain;
    
    public function __construct() {
        // Construction de la chaîne d'approbation
        $supervisor = new SupervisorApprover();
        $manager = new ManagerApprover();
        $director = new DirectorApprover();
        $ceo = new CEOApprover();
        
        // Chaînage des approbateurs
        $supervisor->setNext($manager)->setNext($director)->setNext($ceo);
        
        $this->approvalChain = $supervisor;
    }
    
    public function processExpenseRequest(ExpenseRequest $request): ApprovalResponse {
        echo "\n=== Traitement de la demande {$request->id} ===\n";
        echo "Type: {$request->type}, Montant: {$request->amount}€\n";
        echo "Employé: {$request->employeeLevel}, Justificatifs: " . ($request->receipts ? 'Oui' : 'Non') . "\n";
        echo "Description: {$request->description}\n";
        
        $response = $this->approvalChain->handle($request);
        
        echo "\n--- Résultat ---\n";
        echo "Statut: " . ($response->approved ? 'APPROUVÉ' : 'REJETÉ') . "\n";
        echo "Approbateur: {$response->approverName}\n";
        echo "Commentaires: {$response->comments}\n";
        if ($response->conditions) {
            echo "Conditions: {$response->conditions}\n";
        }
        
        return $response;
    }
}

import java.util.*;

// Énumération des types de logs
enum LogLevel {
    DEBUG(1), INFO(2), WARNING(3), ERROR(4), CRITICAL(5);
    
    private final int priority;
    
    LogLevel(int priority) {
        this.priority = priority;
    }
    
    public int getPriority() {
        return priority;
    }
}

// Classe pour les messages de log
class LogMessage {
    private String id;
    private LogLevel level;
    private String message;
    private String source;
    private Date timestamp;
    private Map<String, Object> metadata;
    
    public LogMessage(String id, LogLevel level, String message, String source) {
        this.id = id;
        this.level = level;
        this.message = message;
        this.source = source;
        this.timestamp = new Date();
        this.metadata = new HashMap<>();
    }
    
    // Getters
    public String getId() { return id; }
    public LogLevel getLevel() { return level; }
    public String getMessage() { return message; }
    public String getSource() { return source; }
    public Date getTimestamp() { return timestamp; }
    public Map<String, Object> getMetadata() { return metadata; }
    
    public void addMetadata(String key, Object value) {
        metadata.put(key, value);
    }
}

// Classe pour les réponses de traitement
class LogResponse {
    private boolean handled;
    private String handlerName;
    private String action;
    private List<String> destinations;
    
    public LogResponse(boolean handled, String handlerName, String action) {
        this.handled = handled;
        this.handlerName = handlerName;
        this.action = action;
        this.destinations = new ArrayList<>();
    }
    
    public void addDestination(String destination) {
        destinations.add(destination);
    }
    
    // Getters
    public boolean isHandled() { return handled; }
    public String getHandlerName() { return handlerName; }
    public String getAction() { return action; }
    public List<String> getDestinations() { return destinations; }
}

// Handler abstrait pour les logs
abstract class LogHandler {
    protected LogHandler nextHandler;
    
    public LogHandler setNext(LogHandler handler) {
        this.nextHandler = handler;
        return handler;
    }
    
    public LogResponse handle(LogMessage message) {
        if (canHandle(message)) {
            return processLog(message);
        }
        
        if (nextHandler != null) {
            System.out.println(getHandlerName() + " passe le message au handler suivant");
            return nextHandler.handle(message);
        }
        
        return new LogResponse(false, "Aucun handler", "Message ignoré");
    }
    
    protected abstract boolean canHandle(LogMessage message);
    protected abstract LogResponse processLog(LogMessage message);
    protected abstract String getHandlerName();
}

// Handler pour les logs de debug
class DebugLogHandler extends LogHandler {
    @Override
    protected boolean canHandle(LogMessage message) {
        return message.getLevel() == LogLevel.DEBUG;
    }
    
    @Override
    protected LogResponse processLog(LogMessage message) {
        System.out.println("Debug Handler traite: " + message.getId());
        
        LogResponse response = new LogResponse(true, "Debug Handler", "Écrit dans fichier debug");
        
        return response;
    }
    
    @Override
    protected String getHandlerName() {
        return "Debug Handler";
    }
}

// Handler pour les logs d'information
class InfoLogHandler extends LogHandler {
    @Override
    protected boolean canHandle(LogMessage message) {
        return message.getLevel() == LogLevel.INFO;
    }
    
    @Override
    protected LogResponse processLog(LogMessage message) {
        System.out.println("Info Handler traite: " + message.getId());
        
        LogResponse response = new LogResponse(true, "Info Handler", "Écrit dans fichier principal");
        response.addDestination("application.log");
        
        // Simulation d'écriture dans fichier principal
        System.out.println("[INFO] " + message.getTimestamp() + " - " + 
                          message.getSource() + ": " + message.getMessage());
        
        return response;
    }
    
    @Override
    protected String getHandlerName() {
        return "Info Handler";
    }
}

// Handler pour les erreurs critiques
class CriticalLogHandler extends LogHandler {
    @Override
    protected boolean canHandle(LogMessage message) {
        return message.getLevel() == LogLevel.CRITICAL;
    }
    
    @Override
    protected LogResponse processLog(LogMessage message) {
        System.out.println("Critical Handler traite: " + message.getId());
        
        LogResponse response = new LogResponse(true, "Critical Handler", "Action d'urgence déclenchée");
        response.addDestination("critical.log");
        response.addDestination("application.log");
        response.addDestination("alerts.log");
        response.addDestination("emergency_contacts.log");
        
        // Simulation d'actions d'urgence
        System.out.println("[CRITICAL] " + message.getTimestamp() + " - " + 
                          message.getSource() + ": " + message.getMessage());
        System.out.println("🚨🚨 ALERTE CRITIQUE - Notification immédiate du responsable technique");
        System.out.println("📞 Appel automatique des contacts d'urgence");
        
        return response;
    }
    
    @Override
    protected String getHandlerName() {
        return "Critical Handler";
    }
}

// Système de logging
class LoggingSystem {
    private LogHandler logChain;
    
    public LoggingSystem() {
        // Construction de la chaîne de handlers
        LogHandler debugHandler = new DebugLogHandler();
        LogHandler infoHandler = new InfoLogHandler();
        LogHandler warningHandler = new WarningLogHandler();
        LogHandler errorHandler = new ErrorLogHandler();
        LogHandler criticalHandler = new CriticalLogHandler();
        
        // Chaînage des handlers (ordre important)
        debugHandler.setNext(infoHandler)
                   .setNext(warningHandler)
                   .setNext(errorHandler)
                   .setNext(criticalHandler);
        
        this.logChain = debugHandler;
    }
    
    public LogResponse log(LogMessage message) {
        System.out.println("\n=== Traitement du log " + message.getId() + " ===");
        System.out.println("Niveau: " + message.getLevel() + " (" + message.getLevel().getPriority() + ")");
        System.out.println("Source: " + message.getSource());
        System.out.println("Message: " + message.getMessage());
        
        LogResponse response = logChain.handle(message);
        
        System.out.println("\n--- Résultat ---");
        System.out.println("Traité par: " + response.getHandlerName());
        System.out.println("Action: " + response.getAction());
        if (!response.getDestinations().isEmpty()) {
            System.out.println("Destinations: " + String.join(", ", response.getDestinations()));
        }
        
        return response;
    }
}

// Utilisation
public class ChainOfResponsibilityDemo {
    public static void main(String[] args) {
        LoggingSystem logger = new LoggingSystem();
        
        // Test avec différents niveaux de logs
        LogMessage[] messages = {
            new LogMessage("L001", LogLevel.DEBUG, "Variable x = 42", "UserService"),

        // Traitement des messages
        for (LogMessage message : messages) {
            logger.log(message);
        }
        
        System.out.println("\nDémonstration terminée !");
    }
}

🎯 Cas d'Usage Pratiques

🎧

Support Client

Système de tickets avec escalade automatique du niveau 1 au management selon la complexité.

Exemple : Zendesk, ServiceNow, Freshdesk
💰

Approbation de Dépenses

Workflow d'approbation avec différents niveaux selon le montant et le type de dépense.

Exemple : Systèmes ERP, applications de notes de frais
📝

Systèmes de Logging

Traitement différencié des logs selon leur niveau de criticité (debug, info, warning, error).

Exemple : Log4j, Winston, Serilog
🔒

Authentification

Chaîne de méthodes d'authentification (token, session, basic auth, OAuth).

Exemple : Middleware d'authentification, systèmes SSO
🌐

Middleware HTTP

Pipeline de traitement des requêtes HTTP avec différents middlewares.

Exemple : Express.js, ASP.NET Core, Laravel
⚡

Gestion d'Événements

Propagation d'événements dans une interface utilisateur (event bubbling).

Exemple : DOM Events, systèmes d'événements GUI
🎯 Conseil : Utilisez Chain of Responsibility quand vous avez plusieurs objets qui peuvent traiter une requête, mais vous ne savez pas à l'avance lequel sera capable de la traiter.

🧠 Biais Cognitifs Associés

Le pattern Chain of Responsibility peut être influencé par plusieurs biais cognitifs lors de sa conception :

📊 Biais de Hiérarchie

Tendance à reproduire automatiquement les hiérarchies organisationnelles dans le code sans considérer si c'est la meilleure approche technique.

🔄 Biais de Séquentialité

Supposer que l'ordre de traitement doit toujours être linéaire et fixe, sans considérer des approches plus flexibles ou parallèles.

⚡ Biais de Performance

Sous-estimer l'impact performance d'une longue chaîne de handlers, surtout quand la plupart des requêtes sont traitées en fin de chaîne.

🎯 Biais de Responsabilité Unique

Créer trop de handlers avec des responsabilités très spécifiques, menant à une sur-ingénierie et une complexité excessive.

⚠️ Anti-Patterns à Éviter

🔗 Chaîne Infinie (Infinite Chain)

Problème : Créer une chaîne circulaire ou sans fin qui peut causer des boucles infinies.

Solution : Toujours avoir un handler final qui traite ou rejette définitivement la requête.

🐌 Chaîne Trop Longue (Overly Long Chain)

Problème : Créer une chaîne avec trop de handlers, impactant les performances et la lisibilité.

Solution : Regrouper les handlers similaires ou utiliser des stratégies de routage plus efficaces.

🔀 Handler Gourmand (Greedy Handler)

Problème : Un handler qui traite toutes les requêtes sans laisser la chance aux suivants.

Solution : Définir clairement les critères de traitement et respecter le principe de responsabilité unique.

🔧 Chaîne Rigide (Rigid Chain)

Problème : Chaîne difficile à modifier ou à étendre, avec des dépendances hardcodées.

Solution : Utiliser la configuration ou l'injection de dépendances pour construire la chaîne dynamiquement.

🎯 Exercice Pratique

Vous développez un système de validation de formulaires. Comment organiseriez-vous la chaîne de validation ?

📋 Validation Séquentielle

Chaque validator traite tous les champs puis passe au suivant

🎯 Validation par Champ

Une chaîne différente pour chaque champ du formulaire

⚡ Validation par Priorité

Validators ordonnés par criticité (requis → format → business rules)

🔄 Validation Parallèle

Tous les validators s'exécutent en parallèle puis agrègent les résultats

⚠️ Attention ! Cette approche peut être inefficace car chaque validator doit traiter tous les champs, même ceux qui ne le concernent pas.

Risque : Performance dégradée et logique de validation complexe.
🤔 Intéressant ! Cette approche est très modulaire mais peut créer beaucoup de chaînes à gérer et maintenir.

Conseil : Bon pour des formulaires complexes avec des règles très spécifiques par champ.
✅ Excellent choix ! L'organisation par priorité permet d'arrêter la validation dès qu'une règle critique échoue.

Avantages : Performance optimale, feedback utilisateur rapide, logique claire et maintenable.
❌ Attention ! Cette approche ne correspond pas au pattern Chain of Responsibility qui est séquentiel par nature.

Alternative : Considérez plutôt le pattern Strategy ou Composite pour une validation parallèle.
