🏛️ Facade Pattern

Simplifier l'interface d'un sous-système complexe

🎨 Design Patterns
⭐ Difficulté: Facile
⏱️ 20 min
🏗️ Structurel

🎯 Définition

Le Facade est un pattern structurel qui fournit une interface simplifiée et unifiée à un ensemble d'interfaces dans un sous-système complexe.

❌ Problème Résolu

  • Sous-système avec de nombreuses classes interdépendantes
  • Interface complexe difficile à utiliser
  • Couplage fort entre client et sous-système
  • Code client verbeux et répétitif

✅ Solution Apportée

  • Interface simplifiée et unifiée
  • Encapsulation de la complexité
  • Découplage client/sous-système
  • Point d'entrée unique et cohérent
💡 Principe clé : Facade ne cache pas le sous-système, il le simplifie. Les clients peuvent toujours accéder directement aux classes du sous-système si nécessaire.

🏗️ Structure UML

Client
+ operation(): void
Facade
- subsystem1: SubSystem1
- subsystem2: SubSystem2
- subsystem3: SubSystem3
+ simpleOperation(): void
+ complexOperation(): void
SubSystem1
+ operationA(): void
+ operationB(): void

Éléments Clés

  • Client : Utilise la façade au lieu d'interagir directement avec le sous-système
  • Facade : Fournit une interface simple pour les opérations complexes du sous-système
  • SubSystems : Classes du sous-système qui implémentent la fonctionnalité
  • Relations : La façade délègue les requêtes aux objets appropriés du sous-système

💡 Point clé : La façade orchestre les appels aux sous-systèmes, simplifiant l'interaction pour le client qui n'a qu'une seule méthode à appeler.

// Façade pour simplifier l'utilisation
class SmartHomeFacade {
    private lighting: LightingSystem;
    private security: SecuritySystem;
    private climate: ClimateSystem;
    private entertainment: EntertainmentSystem;
    
    constructor() {
        this.lighting = new LightingSystem();
        this.security = new SecuritySystem();
        this.climate = new ClimateSystem();
        this.entertainment = new EntertainmentSystem();
    }
    
    // Scénario : Arrivée à la maison
    arriveHome(): void {
        console.log("🏠 Scénario : Arrivée à la maison");
        this.security.disarmAlarm();
        this.security.unlockDoors();
        this.lighting.turnOnLights(['entrée', 'salon', 'cuisine']);
        this.climate.setTemperature(22);
        this.entertainment.turnOnTV();
    }
    
    // Scénario : Départ de la maison
    leaveHome(): void {
        console.log("🚪 Scénario : Départ de la maison");
        this.lighting.turnOffLights(['toutes']);
        this.entertainment.turnOffTV();
        this.entertainment.stopMusic();
        this.climate.turnOff();
        this.security.lockDoors();
        this.security.armAlarm();
    }
    
    // Scénario : Mode soirée
    eveningMode(): void {
        console.log("🌙 Scénario : Mode soirée");
        this.lighting.setAmbiance('tamisé');
        this.climate.setTemperature(20);
        this.entertainment.playMusic('détente');
    }
    
    // Scénario : Mode nuit
    nightMode(): void {
        console.log("😴 Scénario : Mode nuit");
        this.lighting.turnOffLights(['salon', 'cuisine']);
        this.lighting.turnOnLights(['couloir']);
        this.entertainment.turnOffTV();
        this.entertainment.stopMusic();
        this.climate.setMode('nuit');
        this.security.armAlarm();
    }
    
    // Accès direct aux sous-systèmes si nécessaire
    getLightingSystem(): LightingSystem {
        return this.lighting;
    }
    
    getSecuritySystem(): SecuritySystem {
        return this.security;
    }
}

// Sous-système de base de données
class DatabaseService {
    private $connection;
    
    public function __construct() {
        $this->connection = new PDO('mysql:host=localhost;dbname=app', 'user', 'pass');
    }
    
    public function query(string $sql, array $params = []): array {
        $stmt = $this->connection->prepare($sql);
        $stmt->execute($params);
        return $stmt->fetchAll(PDO::FETCH_ASSOC);
    }
    
    public function insert(string $table, array $data): int {
        $columns = implode(',', array_keys($data));
        $placeholders = ':' . implode(', :', array_keys($data));
        $sql = "INSERT INTO {$table} ({$columns}) VALUES ({$placeholders})";
        
        $stmt = $this->connection->prepare($sql);
        $stmt->execute($data);
        return $this->connection->lastInsertId();
    }
}

// Sous-système de validation
class ValidationService {
    public function validateEmail(string $email): bool {
        return filter_var($email, FILTER_VALIDATE_EMAIL) !== false;
    }
    
    public function validatePassword(string $password): array {
        $errors = [];
        if (strlen($password) < 8) {
            $errors[] = 'Le mot de passe doit contenir au moins 8 caractères';
        }
        if (!preg_match('/[A-Z]/', $password)) {
            $errors[] = 'Le mot de passe doit contenir au moins une majuscule';
        }
        if (!preg_match('/[0-9]/', $password)) {
            $errors[] = 'Le mot de passe doit contenir au moins un chiffre';
        }
        return $errors;
    }
}

class SecurityService {
    public function hashPassword(string $password): string {
        return password_hash($password, PASSWORD_BCRYPT);
    }
    
    public function generateToken(): string {
        return bin2hex(random_bytes(32));

    }
}

// Façade pour l'inscription d'utilisateur
class UserRegistrationFacade {
    private DatabaseService $database;
    private ValidationService $validator;
    private NotificationService $notifier;
    private SecurityService $security;
    
    public function __construct() {
        $this->database = new DatabaseService();
        $this->validator = new ValidationService();
        $this->notifier = new NotificationService();
        $this->security = new SecurityService();
    }
    
    public function registerUser(array $userData): array {
        try {
            // Validation des données
            if (!$this->validator->validateEmail($userData['email'])) {
                throw new Exception('Email invalide');
            }
            
            $passwordErrors = $this->validator->validatePassword($userData['password']);
            if (!empty($passwordErrors)) {
                throw new Exception('Mot de passe invalide: ' . implode(', ', $passwordErrors));
            }
            
            // Vérifier si l'utilisateur existe déjà
            $existingUser = $this->database->query(
                'SELECT id FROM users WHERE email = ?', 
                [$userData['email']]
            );
            
            if (!empty($existingUser)) {
                throw new Exception('Un utilisateur avec cet email existe déjà');
            }
            
            // Créer l'utilisateur
            $hashedPassword = $this->security->hashPassword($userData['password']);
            $token = $this->security->generateToken();
            
            $userId = $this->database->insert('users', [
                'name' => $userData['name'],
                'email' => $userData['email'],
                'password' => $hashedPassword,
                'verification_token' => $token,
                'created_at' => date('Y-m-d H:i:s')
            ]);
            
            // Envoyer les notifications
            $this->notifier->sendEmail(
                $userData['email'],
                'Bienvenue !',
                "Bonjour {$userData['name']}, votre compte a été créé avec succès."
            );
            
            // Log de sécurité
            $this->security->logSecurityEvent('USER_REGISTERED', (string)$userId);
            
            return [
                'success' => true,
                'user_id' => $userId,
                'message' => 'Utilisateur créé avec succès'
            ];
            
        } catch (Exception $e) {
            return [
                'success' => false,
                'error' => $e->getMessage()
            ];
        }
    }
    
    public function verifyUser(string $email, string $token): bool {
        $user = $this->database->query(
            'SELECT id FROM users WHERE email = ? AND verification_token = ?',
            [$email, $token]
        );
        
        if (empty($user)) {
            return false;
        }
        
        $this->database->query(
            'UPDATE users SET verified = 1, verification_token = NULL WHERE email = ?',
            [$email]
        );
        
        $this->security->logSecurityEvent('USER_VERIFIED', (string)$user[0]['id']);
        
        return true;
    }
}

// Sous-système d'inventaire
class InventoryService {
    private Map<String, Integer> stock = new HashMap<>();
    
    public InventoryService() {
        // Initialisation du stock
        stock.put("PROD001", 100);
        stock.put("PROD002", 50);
        stock.put("PROD003", 25);
    }
    
    public boolean checkAvailability(String productId, int quantity) {
        Integer available = stock.get(productId);
        return available != null && available >= quantity;
    }
    
    public void reserveItems(List<OrderItem> items) throws InsufficientStockException {
        for (OrderItem item : items) {
            if (!checkAvailability(item.getProductId(), item.getQuantity())) {
                throw new InsufficientStockException("Stock insuffisant pour " + item.getProductId());
            }
        }
        
        // Réserver les articles
        for (OrderItem item : items) {
            int currentStock = stock.get(item.getProductId());
            stock.put(item.getProductId(), currentStock - item.getQuantity());
            System.out.println("Réservé " + item.getQuantity() + " unités de " + item.getProductId());
        }
    }
    
    public void releaseReservation(List<OrderItem> items) {
        for (OrderItem item : items) {
            int currentStock = stock.getOrDefault(item.getProductId(), 0);
            stock.put(item.getProductId(), currentStock + item.getQuantity());
            System.out.println("Libéré " + item.getQuantity() + " unités de " + item.getProductId());
        }
    }
}

class ShippingService {
    public ShippingInfo scheduleDelivery(String customerId, Address address, List<OrderItem> items) {
        System.out.println("Planification de la livraison pour le client " + customerId);
        
        // Calcul du délai de livraison basé sur l'adresse
        int deliveryDays = calculateDeliveryTime(address);
        Date estimatedDelivery = new Date(System.currentTimeMillis() + deliveryDays * 24 * 60 * 60 * 1000L);
        
        String trackingNumber = "TRACK" + System.currentTimeMillis();
        
        return new ShippingInfo(trackingNumber, estimatedDelivery, deliveryDays);
    }
    
    private int calculateDeliveryTime(Address address) {
        // Simulation du calcul du délai
        return address.getCity().equals("Paris") ? 1 : 3;
    }
}

// Façade pour le processus de commande e-commerce
public class ECommerceFacade {
    private OrderService orderService;
    private InventoryService inventoryService;
    private PaymentService paymentService;
    private ShippingService shippingService;
    private NotificationService notificationService;
    
    public ECommerceFacade() {
        this.orderService = new OrderService();
        this.inventoryService = new InventoryService();
        this.paymentService = new PaymentService();
        this.shippingService = new ShippingService();
        this.notificationService = new NotificationService();
    }
    
    public OrderResult placeOrder(String customerId, List<OrderItem> items, 
                                  PaymentMethod paymentMethod, Address shippingAddress) {
        try {
            System.out.println("=== Début du processus de commande ===");
            
            // 1. Vérifier la disponibilité des articles
            inventoryService.reserveItems(items);
            
            // 2. Créer la commande
            Order order = orderService.createOrder(customerId, items);
            
            try {
                // 3. Traiter le paiement
                PaymentResult paymentResult = paymentService.processPayment(
                    customerId, order.getTotal(), paymentMethod
                );
                
                if (!paymentResult.isSuccess()) {
                    // Libérer la réservation en cas d'échec de paiement
                    inventoryService.releaseReservation(items);
                    notificationService.sendPaymentFailureNotification(customerId, paymentResult.getMessage());
                    return new OrderResult(false, null, "Échec du paiement: " + paymentResult.getMessage());
                }
                
                // 4. Planifier la livraison
                ShippingInfo shippingInfo = shippingService.scheduleDelivery(customerId, shippingAddress, items);
                
                // 5. Mettre à jour le statut de la commande
                orderService.updateOrderStatus(order.getId(), OrderStatus.CONFIRMED);
                
                // 6. Envoyer les notifications
                notificationService.sendOrderConfirmation(customerId, order);
                notificationService.sendShippingNotification(customerId, shippingInfo);
                
                System.out.println("=== Commande traitée avec succès ===");
                return new OrderResult(true, order, "Commande passée avec succès");
                
            } catch (Exception e) {
                // En cas d'erreur après le paiement, rembourser
                if (paymentResult != null && paymentResult.isSuccess()) {
                    paymentService.refundPayment(paymentResult.getTransactionId(), order.getTotal());
                }
                inventoryService.releaseReservation(items);
                throw e;
            }
            
        } catch (InsufficientStockException e) {
            return new OrderResult(false, null, "Stock insuffisant: " + e.getMessage());
        } catch (Exception e) {
            return new OrderResult(false, null, "Erreur lors du traitement: " + e.getMessage());
        }
    }
    
    // Méthode simplifiée pour les commandes express
    public OrderResult placeExpressOrder(String customerId, String productId, int quantity, 
                                        PaymentMethod paymentMethod, Address shippingAddress) {
        List<OrderItem> items = Arrays.asList(new OrderItem(productId, quantity, 29.99));
        return placeOrder(customerId, items, paymentMethod, shippingAddress);
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Interface simplifiée : Une seule méthode au lieu de multiples appels
  • Découplage : Réduit les dépendances entre client et sous-système
  • Facilite la maintenance : Changements isolés dans la façade
  • Réutilisabilité : Logique d'orchestration centralisée
  • Lisibilité : Code client plus clair et expressif

❌ Inconvénients

  • Point de défaillance : Façade devient critique
  • Risque de God Object : Façade trop large
  • Limitation d'accès : Peut masquer des fonctionnalités utiles
  • Couche supplémentaire : Complexité et latence ajoutées
  • Évolutivité : Difficile à étendre si mal conçue

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Sous-système complexe : Nombreuses classes interdépendantes
  • API simplifiée : Besoin d'interface unifiée
  • Découplage : Réduire les dépendances client
  • Orchestration : Coordonner plusieurs services
  • Migration : Transition vers nouvelle architecture

❌ Quand l'éviter

  • Système simple : Sous-système déjà facile à utiliser
  • Contrôle fin : Besoin d'accès granulaire
  • Performance critique : Latence inacceptable
  • Évolution rapide : Sous-système change fréquemment
  • Responsabilité unique : Une seule classe suffit

🧩 Biais Cognitifs Associés

🎯 Biais de Simplicité

Manifestation : "Cette façade rend tout plus simple, utilisons-la partout."

Risque : Sur-simplification qui masque des fonctionnalités importantes.

🔨 Marteau de Maslow

Manifestation : "J'ai appris Facade, je vais l'appliquer à tous mes problèmes."

Risque : Utilisation inappropriée même pour des systèmes simples.

📦 Biais d'Abstraction

Manifestation : Croire qu'ajouter des couches améliore toujours l'architecture.

Risque : Complexité inutile et performance dégradée.

⚠️ Anti-Patterns à Éviter

🏛️ God Facade

Une façade qui devient trop large et gère trop de responsabilités.

// ❌ Mauvais : Façade qui fait tout class SystemFacade { manageUsers() { /* ... */ } processPayments() { /* ... */ } generateReports() { /* ... */ } // ... 50 autres méthodes }

🔄 Leaky Facade

Façade qui expose les détails internes du sous-système.

// ❌ Façade qui fuit class DatabaseFacade { getConnection() { return this.pool.getConnection(); } // Client doit gérer la connexion lui-même }
