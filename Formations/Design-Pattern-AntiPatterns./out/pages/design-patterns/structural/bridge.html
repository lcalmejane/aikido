🌉 Bridge Pattern

Séparer l'abstraction de son implémentation

🎨 Design Patterns
⭐ Difficulté: Moyenne
⏱️ 25 min
🏗️ Structure

🎯 Définition

Le Bridge est un pattern structurel qui sépare l'abstraction de son implémentation, permettant aux deux de varier indépendamment. Il crée un pont entre une hiérarchie d'abstractions et une hiérarchie d'implémentations.

❌ Problème Résolu

  • Éviter l'explosion combinatoire de classes
  • Permettre l'évolution indépendante des abstractions et implémentations
  • Réduire le couplage entre interface et implémentation
  • Faciliter l'ajout de nouvelles plateformes ou variantes

✅ Solution Apportée

  • Séparation claire abstraction/implémentation
  • Extensibilité dans les deux dimensions
  • Composition privilégiée à l'héritage
  • Flexibilité au runtime
💡 Analogie : Comme une télécommande universelle qui peut contrôler différents appareils (TV, radio, climatisation) via une interface unifiée, le Bridge sépare l'interface de contrôle de l'implémentation spécifique à chaque appareil.

Éléments Clés

  • Abstraction : Interface de haut niveau pour le client
  • RefinedAbstraction : Extensions de l'abstraction de base
  • Implementor : Interface pour les implémentations concrètes
  • ConcreteImplementor : Implémentations spécifiques

💡 Point clé : L'abstraction délègue le travail à l'implémentation, permettant de changer d'implémentation sans affecter le client.

// Interface d'implémentation
interface NotificationSender {
    sendNotification(message: string, recipient: string): boolean;
}

// Implémentations concrètes
class EmailSender implements NotificationSender {
    private smtpServer: string;
    
    constructor(smtpServer: string) {
        this.smtpServer = smtpServer;
    }
    
    sendNotification(message: string, recipient: string): boolean {
        console.log(`Envoi email via ${this.smtpServer}`);
        console.log(`À: ${recipient}`);
        console.log(`Message: ${message}`);
        return true;
    }
}

class SMSSender implements NotificationSender {
    private apiKey: string;
    
    constructor(apiKey: string) {
        this.apiKey = apiKey;
    }
    
    sendNotification(message: string, recipient: string): boolean {
        console.log(`Envoi SMS via API (${this.apiKey})`);
        console.log(`Numéro: ${recipient}`);
        console.log(`Message: ${message}`);
        return true;
    }
}

class PushNotificationSender implements NotificationSender {
    private platform: string;
    
    constructor(platform: string) {
        this.platform = platform;
    }
    
    sendNotification(message: string, recipient: string): boolean {
        console.log(`Push notification ${this.platform}`);
        console.log(`Device ID: ${recipient}`);
        console.log(`Message: ${message}`);
        return true;
    }
}

// Abstraction de base
abstract class Notification {
    protected sender: NotificationSender;
    
    constructor(sender: NotificationSender) {
        this.sender = sender;
    }
    
    abstract send(message: string, recipient: string): boolean;
}

// Abstractions raffinées
class SimpleNotification extends Notification {
    send(message: string, recipient: string): boolean {
        return this.sender.sendNotification(message, recipient);
    }
}

class UrgentNotification extends Notification {
    send(message: string, recipient: string): boolean {
        const urgentMessage = `🚨 URGENT: ${message}`;
        return this.sender.sendNotification(urgentMessage, recipient);
    }
}

class ScheduledNotification extends Notification {
    private scheduleTime: Date;
    
    constructor(sender: NotificationSender, scheduleTime: Date) {
        super(sender);
        this.scheduleTime = scheduleTime;
    }
    
    send(message: string, recipient: string): boolean {
        const scheduledMessage = `[Programmé pour ${this.scheduleTime.toLocaleString()}] ${message}`;
        console.log(`Notification programmée pour: ${this.scheduleTime}`);
        return this.sender.sendNotification(scheduledMessage, recipient);
    }
}

class BulkNotification extends Notification {
    send(message: string, recipients: string): boolean {
        const recipientList = recipients.split(',');
        let allSent = true;
        
        recipientList.forEach(recipient => {
            const success = this.sender.sendNotification(
                `[Diffusion] ${message}`, 
                recipient.trim()
            );
            allSent = allSent && success;
        });
        
        return allSent;
    }
}

// Utilisation
const emailSender = new EmailSender("smtp.gmail.com");
const smsSender = new SMSSender("API_KEY_123");
const pushSender = new PushNotificationSender("iOS");

// Différentes combinaisons abstraction/implémentation
const simpleEmail = new SimpleNotification(emailSender);
const urgentSMS = new UrgentNotification(smsSender);
const scheduledPush = new ScheduledNotification(
    pushSender, 
    new Date(Date.now() + 3600000)
);
const bulkEmail = new BulkNotification(emailSender);

// Utilisation flexible
simpleEmail.send("Bienvenue sur notre plateforme", "user@example.com");
urgentSMS.send("Votre compte a été compromis", "+33123456789");
scheduledPush.send("N'oubliez pas votre rendez-vous", "device_token_123");
bulkEmail.send("Newsletter mensuelle", "user1@test.com,user2@test.com");

// Changement d'implémentation à l'exécution
const notification = new SimpleNotification(emailSender);
notification.send("Test email", "test@example.com");

// Même abstraction, nouvelle implémentation
const smsNotification = new SimpleNotification(smsSender);
smsNotification.send("Test SMS", "+33987654321");

// Abstraction de base
abstract class Database {
    protected $driver;
    protected $connectionString;
    
    public function __construct(DatabaseDriver $driver, string $connectionString) {
        $this->driver = $driver;
        $this->connectionString = $connectionString;
    }
    
    public function connect(): bool {
        return $this->driver->connect($this->connectionString);
    }
    
    public function disconnect(): void {
        $this->driver->disconnect();
    }
    
    abstract public function query(string $sql): array;
}

// Abstractions raffinées
class SimpleDatabase extends Database {
    public function query(string $sql): array {
        return $this->driver->executeQuery($sql);
    }
}

class CachedDatabase extends Database {
    private $cache = [];
    
    public function query(string $sql): array {
        $cacheKey = md5($sql);
        
        if (isset($this->cache[$cacheKey])) {
            echo "Résultat depuis le cache\n";
            return $this->cache[$cacheKey];
        }
        
        $result = $this->driver->executeQuery($sql);
        $this->cache[$cacheKey] = $result;
        
        return $result;
    }
    
    public function clearCache(): void {
        $this->cache = [];
        echo "Cache vidé\n";
    }
}

class LoggedDatabase extends Database {
    private $logFile;
    
    public function __construct(DatabaseDriver $driver, string $connectionString, string $logFile) {
        parent::__construct($driver, $connectionString);
        $this->logFile = $logFile;
    }
    
    public function query(string $sql): array {
        $timestamp = date('Y-m-d H:i:s');
        file_put_contents($this->logFile, "[{$timestamp}] Query: {$sql}\n", FILE_APPEND);
        
        $result = $this->driver->executeQuery($sql);
        
        file_put_contents($this->logFile, "[{$timestamp}] Result count: " . count($result) . "\n", FILE_APPEND);
        
        return $result;
    }
}

class TransactionalDatabase extends Database {
    private $inTransaction = false;
    private $transactionQueries = [];
    
    public function beginTransaction(): void {
        $this->inTransaction = true;
        $this->transactionQueries = [];
        echo "Transaction démarrée\n";
    }
    
    public function query(string $sql): array {
        if ($this->inTransaction) {
            $this->transactionQueries[] = $sql;
            echo "Requête ajoutée à la transaction: {$sql}\n";
            return ["status" => "queued"];
        }
        
        return $this->driver->executeQuery($sql);
    }
    
    public function commit(): array {
        if (!$this->inTransaction) {
            throw new Exception("Aucune transaction active");
        }
        
        $results = [];
        foreach ($this->transactionQueries as $query) {
            $results[] = $this->driver->executeQuery($query);
        }
        
        $this->inTransaction = false;
        $this->transactionQueries = [];
        echo "Transaction commitée\n";
        
        return $results;
    }
    
    public function rollback(): void {
        $this->inTransaction = false;
        $this->transactionQueries = [];
        echo "Transaction annulée\n";
    }
}

// Interface d'implémentation
public interface RenderingEngine {
    void drawCircle(int x, int y, int radius);
    void drawRectangle(int x, int y, int width, int height);
    void drawLine(int x1, int y1, int x2, int y2);
}

// Implémentations concrètes
public class OpenGLRenderer implements RenderingEngine {
    @Override
    public void drawCircle(int x, int y, int radius) {
        System.out.println("OpenGL: Dessiner cercle à (" + x + "," + y + ") rayon=" + radius);
    }
    
    @Override
    public void drawRectangle(int x, int y, int width, int height) {
        System.out.println("OpenGL: Dessiner rectangle à (" + x + "," + y + ") " + width + "x" + height);
    }
    
    @Override
    public void drawLine(int x1, int y1, int x2, int y2) {
        System.out.println("OpenGL: Dessiner ligne de (" + x1 + "," + y1 + ") à (" + x2 + "," + y2 + ")");
    }
}

public class DirectXRenderer implements RenderingEngine {
    @Override
    public void drawCircle(int x, int y, int radius) {
        System.out.println("DirectX: Rendu cercle position(" + x + "," + y + ") taille=" + radius);
    }
    
    @Override
    public void drawRectangle(int x, int y, int width, int height) {
        System.out.println("DirectX: Rendu rectangle position(" + x + "," + y + ") dimensions=" + width + "x" + height);
    }
    
    @Override
    public void drawLine(int x1, int y1, int x2, int y2) {
        System.out.println("DirectX: Rendu ligne point1(" + x1 + "," + y1 + ") point2(" + x2 + "," + y2 + ")");
    }
}

public class SVGRenderer implements RenderingEngine {
    @Override
    public void drawCircle(int x, int y, int radius) {
        System.out.println("SVG: <circle cx=\"" + x + "\" cy=\"" + y + "\" r=\"" + radius + "\"/>");
    }
    
    @Override
    public void drawRectangle(int x, int y, int width, int height) {
        System.out.println("SVG: <rect x=\"" + x + "\" y=\"" + y + "\" width=\"" + width + "\" height=\"" + height + "\"/>");
    }
    
    @Override
    public void drawLine(int x1, int y1, int x2, int y2) {
        System.out.println("SVG: <line x1=\"" + x1 + "\" y1=\"" + y1 + "\" x2=\"" + x2 + "\" y2=\"" + y2 + "\"/>");
    }
}

// Abstraction de base
public abstract class Shape {
    protected RenderingEngine renderer;
    protected int x, y;
    
    public Shape(RenderingEngine renderer, int x, int y) {
        this.renderer = renderer;
        this.x = x;
        this.y = y;
    }
    
    public abstract void draw();
    
    public void move(int newX, int newY) {
        this.x = newX;
        this.y = newY;
    }
}

// Abstractions raffinées
public class Circle extends Shape {
    private int radius;
    
    public Circle(RenderingEngine renderer, int x, int y, int radius) {
        super(renderer, x, y);
        this.radius = radius;
    }
    
    @Override
    public void draw() {
        renderer.drawCircle(x, y, radius);
    }
    
    public void setRadius(int radius) {
        this.radius = radius;
    }
}

public class Rectangle extends Shape {
    private int width, height;
    
    public Rectangle(RenderingEngine renderer, int x, int y, int width, int height) {
        super(renderer, x, y);
        this.width = width;
        this.height = height;
    }
    
    @Override
    public void draw() {
        renderer.drawRectangle(x, y, width, height);
    }
    
    public void resize(int width, int height) {
        this.width = width;
        this.height = height;
    }
}

public class Line extends Shape {
    private int x2, y2;
    
    public Line(RenderingEngine renderer, int x1, int y1, int x2, int y2) {
        super(renderer, x1, y1);
        this.x2 = x2;
        this.y2 = y2;
    }
    
    @Override
    public void draw() {
        renderer.drawLine(x, y, x2, y2);
    }
    
    public void setEndPoint(int x2, int y2) {
        this.x2 = x2;
        this.y2 = y2;
    }
}

// Formes composées
public class ComplexShape extends Shape {
    private java.util.List<Shape> shapes;
    
    public ComplexShape(RenderingEngine renderer) {
        super(renderer, 0, 0);
        this.shapes = new java.util.ArrayList<>();
    }
    
    public void addShape(Shape shape) {
        shapes.add(shape);
    }
    
    @Override
    public void draw() {
        System.out.println("Dessin de forme complexe:");
        for (Shape shape : shapes) {
            shape.draw();
        }
    }
}

// Utilisation
public class BridgeDemo {
    public static void main(String[] args) {
        // Différents moteurs de rendu
        RenderingEngine openGL = new OpenGLRenderer();
        RenderingEngine directX = new DirectXRenderer();
        RenderingEngine svg = new SVGRenderer();
        
        // Mêmes formes, différents rendus
        Circle circle1 = new Circle(openGL, 100, 100, 50);
        Circle circle2 = new Circle(directX, 100, 100, 50);
        Circle circle3 = new Circle(svg, 100, 100, 50);
        
        Rectangle rect1 = new Rectangle(openGL, 200, 200, 100, 80);
        Rectangle rect2 = new Rectangle(svg, 200, 200, 100, 80);
        
        Line line1 = new Line(directX, 0, 0, 300, 300);
        
        // Rendu avec différents moteurs
        System.out.println("=== Rendu des cercles ===");
        circle1.draw();
        circle2.draw();
        circle3.draw();
        
        System.out.println("\n=== Rendu des rectangles ===");
        rect1.draw();
        rect2.draw();
        
        System.out.println("\n=== Rendu de la ligne ===");
        line1.draw();
        
        // Forme complexe
        ComplexShape complex = new ComplexShape(svg);
        complex.addShape(new Circle(svg, 50, 50, 25));
        complex.addShape(new Rectangle(svg, 75, 25, 50, 50));
        complex.addShape(new Line(svg, 25, 75, 125, 75));
        
        System.out.println("\n=== Forme complexe ===");
        complex.draw();
        
        // Changement de moteur à l'exécution
        System.out.println("\n=== Changement de moteur ===");
        Circle flexibleCircle = new Circle(openGL, 150, 150, 30);
        flexibleCircle.draw();
        
        // Même cercle, nouveau moteur
        Circle sameCircleNewEngine = new Circle(svg, 150, 150, 30);
        sameCircleNewEngine.draw();
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Séparation des préoccupations : Abstraction et implémentation indépendantes
  • Extensibilité : Ajout facile de nouvelles abstractions ou implémentations
  • Flexibilité runtime : Changement d'implémentation à l'exécution
  • Réutilisabilité : Implémentations partagées entre abstractions
  • Évite l'explosion combinatoire : Pas de classe pour chaque combinaison

❌ Inconvénients

  • Complexité accrue : Plus de classes et d'interfaces
  • Indirection : Appels supplémentaires via l'interface
  • Conception initiale : Difficile à introduire après coup
  • Overhead : Performance légèrement réduite
  • Courbe d'apprentissage : Pattern plus complexe à comprendre

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Multi-plateforme : Applications sur différents OS
  • Drivers/Adaptateurs : Différentes implémentations techniques
  • Interfaces graphiques : Différents moteurs de rendu
  • Protocoles réseau : HTTP, TCP, UDP, WebSocket
  • Bases de données : MySQL, PostgreSQL, MongoDB

❌ Quand l'éviter

  • Une seule implémentation : Pas de variabilité prévue
  • Couplage acceptable : Quand la flexibilité n'est pas requise
  • Performance critique : Quand chaque appel compte
  • Simplicité prioritaire : Applications simples
  • Équipe inexpérimentée : Pattern trop complexe

🧩 Biais Cognitifs Associés

🏗️ Biais de Complexité

Manifestation : "Ce pattern est trop complexe, utilisons l'héritage simple."

Risque : Éviter Bridge par peur de la complexité et créer une hiérarchie rigide.

🔮 Biais de Prédiction

Manifestation : "Nous n'aurons jamais besoin de plusieurs implémentations."

Risque : Ne pas prévoir l'évolutivité et se retrouver bloqué plus tard.

⚡ Biais de Performance

Manifestation : "L'indirection va ralentir l'application."

Risque : Optimisation prématurée au détriment de la flexibilité.

⚠️ Anti-Patterns à Éviter

🌳 Explosion de Classes

Créer une classe pour chaque combinaison abstraction/implémentation.
