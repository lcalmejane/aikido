🌳 Composite Pattern

Traiter uniformément objets individuels et compositions

🎨 Design Patterns
⭐ Difficulté: Moyenne
⏱️ 20 min
🏗️ Structure

🎯 Définition

Le Composite est un pattern structurel qui permet de composer des objets en structures arborescentes pour représenter des hiérarchies partie-tout. Il permet aux clients de traiter uniformément les objets individuels et les compositions d'objets.

❌ Problème Résolu

  • Traiter uniformément objets simples et complexes
  • Construire des structures hiérarchiques flexibles
  • Éviter la distinction entre feuilles et conteneurs
  • Simplifier le code client avec des structures récursives

✅ Solution Apportée

  • Interface commune pour tous les éléments
  • Traitement récursif transparent
  • Ajout/suppression dynamique d'éléments
  • Simplicité pour le code client
💡 Analogie : Comme un système de fichiers où dossiers et fichiers partagent des opérations communes (copier, supprimer, déplacer), mais les dossiers peuvent contenir d'autres éléments tandis que les fichiers sont des feuilles.

🏗️ Structure UML

<<interface>>
Component
+ operation()
+ add(Component)
+ remove(Component)
+ getChild(int)
Leaf
+ operation()
Composite
- children: List<Component>
+ operation()
+ add(Component)

+ getChild(int)

Éléments Clés

  • Component : Interface commune pour objets simples et composites
  • Leaf : Objet simple sans enfants (feuille de l'arbre)
  • Composite : Objet complexe contenant d'autres composants
  • Client : Manipule les objets via l'interface Component

🔄 Flux d'Exécution

💡 Point clé : Le traitement récursif permet de parcourir automatiquement toute la structure arborescente de manière transparente.

// Interface commune
interface FileSystemComponent {
    getName(): string;
    getSize(): number;
    display(indent?: string): void;
    add?(component: FileSystemComponent): void;
    remove?(component: FileSystemComponent): void;
    getChildren?(): FileSystemComponent[];
}

// Feuille : Fichier
class File implements FileSystemComponent {
    private name: string;
    private size: number;
    private content: string;
    
    constructor(name: string, content: string = "") {
        this.name = name;
        this.content = content;
        this.size = content.length;
    }
    
    getName(): string {
        return this.name;
    }
    
    getSize(): number {
        return this.size;
    }
    
    display(indent: string = ""): void {
        console.log(`${indent}📄 ${this.name} (${this.size} bytes)`);
    }
    
    getContent(): string {
        return this.content;
    }
    
    setContent(content: string): void {
        this.content = content;
        this.size = content.length;
    }
}

// Composite : Dossier
class Directory implements FileSystemComponent {
    private name: string;
    private children: FileSystemComponent[] = [];
    
    constructor(name: string) {
        this.name = name;
    }
    
    getName(): string {
        return this.name;
    }
    
    getSize(): number {
        return this.children.reduce((total, child) => total + child.getSize(), 0);
    }
    
    display(indent: string = ""): void {
        console.log(`${indent}📁 ${this.name}/ (${this.getSize()} bytes)`);
        this.children.forEach(child => {
            child.display(indent + "  ");
        });
    }
    
    add(component: FileSystemComponent): void {
        this.children.push(component);
    }
    
    remove(component: FileSystemComponent): void {
        const index = this.children.indexOf(component);
        if (index > -1) {
            this.children.splice(index, 1);
        }
    }
    
    getChildren(): FileSystemComponent[] {
        return [...this.children];
    }
    
    find(name: string): FileSystemComponent | null {
        if (this.name === name) {
            return this;
        }
        
        for (const child of this.children) {
            if (child.getName() === name) {
                return child;
            }
            
            // Recherche récursive dans les sous-dossiers
            if (child.getChildren) {
                const found = (child as Directory).find(name);
                if (found) {
                    return found;
                }
            }
        }
        
        return null;
    }
}

interface MenuComponent {
    getName(): string;
    getDescription(): string;
    getPrice(): number;
    isVegetarian(): boolean;
    display(): void;
    add?(component: MenuComponent): void;
    remove?(component: MenuComponent): void;
}

class MenuItem implements MenuComponent {
    private name: string;
    private description: string;
    private price: number;
    private vegetarian: boolean;
    
    constructor(name: string, description: string, price: number, vegetarian: boolean = false) {
        this.name = name;
        this.description = description;
        this.price = price;
        this.vegetarian = vegetarian;
    }
    
    getName(): string {
        return this.name;
    }
    
    getDescription(): string {
        return this.description;
    }
    
    getPrice(): number {
        return this.price;
    }
    
    isVegetarian(): boolean {
        return this.vegetarian;
    }
    
    display(): void {
        const vegIcon = this.vegetarian ? "🌱" : "🍖";
        console.log(`  ${vegIcon} ${this.name} - ${this.description} (${this.price}€)`);
    }
}

class Menu implements MenuComponent {
    private name: string;
    private description: string;
    private items: MenuComponent[] = [];
    
    constructor(name: string, description: string) {
        this.name = name;
        this.description = description;
    }
    
    getName(): string {
        return this.name;
    }
    
    getDescription(): string {
        return this.description;
    }
    
    getPrice(): number {
        // Prix total de tous les éléments (pour un menu complet)
        return this.items.reduce((total, item) => total + item.getPrice(), 0);
    }
    
    isVegetarian(): boolean {
        // Végétarien si tous les éléments le sont
        return this.items.every(item => item.isVegetarian());
    }
    
    display(): void {
        console.log(`\n📋 ${this.name}`);
        console.log(`   ${this.description}`);
        console.log("   " + "=".repeat(40));
        
        this.items.forEach(item => item.display());
        
        if (this.items.length > 1) {
            console.log(`   Total: ${this.getPrice()}€`);
        }
    }
    
    add(component: MenuComponent): void {
        this.items.push(component);
    }
    
    remove(component: MenuComponent): void {
        const index = this.items.indexOf(component);
        if (index > -1) {
            this.items.splice(index, 1);
        }
    }
    
    // Méthodes utilitaires
    getVegetarianItems(): MenuComponent[] {
        const result: MenuComponent[] = [];
        
        this.items.forEach(item => {
            if (item.isVegetarian()) {
                result.push(item);
            }
            
            // Si c'est un sous-menu, chercher récursivement
            if (item instanceof Menu) {
                result.push(...item.getVegetarianItems());
            }
        });
        
        return result;
    }
    
    findItemByName(name: string): MenuComponent | null {
        for (const item of this.items) {
            if (item.getName() === name) {
                return item;
            }
            
            if (item instanceof Menu) {
                const found = item.findItemByName(name);
                if (found) {
                    return found;
                }
            }
        }
        
        return null;
    }
}

// Interface commune
interface GraphicComponent {
    public function draw(): void;
    public function getBounds(): array;
    public function move(int $x, int $y): void;
    public function add(GraphicComponent $component): void;
    public function remove(GraphicComponent $component): void;
    public function getChildren(): array;
}

// Classe abstraite pour éviter la duplication
abstract class AbstractGraphicComponent implements GraphicComponent {
    protected $x = 0;
    protected $y = 0;
    
    public function move(int $x, int $y): void {
        $this->x = $x;
        $this->y = $y;
    }
    
    // Implémentations par défaut pour les feuilles
    public function add(GraphicComponent $component): void {
        throw new Exception("Opération non supportée sur une feuille");
    }
    
    public function remove(GraphicComponent $component): void {
        throw new Exception("Opération non supportée sur une feuille");
    }
    
    public function getChildren(): array {
        return [];
    }
}

// Feuilles : Formes simples
class Circle extends AbstractGraphicComponent {
    private $radius;
    
    public function __construct(int $radius) {
        $this->radius = $radius;
    }
    
    public function draw(): void {
        echo "Dessiner cercle à ({$this->x}, {$this->y}) rayon={$this->radius}\n";
    }
    
    public function getBounds(): array {
        return [
            'x' => $this->x - $this->radius,
            'y' => $this->y - $this->radius,
            'width' => $this->radius * 2,
            'height' => $this->radius * 2
        ];
    }
}

class Rectangle extends AbstractGraphicComponent {
    private $width;
    private $height;
    
    public function __construct(int $width, int $height) {
        $this->width = $width;
        $this->height = $height;
    }
    
    public function draw(): void {
        echo "Dessiner rectangle à ({$this->x}, {$this->y}) {$this->width}x{$this->height}\n";
    }
    
    public function getBounds(): array {
        return [
            'x' => $this->x,
            'y' => $this->y,
            'width' => $this->width,
            'height' => $this->height
        ];
    }
}

class Line extends AbstractGraphicComponent {
    private $x2;
    private $y2;
    
    public function __construct(int $x2, int $y2) {
        $this->x2 = $x2;
        $this->y2 = $y2;
    }
    
    public function draw(): void {
        echo "Dessiner ligne de ({$this->x}, {$this->y}) à ({$this->x2}, {$this->y2})\n";
    }
    
    public function getBounds(): array {
        return [
            'x' => min($this->x, $this->x2),
            'y' => min($this->y, $this->y2),
            'width' => abs($this->x2 - $this->x),
            'height' => abs($this->y2 - $this->y)
        ];
    }
    
    public function move(int $x, int $y): void {
        $deltaX = $x - $this->x;
        $deltaY = $y - $this->y;
        
        $this->x = $x;
        $this->y = $y;
        $this->x2 += $deltaX;
        $this->y2 += $deltaY;
    }
}

// Composite : Groupe de formes
class GraphicGroup extends AbstractGraphicComponent {
    private $children = [];
    private $name;
    
    public function __construct(string $name = "Groupe") {
        $this->name = $name;
    }
    
    public function draw(): void {
        echo "=== Début du groupe '{$this->name}' ===\n";
        foreach ($this->children as $child) {
            $child->draw();
        }
        echo "=== Fin du groupe '{$this->name}' ===\n";
    }
    
    public function getBounds(): array {
        if (empty($this->children)) {
            return ['x' => $this->x, 'y' => $this->y, 'width' => 0, 'height' => 0];
        }
        
        $minX = PHP_INT_MAX;
        $minY = PHP_INT_MAX;
        $maxX = PHP_INT_MIN;
        $maxY = PHP_INT_MIN;
        
        foreach ($this->children as $child) {
            $bounds = $child->getBounds();
            $minX = min($minX, $bounds['x']);
            $minY = min($minY, $bounds['y']);
            $maxX = max($maxX, $bounds['x'] + $bounds['width']);
            $maxY = max($maxY, $bounds['y'] + $bounds['height']);
        }
        
        return [
            'x' => $minX,
            'y' => $minY,
            'width' => $maxX - $minX,
            'height' => $maxY - $minY
        ];
    }
    
    public function move(int $x, int $y): void {
        $deltaX = $x - $this->x;
        $deltaY = $y - $this->y;
        
        $this->x = $x;
        $this->y = $y;
        
        // Déplacer tous les enfants
        foreach ($this->children as $child) {
            $bounds = $child->getBounds();
            $child->move($bounds['x'] + $deltaX, $bounds['y'] + $deltaY);
        }
    }
    
    public function add(GraphicComponent $component): void {
        $this->children[] = $component;
    }
    
    public function remove(GraphicComponent $component): void {
        $index = array_search($component, $this->children, true);
        if ($index !== false) {
            array_splice($this->children, $index, 1);
        }
    }
    
    public function getChildren(): array {
        return $this->children;
    }
    
    public function getName(): string {
        return $this->name;
    }
    
    // Méthodes utilitaires
    public function getComponentCount(): int {
        $count = count($this->children);
        
        foreach ($this->children as $child) {
            if ($child instanceof GraphicGroup) {
                $count += $child->getComponentCount();
            }
        }
        
        return $count;
    }
    
    public function findByType(string $type): array {
        $result = [];
        
        foreach ($this->children as $child) {
            if ($child instanceof $type) {
                $result[] = $child;
            }
            
            if ($child instanceof GraphicGroup) {
                $result = array_merge($result, $child->findByType($type));
            }
        }
        
        return $result;
    }
}

// Exemple d'utilisation : Éditeur graphique
class GraphicEditor {
    private $canvas;
    
    public function __construct() {
        $this->canvas = new GraphicGroup("Canvas Principal");
    }
    
    public function addShape(GraphicComponent $shape): void {
        $this->canvas->add($shape);
    }
    
    public function createGroup(array $shapes, string $name): GraphicGroup {
        $group = new GraphicGroup($name);
        
        foreach ($shapes as $shape) {
            $this->canvas->remove($shape);
            $group->add($shape);
        }
        
        $this->canvas->add($group);
        return $group;
    }
    
    public function render(): void {
        echo "\n=== Rendu du Canvas ===\n";
        $this->canvas->draw();
        
        $bounds = $this->canvas->getBounds();
        echo "\nDimensions du canvas: {$bounds['width']}x{$bounds['height']}\n";
        echo "Nombre total d'éléments: " . $this->canvas->getComponentCount() . "\n";
    }
    
    public function getStatistics(): array {
        return [
            'circles' => count($this->canvas->findByType(Circle::class)),
            'rectangles' => count($this->canvas->findByType(Rectangle::class)),
            'lines' => count($this->canvas->findByType(Line::class)),
            'groups' => count($this->canvas->findByType(GraphicGroup::class))
        ];
    }
}

import java.util.*;

// Interface commune
public interface OrganizationComponent {
    String getName();
    double getSalary();
    void displayHierarchy(String indent);
    void add(OrganizationComponent component);
    void remove(OrganizationComponent component);
    List<OrganizationComponent> getSubordinates();
    int getEmployeeCount();
}

// Feuille : Employé
public class Employee implements OrganizationComponent {
    private String name;
    private String position;
    private double salary;
    
    public Employee(String name, String position, double salary) {
        this.name = name;
        this.position = position;
        this.salary = salary;
    }
    
    @Override
    public String getName() {
        return name;
    }
    
    public String getPosition() {
        return position;
    }
    
    @Override
    public double getSalary() {
        return salary;
    }
    
    @Override
    public void displayHierarchy(String indent) {
        System.out.println(indent + "👤 " + name + " (" + position + ") - " + salary + "€");
    }
    
    @Override
    public void add(OrganizationComponent component) {
        throw new UnsupportedOperationException("Un employé ne peut pas avoir de subordonnés");
    }
    
    @Override
    public void remove(OrganizationComponent component) {
        throw new UnsupportedOperationException("Un employé ne peut pas avoir de subordonnés");
    }
    
    @Override
    public List<OrganizationComponent> getSubordinates() {
        return new ArrayList<>();
    }
    
    @Override
    public int getEmployeeCount() {
        return 1;
    }
}

// Composite : Manager
public class Manager implements OrganizationComponent {
    private String name;
    private String position;
    private double salary;
    private List subordinates;
    
    public Manager(String name, String position, double salary) {
        this.name = name;
        this.position = position;
        this.salary = salary;
        this.subordinates = new ArrayList<>();
    }
    
    @Override
    public String getName() {
        return name;
    }
    
    public String getPosition() {
        return position;
    }
    
    @Override
    public double getSalary() {
        // Salaire du manager + bonus basé sur l'équipe
        double teamBonus = subordinates.size() * 500;
        return salary + teamBonus;
    }
    
    @Override
    public void displayHierarchy(String indent) {
        System.out.println(indent + "👨‍💼 " + name + " (" + position + ") - " + getSalary() + "€");
        System.out.println(indent + "  └─ Équipe de " + subordinates.size() + " personnes:");
        
        for (OrganizationComponent subordinate : subordinates) {
            subordinate.displayHierarchy(indent + "    ");
        }
    }
    
    @Override
    public void add(OrganizationComponent component) {
        subordinates.add(component);
    }
    
    @Override
    public void remove(OrganizationComponent component) {
        subordinates.remove(component);
    }
    
    @Override
    public List getSubordinates() {
        return new ArrayList<>(subordinates);
    }
    
    @Override
    public int getEmployeeCount() {
        int count = 1; // Le manager lui-même
        for (OrganizationComponent subordinate : subordinates) {
            count += subordinate.getEmployeeCount();
        }
        return count;
    }
    
    // Méthodes utilitaires
    public double getTotalTeamSalary() {
        double total = getSalary();
        for (OrganizationComponent subordinate : subordinates) {
            total += subordinate.getSalary();
        }
        return total;
    }
    
    public List findEmployeesByPosition(String position) {
        List result = new ArrayList<>();
        
        if (this.position.equalsIgnoreCase(position)) {
            result.add(this);
        }
        
        for (OrganizationComponent subordinate : subordinates) {
            if (subordinate instanceof Employee &&
                ((Employee) subordinate).getPosition().equalsIgnoreCase(position)) {
                result.add(subordinate);
            } else if (subordinate instanceof Manager) {
                result.addAll(((Manager) subordinate).findEmployeesByPosition(position));
            }
        }
        
        return result;
    }
}

// Classe utilitaire pour l'organisation
public class Organization {
    private OrganizationComponent root;
    
    public Organization(OrganizationComponent root) {
        this.root = root;
    }
    
    public void displayFullHierarchy() {
        System.out.println("=== Structure Organisationnelle ===");
        root.displayHierarchy("");
        System.out.println("\nTotal employés: " + root.getEmployeeCount());
        System.out.println("Masse salariale totale: " + getTotalSalary() + "€");
    }
    
    public double getTotalSalary() {
        return calculateTotalSalary(root);
    }
    
    private double calculateTotalSalary(OrganizationComponent component) {
        double total = component.getSalary();
        
        for (OrganizationComponent subordinate : component.getSubordinates()) {
            total += calculateTotalSalary(subordinate);
        }
        
        return total;
    }
    
    public List findByPosition(String position) {
        List result = new ArrayList<>();
        findByPositionRecursive(root, position, result);
        return result;
    }
    
    private void findByPositionRecursive(OrganizationComponent component, String position, List result) {
        if (component instanceof Employee && ((Employee) component).getPosition().equalsIgnoreCase(position)) {
            result.add(component);
        } else if (component instanceof Manager && ((Manager) component).getPosition().equalsIgnoreCase(position)) {
            result.add(component);
        }
        
        for (OrganizationComponent subordinate : component.getSubordinates()) {
            findByPositionRecursive(subordinate, position, result);
        }
    }
}

        company.displayFullHierarchy();
        
        System.out.println("\n=== Recherche par poste ===");
        List developers = company.findByPosition("Senior Developer");
        System.out.println("Développeurs seniors trouvés: " + developers.size());
        for (OrganizationComponent dev : developers) {
            System.out.println("- " + dev.getName());
        }
        
        List managers = company.findByPosition("Manager");
        System.out.println("\nManagers trouvés: " + managers.size());
        for (OrganizationComponent manager : managers) {
            System.out.println("- " + manager.getName() + " (" + ((Manager) manager).getPosition() + ")");
        }
        
        System.out.println("\n=== Statistiques équipe CTO ===");
        System.out.println("Nombre total d'employés sous CTO: " + cto.getEmployeeCount());
        System.out.println("Masse salariale équipe CTO: " + cto.getTotalTeamSalary() + "€");
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Traitement uniforme : Même interface pour objets simples et complexes
  • Flexibilité structurelle : Ajout/suppression facile d'éléments
  • Récursivité naturelle : Parcours automatique de l'arbre
  • Simplicité client : Code client ne distingue pas les types
  • Extensibilité : Nouveaux types de composants facilement ajoutés

❌ Inconvénients

  • Interface trop générale : Méthodes non pertinentes pour certains objets
  • Vérifications runtime : Erreurs détectées à l'exécution
  • Complexité accrue : Plus difficile à comprendre et maintenir
  • Performance : Appels récursifs peuvent être coûteux
  • Restriction de types : Difficile de limiter les types d'enfants

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Hiérarchies d'objets : Structures arborescentes naturelles
  • Interfaces graphiques : Composants et conteneurs
  • Systèmes de fichiers : Dossiers et fichiers
  • Organisations : Hiérarchies d'employés
  • Expressions mathématiques : Opérateurs et opérandes

❌ Quand l'éviter

  • Structures plates : Pas de hiérarchie naturelle
  • Types très différents : Interface commune artificielle
  • Performance critique : Récursion trop coûteuse
  • Contrôle strict des types : Besoin de validation compile-time
  • Simplicité prioritaire : Pattern trop complexe pour le besoin

🧩 Biais Cognitifs Associés

🌳 Biais de Hiérarchie

Manifestation : "Tout peut être représenté comme un arbre."

Risque : Forcer des structures non-hiérarchiques dans le pattern Composite.

🔄 Biais de Récursion

Manifestation : "La récursion résout tous les problèmes de parcours."

Risque : Ignorer les problèmes de performance et de stack overflow.

🎯 Biais d'Uniformité

Manifestation : "Tous les objets doivent avoir la même interface."

Risque : Créer des interfaces artificielles et peu naturelles.

⚠️ Anti-Patterns à Éviter

🏛️ Interface Gonflée

Interface commune avec trop de méthodes non pertinentes pour certains objets.

// ❌ Mauvais : Interface trop large interface Component { void draw(), void play(), void calculate(), void send()... }
