🪶 Flyweight Pattern

Optimiser la mémoire en partageant des objets similaires

🎨 Design Patterns
⭐ Difficulté: Difficile
⏱️ 25 min
🏗️ Structurel

🎯 Définition

Le Flyweight est un pattern structurel qui permet de réduire la consommation de mémoire en partageant efficacement de grandes quantités d'objets similaires.

❌ Problème Résolu

  • Consommation excessive de mémoire avec de nombreux objets
  • Objets contenant des données redondantes ou similaires
  • Performance dégradée due au manque de mémoire
  • Coût de création élevé pour des objets similaires

✅ Solution Apportée

  • Partage des données communes (état intrinsèque)
  • Externalisation des données variables (état extrinsèque)
  • Réduction drastique de l'utilisation mémoire
  • Amélioration des performances globales
⚠️ Attention : Le Flyweight introduit de la complexité et n'est bénéfique que lorsque vous avez un très grand nombre d'objets similaires.

Éléments Clés

  • Flyweight : Interface déclarant les méthodes acceptant l'état extrinsèque
  • ConcreteFlyweight : Implémente Flyweight et stocke l'état intrinsèque
  • FlyweightFactory : Gère et réutilise les instances de flyweight
  • Context : Contient l'état extrinsèque et référence un flyweight

// Interface Flyweight
interface ParticleFlyweight {
    render(x: number, y: number, velocity: Vector2D, color: string): void;
    getType(): string;
}

interface Vector2D {
    x: number;
    y: number;
}

// Flyweight concret - contient l'état intrinsèque (partagé)
class ParticleType implements ParticleFlyweight {
    private sprite: string;
    private size: number;
    private mass: number;
    private shape: string;
    
    constructor(sprite: string, size: number, mass: number, shape: string) {
        this.sprite = sprite;
        this.size = size;
        this.mass = mass;
        this.shape = shape;
        
        console.log(`🎨 Création ParticleType: ${sprite} (${shape}, ${size}px, ${mass}kg)`);
    }
    
    render(x: number, y: number, velocity: Vector2D, color: string): void {
        // Utilise l'état intrinsèque (sprite, size, mass, shape) 
        // et l'état extrinsèque (x, y, velocity, color)
        console.log(`🎯 Rendu ${this.sprite} à (${x}, ${y}) - ${color} - v(${velocity.x}, ${velocity.y})`);
        
        // Simulation du rendu
        this.drawSprite(x, y, color);
        this.applyPhysics(velocity);
    }
    
    getType(): string {
        return `${this.sprite}_${this.shape}_${this.size}`;
    }
    
    private drawSprite(x: number, y: number, color: string): void {
        // Rendu du sprite avec les paramètres extrinsèques
        console.log(`  📐 Dessiner ${this.sprite} (${this.size}px) en ${color} à (${x}, ${y})`);
    }
    
    private applyPhysics(velocity: Vector2D): void {
        // Calculs physiques utilisant la masse (intrinsèque) et vélocité (extrinsèque)
        const force = Math.sqrt(velocity.x * velocity.x + velocity.y * velocity.y) * this.mass;
        console.log(`  ⚡ Force appliquée: ${force.toFixed(2)}N`);
    }
    
    // Méthodes utilitaires pour l'état intrinsèque
    getMass(): number { return this.mass; }
    getSize(): number { return this.size; }
    getSprite(): string { return this.sprite; }
}

// Factory pour gérer les Flyweights
class ParticleTypeFactory {
    private static flyweights = new Map<string, ParticleFlyweight>();
    private static creationCount = 0;
    
    static getParticleType(sprite: string, size: number, mass: number, shape: string): ParticleFlyweight {
        const key = `${sprite}_${shape}_${size}_${mass}`;
        
        if (!this.flyweights.has(key)) {
            console.log(`🏭 Factory: Création nouveau flyweight pour ${key}`);
            this.flyweights.set(key, new ParticleType(sprite, size, mass, shape));
            this.creationCount++;
        } else {
            console.log(`♻️ Factory: Réutilisation flyweight existant pour ${key}`);
        }
        
        return this.flyweights.get(key)!;
    }
    
    static getCreatedFlyweightsCount(): number {
        return this.flyweights.size;
    }
    
    static getTotalRequestsCount(): number {
        return this.creationCount;
    }
    
    static getStats(): { created: number; requests: number; efficiency: number } {
        const created = this.flyweights.size;
        const requests = this.creationCount;
        const efficiency = requests > 0 ? ((requests - created) / requests) * 100 : 0;
        
        return { created, requests, efficiency };
    }
    
    static reset(): void {
        this.flyweights.clear();
        this.creationCount = 0;
    }
}

// Context - contient l'état extrinsèque
class Particle {
    private x: number;
    private y: number;
    private velocity: Vector2D;
    private color: string;
    private flyweight: ParticleFlyweight;
    private id: string;
    
    constructor(
        x: number, 
        y: number, 
        velocity: Vector2D, 
        color: string, 
        flyweight: ParticleFlyweight
    ) {
        this.x = x;
        this.y = y;
        this.velocity = velocity;
        this.color = color;
        this.flyweight = flyweight;
        this.id = Math.random().toString(36).substr(2, 9);
    }
    
    update(deltaTime: number): void {
        // Mise à jour de l'état extrinsèque
        this.x += this.velocity.x * deltaTime;
        this.y += this.velocity.y * deltaTime;
        
        // Simulation de la gravité
        this.velocity.y += 9.81 * deltaTime;
        
        // Friction
        this.velocity.x *= 0.99;
        this.velocity.y *= 0.99;
    }
    
    render(): void {
        this.flyweight.render(this.x, this.y, this.velocity, this.color);
    }
    
    getPosition(): { x: number; y: number } {
        return { x: this.x, y: this.y };
    }
    
    getId(): string { return this.id; }
    getType(): string { return this.flyweight.getType(); }
}

// Système de particules utilisant le pattern Flyweight
class ParticleSystem {
    private particles: Particle[] = [];
    private particleTypes = [
        { sprite: 'fire', size: 8, mass: 0.1, shape: 'circle' },
        { sprite: 'smoke', size: 12, mass: 0.05, shape: 'cloud' },
        { sprite: 'spark', size: 4, mass: 0.02, shape: 'star' },
        { sprite: 'ember', size: 6, mass: 0.08, shape: 'circle' },
        { sprite: 'ash', size: 10, mass: 0.03, shape: 'irregular' }
    ];
    
    private colors = ['red', 'orange', 'yellow', 'white', 'gray'];
    
    createParticle(x: number, y: number): Particle {
        // Sélection aléatoire du type de particule
        const typeConfig = this.particleTypes[Math.floor(Math.random() * this.particleTypes.length)];
        const color = this.colors[Math.floor(Math.random() * this.colors.length)];
        
        // Obtention du flyweight (partagé)
        const flyweight = ParticleTypeFactory.getParticleType(
            typeConfig.sprite,
            typeConfig.size,
            typeConfig.mass,
            typeConfig.shape
        );
        
        // Création de la particule avec état extrinsèque unique
        const velocity: Vector2D = {
            x: (Math.random() - 0.5) * 100,
            y: (Math.random() - 0.5) * 100
        };
        
        const particle = new Particle(x, y, velocity, color, flyweight);
        this.particles.push(particle);
        
        return particle;
    }
    
    createExplosion(centerX: number, centerY: number, particleCount: number): void {
        console.log(`💥 Création explosion avec ${particleCount} particules à (${centerX}, ${centerY})`);
        
        for (let i = 0; i < particleCount; i++) {
            const angle = (i / particleCount) * 2 * Math.PI;
            const distance = Math.random() * 50;
            
            const x = centerX + Math.cos(angle) * distance;
            const y = centerY + Math.sin(angle) * distance;
            
            this.createParticle(x, y);
        }
    }
    
    update(deltaTime: number): void {
        this.particles.forEach(particle => particle.update(deltaTime));
        
        // Suppression des particules hors limites
        this.particles = this.particles.filter(particle => {
            const pos = particle.getPosition();
            return pos.x > -100 && pos.x < 1000 && pos.y > -100 && pos.y < 800;
        });
    }
    
    render(): void {
        console.log(`🎬 Rendu de ${this.particles.length} particules`);
        this.particles.forEach(particle => particle.render());
    }
    
    getStats(): {
        totalParticles: number;
        flyweightStats: { created: number; requests: number; efficiency: number };
        memoryEstimate: { withFlyweight: number; withoutFlyweight: number; savings: number };
    } {
        const flyweightStats = ParticleTypeFactory.getStats();
        
        // Estimation de la mémoire (en bytes)
        const particleDataSize = 32; // x, y, velocity, color, reference
        const flyweightDataSize = 64; // sprite, size, mass, shape
        
        const withFlyweight = 
            this.particles.length * particleDataSize + 
            flyweightStats.created * flyweightDataSize;
            
        const withoutFlyweight = 
            this.particles.length * (particleDataSize + flyweightDataSize);
        
        const savings = ((withoutFlyweight - withFlyweight) / withoutFlyweight) * 100;
        
        return {
            totalParticles: this.particles.length,
            flyweightStats,
            memoryEstimate: {
                withFlyweight,
                withoutFlyweight,
                savings
            }
        };
    }
    
    clear(): void {
        this.particles = [];
    }
}

// Démonstration du système de particules
function demonstrateParticleSystem(): void {
    console.log("=== Démonstration Système de Particules avec Flyweight ===\n");
    
    const particleSystem = new ParticleSystem();
    
    // Création de plusieurs explosions
    particleSystem.createExplosion(100, 100, 50);
    particleSystem.createExplosion(200, 150, 75);
    particleSystem.createExplosion(300, 200, 100);
    
    console.log("\n--- Statistiques après création ---");
    const stats = particleSystem.getStats();
    console.log(`Particules totales: ${stats.totalParticles}`);
    console.log(`Flyweights créés: ${stats.flyweightStats.created}`);
    console.log(`Efficacité: ${stats.flyweightStats.efficiency.toFixed(1)}%`);
    console.log(`Économie mémoire: ${stats.memoryEstimate.savings.toFixed(1)}%`);
    
    // Simulation de quelques frames
    console.log("\n--- Simulation de rendu ---");
    for (let frame = 0; frame < 3; frame++) {
        console.log(`\nFrame ${frame + 1}:`);
        particleSystem.update(0.016); // 60 FPS
        if (frame === 0) particleSystem.render(); // Rendu seulement de la première frame
    }
    
    console.log("\n--- Statistiques finales ---");
    const finalStats = particleSystem.getStats();
    console.log(`Particules restantes: ${finalStats.totalParticles}`);
    console.log(`Mémoire avec Flyweight: ${finalStats.memoryEstimate.withFlyweight} bytes`);
    console.log(`Mémoire sans Flyweight: ${finalStats.memoryEstimate.withoutFlyweight} bytes`);
    console.log(`Économie: ${finalStats.memoryEstimate.savings.toFixed(1)}%`);
}

// Interface Flyweight
interface CharacterFlyweight {
    public function render(int $x, int $y, string $font, int $size, string $color): void;
    public function getCharacter(): string;
}

// Flyweight concret - contient l'état intrinsèque (le caractère)
class Character implements CharacterFlyweight {
    private string $character;
    private array $bitmap; // Représentation bitmap du caractère
    
    public function __construct(string $character) {
        $this->character = $character;
        $this->bitmap = $this->generateBitmap($character);
        
        echo "🎨 Création Character flyweight: '{$character}'\n";
    }
    
    public function render(int $x, int $y, string $font, int $size, string $color): void {
        // Utilise l'état intrinsèque (character, bitmap) 
        // et l'état extrinsèque (x, y, font, size, color)
        echo "📝 Rendu '{$this->character}' à ({$x}, {$y}) - {$font} {$size}px {$color}\n";
        
        $this->drawBitmap($x, $y, $font, $size, $color);
    }
    
    public function getCharacter(): string {
        return $this->character;
    }
    
    private function generateBitmap(string $character): array {
        // Simulation de génération de bitmap pour le caractère
        $bitmap = [];
        for ($i = 0; $i < 16; $i++) {
            $bitmap[] = str_repeat(random_int(0, 1) ? '█' : ' ', 8);
        }
        
        echo "  🖼️ Bitmap généré pour '{$character}' (16x8)\n";
        return $bitmap;
    }
    
    private function drawBitmap(int $x, int $y, string $font, int $size, string $color): void {
        // Rendu du bitmap avec les paramètres extrinsèques
        echo "  🎯 Dessiner bitmap à ({$x}, {$y}) avec {$font} {$size}px en {$color}\n";
        
        // Simulation d'application des transformations
        $scale = $size / 12; // Taille de base 12px
        echo "  📏 Échelle appliquée: {$scale}x\n";
    }
    
    public function getBitmapSize(): int {
        return count($this->bitmap) * strlen($this->bitmap[0]);
    }
}

// Factory pour gérer les Flyweights
class CharacterFactory {
    private static array $flyweights = [];
    private static int $creationCount = 0;
    
    public static function getCharacter(string $character): CharacterFlyweight {
        if (!isset(self::$flyweights[$character])) {
            echo "🏭 Factory: Création nouveau flyweight pour '{$character}'\n";
            self::$flyweights[$character] = new Character($character);
            self::$creationCount++;
        } else {
            echo "♻️ Factory: Réutilisation flyweight existant pour '{$character}'\n";
        }
        
        return self::$flyweights[$character];
    }
    
    public static function getCreatedFlyweightsCount(): int {
        return count(self::$flyweights);
    }
    
    public static function getTotalRequestsCount(): int {
        return self::$creationCount;
    }
    
    public static function getStats(): array {
        $created = count(self::$flyweights);
        $requests = self::$creationCount;
        $efficiency = $requests > 0 ? (($requests - $created) / $requests) * 100 : 0;
        
        return [
            'created' => $created,
            'requests' => $requests,
            'efficiency' => $efficiency
        ];
    }
    
    public static function listFlyweights(): array {
        return array_keys(self::$flyweights);
    }
    
    public static function reset(): void {
        self::$flyweights = [];
        self::$creationCount = 0;
    }
}

class TextEditor {
    private array $characters = [];
    private array $fonts = ['Arial', 'Times', 'Helvetica', 'Courier'];
    private array $colors = ['black', 'red', 'blue', 'green', 'purple'];
    
    public function addText(string $text, int $startX, int $startY, string $font = 'Arial', int $size = 12, string $color = 'black'): void {
        echo "📄 Ajout du texte: '{$text}' à ({$startX}, {$startY})\n";
        
        $currentX = $startX;
        $currentY = $startY;
        
        for ($i = 0; $i < strlen($text); $i++) {
            $char = $text[$i];
            
            if ($char === ' ') {
                $currentX += $size / 2; // Espacement pour les espaces
                continue;
            }
            
            if ($char === "\n") {
                $currentX = $startX;
                $currentY += $size + 4; // Interligne
                continue;
            }
            
            // Obtention du flyweight pour le caractère
            $flyweight = CharacterFactory::getCharacter($char);
            
            // Création du contexte avec l'état extrinsèque
            $textChar = new TextCharacter($currentX, $currentY, $font, $size, $color, $flyweight);
            $this->characters[] = $textChar;
            
            $currentX += $size * 0.6; // Espacement entre caractères
        }
    }
    
    public function addFormattedText(string $text, int $x, int $y): void {
        echo "🎨 Ajout de texte formaté avec styles variés\n";
        
        $words = explode(' ', $text);
        $currentX = $x;
        $currentY = $y;
        
        foreach ($words as $word) {
            // Style aléatoire pour chaque mot
            $font = $this->fonts[array_rand($this->fonts)];
            $color = $this->colors[array_rand($this->colors)];
            $size = rand(10, 16);
            
            $this->addText($word . ' ', $currentX, $currentY, $font, $size, $color);
            $currentX += strlen($word) * $size * 0.6 + $size; // Espacement entre mots
        }
    }
    
    public function render(): void {
        echo "🎬 Rendu de " . count($this->characters) . " caractères\n";
        
        foreach ($this->characters as $char) {
            $char->render();
        }
    }
    
    public function getStats(): array {
        $flyweightStats = CharacterFactory::getStats();
        
        // Estimation de la mémoire (en bytes)
        $characterDataSize = 48; // x, y, font, size, color, reference
        $flyweightDataSize = 128; // character, bitmap
        
        $withFlyweight =
            count($this->characters) * $characterDataSize +
            $flyweightStats['created'] * $flyweightDataSize;
            
        $withoutFlyweight =
            count($this->characters) * ($characterDataSize + $flyweightDataSize);
        
        $savings = $withoutFlyweight > 0 ? (($withoutFlyweight - $withFlyweight) / $withoutFlyweight) * 100 : 0;
        
        return [
            'totalCharacters' => count($this->characters),
            'flyweightStats' => $flyweightStats,
            'memoryEstimate' => [
                'withFlyweight' => $withFlyweight,
                'withoutFlyweight' => $withoutFlyweight,
                'savings' => $savings
            ]
        ];
    }
    
    public function clear(): void {
        $this->characters = [];
    }
    
    public function getCharacterCount(): int {
        return count($this->characters);
    }
}

// Flyweight concret - contient l'état intrinsèque
class Character implements CharacterFlyweight {
    private final String character;
    private final char[][] bitmap;
    
    public Character(String character) {
        this.character = character;
        this.bitmap = generateBitmap(character);
        
        System.out.println("🎨 Création Character flyweight: '" + character + "'");
    }
    
    @Override
    public void render(int x, int y, String font, int size, String color) {
        // Utilise l'état intrinsèque (character, bitmap)
        // et l'état extrinsèque (x, y, font, size, color)
        System.out.println("📝 Rendu '" + this.character + "' à (" + x + ", " + y + ") - " + font + " " + size + "px " + color);
        
        drawBitmap(x, y, font, size, color);
    }
    
    @Override
    public String getCharacter() {
        return character;
    }
    
    private char[][] generateBitmap(String character) {
        // Simulation de génération de bitmap pour le caractère
        char[][] bitmap = new char[16][8];
        Random random = new Random();
        
        for (int i = 0; i < 16; i++) {
            for (int j = 0; j < 8; j++) {
                bitmap[i][j] = random.nextBoolean() ? '█' : ' ';
            }
        }
        
        System.out.println("  🖼️ Bitmap généré pour '" + character + "' (16x8)");
        return bitmap;
    }
    
    private void drawBitmap(int x, int y, String font, int size, String color) {
        // Rendu du bitmap avec les paramètres extrinsèques
        System.out.println("  🎯 Dessiner bitmap à (" + x + ", " + y + ") avec " + font + " " + size + "px en " + color);
        
        // Simulation d'application des transformations
        double scale = size / 12.0; // Taille de base 12px
        System.out.println("  📏 Échelle appliquée: " + scale + "x");
    }
    
    public int getBitmapSize() {
        return bitmap.length * bitmap[0].length;
    }
}

class CharacterFactory {
    private static final Map<String, CharacterFlyweight> flyweights = new HashMap<>();
    private static int creationCount = 0;

        return stats;

class TextCharacter {
    private int x;
    private int y;
    private String font;
    private int size;
    private String color;
    private CharacterFlyweight flyweight;
    
    public TextCharacter(int x, int y, String font, int size, String color, CharacterFlyweight flyweight) {
        this.x = x;
        this.y = y;
        this.font = font;
        this.size = size;
        this.color = color;
        this.flyweight = flyweight;
    }
    
    public void render() {
        flyweight.render(x, y, font, size, color);
    }
    
    public void move(int deltaX, int deltaY) {
        this.x += deltaX;
        this.y += deltaY;
    }
    
    public void changeStyle(String font, int size, String color) {
        this.font = font;
        this.size = size;
        this.color = color;
    }
    
    public int[] getPosition() {
        return new int[]{x, y};
    }
    
    public String getCharacter() {
        return flyweight.getCharacter();
    }
}

// Éditeur de texte utilisant le pattern Flyweight
class TextEditor {
    private List<TextCharacter> characters = new ArrayList<>();
    private String[] fonts = {"Arial", "Times", "Helvetica", "Courier"};
    private String[] colors = {"black", "red", "blue", "green", "purple"};
    private Random random = new Random();
    
    public void addText(String text, int startX, int startY, String font, int size, String color) {
        System.out.println("📄 Ajout du texte: '" + text + "' à (" + startX + ", " + startY + ")");
        
        int currentX = startX;
        int currentY = startY;
        
        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            String charStr = String.valueOf(ch);
            
            if (ch == ' ') {
                currentX += size / 2; // Espacement pour les espaces
                continue;
            }
            
            if (ch == '\n') {
                currentX = startX;
                currentY += size + 4; // Interligne
                continue;
            }
            
            // Obtention du flyweight pour le caractère
            CharacterFlyweight flyweight = CharacterFactory.getCharacter(charStr);
            
            // Création du contexte avec l'état extrinsèque
            TextCharacter textChar = new TextCharacter(currentX, currentY, font, size, color, flyweight);
            characters.add(textChar);
            
            currentX += (int)(size * 0.6); // Espacement entre caractères
        }
    }
    
    public void addFormattedText(String text, int x, int y) {
        System.out.println("🎨 Ajout de texte formaté avec styles variés");
        
        String[] words = text.split(" ");
        int currentX = x;
        int currentY = y;
        
        for (String word : words) {
            // Style aléatoire pour chaque mot
            String font = fonts[random.nextInt(fonts.length)];
            String color = colors[random.nextInt(colors.length)];
            int size = 10 + random.nextInt(7); // 10-16
            
            addText(word + " ", currentX, currentY, font, size, color);
            currentX += word.length() * size * 0.6 + size; // Espacement entre mots
        }
    }
    
    public void render() {
        System.out.println("🎬 Rendu de " + characters.size() + " caractères");
        
        for (TextCharacter character : characters) {
            character.render();
        }
    }
    
    public Map<String, Object> getStats() {
        Map<String, Object> flyweightStats = CharacterFactory.getStats();
        
        // Estimation de la mémoire (en bytes)
        int characterDataSize = 48; // x, y, font, size, color, reference
        int flyweightDataSize = 128; // character, bitmap
        
        int withFlyweight =
            characters.size() * characterDataSize +
            (Integer)flyweightStats.get("created") * flyweightDataSize;
            
        int withoutFlyweight =
            characters.size() * (characterDataSize + flyweightDataSize);
        
        double savings = withoutFlyweight > 0 ? ((double)(withoutFlyweight - withFlyweight) / withoutFlyweight) * 100 : 0;
        
        Map<String, Object> stats = new HashMap<>();
        stats.put("totalCharacters", characters.size());
        stats.put("flyweightStats", flyweightStats);
        
        Map<String, Object> memoryEstimate = new HashMap<>();
        memoryEstimate.put("withFlyweight", withFlyweight);
        memoryEstimate.put("withoutFlyweight", withoutFlyweight);
        memoryEstimate.put("savings", savings);
        stats.put("memoryEstimate", memoryEstimate);
        
        return stats;
    }
    
    public void clear() {
        characters.clear();
    }
    
    public int getCharacterCount() {
        return characters.size();
    }
}

⚖️ Avantages et Inconvénients

✅ Avantages

  • Économie de mémoire : Réduction drastique de l'utilisation mémoire
  • Performance améliorée : Moins d'allocations et de garbage collection
  • Partage efficace : Réutilisation maximale des objets similaires
  • Scalabilité : Gestion de très grandes quantités d'objets
  • Cache naturel : Les flyweights agissent comme un cache

❌ Inconvénients

  • Complexité accrue : Séparation état intrinsèque/extrinsèque
  • Overhead initial : Coût de mise en place du pattern
  • Debugging difficile : État partagé complique le débogage
  • Thread-safety : Gestion de la concurrence nécessaire
  • Cas d'usage limités : Efficace seulement avec beaucoup d'objets

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Systèmes de particules : Milliers de particules similaires
  • Éditeurs de texte : Caractères avec formatage
  • Jeux vidéo : Sprites, tiles, objets répétitifs
  • Interfaces graphiques : Icônes, boutons similaires
  • Données géographiques : Points d'intérêt similaires

❌ Quand l'éviter

  • Peu d'objets : Moins de 1000 instances
  • Objets très différents : Peu de données communes
  • État principalement extrinsèque : Peu de partage possible
  • Applications simples : Complexité non justifiée
  • Prototypage rapide : Optimisation prématurée

🚫 Anti-Patterns Associés

Erreurs courantes lors de l'implémentation du pattern Flyweight.

❌ Flyweight Inutile

Problème : Utiliser Flyweight avec peu d'objets ou objets très différents

// ❌ Mauvais : Seulement 3 utilisateurs
class UserFlyweight {
    constructor(name, email) {
        this.name = name;
        this.email = email;
    }
}

const users = [
    new UserFlyweight("Alice", "alice@example.com"),
    new UserFlyweight("Bob", "bob@example.com"),
    new UserFlyweight("Charlie", "charlie@example.com")
];

Solution : Utiliser des objets normaux pour de petites quantités

❌ État Extrinsèque dans Flyweight

Problème : Stocker l'état variable dans le flyweight

// ❌ Mauvais : Position stockée dans flyweight
class ParticleFlyweight {
    constructor(type) {
        this.type = type;
        this.x = 0; // ❌ État extrinsèque !
        this.y = 0; // ❌ État extrinsèque !
    }
}

Solution : Séparer clairement état intrinsèque et extrinsèque

❌ Factory Non Thread-Safe

Problème : Accès concurrent non protégé à la factory

// ❌ Mauvais : Race condition possible
class FlyweightFactory {
    static flyweights = new Map();
    
    static getFlyweight(key) {
        if (!this.flyweights.has(key)) {
            // ❌ Race condition ici !
            this.flyweights.set(key, new Flyweight(key));
        }
        return this.flyweights.get(key);
    }
}

Solution : Utiliser des structures thread-safe ou des verrous

❌ Flyweight Mutable

Problème : Permettre la modification de l'état intrinsèque

// ❌ Mauvais : Flyweight modifiable
class CharacterFlyweight {
    constructor(char) {
        this.character = char;
    }
    
    // ❌ Permet de modifier l'état partagé !
    setCharacter(newChar) {
        this.character = newChar;
    }
}

Solution : Rendre les flyweights immutables
