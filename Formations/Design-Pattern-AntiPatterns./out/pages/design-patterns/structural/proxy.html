🛡️ Proxy Pattern

Contrôler l'accès à un objet via un substitut

🎨 Design Patterns
⭐ Difficulté: Moyen
⏱️ 20 min
🏗️ Structurel

🎯 Définition

Le Proxy est un pattern structurel qui fournit un substitut ou un placeholder pour un autre objet afin de contrôler l'accès à celui-ci.

❌ Problème Résolu

  • Contrôler l'accès à un objet coûteux à créer
  • Ajouter une couche de sécurité ou de validation
  • Implémenter le lazy loading pour optimiser les performances
  • Mettre en cache les résultats d'opérations coûteuses

✅ Solution Apportée

  • Interface identique à l'objet réel
  • Contrôle d'accès transparent
  • Optimisation des performances
  • Fonctionnalités supplémentaires sans modification
💡 Astuce : Le Proxy agit comme un intermédiaire intelligent qui peut ajouter des fonctionnalités (cache, sécurité, logging) sans modifier l'objet original.

🏗️ Structure UML

<<interface>>
Subject
+ request(): void
RealSubject
+ request(): void
Proxy
- realSubject: RealSubject
+ request(): void
- checkAccess(): boolean
- logAccess(): void

Éléments Clés

  • Subject : Interface commune au RealSubject et au Proxy
  • RealSubject : Objet réel que le proxy représente
  • Proxy : Maintient une référence au RealSubject et contrôle l'accès
  • checkAccess() : Vérifie les permissions avant d'accéder au RealSubject

💡 Point clé : Le Proxy intercepte tous les appels et peut ajouter des contrôles, optimisations ou fonctionnalités avant de déléguer.

interface DataService {
    fetchUserData(userId: string): Promise<UserData>;
    fetchUserPosts(userId: string): Promise<Post[]>;
}

interface UserData {
    id: string;
    name: string;
    email: string;
    avatar: string;
}

interface Post {
    id: string;
    title: string;
    content: string;
    createdAt: Date;
}

// Service réel qui fait les appels API
class RealApiService implements DataService {
    private baseUrl = "https://api.example.com";
    
    async fetchUserData(userId: string): Promise<UserData> {
        console.log(`🌐 Appel API réel pour utilisateur ${userId}`);
        
        // Simulation d'un appel API lent
        await this.delay(2000);
        
        const response = await fetch(`${this.baseUrl}/users/${userId}`);
        if (!response.ok) {
            throw new Error(`Erreur API: ${response.status}`);
        }
        
        return response.json();
    }
    
    async fetchUserPosts(userId: string): Promise<Post[]> {
        console.log(`🌐 Appel API réel pour posts de ${userId}`);
        
        await this.delay(1500);
        
        const response = await fetch(`${this.baseUrl}/users/${userId}/posts`);
        if (!response.ok) {
            throw new Error(`Erreur API: ${response.status}`);
        }
        
        return response.json();
    }
    
    private delay(ms: number): Promise<void> {
        return new Promise(resolve => setTimeout(resolve, ms));
    }
}

// Proxy avec cache et contrôle d'accès
class CachedApiProxy implements DataService {
    private realService: RealApiService;
    private cache = new Map<string, { data: any; timestamp: number; ttl: number }>();
    private accessLog: string[] = [];
    private maxRequestsPerMinute = 10;
    private requestCounts = new Map<string, { count: number; resetTime: number }>();
    
    constructor() {
        this.realService = new RealApiService();
    }
    
    async fetchUserData(userId: string): Promise<UserData> {
        // Vérification du rate limiting
        if (!this.checkRateLimit(userId)) {
            throw new Error("Rate limit dépassé. Réessayez plus tard.");
        }
        
        // Vérification du cache
        const cacheKey = `user:${userId}`;
        const cached = this.getFromCache(cacheKey);
        
        if (cached) {
            console.log(`💾 Données utilisateur ${userId} servies depuis le cache`);
            this.logAccess(`Cache hit: ${cacheKey}`);
            return cached;
        }
        
        // Appel au service réel
        console.log(`⏳ Cache miss, appel du service réel pour ${userId}`);
        const userData = await this.realService.fetchUserData(userId);
        
        // Mise en cache (TTL: 5 minutes)
        this.setCache(cacheKey, userData, 5 * 60 * 1000);
        this.logAccess(`API call: ${cacheKey}`);
        
        return userData;
    }
    
    async fetchUserPosts(userId: string): Promise<Post[]> {
        if (!this.checkRateLimit(userId)) {
            throw new Error("Rate limit dépassé. Réessayez plus tard.");
        }
        
        const cacheKey = `posts:${userId}`;
        const cached = this.getFromCache(cacheKey);
        
        if (cached) {
            console.log(`💾 Posts de ${userId} servis depuis le cache`);
            this.logAccess(`Cache hit: ${cacheKey}`);
            return cached;
        }
        
        console.log(`⏳ Cache miss, appel du service réel pour posts de ${userId}`);
        const posts = await this.realService.fetchUserPosts(userId);
        
        // Cache plus court pour les posts (2 minutes)
        this.setCache(cacheKey, posts, 2 * 60 * 1000);
        this.logAccess(`API call: ${cacheKey}`);
        
        return posts;
    }
    
    private checkRateLimit(userId: string): boolean {
        const now = Date.now();
        const userKey = `rate:${userId}`;
        const userRate = this.requestCounts.get(userKey);
        
        if (!userRate || now > userRate.resetTime) {
            // Nouveau compteur ou reset
            this.requestCounts.set(userKey, {
                count: 1,
                resetTime: now + 60000 // Reset dans 1 minute
            });
            return true;
        }
        
        if (userRate.count >= this.maxRequestsPerMinute) {
            return false;
        }
        
        userRate.count++;
        return true;
    }
    
    private getFromCache(key: string): any | null {
        const cached = this.cache.get(key);
        
        if (!cached) {
            return null;
        }
        
        if (Date.now() > cached.timestamp + cached.ttl) {
            this.cache.delete(key);
            return null;
        }
        
        return cached.data;
    }
    
    private setCache(key: string, data: any, ttl: number): void {
        this.cache.set(key, {
            data,
            timestamp: Date.now(),
            ttl
        });
    }
    
    private logAccess(action: string): void {
        const timestamp = new Date().toISOString();
        this.accessLog.push(`[${timestamp}] ${action}`);
        
        // Garder seulement les 100 derniers logs
        if (this.accessLog.length > 100) {
            this.accessLog.shift();
        }
    }
    
    // Méthodes utilitaires pour monitoring
    getCacheStats(): { size: number; hitRate: number } {
        const hits = this.accessLog.filter(log => log.includes('Cache hit')).length;
        const total = this.accessLog.length;
        
        return {
            size: this.cache.size,
            hitRate: total > 0 ? (hits / total) * 100 : 0
        };
    }
    
    clearCache(): void {
        this.cache.clear();
        console.log("🗑️ Cache vidé");
    }
}

// Utilisation
async function demonstrateProxy() {
    const apiService: DataService = new CachedApiProxy();
    
    try {
        console.log("=== Premier appel ===");
        const user1 = await apiService.fetchUserData("123");
        console.log("Utilisateur:", user1.name);
        
        console.log("\n=== Deuxième appel (même utilisateur) ===");
        const user2 = await apiService.fetchUserData("123"); // Depuis le cache
        console.log("Utilisateur:", user2.name);
        
        console.log("\n=== Appel pour les posts ===");
        const posts = await apiService.fetchUserPosts("123");
        console.log(`Posts trouvés: ${posts.length}`);
        
        // Affichage des stats
        if (apiService instanceof CachedApiProxy) {
            const stats = apiService.getCacheStats();
            console.log(`\n📊 Stats cache: ${stats.size} entrées, ${stats.hitRate.toFixed(1)}% hit rate`);
        }
        
    } catch (error) {
        console.error("Erreur:", error.message);
    }
}

// Service réel qui charge les images
class RealImageLoader implements ImageLoader {
    private string $basePath;
    
    public function __construct(string $basePath = './images/') {
        $this->basePath = $basePath;
    }
    
    public function loadImage(string $filename): string {
        $filepath = $this->basePath . $filename;
        
        echo "🖼️ Chargement réel de l'image: {$filename}\n";
        
        if (!file_exists($filepath)) {
            throw new Exception("Image non trouvée: {$filename}");
        }
        
        // Simulation d'un chargement coûteux
        sleep(1);
        
        return base64_encode(file_get_contents($filepath));
    }
    
    public function getImageInfo(string $filename): array {
        $filepath = $this->basePath . $filename;
        
        if (!file_exists($filepath)) {
            throw new Exception("Image non trouvée: {$filename}");
        }
        
        $info = getimagesize($filepath);
        
        return [
            'width' => $info[0],
            'height' => $info[1],
            'type' => $info['mime'],
            'size' => filesize($filepath)
        ];
    }
}

// Proxy avec lazy loading et cache
class LazyImageProxy implements ImageLoader {
    private ?RealImageLoader $realLoader = null;
    private array $cache = [];
    private array $accessLog = [];
    private int $maxCacheSize = 50;
    
    public function loadImage(string $filename): string {
        // Vérification des permissions
        if (!$this->checkAccess($filename)) {
            throw new Exception("Accès refusé à l'image: {$filename}");
        }
        
        // Vérification du cache
        $cacheKey = "image:{$filename}";
        if (isset($this->cache[$cacheKey])) {
            echo "💾 Image {$filename} servie depuis le cache\n";
            $this->logAccess("Cache hit: {$filename}");
            return $this->cache[$cacheKey]['data'];
        }
        
        // Lazy loading du service réel
        if ($this->realLoader === null) {
            echo "🔧 Initialisation du loader réel\n";
            $this->realLoader = new RealImageLoader();
        }
        
        // Chargement de l'image
        $imageData = $this->realLoader->loadImage($filename);
        
        // Mise en cache
        $this->addToCache($cacheKey, $imageData);
        $this->logAccess("Image loaded: {$filename}");
        
        return $imageData;
    }
    
    public function getImageInfo(string $filename): array {
        if (!$this->checkAccess($filename)) {
            throw new Exception("Accès refusé à l'image: {$filename}");
        }
        
        $cacheKey = "info:{$filename}";
        if (isset($this->cache[$cacheKey])) {
            echo "💾 Info {$filename} servie depuis le cache\n";
            return $this->cache[$cacheKey]['data'];
        }
        
        if ($this->realLoader === null) {
            $this->realLoader = new RealImageLoader();
        }
        
        $info = $this->realLoader->getImageInfo($filename);
        $this->addToCache($cacheKey, $info);
        
        return $info;
    }
    
    private function checkAccess(string $filename): bool {
        // Vérification de sécurité basique
        if (strpos($filename, '..') !== false) {
            return false;
        }
        
        // Vérification des extensions autorisées
        $allowedExtensions = ['jpg', 'jpeg', 'png', 'gif', 'webp'];
        $extension = strtolower(pathinfo($filename, PATHINFO_EXTENSION));
        
        return in_array($extension, $allowedExtensions);
    }
    
    private function addToCache(string $key, $data): void {
        // Éviction si le cache est plein
        if (count($this->cache) >= $this->maxCacheSize) {
            $oldestKey = array_key_first($this->cache);
            unset($this->cache[$oldestKey]);
            echo "🗑️ Éviction du cache: {$oldestKey}\n";
        }
        
        $this->cache[$key] = [
            'data' => $data,
            'timestamp' => time()
        ];
    }
    
    private function logAccess(string $action): void {
        $this->accessLog[] = [
            'action' => $action,
            'timestamp' => date('Y-m-d H:i:s'),
            'memory' => memory_get_usage(true)
        ];
        
        // Garder seulement les 100 derniers logs
        if (count($this->accessLog) > 100) {
            array_shift($this->accessLog);
        }
    }
    
    public function getCacheStats(): array {
        $hits = array_filter($this->accessLog, function($log) {
            return strpos($log['action'], 'Cache hit') === 0;
        });
        
        $total = count($this->accessLog);
        $hitRate = $total > 0 ? (count($hits) / $total) * 100 : 0;
        
        return [
            'cache_size' => count($this->cache),
            'max_size' => $this->maxCacheSize,
            'hit_rate' => round($hitRate, 2),
            'total_requests' => $total
        ];
    }
    
    public function clearCache(): void {
        $this->cache = [];
        echo "🗑️ Cache vidé\n";
    }
}

// Interface commune
interface DatabaseConnection {
    ResultSet executeQuery(String sql) throws SQLException;
    int executeUpdate(String sql) throws SQLException;
    void close() throws SQLException;
}

// Connexion réelle à la base de données
class RealDatabaseConnection implements DatabaseConnection {
    private Connection connection;
    private String url;
    private String username;
    private String password;
    
    public RealDatabaseConnection(String url, String username, String password) 
            throws SQLException {
        this.url = url;
        this.username = username;
        this.password = password;
        
        System.out.println("🔌 Établissement de la connexion réelle à la DB");
        this.connection = DriverManager.getConnection(url, username, password);
    }
    
    @Override
    public ResultSet executeQuery(String sql) throws SQLException {
        System.out.println("🔍 Exécution requête: " + sql);
        Statement stmt = connection.createStatement();
        return stmt.executeQuery(sql);
    }
    
    @Override
    public int executeUpdate(String sql) throws SQLException {
        System.out.println("✏️ Exécution mise à jour: " + sql);
        Statement stmt = connection.createStatement();
        return stmt.executeUpdate(sql);
    }
    
    @Override
    public void close() throws SQLException {
        if (connection != null && !connection.isClosed()) {
            connection.close();
            System.out.println("🔌 Connexion fermée");
        }
    }
}

// Proxy avec contrôle d'accès et cache
class SecureDatabaseProxy implements DatabaseConnection {
    private RealDatabaseConnection realConnection;
    private String url;
    private String username;
    private String password;
    private Set<String> allowedUsers;
    private Map<String, CachedResult> queryCache;
    private List<String> accessLog;
    private int maxCacheSize = 100;
    private long cacheTimeout = 300000; // 5 minutes
    
    public SecureDatabaseProxy(String url, String username, String password) {
        this.url = url;
        this.username = username;
        this.password = password;
        this.allowedUsers = new HashSet<>();
        this.queryCache = new LinkedHashMap<>();
        this.accessLog = new ArrayList<>();
        
        // Configuration des utilisateurs autorisés
        allowedUsers.add("admin");
        allowedUsers.add("readonly");
        allowedUsers.add("analyst");
    }
    
    @Override
    public ResultSet executeQuery(String sql) throws SQLException {
        // Vérification des permissions
        if (!checkAccess(sql)) {
            logAccess("DENIED: " + sql);
            throw new SQLException("Accès refusé à cette requête");
        }
        
        // Vérification du cache pour les SELECT
        if (sql.trim().toUpperCase().startsWith("SELECT")) {
            String cacheKey = sql.toLowerCase().trim();
            CachedResult cached = queryCache.get(cacheKey);
            
            if (cached != null && !cached.isExpired()) {
                System.out.println("💾 Résultat servi depuis le cache");
                logAccess("CACHE_HIT: " + sql);
                return cached.getResultSet();
            }
        }
        
        // Lazy loading de la connexion réelle
        if (realConnection == null) {
            realConnection = new RealDatabaseConnection(url, username, password);
        }
        
        ResultSet result = realConnection.executeQuery(sql);
        
        // Mise en cache des SELECT
        if (sql.trim().toUpperCase().startsWith("SELECT")) {
            cacheQuery(sql, result);
        }
        
        logAccess("QUERY: " + sql);
        return result;
    }
    
    @Override
    public int executeUpdate(String sql) throws SQLException {
        // Vérifications de sécurité renforcées pour les modifications
        if (!checkWriteAccess(sql)) {
            logAccess("DENIED_WRITE: " + sql);
            throw new SQLException("Accès en écriture refusé");
        }
        
        if (realConnection == null) {
            realConnection = new RealDatabaseConnection(url, username, password);
        }
        
        int result = realConnection.executeUpdate(sql);
        
        // Invalidation du cache après modification
        invalidateCache();
        
        logAccess("UPDATE: " + sql + " (affected: " + result + " rows)");
        return result;
    }
    
    @Override
    public void close() throws SQLException {
        if (realConnection != null) {
            realConnection.close();
            realConnection = null;
        }
        logAccess("CONNECTION_CLOSED");
    }
    
    private boolean checkAccess(String sql) {
        // Vérification basique des mots-clés dangereux
        String upperSql = sql.toUpperCase();
        // Interdire certaines opérations
        String[] forbiddenKeywords = {"DROP", "TRUNCATE", "ALTER", "CREATE"};
        
        for (String keyword : forbiddenKeywords) {
            if (upperSql.contains(keyword)) {
                return false;
            }
        }
        
        return true;
    }
    
    private boolean checkWriteAccess(String sql) {
        // Vérifications supplémentaires pour les opérations d'écriture
        if (!allowedUsers.contains(username)) {
            return false;
        }
        
        // Interdire les opérations de structure
        String upperSql = sql.toUpperCase();
        return !upperSql.contains("DROP") && !upperSql.contains("TRUNCATE");
    }
    
    private void cacheQuery(String sql, ResultSet resultSet) {
        if (queryCache.size() >= maxCacheSize) {
            // Éviction LRU
            String oldestKey = queryCache.keySet().iterator().next();
            queryCache.remove(oldestKey);
        }
        
        try {
            queryCache.put(sql.toLowerCase().trim(), new CachedResult(resultSet));
        } catch (SQLException e) {
            System.err.println("Erreur lors de la mise en cache: " + e.getMessage());
        }
    }
    
    private void invalidateCache() {
        queryCache.clear();
        System.out.println("🗑️ Cache invalidé après modification");
    }
    
    private void logAccess(String action) {
        String timestamp = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(new Date());
        accessLog.add(String.format("[%s] %s", timestamp, action));
        
        // Garder seulement les 1000 derniers logs
        if (accessLog.size() > 1000) {
            accessLog.remove(0);
        }
    }
    
    // Classe interne pour le cache
    private static class CachedResult {
        private final ResultSet resultSet;
        private final long timestamp;
        
        public CachedResult(ResultSet resultSet) throws SQLException {
            this.resultSet = resultSet;
            this.timestamp = System.currentTimeMillis();
        }
        
        public boolean isExpired() {
            return System.currentTimeMillis() - timestamp > 300000; // 5 minutes
        }
        
        public ResultSet getResultSet() {
            return resultSet;
        }
    }
    
    // Méthodes utilitaires
    public void printAccessLog() {
        System.out.println("=== Log d'accès ===");
        accessLog.forEach(System.out::println);
    }
    
    public Map getStats() {
        Map stats = new HashMap<>();
        stats.put("cache_size", queryCache.size());
        stats.put("max_cache_size", maxCacheSize);
        stats.put("total_requests", accessLog.size());
        stats.put("connection_active", realConnection != null);
        
        return stats;
    }
}

public class DatabaseProxyDemo {
    public static void main(String[] args) {
        SecureDatabaseProxy dbProxy = new SecureDatabaseProxy(
            "jdbc:mysql://localhost:3306/myapp",

            "password"
        );

            System.out.println("=== Premier appel ===");

            System.out.println("\n=== Tentative d'opération interdite ===");

                dbProxy.executeUpdate("DROP TABLE users");
            } catch (SQLException e) {
                System.out.println("Sécurité OK: " + e.getMessage());

            System.out.println("\n=== Statistiques ===");

            stats.forEach((key, value) ->
                System.out.println(key + ": " + value));
            
        } catch (SQLException e) {
            System.err.println("Erreur: " + e.getMessage());
        } finally {
            try {
                dbProxy.close();
            } catch (SQLException e) {
                System.err.println("Erreur fermeture: " + e.getMessage());
            }
        }
    }

⚖️ Avantages et Inconvénients

✅ Avantages

  • Contrôle d'accès : Sécurité et validation transparentes
  • Lazy loading : Création différée des objets coûteux
  • Cache intelligent : Optimisation des performances
  • Logging et monitoring : Traçabilité des accès
  • Interface identique : Transparence pour le client

❌ Inconvénients

  • Complexité ajoutée : Couche supplémentaire à maintenir
  • Latence potentielle : Vérifications avant chaque appel
  • Consommation mémoire : Cache et logs en mémoire
  • Gestion d'erreurs : Propagation des exceptions complexe
  • Synchronisation : Problèmes de concurrence possibles

🎯 Cas d'Usage Appropriés

✅ Quand l'utiliser

  • Lazy loading : Objets coûteux à créer
  • Contrôle d'accès : Sécurité et permissions
  • Cache : Optimisation des appels répétés
  • Logging : Traçabilité des opérations
  • Rate limiting : Limitation du nombre d'appels

❌ Quand l'éviter

  • Objets simples : Pas de bénéfice apparent
  • Performance critique : Latence inacceptable
  • Interface instable : Changements fréquents
  • Logique complexe : Proxy devient trop intelligent
  • Tests unitaires : Complexification des mocks

🔄 Alternatives et Patterns Liés

🎭 Decorator Pattern

Ajouter des fonctionnalités sans contrôler l'accès

// Enrichit l'objet au lieu de le contrôler new LoggingDecorator(new CacheDecorator(service));

🏗️ Facade Pattern

Simplifier l'interface au lieu de la contrôler

// Interface simplifiée pour système complexe facade.processOrder(orderData);

🔗 Adapter Pattern

Adapter l'interface au lieu de la contrôler

// Adaptation d'interface incompatible new DatabaseAdapter(legacyDatabase);

⚡ Optimisation Prématurée

Manifestation : "Ce proxy avec cache va optimiser les performances."

Risque : Ajouter de la complexité avant de mesurer un réel besoin de performance.

🔨 Marteau de Maslow

Manifestation : "Le Proxy résout tous les problèmes de contrôle d'accès."

Risque : Utiliser systématiquement des proxies même quand d'autres solutions sont plus simples.

⚠️ Anti-Patterns à Éviter

🧠 Smart Proxy

Un proxy qui devient trop intelligent et accumule trop de logique métier.

// ❌ Mauvais : Proxy qui fait trop de choses class SmartProxy { // Cache, sécurité, validation, transformation, logging, metrics... }

🔄 Proxy Chain

Chaîner trop de proxies créant une complexité excessive.

// ❌ Chaîne de proxies difficile à déboguer new SecurityProxy(new CacheProxy(new LogProxy(new RealService())));

Scenario : Service de Téléchargement de Fichiers
