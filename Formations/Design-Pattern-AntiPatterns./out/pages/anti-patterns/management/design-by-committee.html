🏛️ Design by Committee

L'anti-pattern de la conception par consensus qui dilue la vision

👥 Anti-Pattern organisationnel
⏱️ ~25 minutes
🎯 Gouvernance essentielle
🧩 5 biais cognitifs liés

🎯 Définition

Le Design by Committee est un anti-pattern de management où les décisions de conception sont prises par un groupe nombreux cherchant le consensus, résultant en des solutions diluées, incohérentes et souvent médiocres. Chaque membre du comité veut voir ses idées intégrées, créant un produit final qui tente de satisfaire tout le monde mais ne satisfait personne pleinement.

❌ Problèmes Causés

  • Vision produit diluée et incohérente
  • Compromis qui affaiblissent la solution
  • Processus de décision lent et laborieux
  • Architecture complexe et sur-conçue
  • Responsabilité diffuse et déresponsabilisation

✅ Solutions Apportées

  • Désignation d'un architecte principal
  • Processus de décision structuré
  • Rôles et responsabilités clairs
  • Consultation ciblée des experts
  • Vision produit unifiée et documentée
⚠️ Attention : Le Design by Committee peut sembler démocratique et inclusif, mais il conduit souvent à des solutions médiocres qui ne résolvent aucun problème efficacement.

🧠 Biais Cognitifs Associés

Le Design by Committee résulte de plusieurs biais cognitifs qui favorisent le consensus au détriment de l'efficacité :

🤝

Biais de Conformité Sociale

Manifestation : "Il faut que tout le monde soit d'accord avant de décider"

La tendance à chercher l'approbation du groupe plutôt que de prendre des décisions tranchées mais nécessaires.

Exemple : Multiplier les réunions de validation jusqu'à obtenir un consensus mou qui satisfait superficiellement chacun.
⚖️

Biais de Faux Consensus

Manifestation : "Si on intègre l'idée de chacun, ce sera forcément mieux"

Croire qu'additionner les idées de tous produit automatiquement une meilleure solution que celle d'un expert unique.

Exemple : Créer une interface avec 15 fonctionnalités différentes pour satisfaire les demandes de chaque département.
🎭

Biais de Responsabilité Diffuse

Manifestation : "Ce n'est pas ma faute, c'est une décision collective"

Quand la responsabilité est partagée entre tous, personne ne se sent vraiment responsable du résultat final.

Exemple : Éviter de prendre position sur des choix techniques controversés en les renvoyant au "comité d'architecture".
🏛️

Biais d'Autorité Distribuée

Manifestation : "Chaque expert doit valider sa partie"

Croire qu'il faut l'aval de tous les experts pour légitimer une décision, même quand leurs domaines ne se recoupent pas.

Exemple : Demander l'avis du DBA sur l'UX et celui du designer sur l'architecture de données.
🎯

Biais de Compromis

Manifestation : "Trouvons un juste milieu qui convient à tous"

Privilégier systématiquement les solutions moyennes qui évitent les conflits plutôt que les solutions optimales mais potentiellement controversées.

Exemple : Choisir une technologie "neutre" que personne n'aime vraiment plutôt qu'une solution excellente mais clivante.

    @PostMapping("/create-complete")
    public ResponseEntity createCompleteUser(
            @RequestBody CreateUserRequest request,
            @RequestParam(defaultValue = "web") String source,
            @RequestParam(defaultValue = "json") String format,
            @RequestParam(defaultValue = "full") String profile,
            @RequestParam(defaultValue = "true") boolean trackAnalytics,
            @RequestParam(defaultValue = "true") boolean sendNotifications,
            @RequestParam(defaultValue = "true") boolean createSupportTicket,
            @RequestParam(defaultValue = "true") boolean assignSegments,
            @RequestParam(defaultValue = "false") boolean generateReports,
            @RequestParam(defaultValue = "true") boolean enableCaching,
            @RequestParam(defaultValue = "true") boolean auditLog,
            @RequestParam(defaultValue = "false") boolean syncExternalSystems,
            HttpServletRequest httpRequest) {
        
        try {
            // Validation multi-niveaux demandée par Security
            ValidationResult basicValidation = validationService.validateBasic(request);
            ValidationResult securityValidation = securityService.validateSecurity(request);
            ValidationResult complianceValidation = complianceService.validateCompliance(request);
            ValidationResult businessValidation = userService.validateBusiness(request);
            
            if (!basicValidation.isValid() || !securityValidation.isValid() || 
                !complianceValidation.isValid() || !businessValidation.isValid()) {
                return ResponseEntity.badRequest().body(
                    CompleteUserResponse.error("Validation failed")
                );
            }
            
            // Création utilisateur avec tous les enrichissements
            User user = userService.createUser(request);
            
            // Analytics demandé par Data Team
            if (trackAnalytics) {
                analyticsService.trackUserCreation(user, source);
                analyticsService.trackConversion(user, "registration");
                analyticsService.updateFunnel(user, "completed_registration");
            }
            
            // Segmentation demandée par Marketing
            if (assignSegments) {
                List segments = marketingService.assignSegments(user);
                marketingService.triggerWelcomeCampaign(user, segments);
            }
            
            // Support ticket demandé par Customer Success
            SupportTicket ticket = null;
            if (createSupportTicket) {
                ticket = supportService.createWelcomeTicket(user);
                supportService.assignToOnboardingAgent(ticket);
            }
            
            // Notifications demandées par Product
            if (sendNotifications) {
                notificationService.sendWelcomeEmail(user);
                notificationService.sendSMSVerification(user);
                notificationService.scheduleOnboardingSequence(user);
            }
            
            // Rapports demandés par Business Intelligence
            UserReports reports = null;
            if (generateReports) {
                reports = reportingService.generateUserReports(user);
            }
            
            // Cache demandé par Performance Team
            if (enableCaching) {
                cacheService.cacheUser(user);
                cacheService.preloadRelatedData(user);
            }
            
            // Audit demandé par Compliance
            if (auditLog) {
                auditService.logUserCreation(user, httpRequest);
                auditService.logDataProcessing(user, "creation");
            }
            
            // Synchronisation externe demandée par Integration Team
            if (syncExternalSystems) {
                integrationService.syncWithCRM(user);
                integrationService.syncWithERP(user);
                integrationService.syncWithBI(user);
            }
            
            // Monitoring demandé par DevOps
            monitoringService.recordMetric("user.created", 1);
            monitoringService.recordLatency("user.creation", System.currentTimeMillis());
            
            // Construction de la réponse "complète"
            CompleteUserResponse response = CompleteUserResponse.builder()
                .user(user)
                .profile(profile.equals("light") ? user.toLightProfile() : user.toFullProfile())
                .segments(assignSegments ? marketingService.getUserSegments(user) : null)
                .supportTicket(ticket)
                .reports(reports)
                .analytics(trackAnalytics ? analyticsService.getUserAnalytics(user) : null)
                .notifications(sendNotifications ? notificationService.getNotificationStatus(user) : null)
                .integrationStatus(syncExternalSystems ? integrationService.getSyncStatus(user) : null)
                .cacheStatus(enableCaching ? cacheService.getCacheStatus(user) : null)
                .auditTrail(auditLog ? auditService.getAuditTrail(user) : null)
                .build();
            
            return ResponseEntity.ok(response);
            
        } catch (Exception e) {
            // Gestion d'erreur "complète" demandée par tous
            monitoringService.recordError("user.creation.failed", e);
            auditService.logError("user_creation", e, httpRequest);
            return ResponseEntity.status(500).body(
                CompleteUserResponse.error("Internal server error: " + e.getMessage())
            );
        }
    }

        $user->update($request);

        $this->eventDispatcher->dispatch(new UserUpdatedEvent($user));
        
        return $user;
    }

        $result = $this->repository->delete($user);
        
        if ($result) {
            $this->eventDispatcher->dispatch(new UserDeletedEvent($user));
        }

class UserController {
    private UserService $userService;
    
    public function __construct(UserService $userService) {
        $this->userService = $userService;
    }
    
    public function create(CreateUserRequest $request): JsonResponse {
        try {
            $user = $this->userService->createUser($request);
            return new JsonResponse(['user' => $user->toArray()], 201);
        } catch (ValidationException $e) {
            return new JsonResponse(['error' => $e->getMessage()], 400);
        } catch (Exception $e) {
            return new JsonResponse(['error' => 'Internal server error'], 500);
        }
    }
    
    public function show(string $userId): JsonResponse {
        try {
            $user = $this->userService->getUser($userId);
            return new JsonResponse(['user' => $user->toArray()]);
        } catch (UserNotFoundException $e) {
            return new JsonResponse(['error' => 'User not found'], 404);
        }
    }
    
    public function update(string $userId, UpdateUserRequest $request): JsonResponse {
        try {
            $user = $this->userService->updateUser($userId, $request);
            return new JsonResponse(['user' => $user->toArray()]);
        } catch (ValidationException $e) {
            return new JsonResponse(['error' => $e->getMessage()], 400);
        } catch (UserNotFoundException $e) {
            return new JsonResponse(['error' => 'User not found'], 404);
        }
    }
    
    public function delete(string $userId): JsonResponse {
        try {
            $this->userService->deleteUser($userId);
            return new JsonResponse(null, 204);
        } catch (UserNotFoundException $e) {
            return new JsonResponse(['error' => 'User not found'], 404);
        }
    }
}

// 1. Domain Layer - Décision de l'architecte principal
@Entity
public class User {
    @Id
    private String id;
    private String email;
    private String name;
    private LocalDateTime createdAt;
    private UserStatus status;
    
    // Logique métier pure, sans dépendances externes
    public void activate() {
        if (this.status == UserStatus.PENDING) {
            this.status = UserStatus.ACTIVE;
        } else {
            throw new IllegalStateException("Cannot activate user in status: " + this.status);
        }
    }
    
    public void deactivate() {
        if (this.status == UserStatus.ACTIVE) {
            this.status = UserStatus.INACTIVE;
        } else {
            throw new IllegalStateException("Cannot deactivate user in status: " + this.status);
        }
    }
    
    public boolean canLogin() {
        return this.status == UserStatus.ACTIVE;
    }
}

        this.eventPublisher = eventPublisher;
    }
    
    public User createUser(CreateUserCommand command) {
        // 1. Validation
        userValidator.validate(command);
        
        // 2. Création
        User user = new User(
            UUID.randomUUID().toString(),
            command.getEmail(),
            command.getName(),
            LocalDateTime.now(),
            UserStatus.PENDING
        );
        
        // 3. Persistance
        user = userRepository.save(user);
        
        // 4. Événement - les autres services s'abonnent
        eventPublisher.publishEvent(new UserCreatedEvent(user));
        
        return user;
    }
    
    public User getUserById(String userId) {
        return userRepository.findById(userId)
            .orElseThrow(() -> new UserNotFoundException("User not found: " + userId));
    }
    
    public User updateUser(String userId, UpdateUserCommand command) {
        User user = getUserById(userId);
        userValidator.validateUpdate(command, user);
        
        user.updateFrom(command);
        user = userRepository.save(user);
        
        eventPublisher.publishEvent(new UserUpdatedEvent(user));
        
        return user;
    }
    
    public void deleteUser(String userId) {
        User user = getUserById(userId);
        userRepository.delete(user);
        
        eventPublisher.publishEvent(new UserDeletedEvent(user));
    }
}

// 4. API Layer - Interface REST simple
@RestController
@RequestMapping("/api/users")
@Validated
public class UserController {
    private final UserApplicationService userService;
    
    public UserController(UserApplicationService userService) {
        this.userService = userService;
    }
    
    @PostMapping
    public ResponseEntity createUser(@Valid @RequestBody CreateUserRequest request) {
        CreateUserCommand command = CreateUserCommand.from(request);
        User user = userService.createUser(command);
        
        return ResponseEntity.status(HttpStatus.CREATED)
            .body(UserResponse.from(user));
    }
    
    @GetMapping("/{userId}")
    public ResponseEntity getUser(@PathVariable String userId) {
        User user = userService.getUserById(userId);
        return ResponseEntity.ok(UserResponse.from(user));
    }
    
    @PutMapping("/{userId}")
    public ResponseEntity updateUser(
            @PathVariable String userId,
            @Valid @RequestBody UpdateUserRequest request) {
        
        UpdateUserCommand command = UpdateUserCommand.from(request);
        User user = userService.updateUser(userId, command);
        
        return ResponseEntity.ok(UserResponse.from(user));
    }
    
    @DeleteMapping("/{userId}")
    public ResponseEntity deleteUser(@PathVariable String userId) {
        userService.deleteUser(userId);
        return ResponseEntity.noContent().build();
    }
}
