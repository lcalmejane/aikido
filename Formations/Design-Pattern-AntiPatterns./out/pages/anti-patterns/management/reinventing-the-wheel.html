Le cycle de réinvention montre comment le syndrome "Not Invented Here" conduit à développer des solutions maison coûteuses au lieu d'utiliser des bibliothèques éprouvées.

🎯 Définition

Reinventing the Wheel est un anti-pattern de management où les équipes développent des solutions personnalisées pour des problèmes déjà résolus par des bibliothèques, frameworks ou services existants et éprouvés. Cette approche résulte souvent du syndrome "Not Invented Here" (NIH) et conduit à un gaspillage de ressources considérable.

❌ Problèmes Causés

  • Temps de développement multiplié par 3-5
  • Bugs et problèmes de sécurité
  • Maintenance coûteuse et complexe
  • Retard sur les fonctionnalités métier
  • Expertise technique diluée

✅ Solutions Apportées

  • Évaluation systématique des solutions existantes
  • Critères de décision objectifs
  • Architecture modulaire et remplaçable
  • Focus sur la valeur métier
  • Veille technologique continue
⚠️ Attention : Le développement maison peut sembler offrir plus de contrôle, mais il conduit souvent à des solutions moins robustes et plus coûteuses que les alternatives éprouvées.

🧠 Biais Cognitifs Associés

Le Reinventing the Wheel résulte de plusieurs biais cognitifs qui favorisent le développement maison :

🏠

Syndrome NIH (Not Invented Here)

Manifestation : "On ne peut faire confiance qu'à ce qu'on développe nous-mêmes"

Rejet systématique des solutions externes par préférence pour les développements internes, même quand ils sont moins efficaces.

Exemple : Refuser d'utiliser Redis pour développer son propre système de cache "plus adapté à nos besoins".
🎮

Illusion de Contrôle

Manifestation : "Avec notre solution, on maîtrise tout de A à Z"

Croyance qu'une solution maison offre plus de contrôle et de flexibilité, en ignorant les coûts de maintenance.

Exemple : Développer son propre ORM "pour avoir le contrôle total" au lieu d'utiliser Doctrine ou Hibernate.
⚡

Effet Dunning-Kruger

Manifestation : "C'est pas si compliqué, on peut le faire en 2 semaines"

Surestimation de ses capacités à résoudre des problèmes complexes déjà résolus par des équipes spécialisées.

Exemple : Penser qu'implémenter un système de logs est trivial, en ignorant la rotation, compression, performance, etc.
💰

Biais du Coût Irrécupérable

Manifestation : "On a déjà investi tant de temps, il faut continuer"

Persistance dans le développement maison malgré les coûts croissants et les problèmes rencontrés.

Exemple : Continuer à développer son parser JSON maison malgré 6 mois de développement et de nombreux bugs.
🔒

Aversion à la Dépendance

Manifestation : "Et si la bibliothèque n'est plus maintenue ?"

Peur irrationnelle de dépendre de solutions externes, même fiables et largement adoptées, par crainte de perte de contrôle.

Exemple : Éviter jQuery ou React par peur de la dépendance, en développant ses propres composants UI.

// 2. Réinvention d'un système de cache (au lieu de Redis/Memcached)
class CustomCache
{
    private string $cacheDir;
    
    public function __construct(string $cacheDir = '/tmp/cache')
    {
        $this->cacheDir = $cacheDir;
        if (!is_dir($cacheDir)) {
            mkdir($cacheDir, 0755, true);
        }
    }
    
    public function get(string $key): mixed
    {
        $filename = $this->getCacheFilename($key);
        
        if (!file_exists($filename)) {
            return null;
        }
        
        $content = file_get_contents($filename);
        $data = unserialize($content);
        
        // Gestion manuelle de l'expiration - source de bugs
        if ($data['expires'] < time()) {
            unlink($filename);
            return null;
        }
        
        return $data['value'];
    }
    
    public function set(string $key, mixed $value, int $ttl = 3600): void
    {
        $filename = $this->getCacheFilename($key);
        $data = [
            'value' => $value,
            'expires' => time() + $ttl
        ];
        
        // Pas de gestion des erreurs d'écriture
        file_put_contents($filename, serialize($data));
    }
    
    private function getCacheFilename(string $key): string
    {
        return $this->cacheDir . '/' . md5($key) . '.cache';
    }
    
    // Pas de nettoyage automatique des fichiers expirés
    // Pas de gestion de la concurrence
    // Pas de compression
    // Pas de distribution
}

// 3. Réinvention d'un système de logs (au lieu de Monolog)
class CustomLogger
{
    private string $logFile;
    
    public function __construct(string $logFile = '/var/log/app.log')
    {
        $this->logFile = $logFile;
    }
    
    public function log(string $level, string $message, array $context = []): void
    {
        $timestamp = date('Y-m-d H:i:s');
        $contextStr = empty($context) ? '' : ' ' . json_encode($context);
        $logEntry = "[$timestamp] $level: $message$contextStr\n";
        
        // Gestion manuelle très basique
        if (filesize($this->logFile) > 10 * 1024 * 1024) { // 10MB
            $this->rotateLog();
        }
        
        // Pas de gestion des erreurs d'écriture
        file_put_contents($this->logFile, $logEntry, FILE_APPEND | LOCK_EX);
    }
    
    private function rotateLog(): void
    {
        $backupFile = $this->logFile . '.' . date('Y-m-d-H-i-s');
        rename($this->logFile, $backupFile);
        
        // Compression manuelle basique
        if (function_exists('gzopen')) {
            $this->compressFile($backupFile);
        }
    }
    
    // Pas de niveaux de log configurables
    // Pas de formatters personnalisables
    // Pas de handlers multiples
    // Pas de buffering
}

// 4. Réinvention d'un ORM (au lieu de Doctrine/Eloquent)
class CustomORM
{
    private PDO $pdo;
    
    public function __construct(PDO $pdo)
    {
        $this->pdo = $pdo;
    }
    
    public function find(string $table, int $id): ?array
    {
        // Requête SQL directe - vulnérable aux injections si mal utilisée
        $stmt = $this->pdo->prepare("SELECT * FROM $table WHERE id = ?");
        $stmt->execute([$id]);
        return $stmt->fetch(PDO::FETCH_ASSOC) ?: null;
    }
    
    public function findBy(string $table, array $criteria): array
    {
        $conditions = [];
        $values = [];
        
        foreach ($criteria as $field => $value) {
            $conditions[] = "$field = ?";
            $values[] = $value;
        }
        
        $sql = "SELECT * FROM $table WHERE " . implode(' AND ', $conditions);
        $stmt = $this->pdo->prepare($sql);
        $stmt->execute($values);
        
        return $stmt->fetchAll(PDO::FETCH_ASSOC);
    }
    
    public function save(string $table, array $data): int
    {
        if (isset($data['id'])) {
            // Update basique
            $id = $data['id'];
            unset($data['id']);
            
            $fields = [];
            $values = [];
            
            foreach ($data as $field => $value) {
                $fields[] = "$field = ?";
                $values[] = $value;
            }
            
            $values[] = $id;
            $sql = "UPDATE $table SET " . implode(', ', $fields) . " WHERE id = ?";
            
            $stmt = $this->pdo->prepare($sql);
            $stmt->execute($values);
            
            return $id;
        } else {
            // Insert basique
            $fields = array_keys($data);
            $placeholders = array_fill(0, count($fields), '?');
            
            $sql = "INSERT INTO $table (" . implode(', ', $fields) . ") VALUES (" . implode(', ', $placeholders) . ")";
            
            $stmt = $this->pdo->prepare($sql);
            $stmt->execute(array_values($data));
            
            return $this->pdo->lastInsertId();
        }
    }
    
    // Pas de relations
    // Pas de lazy loading
    // Pas de cache de requêtes
    // Pas de migrations
    // Pas de validation
    // Pas de events/hooks
}

// 1. Réinvention d'un sérialiseur JSON (au lieu de Jackson/Gson)
public class CustomJsonSerializer {
    
    public String toJson(Object obj) {
        if (obj == null) return "null";
        
        if (obj instanceof String) {
            return "\"" + escapeString((String) obj) + "\"";
        }
        
        if (obj instanceof Number || obj instanceof Boolean) {
            return obj.toString();
        }
        
        if (obj instanceof List) {
            List list = (List) obj;
            StringBuilder sb = new StringBuilder("[");
            for (int i = 0; i < list.size(); i++) {
                if (i > 0) sb.append(",");
                sb.append(toJson(list.get(i)));
            }
            sb.append("]");
            return sb.toString();
        }
        
        if (obj instanceof Map) {
            Map map = (Map) obj;
            StringBuilder sb = new StringBuilder("{");
            boolean first = true;
            for (Map.Entry entry : map.entrySet()) {
                if (!first) sb.append(",");
                sb.append("\"").append(entry.getKey()).append("\":");
                sb.append(toJson(entry.getValue()));
                first = false;
            }
            sb.append("}");
            return sb.toString();
        }
        
        // Réflexion manuelle pour les objets - très lent et limité
        return serializeObject(obj);
    }
    
    private String serializeObject(Object obj) {
        Class clazz = obj.getClass();
        Field[] fields = clazz.getDeclaredFields();
        
        StringBuilder sb = new StringBuilder("{");
        boolean first = true;
        
        for (Field field : fields) {
            field.setAccessible(true);
            try {
                Object value = field.get(obj);
                if (!first) sb.append(",");
                sb.append("\"").append(field.getName()).append("\":");
                sb.append(toJson(value));
                first = false;
            } catch (IllegalAccessException e) {
                // Gestion d'erreur basique
            }
        }
        
        sb.append("}");
        return sb.toString();
    }
    
    private String escapeString(String str) {
        // Échappement basique - incomplet
        return str.replace("\\", "\\\\")
                  .replace("\"", "\\\"")
                  .replace("\n", "\\n")
                  .replace("\r", "\\r")
                  .replace("\t", "\\t");
        // Manque beaucoup de cas d'échappement Unicode, etc.
    }
    
    // Pas de désérialisation
    // Pas de gestion des annotations
    // Pas de gestion des types génériques
    // Pas d'optimisations de performance
}

// 2. Réinvention d'un pool de connexions (au lieu de HikariCP/C3P0)
public class CustomConnectionPool {
    private final Queue availableConnections = new LinkedList<>();
    private final Set usedConnections = new HashSet<>();
    private final String url;
    private final String username;
    private final String password;
    private final int maxPoolSize;
    
    public CustomConnectionPool(String url, String username, String password, int maxPoolSize) {
        this.url = url;
        this.username = username;
        this.password = password;
        this.maxPoolSize = maxPoolSize;
        
        // Initialisation basique
        for (int i = 0; i < maxPoolSize / 2; i++) {
            try {
                availableConnections.offer(createConnection());
            } catch (SQLException e) {
                throw new RuntimeException("Failed to initialize connection pool", e);
            }
        }
    }
    
    public synchronized Connection getConnection() throws SQLException {
        if (availableConnections.isEmpty()) {
            if (usedConnections.size() < maxPoolSize) {
                return createConnection();
            } else {
                // Attente active - très inefficace !
                while (availableConnections.isEmpty()) {
                    try {
                        Thread.sleep(100);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        throw new SQLException("Interrupted while waiting for connection");
                    }
                }
            }
        }
        
        Connection connection = availableConnections.poll();
        usedConnections.add(connection);
        return connection;
    }
    
    public synchronized void releaseConnection(Connection connection) {
        if (usedConnections.remove(connection)) {
            availableConnections.offer(connection);
        }
    }
    
    private Connection createConnection() throws SQLException {
        return DriverManager.getConnection(url, username, password);
    }
    
    // Pas de validation des connexions
    // Pas de timeout configurables
    // Pas de métriques
    // Pas de gestion des connexions fermées
    // Pas de leak detection
    // Synchronisation inefficace
}

// 3. Réinvention d'un moteur de template (au lieu de Thymeleaf/Freemarker)
public class CustomTemplateEngine {
    
    public String render(String template, Map variables) {
        String result = template;
        
        // Remplacement simple des variables {{variable}}
        for (Map.Entry entry : variables.entrySet()) {
            String placeholder = "{{" + entry.getKey() + "}}";
            String value = entry.getValue() != null ? entry.getValue().toString() : "";
            result = result.replace(placeholder, value);
        }
        
        // Gestion basique des conditions
        result = processConditions(result, variables);
        
        // Gestion basique des boucles
        result = processLoops(result, variables);
        
        return result;
    }
    
    private String processConditions(String template, Map variables) {
        Pattern pattern = Pattern.compile("\\{\\{#if (\\w+)\\}\\}(.*?)\\{\\{/if\\}\\}", Pattern.DOTALL);
        Matcher matcher = pattern.matcher(template);
        
        StringBuffer result = new StringBuffer();
        while (matcher.find()) {
            String variable = matcher.group(1);
            String content = matcher.group(2);
            
            Object value = variables.get(variable);
            boolean condition = value != null &&
                               (!(value instanceof Boolean) || (Boolean) value) &&
                               (!(value instanceof String) || !((String) value).isEmpty());
            
            matcher.appendReplacement(result, condition ? content : "");
        }
        matcher.appendTail(result);
        
        return result.toString();
    }
    
    private String processLoops(String template, Map variables) {
        // Gestion basique des boucles {{#each items}}...{{/each}}
        Pattern pattern = Pattern.compile("\\{\\{#each (\\w+)\\}\\}(.*?)\\{\\{/each\\}\\}", Pattern.DOTALL);
        Matcher matcher = pattern.matcher(template);
        
        StringBuffer result = new StringBuffer();
        while (matcher.find()) {
            String variable = matcher.group(1);
            String content = matcher.group(2);
            
            Object value = variables.get(variable);
            StringBuilder loopResult = new StringBuilder();
            
            if (value instanceof List) {
                List list = (List) value;
                for (Object item : list) {
                    String itemContent = content.replace("{{this}}", item.toString());
                    loopResult.append(itemContent);
                }
            }
            
            matcher.appendReplacement(result, loopResult.toString());
        }
        matcher.appendTail(result);
        
        return result.toString();
    }
    
    // Pas de gestion avancée des templates
    // Pas de cache de compilation
    // Pas de sécurité contre XSS
    // Pas de fonctions personnalisées
    // Pas de layouts/partials
}
