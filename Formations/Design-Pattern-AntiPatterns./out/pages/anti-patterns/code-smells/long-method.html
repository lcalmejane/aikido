🎯 Définition

Une Long Method (méthode longue) est une méthode ou fonction qui contient trop de lignes de code et/ou trop de responsabilités différentes. Ces méthodes deviennent difficiles à comprendre, tester, maintenir et réutiliser.

❌ Problèmes Causés

  • Compréhension difficile du code
  • Tests complexes et incomplets
  • Réutilisation impossible
  • Maintenance coûteuse et risquée
  • Violation du principe de responsabilité unique
  • Debugging compliqué

✅ Solutions Apportées

  • Décomposition en méthodes plus petites
  • Extraction de méthodes spécialisées
  • Séparation des responsabilités
  • Amélioration de la lisibilité
  • Tests unitaires plus faciles
  • Réutilisabilité accrue
⚠️ Règle d'or : Si une méthode fait plus d'une chose ou dépasse 20-30 lignes, elle est probablement trop longue !

Indicateurs de Long Method

📏
Taille excessive

Plus de 20-30 lignes de code

🔄
Multiples responsabilités

Fait plusieurs choses différentes

🌀

📝
Commentaires excessifs

Besoin de beaucoup de commentaires explicatifs

🧠 Biais Cognitifs Associés

Les Long Methods résultent souvent de biais cognitifs qui nous poussent à tout mettre au même endroit :

🎯

Biais de Focalisation

Manifestation : "Je suis dans cette méthode, autant tout faire ici !"

La tendance à se concentrer sur la tâche immédiate sans prendre du recul pour voir la structure globale et les possibilités de décomposition.

Exemple : Ajouter "juste une petite validation" dans une méthode de traitement, puis "juste un petit log", etc.
⚡

Biais de Commodité

Manifestation : "C'est plus simple de tout mettre dans la même fonction !"

Préférer la solution apparemment la plus simple à court terme, sans considérer les coûts de maintenance à long terme.

Exemple : Éviter de créer de nouvelles méthodes car "ça fait plus de fichiers à gérer".
🔄

Escalade d'Engagement

Manifestation : "J'ai déjà écrit 50 lignes, autant continuer !"

Plus on investit de temps dans une méthode, plus on hésite à la refactoriser, même quand elle devient trop complexe.

Exemple : Continuer à ajouter du code dans une méthode déjà longue plutôt que de la restructurer.

class PricingService {
    
    public function calculateOrderTotal(array $items, Customer $customer): array {
        $processedItems = [];
        $orderTotal = 0;
        
        foreach ($items as $item) {
            $processedItem = $this->processItem($item, $customer);
            $processedItems[] = $processedItem;
            $orderTotal += $processedItem['line_total'];
        }
        
        return [
            'items' => $processedItems,
            'subtotal' => $orderTotal
        ];
    }
    
    private function processItem(array $item, Customer $customer): array {
        $product = $this->getValidatedProduct($item['product_id'], $item['quantity']);
        $discount = $this->calculateDiscount($item['quantity'], $customer);
        $finalPrice = $product->price * (1 - $discount);
        
        return [
            'product_id' => $product->id,
            'product_name' => $product->name,
            'quantity' => $item['quantity'],
            'unit_price' => $product->price,
            'discount' => $discount,
            'final_price' => $finalPrice,
            'line_total' => $finalPrice * $item['quantity']
        ];
    }
    
    private function getValidatedProduct(int $productId, int $quantity): Product {
        $product = Product::find($productId);
        
        if (!$product) {
            throw new NotFoundException("Product {$productId} not found");
        }
        
        if (!$product->is_available) {
            throw new BusinessException("Product {$product->name} is not available");
        }
        
        if ($product->stock < $quantity) {
            throw new BusinessException("Insufficient stock for {$product->name}");
        }
        
        return $product;
    }
    
    private function calculateDiscount(int $quantity, Customer $customer): float {
        $discount = 0;
        
        // Remise quantité
        if ($quantity >= 10) $discount += 0.05;
        if ($quantity >= 50) $discount += 0.05;
        
        // Remise client VIP
        if ($customer->type === 'vip') $discount += 0.10;
        
        // Remise saisonnière
        if ($this->isWinterSeason()) $discount += 0.15;
        
        return $discount;
    }
    
    private function isWinterSeason(): bool {
        return in_array(date('n'), [11, 12, 1]);
    }
}

class TaxAndShippingService {
    
    public function calculateTaxes(float $orderTotal, Customer $customer): array {
        $taxRate = $this->getTaxRate($customer->country);
        $taxAmount = $orderTotal * $taxRate;
        
        return [
            'tax_rate' => $taxRate,
            'tax_amount' => $taxAmount
        ];
    }
    
    public function calculateShipping(float $orderTotal, Customer $customer): float {
        if ($orderTotal >= 100) {
            return 0; // Livraison gratuite
        }
        
        return $customer->country === 'FR' ? 9.99 : 19.99;
    }
    
    private function getTaxRate(string $country): float {
        return match($country) {
            'FR' => 0.20,
            'DE' => 0.19,
            'ES' => 0.21,
            'IT' => 0.22,
            default => 0.25
        };
    }
}

        // 6. Création commande

            'final_total' => $finalTotal
        ]);

// 1. Service de validation
@Component
public class UserValidationService {
    
    public void validateRegistrationRequest(UserRegistrationRequest request) {
        validateBasicFields(request);
        validateAge(request.getDateOfBirth());
        validatePassword(request.getPassword());
    }
    
    private void validateBasicFields(UserRegistrationRequest request) {
        if (isBlank(request.getEmail()) || !isValidEmail(request.getEmail())) {
            throw new ValidationException("Valid email is required");
        }
        if (isBlank(request.getFirstName())) {
            throw new ValidationException("First name is required");
        }
        if (isBlank(request.getLastName())) {
            throw new ValidationException("Last name is required");
        }
        if (request.getDateOfBirth() == null) {
            throw new ValidationException("Date of birth is required");
        }
    }
    
    private void validateAge(LocalDate dateOfBirth) {
        int age = Period.between(dateOfBirth, LocalDate.now()).getYears();
        if (age < 13 || age > 120) {
            throw new ValidationException("Invalid age");
        }
    }
    
    private void validatePassword(String password) {
        if (password == null || password.length() < 8) {
            throw new ValidationException("Password must be at least 8 characters");
        }
        
        if (calculatePasswordComplexity(password) < 3) {
            throw new ValidationException("Password complexity insufficient");
        }
        
        if (isCommonPassword(password)) {
            throw new ValidationException("Password is too common");
        }
    }
    
    private int calculatePasswordComplexity(String password) {
        int score = 0;
        if (password.matches(".*[a-z].*")) score++;
        if (password.matches(".*[A-Z].*")) score++;
        if (password.matches(".*\\d.*")) score++;
        if (password.matches(".*[!@#$%^&*()_+\\-=\\[\\]{};':\"\\\\|,.<>\\/?].*")) score++;
        return score;
    }
    
    private boolean isCommonPassword(String password) {
        Set commonPasswords = Set.of(
            "password", "123456", "password123", "admin", "qwerty"
        );
        return commonPasswords.contains(password.toLowerCase());
    }
    
    private boolean isBlank(String str) {
        return str == null || str.trim().isEmpty();
    }
    
    private boolean isValidEmail(String email) {
        return email.matches("^[A-Za-z0-9+_.-]+@(.+)$");
    }
}

@Service
public class UserManagementService {
    
    @Autowired
    private UserRepository userRepository;
    
    public void checkEmailUniqueness(String email) {
        if (userRepository.findByEmail(email).isPresent()) {
            throw new BusinessException("Email already registered");
        }
    }
    
    public String generateUniqueUsername(String firstName, String lastName) {
        String baseUsername = (firstName + lastName).toLowerCase()
                             .replaceAll("[^a-z0-9]", "");
        
        String username = baseUsername;
        int counter = 1;
        
        while (userRepository.findByUsername(username).isPresent()) {
            username = baseUsername + counter++;
        }
        
        return username;
    }
    
    public UserRole determineUserRole(String email) {
        if (email.equals("admin@company.com")) {
            return UserRole.ADMIN;
        }
        if (email.endsWith("@company.com")) {
            return UserRole.EMPLOYEE;
        }
        return UserRole.USER;
    }
    
    public User createUser(UserRegistrationRequest request, String username, 
                          String hashedPassword, UserRole role, String activationToken) {
        User user = new User();
        user.setEmail(request.getEmail());
        user.setUsername(username);
        user.setPasswordHash(hashedPassword);
        user.setFirstName(request.getFirstName());
        user.setLastName(request.getLastName());
        user.setDateOfBirth(request.getDateOfBirth());
        user.setRole(role);
        user.setActive(false);
        user.setActivationToken(activationToken);
        user.setActivationTokenExpiry(LocalDateTime.now().plusHours(24));
        user.setCreatedAt(LocalDateTime.now());
        user.setUpdatedAt(LocalDateTime.now());
        
        return userRepository.save(user);
    }
}

🔧 Techniques de Refactoring

Voici les principales techniques pour décomposer les Long Methods :

✂️

Extract Method

Extraire des blocs de code logiques en méthodes séparées

Avant : 

public function process($data) {
    // Validation (10 lignes)
    if (empty($data)) { ... }
    
    // Traitement (15 lignes)
    foreach ($data as $item) { ... }
    
    // Sauvegarde (8 lignes)
    $this->save($result);
}
Après : 

public function process($data) {
    $this->validateData($data);
    $result = $this->processData($data);
    $this->saveResult($result);
}
Avantages : Clarté, réutilisabilité, tests unitaires
🏭

Extract Class

Créer des classes spécialisées pour des responsabilités distinctes

Principe : 

// Avant : tout dans UserService
class UserService {
    public void registerUser() {
        // validation, hashage, email, audit...
    }
}

// Après : responsabilités séparées
class UserValidator { ... }
class PasswordHasher { ... }
class EmailService { ... }
class AuditLogger { ... }
Avantages : SRP, testabilité, maintenance
🔄

Replace Temp with Query

Remplacer les variables temporaires par des appels de méthodes

Avant : 

$basePrice = $quantity * $itemPrice;
$discount = $basePrice * 0.1;
$total = $basePrice - $discount;
Après : 

$total = $this->calculateTotal();

private function calculateTotal() {
    return $this->getBasePrice() - $this->getDiscount();
}
Avantages : Expressivité, élimination des variables temporaires
📋

Introduce Parameter Object

Regrouper les paramètres liés dans un objet dédié

Avant : 

public void createUser(String firstName, String lastName, 
                      String email, LocalDate birthDate, 
                      String address, String phone) { ... }
Après : 

public void createUser(UserData userData) { ... }

class UserData {
    private String firstName, lastName, email;
    private LocalDate birthDate;
    // ...
}
Avantages : Moins de paramètres, validation centralisée
🎯

Decompose Conditional

Extraire les conditions complexes en méthodes expressives

Avant : 

if ($date < $SUMMER_START || $date > $SUMMER_END) {
    $charge = $quantity * $winterRate + $winterServiceCharge;
} else {
    $charge = $quantity * $summerRate;
}
Après : 

if ($this->isWinter($date)) {
    $charge = $this->calculateWinterCharge($quantity);
} else {
    $charge = $this->calculateSummerCharge($quantity);
}
Avantages : Lisibilité, intention claire, réutilisabilité

🏗️ Design Patterns Recommandés

Voici les patterns qui aident à éviter et refactoriser les Long Methods :

🎭

Template Method

Définir le squelette d'un algorithme en déléguant les étapes spécifiques à des méthodes.

Exemple : Processus de commande avec étapes définies
Avantages : Structure claire, étapes réutilisables, extensibilité
🔗

Chain of Responsibility

Décomposer une longue séquence de traitements en chaîne de handlers.

Exemple : Pipeline de validation avec multiple validateurs
Avantages : Flexibilité, ajout/suppression facile, SRP
🎯

Strategy

Extraire les algorithmes complexes en stratégies interchangeables.

Exemple : Calculs de prix avec différentes stratégies de remise
Avantages : Algorithmes isolés, testabilité, extensibilité
🏭

Factory Method

Déléguer la création d'objets complexes à des factories spécialisées.

Exemple : Factory pour créer différents types d'utilisateurs
Avantages : Logique de création centralisée, extensibilité
