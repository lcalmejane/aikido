💀 Dead Code

L'anti-pattern du code mort et inutilisé qui pollue la base de code

🦨 Code Smells
⏱️ ~20 minutes
🎯 Nettoyage requis
🧩 3 biais cognitifs liés

💡 Mécanisme : Le Dead Code naît souvent de bonnes intentions (garder "au cas où") mais devient rapidement un fardeau qui pollue la base de code.

🎯 Définition

Le Dead Code (code mort) désigne toutes les portions de code qui ne sont jamais exécutées ou utilisées dans l'application. Ce code inutile s'accumule au fil du temps et devient un fardeau pour la maintenance, la compréhension et les performances du projet.

❌ Problèmes Causés

  • Augmentation de la complexité du code
  • Confusion pour les nouveaux développeurs
  • Temps de compilation et déploiement allongés
  • Fausse impression de fonctionnalités existantes
  • Maintenance inutile et coûteuse
  • Risques de sécurité cachés

✅ Solutions Apportées

  • Analyse statique automatisée
  • Outils de détection de code mort
  • Refactoring progressif et sécurisé
  • Tests de couverture de code
  • Processus de revue de code
  • Documentation des suppressions
⚠️ Règle d'or : Si du code n'est pas testé, documenté ou appelé, il est probablement mort et doit être supprimé !

🧠 Biais Cognitifs Associés

Le Dead Code persiste souvent à cause de biais cognitifs qui nous empêchent de le supprimer :

💎

Biais de Dotation

Manifestation : "Ce code pourrait servir un jour, gardons-le au cas où !"

La tendance à surévaluer ce qu'on possède déjà. Les développeurs hésitent à supprimer du code qu'ils ont écrit, même s'il n'est plus utilisé.

Exemple : Garder une ancienne API "au cas où" alors qu'elle n'a pas été appelée depuis des mois.
😰

Aversion à la Perte

Manifestation : "Et si on en a besoin plus tard ? Mieux vaut ne pas risquer !"

La peur de perdre quelque chose d'important nous pousse à conserver du code "par sécurité", même sans justification claire.

Exemple : Commenter du code au lieu de le supprimer "pour pouvoir le récupérer facilement".
⏳

Procrastination

Manifestation : "Je nettoierai ce code plus tard, quand j'aurai le temps."

Reporter indéfiniment les tâches de nettoyage car elles ne semblent pas urgentes, permettant au Dead Code de s'accumuler.

Exemple : Laisser des imports inutilisés "pour plus tard" qui finissent par se multiplier.

🧹 Stratégies de Nettoyage

Approches méthodiques pour éliminer le Dead Code en toute sécurité :

🎯

Approche Progressive

Étapes :
  1. Audit initial : Scanner tout le projet
  2. Catégorisation : Trier par type et risque
  3. Suppression graduelle : Commencer par le moins risqué
  4. Tests continus : Vérifier après chaque suppression
  5. Documentation : Tracer les suppressions
Avantages : Sécurisé, contrôlé, réversible
🔒

Dépréciation Préalable

Processus :
  1. Marquer @deprecated : Signaler l'intention
  2. Période d'observation : Attendre 1-2 sprints
  3. Logs de surveillance : Vérifier les appels
  4. Communication équipe : Informer les développeurs
  5. Suppression finale : Si aucun usage détecté
Avantages : Sécurité maximale, détection d'usage caché
🔄

Nettoyage Continu

Mise en place :
  1. CI/CD intégré : Analyse automatique
  2. Seuils d'alerte : Limites de code mort
  3. Revues régulières : Sprint reviews dédiées
  4. Métriques tracking : Évolution du dead code
  5. Formation équipe : Sensibilisation continue
Avantages : Prévention, automatisation, culture qualité
🎨

Refactoring Opportuniste

Occasions :
  1. Nouvelles features : Nettoyer les zones touchées
  2. Bug fixes : Profiter pour éliminer le mort
  3. Code reviews : Identifier et supprimer

  4. Créer un rapport d'audit détaillé

Nettoyage Sécurisé

Moyen

Étapes :
  1. Sélectionner le code le moins risqué à supprimer
  2. Créer une branche dédiée au nettoyage
  3. Supprimer progressivement par petits commits
  4. Exécuter tous les tests après chaque suppression
  5. Documenter les suppressions importantes
✅ Validation : Tous les tests passent, aucune régression détectée

  dead-code-analysis:

        run: composer install
      - name: Run PHPStan

      - name: Dead Code Report
        run: psalm --find-dead-code --report=dead-code.json
