🍝 Spaghetti Code

L'anti-pattern du code enchevêtré et impossible à suivre

🦨 Code Smell critique
⏱️ ~30 minutes
🎯 Refactoring essentiel
🧩 4 biais cognitifs liés

🎯 Définition

Le Spaghetti Code est un anti-pattern caractérisé par une structure de contrôle complexe et enchevêtrée, avec des flux d'exécution difficiles à suivre. Le code ressemble à un plat de spaghettis où chaque "nouille" (ligne de code) s'entremêle avec les autres, créant un ensemble impossible à démêler.

❌ Problèmes Causés

  • Flux de contrôle chaotique et imprévisible
  • Maintenance extrêmement difficile
  • Bugs récurrents et effets de bord
  • Impossible à tester unitairement
  • Onboarding des nouveaux développeurs ralenti

✅ Solutions Apportées

  • Refactoring vers des fonctions courtes
  • Séparation des responsabilités
  • Utilisation de design patterns
  • Tests unitaires pour valider le comportement
  • Documentation du flux métier
⚠️ Attention : Le Spaghetti Code peut sembler fonctionnel, mais il devient rapidement un cauchemar de maintenance et une source constante de bugs.

Caractéristiques du Spaghetti Code

🌀
Flux de contrôle complexe

Nombreux goto, break, continue imbriqués

🔀
Logique entremêlée

Plusieurs responsabilités mélangées

🧩
Difficile à comprendre

Impossible de suivre le flux d'exécution

🐛
Propice aux bugs

Effets de bord imprévisibles

🧠 Biais Cognitifs Associés

Le Spaghetti Code résulte souvent de plusieurs biais cognitifs qui poussent vers des solutions rapides mais désordonnées :

⚡

Biais de Disponibilité

Manifestation : "Je vais juste ajouter cette condition ici, c'est plus rapide !"

La tendance à utiliser la solution la plus immédiatement accessible plutôt que de réfléchir à une structure propre.

Exemple : Ajouter des if/else imbriqués plutôt que de refactorer vers une structure plus claire.
✅

Biais de Confirmation

Manifestation : "Ça marche, donc c'est bon !"

Ignorer les signaux d'alarme (complexité, difficultés de debug) car le code produit le résultat attendu.

Exemple : Refuser de voir que le code est illisible car "les tests passent".
⏰

Biais de Pression Temporelle

Manifestation : "Pas le temps de faire propre, il faut livrer !"

La pression des délais pousse à prendre des raccourcis qui créent de la dette technique.

Exemple : Copier-coller du code existant et le modifier "juste pour cette fois".
🎯

Biais d'Engagement

Manifestation : "J'ai déjà commencé comme ça, je continue !"

Une fois engagé dans une approche désordonnée, la résistance au changement augmente avec l'investissement.

Exemple : Continuer à ajouter des conditions plutôt que de refactorer vers un pattern plus propre.

public class OrderProcessor {
    
    public OrderResult processOrder(Order order, User user, List products, 
                                   List discounts, ShippingInfo shipping) {
        double total = 0;
        List errors = new ArrayList<>();
        String status = "pending";
        double shippingCost = 0;
        double discountAmount = 0;
        
        // Validation utilisateur (mélangée avec la logique métier)
        if (user == null) {
            errors.add("User required");
            return handleError(order, errors); // ❌ Flux de contrôle chaotique
        }
        
        if ("banned".equals(user.getStatus())) {
            if ("fraud".equals(user.getBanReason())) {
                errors.add("Fraud user");
                status = "rejected";
                return cleanup(order, status, errors);
            } else if ("spam".equals(user.getBanReason())) {
                if (user.getLastActivity().after(new Date(System.currentTimeMillis() - 30L * 24 * 60 * 60 * 1000))) {
                    errors.add("Recent spam activity");
                    return handleError(order, errors);
                } else {
                    // Peut-être autoriser...
                    if (order.getTotal() < 50) {
                        user.setStatus("probation");
                    } else {
                        errors.add("Large order from spam user");
                        return handleError(order, errors);
                    }
                }
            }
        }
        
        // Calcul des produits (logique entremêlée)
        for (OrderItem item : order.getItems()) {
            Product product = products.stream()
                .filter(p -> p.getId().equals(item.getProductId()))
                .findFirst().orElse(null);
            
            if (product == null) {
                errors.add("Product " + item.getProductId() + " not found");
                continue; // ❌ Flux complexe
            }
            
            if (product.getStock() < item.getQuantity()) {
                if (product.isBackorderAllowed()) {
                    if (user.isPremium()) {
                        item.setBackorder(true);
                        item.setEstimatedDelivery(product.getRestockDate());
                    } else {
                        if (item.getQuantity() <= product.getStock() + product.getIncomingStock()) {
                            item.setPartialBackorder(true);
                            item.setAvailableNow(product.getStock());
                            item.setBackorderQuantity(item.getQuantity() - product.getStock());
                        } else {
                            errors.add("Insufficient stock for " + product.getName());
                            continue;
                        }
                    }
                } else {
                    errors.add("Product " + product.getName() + " out of stock");
                    continue;
                }
            }
            
            // Calcul prix avec remises (logique complexe imbriquée)
            double itemPrice = product.getPrice() * item.getQuantity();
            
            if (discounts != null && !discounts.isEmpty()) {
                for (Discount discount : discounts) {
                    if ("percentage".equals(discount.getType())) {
                        if (discount.getApplicableProducts().contains(product.getId())) {
                            if (discount.getMinQuantity() != null && item.getQuantity() >= discount.getMinQuantity()) {
                                itemPrice *= (1 - discount.getValue() / 100.0);
                                discountAmount += (product.getPrice() * item.getQuantity() * discount.getValue() / 100.0);
                            } else if (discount.getMinQuantity() == null) {
                                itemPrice *= (1 - discount.getValue() / 100.0);
                                discountAmount += (product.getPrice() * item.getQuantity() * discount.getValue() / 100.0);
                            }
                        } else if (discount.getCategoryIds().contains(product.getCategoryId())) {
                            if (discount.getMinAmount() != null && itemPrice >= discount.getMinAmount()) {
                                double discountValue = Math.min(itemPrice * discount.getValue() / 100.0, 
                                                               discount.getMaxDiscount() != null ? discount.getMaxDiscount() : Double.MAX_VALUE);
                                itemPrice -= discountValue;
                                discountAmount += discountValue;
                            }
                        }
                    } else if ("fixed".equals(discount.getType())) {
                        if (itemPrice >= discount.getMinAmount()) {
                            itemPrice -= discount.getValue();
                            discountAmount += discount.getValue();
                        }
                    }
                }
            }
            
            total += itemPrice;
            
            // Gestion stock (mélangée avec le calcul)
            if (!item.isBackorder()) {
                product.setStock(product.getStock() - item.getQuantity());
                if (product.getStock() < product.getLowStockThreshold()) {
                    sendLowStockAlert(product);
                    if (product.isAutoReorder() && product.getSupplier() != null) {
                        createReorderRequest(product);
                    }
                }
            }
        }
        
        // Calcul frais de port (encore plus de conditions imbriquées)
        if (shipping != null) {
            switch (shipping.getMethod()) {
                case "standard":
                    if (total > 100) {
                        shippingCost = 0;
                    } else if (user.isPremium()) {
                        shippingCost = 2.99;
                    } else {
                        shippingCost = 5.99;
                    }
                    break;
                case "express":
                    shippingCost = 12.99;
                    if (user.isPremium()) {
                        shippingCost *= 0.8;
                    }
                    if (!isExpressAvailable(shipping.getAddress())) {
                        errors.add("Express shipping not available");
                        return handleError(order, errors);
                    }
                    break;
                case "pickup":
                    shippingCost = 0;
                    if (!isPickupLocationOpen(shipping.getPickupId())) {
                        errors.add("Pickup location closed");
                        return handleError(order, errors);
                    }
                    break;
            }
        }
        
        total += shippingCost;
        
        // Validation finale
        if (total < 0) {
            errors.add("Invalid total amount");
            return handleError(order, errors);
        }
        
        if (user.getCreditLimit() != null && total > user.getCreditLimit()) {
            if ("credit".equals(user.getPaymentMethod())) {
                errors.add("Credit limit exceeded");
                return handleError(order, errors);
            }
        }
        
        // Sauvegarde
        try {
            saveOrder(order);
            updateUserStats(user);
            logOrderEvent("created", order.getId());
        } catch (Exception e) {
            errors.add("Database error: " + e.getMessage());
            return handleError(order, errors);
        }
        
        return new OrderResult(true, order.getId(), total, status);
    }
    
    // ❌ Méthodes de gestion d'erreur répétitives
    private OrderResult handleError(Order order, List errors) {
        logOrderEvent("error", order.getId(), errors);
        return new OrderResult(false, null, 0, null, errors);
    }
    
    private OrderResult cleanup(Order order, String status, List errors) {
        cleanupTempData(order.getId());
        return new OrderResult(false, null, 0, status, errors);
    }

class PriceCalculator {
    private DiscountService $discountService;
    
    public function __construct(DiscountService $discountService) {
        $this->discountService = $discountService;
    }
    
    public function calculateItemPrice(OrderItem $item, Product $product, array $discounts): float {
        $basePrice = $product->getPrice() * $item->getQuantity();
        $discountAmount = $this->discountService->calculateDiscount($item, $product, $discounts);
        
        return max(0, $basePrice - $discountAmount);
    }
}

// 3. Service pour les remises
class DiscountService {
    public function calculateDiscount(OrderItem $item, Product $product, array $discounts): float {
        $totalDiscount = 0;
        
        foreach ($discounts as $discount) {
            $totalDiscount += $this->applyDiscount($discount, $item, $product);
        }
        
        return $totalDiscount;
    }
    
    private function applyDiscount(Discount $discount, OrderItem $item, Product $product): float {
        if (!$this->isDiscountApplicable($discount, $item, $product)) {
            return 0;
        }
        
        return match($discount->getType()) {
            'percentage' => $this->calculatePercentageDiscount($discount, $item, $product),
            'fixed' => $this->calculateFixedDiscount($discount, $item, $product),
            default => 0
        };
    }
    
    private function isDiscountApplicable(Discount $discount, OrderItem $item, Product $product): bool {
        return in_array($product->getId(), $discount->getApplicableProducts()) ||
               in_array($product->getCategoryId(), $discount->getCategoryIds());
    }
    
    private function calculatePercentageDiscount(Discount $discount, OrderItem $item, Product $product): float {
        $basePrice = $product->getPrice() * $item->getQuantity();
        $discountAmount = $basePrice * ($discount->getValue() / 100);
        
        return min($discountAmount, $discount->getMaxDiscount() ?? PHP_FLOAT_MAX);
    }
    
    private function calculateFixedDiscount(Discount $discount, OrderItem $item, Product $product): float {
        $itemPrice = $product->getPrice() * $item->getQuantity();
        
        return $itemPrice >= $discount->getMinAmount() ? $discount->getValue() : 0;
    }
}

// 4. Service pour les frais de port
class ShippingCalculator {
    public function calculateShippingCost(float $total, User $user, ?ShippingInfo $shipping): float {
        if (!$shipping) {
            return 0;
        }
        
        return match($shipping->getMethod()) {
            'standard' => $this->calculateStandardShipping($total, $user),
            'express' => $this->calculateExpressShipping($user),
            'pickup' => 0,
            default => 0
        };
    }
    
    private function calculateStandardShipping(float $total, User $user): float {
        if ($total > 100) {
            return 0; // Gratuit au-dessus de 100€
        }
        
        return $user->isPremium() ? 2.99 : 5.99;
    }
    
    private function calculateExpressShipping(User $user): float {
        $cost = 12.99;
        
        return $user->isPremium() ? $cost * 0.8 : $cost;
    }
}

// 5. Processeur principal simplifié
class OrderProcessor {
    private OrderValidator $validator;
    private PriceCalculator $priceCalculator;
    private ShippingCalculator $shippingCalculator;
    private OrderRepository $orderRepository;
    
    public function __construct(
        OrderValidator $validator,
        PriceCalculator $priceCalculator,
        ShippingCalculator $shippingCalculator,
        OrderRepository $orderRepository
    ) {
        $this->validator = $validator;
        $this->priceCalculator = $priceCalculator;
        $this->shippingCalculator = $shippingCalculator;
        $this->orderRepository = $orderRepository;
    }
    
    public function processOrder(Order $order, User $user, array $products, array $discounts, ?ShippingInfo $shipping): OrderResult {
        // 1. Validation
        $validationResult = $this->validator->validateUser($user);
        if (!$validationResult->isSuccess()) {
            return OrderResult::error($validationResult->getErrors());
        }
        
        // 2. Calcul du total
        $total = $this->calculateOrderTotal($order, $products, $discounts);
        
        // 3. Calcul des frais de port
        $shippingCost = $this->shippingCalculator->calculateShippingCost($total, $user, $shipping);
        $finalTotal = $total + $shippingCost;
        
        // 4. Validation finale
        if (!$this->validateFinalOrder($finalTotal, $user)) {
            return OrderResult::error(['Invalid order total or credit limit exceeded']);
        }
        
        // 5. Sauvegarde
        try {
            $this->orderRepository->save($order);
            return OrderResult::success($order->getId(), $finalTotal);
        } catch (Exception $e) {
            return OrderResult::error(['Database error: ' . $e->getMessage()]);
        }
    }
    
    private function calculateOrderTotal(Order $order, array $products, array $discounts): float {
        $total = 0;
        
        foreach ($order->getItems() as $item) {
            $product = $this->findProduct($products, $item->getProductId());
            if ($product) {
                $total += $this->priceCalculator->calculateItemPrice($item, $product, $discounts);
            }
        }
        
        return $total;
    }
    
    private function findProduct(array $products, string $productId): ?Product {
        foreach ($products as $product) {
            if ($product->getId() === $productId) {
                return $product;
            }
        }
        return null;
    }
    
    private function validateFinalOrder(float $total, User $user): bool {
        if ($total < 0) {
            return false;
        }
        
        if ($user->getCreditLimit() && $total > $user->getCreditLimit()) {
            return $user->getPaymentMethod() !== 'credit';
        }
        
        return true;
    }
}

class ValidationResult {
    private bool $success;
    private array $errors;
    private ?string $status;
    
    private function __construct(bool $success, array $errors = [], ?string $status = null) {
        $this->success = $success;
        $this->errors = $errors;
        $this->status = $status;
    }
    
    public static function success(): self {
        return new self(true);
    }
    
    public static function error(string $message, ?string $status = null): self {
        return new self(false, [$message], $status);
    }
    
    public function isSuccess(): bool { return $this->success; }
    public function getErrors(): array { return $this->errors; }
    public function getStatus(): ?string { return $this->status; }
}

// 1. Strategy Pattern pour les calculs de remises
public interface DiscountStrategy {
    double calculateDiscount(OrderItem item, Product product);
    boolean isApplicable(OrderItem item, Product product);
}

public class PercentageDiscountStrategy implements DiscountStrategy {
    private final Discount discount;
    
    public PercentageDiscountStrategy(Discount discount) {
        this.discount = discount;
    }
    
    @Override
    public double calculateDiscount(OrderItem item, Product product) {
        if (!isApplicable(item, product)) {
            return 0;
        }
        
        double basePrice = product.getPrice() * item.getQuantity();
        double discountAmount = basePrice * (discount.getValue() / 100.0);
        
        return Math.min(discountAmount,
                       discount.getMaxDiscount() != null ? discount.getMaxDiscount() : Double.MAX_VALUE);
    }
    
    @Override
    public boolean isApplicable(OrderItem item, Product product) {
        return discount.getApplicableProducts().contains(product.getId()) ||
               discount.getCategoryIds().contains(product.getCategoryId());
    }
}

public class FixedDiscountStrategy implements DiscountStrategy {
    private final Discount discount;
    
    public FixedDiscountStrategy(Discount discount) {
        this.discount = discount;
    }
    
    @Override
    public double calculateDiscount(OrderItem item, Product product) {
        double itemPrice = product.getPrice() * item.getQuantity();
        
        return itemPrice >= discount.getMinAmount() ? discount.getValue() : 0;
    }
    
    @Override
    public boolean isApplicable(OrderItem item, Product product) {
        return true; // Les remises fixes s'appliquent généralement à tous les produits
    }
}

public abstract class ValidationHandler {
    protected ValidationHandler nextHandler;
    
    public ValidationHandler setNext(ValidationHandler handler) {
        this.nextHandler = handler;
        return handler;
    }
    
    public abstract ValidationResult handle(ValidationRequest request);
    
    protected ValidationResult handleNext(ValidationRequest request) {
        if (nextHandler != null) {
            return nextHandler.handle(request);
        }
        return ValidationResult.success();
    }
}

public class UserValidationHandler extends ValidationHandler {
    @Override
    public ValidationResult handle(ValidationRequest request) {
        if (request.getUser() == null) {
            return ValidationResult.error("User required");
        }
        
        return handleNext(request);
    }
}

public class BannedUserValidationHandler extends ValidationHandler {
    @Override
    public ValidationResult handle(ValidationRequest request) {
        User user = request.getUser();
        
        if ("banned".equals(user.getStatus())) {
            if ("fraud".equals(user.getBanReason())) {
                return ValidationResult.error("Fraud user", "rejected");
            }
            
            if ("spam".equals(user.getBanReason())) {
                return validateSpamUser(user, request.getOrder());
            }
        }
        
        return handleNext(request);
    }
    
    private ValidationResult validateSpamUser(User user, Order order) {
        long thirtyDaysAgo = System.currentTimeMillis() - (30L * 24 * 60 * 60 * 1000);
        
        if (user.getLastActivity().getTime() > thirtyDaysAgo) {
            return ValidationResult.error("Recent spam activity");
        }
        
        if (order.getTotal() >= 50) {
            return ValidationResult.error("Large order from spam user");
        }
        
        user.setStatus("probation");
        return ValidationResult.success();
    }
}

// 3. Factory pour créer les stratégies de remise
public class DiscountStrategyFactory {
    public static DiscountStrategy createStrategy(Discount discount) {
        return switch (discount.getType()) {
            case "percentage" -> new PercentageDiscountStrategy(discount);
            case "fixed" -> new FixedDiscountStrategy(discount);
            default -> throw new IllegalArgumentException("Unknown discount type: " + discount.getType());
        };
    }
}

// 4. Service principal refactorisé
@Service
public class OrderProcessorService {
    private final ValidationHandler validationChain;
    private final PriceCalculatorService priceCalculator;
    private final ShippingCalculatorService shippingCalculator;
    private final OrderRepository orderRepository;
    
    public OrderProcessorService(
            PriceCalculatorService priceCalculator,
            ShippingCalculatorService shippingCalculator,
            OrderRepository orderRepository) {
        
        this.priceCalculator = priceCalculator;
        this.shippingCalculator = shippingCalculator;
        this.orderRepository = orderRepository;
        
        // Configuration de la chaîne de validation
        this.validationChain = new UserValidationHandler();
        this.validationChain
            .setNext(new BannedUserValidationHandler())
            .setNext(new CreditLimitValidationHandler());
    }
    
    public OrderResult processOrder(Order order, User user, List products,
                                   List discounts, ShippingInfo shipping) {
        
        // 1. Validation avec Chain of Responsibility
        ValidationRequest validationRequest = new ValidationRequest(order, user);
        ValidationResult validationResult = validationChain.handle(validationRequest);
        
        if (!validationResult.isSuccess()) {
            return OrderResult.error(validationResult.getErrors());
        }
        
        // 2. Calcul du prix avec Strategy Pattern
        double total = priceCalculator.calculateOrderTotal(order, products, discounts);
        
        // 3. Calcul des frais de port
        double shippingCost = shippingCalculator.calculateShippingCost(total, user, shipping);
        double finalTotal = total + shippingCost;
        
        // 4. Sauvegarde
        try {
            orderRepository.save(order);
            return OrderResult.success(order.getId(), finalTotal);
        } catch (Exception e) {
            return OrderResult.error(List.of("Database error: " + e.getMessage()));
        }
    }
}

@Service
public class PriceCalculatorService {
    public double calculateOrderTotal(Order order, List products, List discounts) {
        return order.getItems().stream()
            .mapToDouble(item -> calculateItemPrice(item, findProduct(products, item.getProductId()), discounts))
            .sum();
    }
    
    private double calculateItemPrice(OrderItem item, Product product, List discounts) {
        if (product == null) {
            return 0;
        }
        
        double basePrice = product.getPrice() * item.getQuantity();
        double totalDiscount = discounts.stream()
            .map(DiscountStrategyFactory::createStrategy)
            .mapToDouble(strategy -> strategy.calculateDiscount(item, product))
            .sum();
        
        return Math.max(0, basePrice - totalDiscount);
    }
    
    private Product findProduct(List products, String productId) {
        return products.stream()
            .filter(p -> p.getId().equals(productId))
            .findFirst()
            .orElse(null);
    }
}

// Classes de support
public class ValidationRequest {
    private final Order order;
    private final User user;
    
    public ValidationRequest(Order order, User user) {
        this.order = order;
        this.user = user;
    }
    
    public Order getOrder() { return order; }
    public User getUser() { return user; }
}

public class ValidationResult {
    private final boolean success;
    private final List errors;
    private final String status;
    
    private ValidationResult(boolean success, List errors, String status) {
        this.success = success;
        this.errors = errors != null ? errors : List.of();
        this.status = status;
    }
    
    public static ValidationResult success() {
        return new ValidationResult(true, null, null);
    }
    
    public static ValidationResult error(String message) {
        return new ValidationResult(false, List.of(message), null);
    }
    
    public static ValidationResult error(String message, String status) {
        return new ValidationResult(false, List.of(message), status);
    }
    
    public boolean isSuccess() { return success; }
    public List getErrors() { return errors; }
    public String getStatus() { return status; }
}
