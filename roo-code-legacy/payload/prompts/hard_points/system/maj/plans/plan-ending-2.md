# Plan Ending-2 – Differences Report Analysis

> **Type** : ending | **Ordre** : 2 | **Bloquant** : NON

## 🎯 Objective

Analyze the differences report generated by ending-1 plan and prepare information for the index update (ending-3 plan).

This plan identifies modified, added, deleted files and detects `.bak` files for later cleanup.

---

## 📥 Required Inputs

- `/tmp/aikido/maj_diff.json` : Differential report (generated by ending-1 plan)
- `$SOURCE` : Current project directory

---

## 📋 Execution Steps

### 1️⃣ Phase 1 : Report Verification (NON-BLOCKING)

**Action : Verify existence and validity of the differential report**

```bash
REPORT_STATUS=$(bash prompts/hard_points/system/maj/scripts/ending-2-check-diff-report.sh)

if [ "$REPORT_STATUS" = "EMPTY" ]; then
  REPORT_EMPTY=true
else
  REPORT_EMPTY=false
fi
```

This script verifies the existence of the differential report.
- **Return** : `EMPTY` if missing, `PRESENT` if detected
- **Exit code** : 0 (always, non-blocking)

---

### 2️⃣ Phase 2 : Report Reading and Validation (NON-BLOCKING)

**Action : Read report content and verify its structure**

#### 2.1 Display the report

```bash
if [ "$REPORT_EMPTY" = false ]; then
  cat /tmp/aikido/maj_diff.json | jq '.' || cat /tmp/aikido/maj_diff.json
fi
```

#### 2.2 Validate JSON format

```bash
JSON_STATUS=$(bash prompts/hard_points/system/maj/scripts/ending-2-validate-json.sh)

if [ "$JSON_STATUS" = "VALID" ]; then
  JSON_VALID=true
else
  JSON_VALID=false
fi
```

This script validates the JSON format of the report.
- **Return** : `VALID` or `INVALID`
- **Exit code** : 0 (always, non-blocking)

---

### 3️⃣ Phase 3 : Detailed Change Analysis (NON-BLOCKING)

**Action : Extract and categorize changes**

```bash
if [ "$JSON_VALID" = true ] && [ "$REPORT_EMPTY" = false ]; then
  STATS=$(bash prompts/hard_points/system/maj/scripts/ending-2-analyze-changes.sh --list)

  TOTAL_CHANGES=$(echo "$STATS" | tail -1 | awk '{print $1}')
  ADDED=$(echo "$STATS" | tail -1 | awk '{print $2}')
  REMOVED=$(echo "$STATS" | tail -1 | awk '{print $3}')
  MODIFIED=$(echo "$STATS" | tail -1 | awk '{print $4}')
fi
```

This script analyzes and displays detailed changes.
- **Option** : `--list` to display files
- **Return** : `TOTAL_CHANGES ADDED REMOVED MODIFIED`
- **Exit code** : 0 (always)

---

### 4️⃣ Phase 4 : Backup File Detection (NON-BLOCKING)

**Action : Identify .bak files for potential cleanup**

```bash
BACKUP_FILES=$(bash prompts/hard_points/system/maj/scripts/ending-2-detect-backups.sh "$SOURCE")
```

This script detects and lists .bak files created during the update.
- **Output** : `/tmp/aikido/backup_files_list.txt` (if backups found)
- **Return** : Number of .bak files detected
- **Exit code** : 0 (always)

---

### 5️⃣ Phase 5 : Preparation for Ending-3 (NON-BLOCKING)

**Action : Create summary for ending-3 plan**

```bash
echo "═══════════════════════════════════════════════════════════════"
echo "📋 PREPARATION ENDING-3 PLAN"
```

## ✅ Success Conditions

The **ending-2** plan is considered successful in **ALL cases**:

1. ✅ Report analyzed (even if empty or invalid)
2. ✅ Statistics extracted (or marked N/A)
3. ✅ Backup files detected (or 0 found)
4. ✅ Summary created for ending-3

**Note** : This plan is **NON-BLOCKING** and always succeeds. It adapts its behavior according to data availability.

---

## ❌ Failure Handling

This plan **cannot fail** in a blocking way. All cases are handled:

### Degraded cases (warnings only) :

1. **Report missing** → Summary with N/A values
2. **Invalid JSON** → Raw content display + warning
3. **No changes** → Summary with 0 everywhere
4. **jq not installed** → Manual reading fallback

**Degraded output example** :
```
⚠️  WARNING : Analysis in degraded mode

Cause : Differential report missing or invalid
Impact : Statistics not available

Summary created with N/A values for ending-3 plan.
Workflow continues normally.
```
