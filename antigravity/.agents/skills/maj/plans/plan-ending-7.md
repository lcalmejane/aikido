# Plan Ending-7 – Gap Population Proposal

> **Type** : ending | **Order** : 7 | **Blocking** : NO

## 🎯 Objective

Analyze the Memory Bank to identify **gaps** (missing files, incomplete indexes, absent documentation) and propose automatic population via **agent-aikido-bank-populate**.

---

## 📥 Required Inputs

- `$SOURCE` : Current project directory
- `/tmp/aikido/validation-report.md` : Validation report (optional, generated by ending-6)

---

## 📋 Execution Steps

### 1️⃣ Phase 1 : Gap Analysis (NON BLOCKING)

**Action : Detect missing files/directories**

```bash
GAPS_STATS=$(bash prompts/hard_points/system/maj/scripts/ending-7-detect-gaps.sh "$SOURCE")

MISSING_DIRS_COUNT=$(echo "$GAPS_STATS" | awk '{print $1}')
MISSING_FILES_COUNT=$(echo "$GAPS_STATS" | awk '{print $2}')
```

This script detects gaps in the Memory Bank.
- **Function** : Checks minimal structure (expected directories + files)
- **Output** : `/tmp/aikido/gaps_report.txt` (detailed list)
- **Return** : `MISSING_DIRS_COUNT MISSING_FILES_COUNT`
- **Exit code** : 0 (always, non blocking)

---

### 2️⃣ Phase 2 : Population Proposal (NON BLOCKING)

**Action : If gaps detected, propose automatic population**

```bash
TOTAL_GAPS=$((MISSING_DIRS_COUNT + MISSING_FILES_COUNT))

if [ $TOTAL_GAPS -gt 0 ]; then
  bash prompts/hard_points/system/maj/scripts/ending-7-propose-populate.sh "$SOURCE"
else
  echo "✅ NO GAPS DETECTED - Memory Bank complete"
fi
```

This script proposes population via agent-aikido-bank-populate.
- **Function** : Checks agent, creates context, LLM instructions or manual recommendations
- **Context** : `/tmp/aikido/populate-context-$$.md` (if agent available)
- **Exit code** : 0 (always, non blocking)

---

### 3️⃣ Phase 3 : Logging (NON BLOCKING)

**Action : Create population log**

```bash
mkdir -p "$SOURCE/prompts/spec/logs"
LOG_FILE="$SOURCE/prompts/spec/logs/phase-7.log"

cat > "$LOG_FILE" <<LOG
═══════════════════════════════════════════════════════════════
Plan Ending-7 : Gap Population Proposal
═══════════════════════════════════════════════════════════════
Date: $(date '+%Y-%m-%d %H:%M:%S')

GAP ANALYSIS:
  Missing directories    : ${#MISSING_DIRS[@]}
  Missing files          : ${#MISSING_FILES[@]}

$([ ${#MISSING_DIRS[@]} -eq 0 ] && [ ${#MISSING_FILES[@]} -eq 0 ] && echo "STATUS: Memory Bank complete" || echo "STATUS: Gaps detected, population proposed")

AGENT:
  bank-populate          : $([ -f "$POPULATE_AGENT" ] && echo "Available" || echo "Not available")
  Context                : $([ -f "$POPULATE_CONTEXT" ] && echo "$POPULATE_CONTEXT" || echo "Not created")

═══════════════════════════════════════════════════════════════
LOG

echo "📝 Log created: $LOG_FILE"
echo ""
```
