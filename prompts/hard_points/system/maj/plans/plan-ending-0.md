# Plan Ending-0 – Intelligent Merge TARGET → SOURCE

> **Type** : ending | **Ordre** : 0 | **Bloquant** : NON (with fallback)

## 🎯 Objective

Intelligently merge modified or added files from the external repository (TARGET) into the current project (SOURCE), preserving project context while adopting the new formalism.

This plan uses **agent-aikido-fusion** for intelligent merging, with manual fallback if the LLM is insufficient.

---

## 📥 Required Inputs

- `$SOURCE` : Current project directory
- `$TARGET` : External source directory (update)
- `/tmp/aikido/maj_target.json` : TARGET structure (generated by plan-beginning)
- `/tmp/aikido/maj_before.json` : SOURCE structure before update (generated by plan-beginning)

---

## 📋 Execution Steps

### 1️⃣ Phase 1 : Change Detection (BLOCKING)

**Action : Analyze differences between TARGET and SOURCE**

#### 1.1 Verify existence of JSON files

**Action : Verify JSON structure files**

```bash
bash prompts/hard_points/system/maj/scripts/ending-0-check-json-files.sh
```

This script verifies the existence of JSON files generated by plan-beginning.
- **Files checked** : `/tmp/aikido/maj_target.json`, `/tmp/aikido/maj_before.json`
- **Exit code** : 0 if OK, 1 if missing (BLOCKING)

#### 1.2 Generate the differences report

**Action : Compare JSON structures and create report**

```bash
TOTAL_CHANGES=$(bash prompts/hard_points/system/maj/scripts/ending-0-generate-diff-report.sh)
```

This script compares TARGET vs SOURCE and generates a differential report.
- **Outputs** :
  - `/tmp/aikido/diff_report.txt` : List of modified/added files
  - `/tmp/aikido/added_files.txt` : Added files
  - `/tmp/aikido/modified_files.txt` : Modified files
- **Return** : Total number of changes
- **Exit code** : 0 (always)

#### 1.3 Validation

```bash
if [ $TOTAL_CHANGES -eq 0 ]; then
  echo "ℹ️  No changes detected, merge not necessary"
  echo "   Direct pass to ending-1 plan"
  exit 0
fi

echo "✅ $TOTAL_CHANGES file(s) to process"
```

---

### 2️⃣ Phase 2 : LLM Prerequisites Verification (NON-BLOCKING)

**Action : Verify LLM capability and choose merge mode**

```bash
FUSION_MODE=$(bash prompts/hard_points/system/maj/scripts/ending-0-ask-llm-capability.sh)
```

This script interactively asks if the user has a powerful LLM.
- **Possible modes** :
  - `INTELLIGENT` : Merge with agent-aikido-fusion (LLM ≥ Sonnet 4)
  - `REPLACE` : Direct replacement TARGET → SOURCE
  - `SKIP` : Keep local files
  - `MANUAL_LATER` : Prepare manual merge scripts
- **Return** : Selected mode
- **Exit code** : 0 (always)

---

### 3️⃣ Phase 3 : File Processing (BLOCKING IF FUSION_MODE=INTELLIGENT)

**Action : Process files according to merge mode**

```bash
bash prompts/hard_points/system/maj/scripts/ending-0-process-fusion.sh "$SOURCE" "$TARGET" "$FUSION_MODE"
```

This script processes all files from the differential report according to the chosen mode.
- **Modes handled** :
  - `INTELLIGENT` : Prepares contexts for agent-aikido-fusion
  - `REPLACE` : Direct copy with automatic backup
  - `SKIP` : Keeps local files
  - `MANUAL_LATER` : Generates merge scripts in `/tmp/aikido/manual-fusion/`
- **Outputs** :
  - `.bak` backups for modified files
  - Manual scripts if MANUAL_LATER mode
- **Exit code** : 0 (always, counts errors internally)

---

## 📤 Produced Outputs

| File/Directory | Description |
|--------------------|-------------|
| `/tmp/aikido/diff_report.txt` | List of modified/added files |
| `/tmp/aikido/added_files.txt` | Added files only |

| `*.bak.YYYYMMDD-HHMMSS` | Automatic backups of modified files |
| `/tmp/aikido/manual-fusion/*.md` | Manual merge scripts (if MANUAL_LATER mode) |
| `/tmp/aikido/fusion-context-*.md` | Merge contexts for agent (if INTELLIGENT mode) |

---

## ✅ Success Conditions

The **ending-0** plan is considered successful if:

1. ✅ Differences report generated successfully
2. ✅ All files processed according to chosen mode
3. ✅ No blocking errors (ERRORS=0 if INTELLIGENT mode)
4. ✅ Backups created for all modified files

**Note** : In SKIP or MANUAL_LATER mode, the plan is always successful (non-blocking).

---

## ❌ Failure Handling

### Critical failures (INTELLIGENT mode only) :

1. **Agent-aikido-fusion not found**
   - Verify `prompts/hard_points/agents/agent-aikido-fusion.md` exists
   - Restore from backup if necessary

2. **Merge failed**
   - Restore file from `.bak.*`
   - Switch to MANUAL_LATER mode
   - Continue with remaining files

**Failure message example** :
```
❌ ERROR : Intelligent merge failed for 3 file(s)

Files in error :
  - prompts/hard_points/commands/analyse-project.md
  - prompts/gen/concepts/memory-bank.md
  - AGENTS.md

Recommended action :
  1. Restore from backups : ls -la *.bak.*
  2. Switch to MANUAL mode : export FUSION_MODE=MANUAL_LATER
  3. Re-run ending-0 plan

Successfully merged files are preserved.
```
