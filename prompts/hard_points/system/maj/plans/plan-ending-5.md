# Plan Ending-5 – Optimization and Cleanup

> **Type** : ending | **Order** : 5 | **Blocking** : NO

## 🎯 Objective

Optimize the Memory Bank by cleaning up temporary files and proposing a review of backup files created during the update.

This plan performs a light, non-destructive cleanup, leaving the final decision on backup files to the user.

---

## 📥 Required Inputs

- `$SOURCE` : Current project directory
- `/tmp/aikido/backup_files_list.txt` : List of .bak files (generated by plan ending-2)

---

## 📋 Execution Steps

### 1️⃣ Phase 1 : Temporary Files Cleanup (NON BLOCKING)

**Action : Delete .tmp files from the project**

```bash
TMP_COUNT=$(bash prompts/hard_points/system/maj/scripts/ending-5-cleanup-tmp-files.sh "$SOURCE")
```

This script cleans up .tmp files from the project.
- **Function** : Detects and deletes all *.tmp
- **Return** : Number of deleted files
- **Exit code** : 0 (always, non blocking)

---

### 2️⃣ Phase 2 : Backup Files Review (NON BLOCKING)

**Action : Analyze .bak files and suggest actions**

```bash
BACKUP_STATS=$(bash prompts/hard_points/system/maj/scripts/ending-5-analyze-backups.sh "$SOURCE")

BACKUP_COUNT=$(echo "$BACKUP_STATS" | awk '{print $1}')
RECENT=$(echo "$BACKUP_STATS" | awk '{print $2}')
OLD=$(echo "$BACKUP_STATS" | awk '{print $3}')
```

This script analyzes backup files by age and suggests actions.
- **Function** : Detects .bak, classifies by age, cleanup recommendations
- **Return** : `BACKUP_COUNT RECENT OLD`
- **Exit code** : 0 (always, non blocking)

---

### 3️⃣ Phase 3 : /tmp/aikido Temporary Files Cleanup (NON BLOCKING)

**Action : Suggest cleanup of process temporary files**

```bash
TMP_INFO=$(bash prompts/hard_points/system/maj/scripts/ending-5-display-tmp-aikido.sh)

TMP_AIKIDO_SIZE=$(echo "$TMP_INFO" | awk '{print $1}')
TMP_AIKIDO_COUNT=$(echo "$TMP_INFO" | awk '{print $2}')
```

This script displays info on /tmp/aikido and suggests cleanup.
- **Function** : Analyzes temporary directory, lists files, recommendations
- **Return** : `SIZE COUNT`
- **Exit code** : 0 (always, non blocking)

---

### 4️⃣ Phase 4 : Final Statistics (NON BLOCKING)

**Action : Display global cleanup statistics**

echo "═══════════════════════════════════════════════════════════════"

## ✅ Success Criteria

The **ending-5** plan is considered successful in **ALL cases** :

1. ✅ .tmp files deleted (or none found)
2. ✅ Backup files analyzed and listed
3. ✅ Recommendations provided
4. ✅ Log created

**Note** : This plan is **NON BLOCKING** and always succeeds. It deletes NOTHING critical.

---

## ❌ Failure Handling

This plan **cannot fail** in a blocking way:

### Degraded cases (no impact):

1. **find fails** → Warning + skip cleanup
2. **Insufficient permissions** → Warning + manual recommendation
3. **Backup list missing** → Created on the fly

**Example of degraded behavior** :
```
⚠️  Unable to delete some .tmp files (permissions)

Files not deleted: 2
  - ./prompts/spec/cache/data.tmp (Permission denied)
  - ./logs/session.tmp (Permission denied)

Recommendation:
  Delete manually with elevated privileges if necessary.

The plan continues normally (non blocking).
```
