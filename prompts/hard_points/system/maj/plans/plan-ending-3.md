# Plan Ending-3 – General Index Update

> **Type** : ending | **Order** : 3 | **Blocking** : YES

## 🎯 Objective

Update the project's general index files (mono or multi-project) after the change analysis from the ending-2 phase.

This plan generates or updates the unified entry point `/prompts/index.md` and, in the case of a multi-project, the intermediate indexes `/prompts/{project}/index.md`.

---

## 📥 Required Inputs

- `$PROJECT_TYPE` : Detected project type ("MONO" or "MULTI")
- `$SOURCE` : Source directory of the current project
- `$TARGET` : Target directory containing the update files
- `/tmp/aikido/maj_diff.json` : Differences report (generated by ending-2)

---

## 📋 Execution Steps

### 1️⃣ Phase 1 : Project Type Detection (IF NOT DEFINED)

**Action : Use the technical script to detect mono/multi**

**Condition** : If `$PROJECT_TYPE` is not already defined (rare case, normally defined in plan-beginning)

```bash
if [ -z "$PROJECT_TYPE" ]; then
  echo "⚠️  Variable PROJECT_TYPE not defined, auto-detection..."
  DETECT_SCRIPT="prompts/hard_points/system/maj/scripts/detect-project-type.sh"

  # Execute the technical script (one of the 4 authorized)
  DETECT_OUTPUT=$("$DETECT_SCRIPT" detect)
  PROJECT_TYPE=$(echo "$DETECT_OUTPUT" | head -1)

  echo "✅ Detected type: $PROJECT_TYPE"
  export PROJECT_TYPE
fi
```

**Result** :
- ✅ `$PROJECT_TYPE` is now defined (MONO or MULTI)
- Continue to phase 2

---

### 2️⃣ Phase 2.A : MONO-PROJECT Index Generation

**Condition** : Execute **ONLY IF** `$PROJECT_TYPE = "MONO"`

**Action : Create or update `/prompts/index.md` for mono-project**

```bash
if [ "$PROJECT_TYPE" = "MONO" ]; then
  bash prompts/hard_points/system/maj/scripts/ending-3-generate-mono-index.sh "$SOURCE"
fi
```

This script generates or updates the mono-project V1.3 index.
- **Output** : `$SOURCE/prompts/index.md`
- **Functions** : Checks existence, creates/updates according to version, backup if necessary
- **Exit code** : 0 on success, 1 on failure (BLOCKING)

**Move to Phase 3 (validation)**

---

### 2️⃣ Phase 2.B : MULTI-PROJECT Index Generation

**Condition** : Execute **ONLY IF** `$PROJECT_TYPE = "MULTI"`

**Action : Create 3-level index structure for multi-project**

```bash
if [ "$PROJECT_TYPE" = "MULTI" ]; then
  bash prompts/hard_points/system/maj/scripts/ending-3-generate-multi-index.sh "$SOURCE"
fi
```

This script generates the complete multi-project index structure:
- **Global index** : `$SOURCE/prompts/index.md` (project list)
- **Project indexes** : `$SOURCE/prompts/{project}/index.md` (one per project)
- **Functions** : Detects projects, generates 3-level index, logs
- **Exit code** : 0 on success, 1 on failure (BLOCKING)

**Move to Phase 3 (validation)**

---

### 3️⃣ Phase 3 : Validation of Created Indexes

**Action : Verify that all index files exist**

```bash
bash prompts/hard_points/system/maj/scripts/ending-3-validate-indexes.sh "$SOURCE" "$PROJECT_TYPE"
```

This script validates the existence and compliance of the created indexes.
- **Function** : Checks indexes by type (MONO or MULTI)
- **MONO** : Checks `prompts/index.md`
- **MULTI** : Checks global index + all project indexes
- **Exit code** : 0 if OK, 1 if index missing (BLOCKING)

---

## 📤 Produced Outputs

### For MONO-PROJECT:
- `$SOURCE/prompts/index.md` : Unified entry point V1.3
- `$SOURCE/prompts/spec/logs/phase-3.log` : Generation log

### For MULTI-PROJECT:
- `$SOURCE/prompts/index.md` : Global index with links to all projects
- `$SOURCE/prompts/{project}/index.md` : Intermediate index for each project
- `$SOURCE/prompts/spec/logs/phase-3.log` : Generation log

---

## ✅ Success Criteria

The **ending-3** plan is considered successful if:

**For MONO-PROJECT**:
1. ✅ `$SOURCE/prompts/index.md` exists
2. ✅ The file contains version 1.3
3. ✅ The phase-3 log is created

**For MULTI-PROJECT**:
1. ✅ `$SOURCE/prompts/index.md` (global) exists
2. ✅ All `$SOURCE/prompts/{project}/index.md` exist
3. ✅ Each index contains the correct links
4. ✅ The phase-3 log is created

---

## ❌ Failure Handling

If validation fails (phase 3):

1. **Display the precise error** (which file is missing)
2. **Recommend action** :
   - Check permissions on the `prompts/` directory
   - Check that the detected projects actually exist
3. **Move to plan ending-10** (centralized error handling)
4. **DO NOT continue** to ending-4

**Example failure message** :
```
❌ CRITICAL ERROR: Plan ending-3 failed

Type: MULTI-PROJECT
Problem: Project index missing after generation

Details:
  ✅ Global index : /prompts/index.md (OK)
  ❌ Project index : /prompts/projet-backend/index.md (MISSING)
  ✅ Project index : /prompts/projet-frontend/index.md (OK)

Required action:
  1. Check that the directory exists: ls -la prompts/projet-backend/
  2. Check permissions: ls -la prompts/
  3. Restart: /maj-aikido

Moving to plan ending-10 for in-depth diagnosis...
```
