Définition de Skill : [`/prompts/hard_points/system/Skills.md`](prompts/hard_points/system/Skills.md)

- **analyse** – Ce Skill fournit les capacités d'analyse de texte, de code et de données structurées. – [`prompts/hard_points/system/analyse/SKILL.md`](prompts/hard_points/system/analyse/SKILL.md)
- **search** – Ce Skill fournit les capacités de recherche à travers la *Memory Bank* et le code source du projet. – [`prompts/hard_points/system/search/SKILL.md`](prompts/hard_points/system/search/SKILL.md)
- **structure** – Le Skill « structure » d’AI‑KIDO génère, analyse et maintient la structure de répertoires et de fichiers du projet. – [`prompts/hard_points/system/structure/SKILL.md`](prompts/hard_points/system/structure/SKILL.md)
- **web** – Le Skill Web d'AI‑KIDO gère les interactions avec le Web : téléchargement de sites, extraction de contenu pertinent, normalisation du HTML et génération de réponses structurées (texte brut ou JSON). – [`prompts/hard_points/system/web/SKILL.md`](prompts/hard_points/system/web/SKILL.md)
- **maj** – Ce Skill gère le processus complet de mise à jour du système AI‑KIDO : il détecte le contexte du projet, sélectionne le plan de mise à jour approprié, exécute les scripts de migration, met à jour les métadonnées de version et valide la réussite de l'opération. – [`prompts/hard_points/system/maj/SKILL.md`](prompts/hard_points/system/maj/SKILL.md)
