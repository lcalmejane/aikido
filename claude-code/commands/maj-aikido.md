# /aikido:maj-aikido

Check whether the current project has an AI-KIDO installation and read its `.aikido/lock.json` first. For this update command, always use the bundled command at `${CLAUDE_PLUGIN_ROOT}/payload/prompts/hard_points/commands/maj-aikido.md` so it can update projects that contain older AI-KIDO instructions.

Follow that command's instructions exactly. A plugin install does not initialize or update the project by itself.
