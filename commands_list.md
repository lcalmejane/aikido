# Liste des commandes AI‑KIDO

- **analyse-aikido** : Audit complet des tables de vérités AI‑KIDO pour détecter dérivations, incohérences et liens cassés ([`analyse-aikido.md`](prompts/hard_points/commands/analyse-aikido.md:2))
- **analyse-project** : Analyser les sources projet existantes pour alimenter et mettre à jour les tables de vérités AI‑KIDO ([`analyse-project.md`](prompts/hard_points/commands/analyse-project.md:2))
- **check-claude** : Analyse et met à jour le fichier CLAUDE.md en fonction de la Memory Bank AI‑KIDO et des concepts CLAUDE.md ([`check-claude.md`](prompts/hard_points/commands/check-claude.md:2))
- **check-truth** : Vérifie la cohérence entre documentation AI‑KIDO et code source, détecte l'obsolescence et propose des redressements automatiques ([`check-truth.md`](prompts/hard_points/commands/check-truth.md:2))
- **clean-index** : Nettoie les entrées orphelines de l'index de structure AI‑KIDO ([`clean-index.md`](prompts/hard_points/commands/clean-index.md:2))
- **compile-agent-from-use** : Compilation interactive d'agents AI‑KIDO spécialisés avec questionnaire utilisateur ([`compile-agent-from-use.md`](prompts/hard_points/commands/compile-agent-from-use.md:2))
- **create-analyse-plan** : Guide interactif pour créer un plan d'analyse AI‑KIDO ([`create-analyse-plan.md`](prompts/hard_points/commands/create-analyse-plan.md:2))
- **create-command** : Guide interactif pour créer des commandes AI‑KIDO ([`create-command.md`](prompts/hard_points/commands/create-command.md:2))
- **create-persona** : Créer un nouveau persona ou agent AI‑KIDO interactivement (anthropomorphique ou technique) ([`create-persona.md`](prompts/hard_points/commands/create-persona.md:2))
- **create-skill** : Guide interactif pour créer un squelette de Skill AI‑KIDO complet ([`create-skill.md`](prompts/hard_points/commands/create-skill.md:2))
- **create-search-plan** : Guide interactif pour créer un plan de recherche AI‑KIDO ([`create-search-plan.md`](prompts/hard_points/commands/create-search-plan.md:2))
- **download-site** : Télécharge un site web et convertit son contenu en Markdown ([`download-site.md`](prompts/hard_points/system/web/commands/download-site.md:2))
- **init-aikido** : Initialiser la memory bank AI‑KIDO avec les éléments fondamentaux du projet ([`init-aikido.md`](prompts/hard_points/commands/init-aikido.md:2))
- **init-glossaire** : Créer un glossaire métier ventilé par domaines/personas experts dans la Memory Bank AI‑KIDO, optimisé pour la recherche sémantique ([`init-glossaire.md`](prompts/hard_points/commands/init-glossaire.md:2))
- **init-raci-aikido** : Initialiser la matrice RACI et les spécifications d'équipe AI‑KIDO pour définir la hiérarchie des sous‑répertoires par rôles ([`init-raci-aikido.md`](prompts/hard_points/commands/init-raci-aikido.md:2))
- **list-command** : Affiche la liste des commandes AI‑KIDO disponibles depuis `commands_list.md` ([`list-command.md`](prompts/hard_points/commands/list-command.md:2))
- **maj-aikido** : Mise à jour et synchronisation complète AI‑KIDO : sources externes (git/archive/local) + migration + optimisation ([`maj-aikido.md`](prompts/hard_points/commands/maj-aikido.md:2))
- **optimize-command-with-aikido-agents** : Analyse et optimise les commandes AI‑KIDO avec les agents techniques disponibles ([`optimize-command-with-aikido-agents.md`](prompts/hard_points/commands/optimize-command-with-aikido-agents.md:2))
- **reindex-projet** : Re‑indexe le projet pour mettre à jour la structure interne de la Memory Bank ([`reindex-projet.md`](prompts/hard_points/commands/reindex-projet.md:2))
- **skill-manage** : Gère le cycle de vie complet des skills AI‑KIDO : recherche (`search`), installation (`get`), mise à jour (`update`) et désinstallation (`uninstall`) depuis un groupe Git distant ([`skill-manage.md`](prompts/hard_points/commands/skill-manage.md:2))
- **validate-analyse-plan** : Valide la conformité d'un plan d'analyse AI‑KIDO ([`validate-analyse-plan.md`](prompts/hard_points/commands/validate-analyse-plan.md:2))
- **validate-search-plan** : Valide la conformité d’un plan de recherche AI‑KIDO ([`validate-search-plan.md`](prompts/hard_points/commands/validate-search-plan.md:2))
