# Plan Ending-1 – Post-Rebase Change Detection

> **Type** : ending | **Ordre** : 1 | **Bloquant** : NON

## 🎯 Objective

Generate the project structure **after update** and create a differences report by comparing with the structure **before update**.

This plan detects all changes (new files, modifications, deletions) resulting from the Git rebase or file merge.

---

## 📥 Required Inputs

- `$SOURCE` : Current project directory
- `/tmp/aikido/maj_before.json` : Structure before update (generated by plan-beginning)

---

## 📋 Execution Steps

### 1️⃣ Phase 1 : Prerequisites Verification (NON-BLOCKING)

**Action : Verify existence of "before" JSON file**

```bash
SKIP_STATUS=$(bash prompts/hard_points/system/maj/scripts/ending-1-check-before-json.sh)

if [ "$SKIP_STATUS" = "SKIP_DIFF" ]; then
  SKIP_DIFF=true
else
  SKIP_DIFF=false
fi
```

This script verifies if the "before" structure file exists.
- **Return** : `SKIP_DIFF` if missing, `NO_SKIP` if present
- **Exit code** : 0 (always, non-blocking)

---

### 2️⃣ Phase 2 : AFTER Structure Generation (BLOCKING)

**Action : Generate the project structure after update**

```bash
bash prompts/hard_points/system/maj/scripts/ending-1-generate-after-structure.sh "$SOURCE"
```

This script generates the JSON structure of the project after update.
- **Output** : `/tmp/aikido/maj_after.json`
- **Exit code** : 0 on success, 1 on failure (BLOCKING)

---

### 3️⃣ Phase 3 : Differences Report Generation (NON-BLOCKING)

**Action : Compare before/after structures and create a report**

#### 3.1 Case 1 : "before" file missing

```bash
if [ "$SKIP_DIFF" = true ]; then
  echo "⚠️  Differential report skipped ('before' file missing)"
  echo "# Empty differential report (before missing)" > /tmp/aikido/maj_diff.json
  exit 0
fi
```

#### 3.2 Case 2 : Comparison with jq

```bash
bash prompts/hard_points/system/maj/scripts/ending-1-compare-structures.sh
```

This script compares JSON structures with jq.
- **Output** : `/tmp/aikido/maj_diff.json`
- **Exit code** : 0 on success, 1 on failure (non-blocking)

#### 3.3 Report statistics

```bash
STATS=$(bash prompts/hard_points/system/maj/scripts/ending-1-display-statistics.sh)

CHANGES_COUNT=$(echo "$STATS" | awk '{print $1}')
ADDED=$(echo "$STATS" | awk '{print $2}')
REMOVED=$(echo "$STATS" | awk '{print $3}')
MODIFIED=$(echo "$STATS" | awk '{print $4}')
```

This script displays the differential report statistics.
- **Return** : `CHANGES_COUNT ADDED REMOVED MODIFIED`

---

### 4️⃣ Phase 4 : Logging (NON-BLOCKING)

**Action : Create phase log**

```bash
mkdir -p "$SOURCE/prompts/spec/logs"
LOG_FILE="$SOURCE/prompts/spec/logs/phase-1.log"

cat > "$LOG_FILE" <<LOG
═══════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════

echo "📝 Log created : $LOG_FILE"
```

## ✅ Success Conditions

The **ending-1** plan is considered successful if:

**Complete success** :
1. ✅ AFTER structure generated (`maj_after.json` exists)
2. ✅ Differential report generated (`maj_diff.json` exists)
3. ✅ No errors during generation

**Partial success** (acceptable):
1. ✅ AFTER structure generated
2. ⚠️ Differential report missing (before absent or jq failed)
3. ✅ Log created with "Partial" indication

**Note** : This plan is **NON-BLOCKING** - even in case of partial failure, the workflow continues.

---

## ❌ Failure Handling

### Critical failures (very rare) :

1. **Generation script not found**
   ```
   ❌ ERROR : prompts/hard_points/system/structure/scripts/generate-all-indexes-v3.1.sh missing

   Required action :
     1. Verify AI-KIDO project structure
     2. Restore from backup if necessary
     3. Relaunch /maj-aikido
   ```

2. **index.json not generated**
   ```
   ❌ ERROR : index.json not created after script execution

   Possible causes :
     - Insufficient permissions
     - Error in generation script
     - Corrupted project

   Required action :
     1. Execute manually : bash prompts/hard_points/system/structure/scripts/generate-all-indexes-v3.1.sh
     2. Verify displayed errors
     3. Fix and relaunch
   ```

### Non-blocking failures (warnings) :

1. **before missing** → Warning + pass to ending-2
2. **jq fails** → Warning + manual comparison suggested
