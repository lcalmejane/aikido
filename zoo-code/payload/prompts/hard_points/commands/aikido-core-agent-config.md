# /aikido-core-agent-config

Use `aikido task config core-agent show`, `aikido task config core-agent set --url <url> --project <id> --token-env <VARIABLE>` or `aikido task config core-agent clear`. Never put a token on the command line or in the conversation. The address is stored in the ignored part of the knowledge base and the token in the private user directory.
